자유 이해: 클라이맥스에서 주인공은 승리를 독점하지 않는다. 자신만이 사용할 수 있는 마지막 자원을 적의 목숨을 끊는 데 쓰는 대신, 다른 인물들이 자기 비원을 실행할 수 없게 막던 구속을 제거하는 데 쓴다. 이후 적을 붙잡아 실행 조건만 확보하고 최종 처형은 제자들에게 맡긴다. 주인공의 기여는 줄지 않지만 타인의 서사적 행위권도 보존된다.
조합 가설: 주인공이 클라이맥스에서 타인의 문제를 대신 해결하지 않으면서도 결정적으로 기여하려면 결정적 자원 확보 → 직접 승리와 조건 복원 사이의 선택 → 타인의 행위권을 막는 구속 제거 → 실행 가능한 시간·공간 확보 → 최종 선택과 행동을 당사자에게 반환의 사슬을 만든다.
현재 질문: 이 작품의 다른 회차에서도 주인공이 최종 해결을 독점하지 않고 타인의 실행 조건을 복원하는 방식이 반복되는가? 직접 승리보다 권한 반환을 선택했을 때 주인공과 타인에게 남는 후속 비용은 무엇인가?
확인 범위: 서은현이 최후의 강기를 막리황신 처단에 집중하지 않고 제자들의 상단전에 새겨진 원혼 구속을 해제하는 데 분산 사용한 뒤, 적을 붙잡아 제자들이 직접 처형하게 하는 장면

## 장면 문제

주인공이 적을 직접 끝낼 수 있는 마지막 자원을 가진 상황에서, 제자들의 복수와 성장 봉쇄를 대신 해결하지 않으면서도 결정적으로 기여해야 한다.

## 작동 사슬

결정적 자원 확보 → 적 직접 처단 가능 → 제자들의 행위권을 막는 원혼 구속 확인 → 자원을 구속 해제에 분산 → 적을 붙잡아 실행 조건 확보 → 최종 처형권을 제자들에게 반환 → 제자들이 자기 비원을 직접 완수

## 상태 변화

- 주인공이 승리를 독점하는 구조 → 주인공이 조건을 만들고 당사자가 실행하는 구조
- 보호 대상 → 자기 비원을 직접 완수하는 행위자
- 강제 통제 → 생존 조건과 실행권의 동시 반환

## 표현 구현

- 결심을 장문 독백으로 먼저 설명하지 않고 강기가 적이 아니라 제자들의 상단전으로 갈라지는 행동으로 보여 준다.
- 구속이 깨진 뒤에도 주인공은 전장을 이탈하지 않고 적을 붙잡는 신체 비용을 부담한다.
- 마지막 의미는 제자의 직접 처형으로 확정한다. 단순히 ‘너희가 해라’고 말하는 것만으로 끝내지 않는다.

## 완료 조건

당사자가 이미 독립 욕망·능력·비용을 축적했고, 주인공의 마지막 선택이 실제로 당사자의 선택 가능 범위를 넓히며, 최종 행동과 결과 귀속이 당사자에게 남아야 한다.
