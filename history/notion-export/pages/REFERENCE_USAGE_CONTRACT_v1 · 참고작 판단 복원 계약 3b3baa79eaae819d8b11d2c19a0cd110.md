# REFERENCE_USAGE_CONTRACT_v1 · 참고작 판단 복원 계약

<aside>
🛡️

**역할: 공통 안전 절차**

이 계약은 작품별 정사·문체·캐릭터·전개를 통일하지 않는다. 참고작을 읽고 현재 작품으로 돌아오는 절차와 침범 금지선만 규정한다.

</aside>

- `CONTRACT_ID`: REFERENCE_USAGE_CONTRACT_v1
- `STATUS`: ACTIVE
- `SCOPE`: 참고작 원문 장면, Macro, Micro, TH, 공용 카드의 집필 활용 절차
- `NOT_AUTHORITY_FOR`: 작품 정사, 인물 성격, 말투, 문체, 사건 순서, 화말, 상태 변화, 대사·행동 배열

## 권위 순서

1. 사용자의 현재 명시 지시와 승인
2. 최신 확정 한국판 원고
3. 작품별 ACTIVE-RULES
4. 작품별 연속성 위키와 CURRENT-PACKET
5. 작품별 승인 문체 프로필
6. 해당 작품의 원문 사건·인과·선택자·정보 공개 순서
7. 이 공통 계약과 공용 참고작 라이브러리

충돌 시 상위 자료를 따른다. 공통 계약은 작품별 ACTIVE-RULES를 자동 수정하거나 대체하지 않는다.

## 적용 상태

각 프로젝트 또는 회차는 다음 중 하나를 명시한다.

- `ADOPTED`: 계약을 그대로 사용
- `ADOPTED_WITH_EXCEPTIONS`: 작품별 예외와 함께 사용
- `NOT_APPLICABLE`: 참고작을 사용하지 않음

계약 버전이 바뀌어도 기존 프로젝트의 적용 상태는 자동 변경하지 않는다.

## 사용 절차

1. 현재 작품의 원문·확정 정사·현재 장면 조건·인물 욕망·관계·권한·정보 상태를 먼저 잠근다.
2. 현재 문제를 소재가 아니라 상황과 전환 문제로 정의한다.
3. Macro와 TH는 관련 원천 장면을 찾는 후방 색인으로만 사용한다.
4. 정리문만 읽지 않고 연결된 실제 원천 장면을 다시 읽는다.
5. 가능하면 같은 참고작 안에서 대표 사례와 대비·이탈·실패·오해·미해결 사례를 함께 읽는다.
6. 장면 표현, 스토리 표현, 캐릭터 판단을 서로 분리해 관찰한다.
7. 참고작을 닫고 현재 작품의 원문·정사·관계·감정 잔여를 다시 읽는다.
8. 현재 작품 인물의 판단과 압력에서 새로운 표현 배열을 작성한다.
9. 완성 후 문장·비유·호칭·고유 물건·대사 순서·관계 외형의 표면 모방을 감사한다.
10. 안전한 장면 묶음이 없거나 현재 문제와 맞지 않으면 `NO_OP`으로 처리한다.

## 특색 보존 금지선

공통 계약과 공용 라이브러리는 다음을 정하지 않는다.

- 어떤 인물이 무엇을 말하거나 침묵해야 하는지
- 대사와 반응의 고정 순서
- 관계 변화가 취해야 할 특정 형태
- 장면마다 반드시 발생해야 할 상태 변화
- 화말의 형식
- 작품별 어미·호칭·문장 길이·서술 속도
- 원작 사건과 정보 공개 시점의 변경
- 특정 Macro·Micro·TH의 의무 적용

## 자료별 역할

- `원천 장면`: 작가의 실제 표현과 전후 맥락을 다시 읽기 위한 재진입 장치
- `Macro`: 유사한 서사 상황에서 원천 장면을 찾는 검색 단위
- `Micro`: Macro만으로 사라지는 결정적인 표현 선택을 확인하는 예외적 보조 자료
- `TH`: 작품 내부에서 반복·변형·실패·반례가 축적된 연구 가설

Macro·Micro·TH의 문구를 집필 명령으로 변환하지 않는다. Micro의 문장을 이식하거나 Macro의 배열을 완료 조건으로 사용하지 않는다.

## 비기계화 검사

다음이 발생하면 참고작 적용을 중단하고 자연 초고와 비교한다.

- 인물들이 카드의 기능을 수행하듯 정확하게 반응함
- 모든 대사가 다음 행동이나 상태 변화를 만들어 냄
- 대표 장면 하나가 모범 답안처럼 반복됨
- 작품별 말투와 관계 이력보다 참고작의 외형이 앞섬
- 현재 작품의 오해·망설임·헛된 대화·미해결 감정이 제거됨

## 작품별 특색 보존

각 프로젝트는 별도의 정사, 문체 프로필, 인물 변화 근거, 정보 공개 순서, 서술 시점, 분량, 장면 경계를 유지한다. 이 계약은 그 차이를 줄이지 않고 참고작이 그 차이를 침범하지 못하게 한다.

## 사용 영수증

참고작을 실제 사용한 경우 최소한 다음을 기록한다.

- 현재 작품의 문제 정의
- 검색한 상황 또는 전환 조건
- 다시 읽은 원천 장면
- 참고하지 않기로 버린 선택
- 현재 작품에 맞게 새로 판단한 내용
- 표면 모방 감사 결과
- 적용 결과: 도움 / 부분 도움 / 효과 불명 / 기계화·모방 발생 / NO_OP

## 변경 경계

이 계약의 개정은 공용 활용 절차만 바꾼다. 프로젝트별 정사·ACTIVE-RULES·문체 프로필·원고·CURRENT-STATE를 자동 변경하지 않는다. 각 프로젝트의 명시적 채택 기록이 있어야 새 버전이 적용된다.

## 작품별 누적 패치 보존 규칙

- 작품별 ACTIVE-RULES에 축적된 사용자 피드백, 인물별 말투, 관계 원리, 정사 변경 경계, 장면 허용 범위, 실패 교정, 회차별 감사 결과는 해당 작품의 고유 자산이다.
- 내용이 유사해 보인다는 이유만으로 기존 패치 전체를 공통 계약의 중복으로 판정하거나 `LEGACY_REFERENCE`로 강등하지 않는다.
- 공통 계약으로 위임할 수 있는 것은 의미와 적용 범위가 완전히 같은 참고작 조회·재독·표면 모방 방지 절차뿐이다.
- 하나의 패치에 공통 절차와 작품 고유 판단이 섞여 있으면 패치 전체를 폐기하지 않고 둘을 분리한다.
- 다음 항목은 공통 계약과 표현이 일부 겹쳐도 작품별 ACTIVE-RULES에 유지한다.
    - 특정 인물·관계·조직에 대한 판단
    - 사용자 피드백에서 발생한 말맛·문체·허용 범위
    - 해당 작품의 원문 보존 및 각색 변경 경계
    - 작품 내부에서 확인된 실패·퇴행·예외와 교정 규칙
    - 회차 범위, 적용 인물, 특정 장면 조건이 붙은 규칙
    - 프로젝트 전용 검사와 영수증 의무
- 기존 작품 패치를 공통 계약으로 치환하려면 `완전 중복`, `부분 중복`, `작품 고유`를 먼저 구분해 기록한다.
- `부분 중복`인 경우 공통 절차만 계약에 위임하고 작품 고유 조항은 원래 RULE_ID와 발생 근거를 유지한다.
- 사용자가 작업하며 축적한 기존 패치는 명시적 검토 없이 삭제·강등·요약 대체하지 않는다.
