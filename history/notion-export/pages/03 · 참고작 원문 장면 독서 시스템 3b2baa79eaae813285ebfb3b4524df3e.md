# 03 · 참고작 원문 장면 독서 시스템

<aside>
📖

이 층은 **성공한 참고작의 실제 표현을 필요한 순간에 가볍게 다시 읽기 위한 집필 보조층**입니다. 기법 문장·실행 공식·TH 결론을 집필 입력으로 전달하지 않습니다.

</aside>

## 전역 후보 검색 경계

- 현재 정본 계약은 [REFERENCE_USAGE_CONTRACT_v2 · 전역 후보 검색·판단 복원 계약](REFERENCE_USAGE_CONTRACT_v2%20%C2%B7%20%EC%A0%84%EC%97%AD%20%ED%9B%84%EB%B3%B4%20%EA%B2%80%EC%83%89%C2%B7%ED%8C%90%EB%8B%A8%20%EB%B3%B5%EC%9B%90%20%EA%B3%84%EC%95%BD%203b3baa79eaae81059735de7d513e6deb.md)입니다.
- 전체 검색 가능 REF에는 후보가 될 기회만 주고, 매번 모든 TH·Macro·원문을 펼치지 않습니다.
- 전역 검색은 색인 메타와 짧은 연구 좌표로 상위 후보 최대 3개만 반환합니다.
- `SOURCE_READY`만 초고 전 실제 원문 독서가 허용됩니다.
- `RESEARCH_READY`는 후보 판단·원천 복구·초고 후 질문형 진단에만 사용하고, `INDEX_ONLY`는 연구 대기열 좌표로만 사용합니다.
- 최적 후보가 미준비라는 이유로 준비된 다른 REF를 자동 대체하지 않습니다.
- 실제 원문 독서 묶음은 선택된 하나의 SOURCE_READY REF 안에서 2~4개 장면으로 구성합니다.

## 기본 구조

1. **원천 보관층**은 참고작 전체 원문과 정확한 화수·위치를 보존합니다.
2. **원문 장면 색인**은 짧은 사실 좌표와 연결 장면만 저장합니다.
3. **임시 독서 묶음**은 현재 장면에 필요한 원문 범위 2~4개만 펼칩니다.
4. 카드와 TH는 어떤 장면을 찾을지 결정하는 연구자용 뒤편 색인으로만 사용합니다.

## 집필 전 허용·금지

- 허용: 같은 참고작 안의 핵심 장면, 대비 장면, 이탈·실패·오해 장면, 필요한 선행·후속 원문
- 금지: `이 장면에서는 이렇게 써라` 형식의 정리문, 반응 사슬, 완료 조건, 인물별 발화 공식

## 경량 원칙

- 원문은 원천층에 한 번만 보존하고 장면 색인에는 위치·인물·조건·연결 장면만 둡니다.
- 한 번의 독서 묶음은 원칙적으로 2~4개 장면 범위로 제한합니다.
- 한 장면만 모범 답안처럼 제시하지 않습니다. 같은 작품 안의 다른 처리나 실패·오해·이탈 중 하나를 함께 둡니다.
- 집필이 끝나면 독서 묶음을 다음 회차 패킷으로 자동 승계하지 않습니다.

## 사용 순서

1. 현재 작품의 사건·정사·관계·정보 공개 순서를 먼저 잠급니다.
2. 원하는 효과가 아니라 현재 장면의 실제 조건으로 장면 색인을 검색합니다.
3. 선택된 원문 범위만 읽고 연구자의 결론문은 읽지 않습니다.
4. 현재 작품 자료를 다시 읽은 뒤 현재 인물과 원문에서 초고를 작성합니다.
5. 완성 후 문장·비유·호칭·대사 배열·관계 외형의 표면 모방을 검사합니다.

## 장면 메모 경계

허용되는 메모는 `직접 출입이 처음 허용됨`, `핵심 정보는 여전히 비공개`, `상대 해석 미확정`, `후속 부담은 7화 뒤 발생` 같은 **관찰 좌표**입니다.

`관계 변화는 권리 이동으로 써라`, `반문 뒤 침묵을 넣어라`, `이 장면에서 상태를 바꿔라` 같은 문장은 저장하지 않습니다.

## 연구 격리

장면 묶음은 먼저 한 참고작 안에서 구성합니다. 작품별 연구가 충분히 축적되기 전에는 서로 다른 참고작 장면을 섞어 공통 정답처럼 제시하지 않습니다.
