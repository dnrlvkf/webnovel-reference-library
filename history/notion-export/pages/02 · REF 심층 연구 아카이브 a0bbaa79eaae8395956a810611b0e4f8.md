## 개편된 연구 흐름

`익명 원천 → 심층 증거 스레드 → 공용 카드 승격 후보 → 공용 실행 카드`

- 작품 전체의 인과·인물별 인식·감정·행동·재반응·상태 변화·반례는 **02-B · REF 심층 증거 스레드**에 보존합니다.
- 실행 가능한 독립 단위만 **02-C · 공용 카드 승격 후보**에서 심사합니다.
- 승인된 카드만 **01 · 공용 실행 카드 · 개편본**으로 올립니다.
- 스레드 간 결합은 엔진으로 강제하지 않고 `조합 가설`과 관련 카드 정보로 보존합니다.
- 검색 영수증과 범위 감사는 평상시 스킬 조회에서 제외합니다.

## 운영 상태

- 기존 공용 기법 카드는 삭제하거나 일괄 배제하지 않습니다. 새 원문 증거와 대조해 `현행 유지 · 개정 필요 · 신규 승격 후보 · 근거 전용 · 폐기 검토` 중 하나로 갱신합니다.
- 25개 작품 전체를 미리 수동 분석하지 않습니다. 로컬 전체 원문 색인에서 현재 장면의 문제를 먼저 검색합니다.
- 검색 결과는 작품을 자유 서술로 이해한 뒤에만 캐릭터·관계·사건·표현으로 풀어냅니다.
- 검증된 증거 스레드와 최소 메커니즘 카드는 반드시 기존 상위 정규화 카드와 대조합니다. 일치하면 근거를 보강하고, 범위가 다르면 수정·분할·신규 승격·폐기를 판정합니다.
- 한 회차에는 갱신 상태와 적용 조건이 확인된 카드 최대 2개만 조건부 적용합니다. 적합한 근거가 없으면 `NO_OP`, 더 읽어야 하면 `RESEARCH_REQUIRED`로 남깁니다.

## 한 증거 흐름에서 함께 읽을 것

1. 인물이 지금 원하는 것, 알고 있는 것, 숨기는 것, 말과 행동으로 택한 전술
2. 상대가 그 전술을 어떻게 해석하고 무엇을 실제로 바꾸는지
3. 두 사람 사이 권력·신뢰·부채·두려움·오해가 장면 전후로 어떻게 이동하는지
4. 사건이 어떤 원인과 선택에서 발생하고 뒤 회차에서 무엇을 강제하는지
5. 작품이 그것을 대사 길이, 침묵, 시점 제한, 동작, 감각, 정보 순서, 문단 호흡으로 어떻게 체험시키는지
6. 멀리 떨어진 재등장과 반례에서도 같은 설명이 버티는지

## 연구 순서

`현재 장면의 자유 질문 → 원문 후보 검색 → 앞뒤 문맥 확인 → 먼 재등장 확인 → 반례 확인 → 작품 자유 이해 → 증거 스레드 → 최소 메커니즘 카드 → CHAT 적용 영수증`

- 기존 카드 갱신 규칙
    
    기존 카드의 장르·기능·작동 시기·범용성은 확정 사실이 아니라 재검증할 가설로 사용합니다. 새 원문 증거 스레드와 반례를 대조해 확인된 항목만 유지하며, 공란은 부정이나 무제한 허용으로 추정하지 않습니다.
    
    갱신 순서는 `증거 스레드 → 최소 메커니즘 카드 → 기존 상위 카드 대조 → 유지·보강·축소·분할·병합·신규 승격·폐기 판정 → 상위 카드 근거 연결 → 감사 규칙·선택 엔진 반영`입니다.
