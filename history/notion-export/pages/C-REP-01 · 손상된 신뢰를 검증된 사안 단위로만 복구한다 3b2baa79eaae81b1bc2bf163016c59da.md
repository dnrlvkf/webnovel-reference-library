# C-REP-01 · 손상된 신뢰를 검증된 사안 단위로만 복구한다

갱신 상태: 현행 유지
검증 메모: 단일 REF 근거이지만 사용자의 명시 승인으로 활성화한다. 자동 적용은 평판 손상과 검증 가능한 단일 사안이 동시에 존재할 때 선택 엔진이 조회하는 의미이며, 전면 복권을 금지한다.
검증 판정: 운영 규칙 확정
근거 단계: S1 · 단일 REF
근거 범위: REF-45의 과거 연구 비위 평판, 적대적 질문 준비, 독립 심사, 공개 풀이·반론·시연, 과오 인정과 후반 재비난.
금지 조건: 한 번의 압도적 성취로 과거를 세탁하지 않는다. 칭찬 인원수를 증거로 세지 않는다. 모든 관찰자가 같은 범위로 신뢰를 회복하게 하지 않는다.
기능 대분류: 캐릭터 구현
누적 방식: 단계 발전형
독자 효과: 압도적 성취로 과거가 세탁되는 불신을 피하면서, 현재 성과를 납득하고 인물의 책임 문제를 계속 긴장으로 보존한다.

실행 완료 조건: 현재 주장이나 성과가 독립된 증거로 검증된다. 적어도 한 관찰자가 검증된 사안에 한해 행동권·접근권·발언권을 갱신한다. 과거 비위와 도덕 책임은 별도 판정으로 남는다.
심층 적용 메모: 칭찬보다 질문·반론·시험을 먼저 둔다. 설명·기록·시연처럼 서로 다른 증거를 사용하되, 장면 길이에 맞춰 둘 이상만 선택해도 된다.
심층 증거 스레드: TH-REF45-08 · 과거 비위가 있는 전문가가 반대자의 질문·공개 증명·책임 인정으로 제한적 신뢰를 재건하는 장기 구성 (https://app.notion.com/p/TH-REF45-08-3b2baa79eaae810c8aeceaa7fb7d4bb7?pvs=21)

적용 조건: 과거 비위·실패·기만 때문에 유능한 인물의 현재 성과를 자기 선언이나 주변 칭찬만으로 믿게 할 수 없는 장면.
