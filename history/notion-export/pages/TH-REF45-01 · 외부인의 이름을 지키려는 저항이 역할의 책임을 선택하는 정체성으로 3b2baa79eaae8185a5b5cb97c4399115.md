# TH-REF45-01 · 외부인의 이름을 지키려는 저항이 역할의 책임을 선택하는 정체성으로 변하는 장기 구성

REF 코드: REF-45
경계 상태: exact
먼 재등장: 초반의 '김우진' 자기호명은 349~350화에서 옛 지인이 같은 이름을 부르는 시험으로 재등장한다. 초반에는 자아 보존 장치였으나 결말에는 반응 여부를 판정하는 관계 장치가 된다.
미확인 범위: 중간부 전 회차의 순차적 심리 전환점, 시스템 성격 전염의 정확한 한계.
반례: 결말의 옛 이름 무반응만으로 원래 자아가 완전히 소멸했다고 확정할 수 없다. 옛 관계의 감정과 기억은 현재 역할의 언어로 남아 있으며, 작품은 양자택일보다 통합을 지지한다.
비정사: Yes
사용자 확인 필요: No
상태: VERIFIED_THREAD
원문 위치: 프롤로그~초반 620~790행 / 349~350화 184,720~185,651행
유사성 판정: 작품 고유
인물·관계·사건·표현: 초반: 거울·독백·원래 이름의 반복으로 내면 경계를 명시한 직후, 걸음걸이·말투·의무 수행에서는 역할 성격이 즉시 작동한다. 결말: 옛 지인이 옛 이름을 시험하지만 외면 반응은 없고, 둘만 남긴 뒤 현재 역할의 이름과 감정으로 과거 관계를 고백한다. 장면 표현은 이름 시험→침묵→업무 전환→역할적 악역 발화→격리→사적 고백 순서다.
자유 이해: 초반 주인공은 원래 이름을 거울 앞에서 반복하며 인물 성격에 삼켜지지 않겠다고 선언한다. 그러나 실제 행동은 생존을 위해 맡은 역할의 의무·지식·권한을 수행하는 방향으로 누적된다. 결말부에는 옛 이름에 즉각 반응하지 않고, 현재 역할의 어법과 책임으로 대륙의 멸망·구원 계획을 수행하면서도 옛 관계의 감정은 현재 인물의 고백으로 표현한다. 정체성의 해결은 원래 자아로 복귀하거나 역할에 완전히 소멸하는 이분법이 아니라, 역할이 만든 선택과 책임을 자기 것으로 떠안는 통합에 가깝다.
조합 가설: 이 작품 내부에서는 정체성 갈등을 독백으로 해결하지 않고, 맡은 역할의 권리·의무·관계가 누적된 뒤 옛 이름에 대한 반응과 현재 역할의 선택을 병치해 판정한다.
현재 질문: 중간부 어느 시점부터 원래 이름의 자기호명이 사라지고 역할의 판단 기준이 우세해지는가. 이 변화가 명시적 사건인지 누적적 소거인지 추가 구간 검증이 필요하다.
확인 범위: 프롤로그, 초반 전제·이름 장면, 349~350화 결말 장면을 직접 확인. 중간부는 전 작품 왕복 검색으로 역할 수행·관계 축적을 표본 확인했으나 순차 완독과 동일하지 않음.

## 해결하는 문제

빙의 인물의 정체성 갈등을 반복 독백이나 원래 세계 복귀 욕망만으로 끌지 않고, 장기 행동과 관계 책임으로 판정하는 방법.

## 작동 사슬

외부인 자아 보존 선언 → 역할 성격·의무의 행동 침투 → 생존을 위한 역할 수행 → 수행이 관계·권한·책임을 생성 → 옛 이름으로 정체성 시험 → 현재 역할의 선택과 고백으로 응답 → 정체성 통합을 독자가 판정

## 표현 구현

초반에는 거울과 자기호명으로 경계를 직접 말한다. 결말에는 같은 이름을 다른 인물이 불러 반응을 관찰하게 하고, 설명 대신 침묵과 업무 전환을 먼저 배치한다. 이후 공개 악역 발화와 사적 고백을 분리하여 현재 역할과 남은 감정이 동시에 존재함을 보여준다.

## 독자 경험

자아 상실 공포 → 역할 적응의 불편 → 책임 축적에 대한 신뢰 → 옛 이름 시험의 기대 → 무반응으로 인한 상실 → 현재 인물의 고백으로 재해석.
