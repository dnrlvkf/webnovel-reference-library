# 첫 회차 기억을 연구·투자 조건·환급 증거로 환전해 복수 집단 공략대를 만드는 장면

REF 코드: REF-46
감정 증거: 공략자는 위험을 혼자 감당했다는 이유로 정보를 무료로 풀지 않지만, 외부 집단이 손익을 계산할 수 있는 증거와 참여 조건은 제공한다.
대사·행동 배열: 민간 조사 실패·단서 → 공략 기억 제공 → 재조사 → 재입장 선언 → 정보 보증금 → 위험 브리핑 → 투자 위축 → 소모 자원 환급 증거 → 희귀 병기 약속 → 파편 유물 대조 → 적·약점·조건 가설 → 연구자 편입 → 복수 집단 인선·물자 장부 → 즉시 진입
대표성: 대표
마지막 검토: 2026년 8월 5일
상태: 준비
상태 변화: 개인이 독점한 1회차 기억 → 연구 가능한 단서·유료 정보 → 복수 집단의 인력·희귀 자원·전략으로 확대
상황군: 권한·위계, 정보·비밀, 조직·제도, 협상·거래
식별자 비노출: Yes
역할 표기: 공략자, 연구자 A, 복수 집단 대표들, 공략대

장면 조건: 공략자의 기억은 남았지만 외부 집단은 위험·수익·조건을 검증해야 희귀 자원을 투자할 수 있음
장면 종료 방식: 검증되지 않은 가설과 환급 증거를 함께 장부화한 뒤 네 집단의 실제 인선·물자로 전환함
정리문 제외: Yes
정보 공개 순서: 민간 실패 → 기억 제공 → 참여 조건 → 위험 → 환급 규칙 → 투자 약속 → 문헌 가설 → 공략대 편성
진입 방식: 기억을 잃은 민간 조사대가 남긴 작은 단서와 연구자의 동기를 확인하는 장면에서 시작함
표면 모방 위험: 높음
