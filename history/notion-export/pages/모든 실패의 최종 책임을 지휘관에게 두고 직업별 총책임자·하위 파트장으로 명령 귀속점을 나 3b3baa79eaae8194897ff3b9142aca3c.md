# 모든 실패의 최종 책임을 지휘관에게 두고 직업별 총책임자·하위 파트장으로 명령 귀속점을 나누는 장면

REF 코드: REF-46
감정 증거: 새 지휘관 A는 권한을 얻은 기쁨보다 사망과 계획 실패를 변명할 수 없다는 부담을 먼저 인식한다. 모든 세부를 직접 통제할 수 없기에 기능별 책임자를 세운다.
대사·행동 배열: 최종 책임 인식 → 기존 네 개 혼합 조 검토 → 균등 배치 장점 → 기능별 책임 불명확 → 전면 재배치 비용 판단 → 직업군 분류 → 총책임자 임명 → 연구·조사·전투 하위 파트 → 재량권 부여
대표성: 대표

상태: 준비
상태 변화: 투표로 선출된 새 지휘관 → 모든 실패의 최종 책임자 → 기능별 책임과 재량권을 분산한 명령 체계의 설계자

장면 종료 방식: 최종 책임은 지휘관에게 남기고 실행 책임은 직업별·하위 파트별로 분산함
