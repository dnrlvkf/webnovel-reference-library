# 구성원의 성장을 칭찬이 아니라 분배율과 공동 자원 결정권으로 기록하는 장면

REF 코드: REF-46
감정 증거: 빚만 남은 구성원은 당황하고 다른 구성원들은 성장 사실을 인정한다. 후반에는 각자의 외부 의무를 말하면서 합류 시기를 조정한다.
대사·행동 배열: 정산 공개 → 기존 낮은 권리 확인 → 성장 전력 판정 → 분배율 인상 제안 → 집단 동의 / 공동 전리품 확인 → 사용권 논의 → 외부 직위 확인 → 합류 시기 조정
