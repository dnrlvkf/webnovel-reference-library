# 참 판정과 정보량을 분리하고 잘못된 확신·상반된 주장까지 통과시키는 장치의 한계를 드러내는 장면

REF 코드: REF-46
감정 증거: 참가자들은 처음에는 장치 색에 안도하지만, 최소 문장·현실과 충돌하는 정보·상반된 확신이 모두 통과하자 출처와 누적 행동 기록을 더 중시한다.
대사·행동 배열: 사적 질문 거절 → 공식 정보 발화 → 참 판정 → 정보량 부족 이의 → 추가 발화 협상 → 현실과 충돌하는 참 판정 → 잘못된 확신 가능성 → 후반 상반된 주장 모두 통과 가능성 → 집단 평판으로 수용 결정 → 최소 발화 뒤 턴 종료
