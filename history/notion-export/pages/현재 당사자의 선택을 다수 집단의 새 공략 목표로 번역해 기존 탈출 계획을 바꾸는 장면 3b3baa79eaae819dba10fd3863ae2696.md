# 현재 당사자의 선택을 다수 집단의 새 공략 목표로 번역해 기존 탈출 계획을 바꾸는 장면

REF 코드: REF-46
감정 증거: 공략대는 과격한 새 목표에 충격받지만, 공략자는 이전 회차와 현재 소망이 달라졌다는 논리로 계획 변경을 밀어붙인다.
대사·행동 배열: 전투 정산 → 공략 조건 토론 → 공략자의 보고 → 탈출이 아닌 소망이라는 재정의 → 이전 회차 반론 → 소망 변화 설명 → 현재 목표 공개 → 집단 충격 → 새 계획 수립
대표성: 대비
마지막 검토: 2026년 8월 5일
상태: 준비
상태 변화: 탈출과 생존 중심 공략대 → 개인의 현재 욕망을 공유받은 집단 → 복수·파괴 중심 루트의 실행 조직
상황군: 권한·위계, 전투·대결, 정보·비밀, 조직·제도

장면 조건: 현재 당사자의 선택이 기존 공략 목표와 충돌하며 다수 집단의 전략·위험 부담을 바꿔야 함
장면 종료 방식: 과격한 목표를 공론화하고 공략대가 새 루트의 계획 수립에 들어감

진입 방식: 전투 보상 정산 뒤 공략 성공 조건을 논의하는 집단 회의에서 시작함
