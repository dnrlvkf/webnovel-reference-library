# TH-REF46-17 · 공동 전리품은 현금 분배·개인 매입·공용 비축·군자금으로 용도별 권리를 분리해 보존된다

REF 코드: REF-46
경계 상태: exact
먼 재등장: 희귀 정수의 외부 소유권 분쟁은 무력 충돌 직전까지 가지만 관례와 마법사들의 협상으로 정리되고, 내부에서는 판매와 흡수 중 어느 쪽이 팀 전체에 유리한지 다시 논의한다. 다음 대형 정산에서는 획득물을 현금·특수 노동·공용 소모품·개인 매입·공용 장비로 세분화해 장부화한다. 훨씬 뒤 원정대 단위에서는 개별 전리품을 군자금으로 통합하고 처분 권한을 지휘자에게 맡기지만, 희귀 소재의 제작 대상은 공동 판단으로 남겨 개인 파티의 사용권 분리가 조직 규모로 확대된다.
미확인 범위: 917화 이후 클랜 공금·공용 장비·희귀 정수의 최종 소유 주체, 지휘자 교체나 조직 해산 시 군자금과 공용 물품의 귀속, 내부 매입 기회가 복수 희망자 사이에서 어떻게 배분되는지.
반례: 소유권 관례는 법처럼 확정적이지 않아 희귀 보상이 걸리면 무력 분쟁으로 쉽게 붕괴한다. 내부 매입 제도는 공동체 몫을 보존하지만 현금이 부족한 구성원을 빚에 묶고, 부유한 구성원이 좋은 장비를 선점하기 쉽게 만들 수 있다. 공용 물품 지정도 미래 공략이라는 명분 아래 개인 지불을 피하려는 전략으로 오해받을 수 있다. 원정대가 전리품과 사용 권한을 지휘자 한 명에게 맡기는 장면에서는 감시·정기 보고·거부 절차가 확인되지 않아 신뢰가 잘못된 리더에게 집중될 위험이 남는다.

인물·관계·사건·표현: 다른 팀이 사냥 중인 몬스터의 마지막 타격을 가한 뒤 희귀 정수가 나오자 양측은 소유권을 주장한다. 기존 관례는 먼저 사냥하던 팀의 권리를 지지하지만, 관례 위반이 곧 법적 강제는 아니며 위원회가 개인 분쟁으로 처리할 가능성도 제시된다. 소유권이 자기 팀에 남은 뒤에는 리더가 독단적으로 흡수하지 않고 판매할지 특정 구성원이 사용할지를 논의하며, 팀원이 정수를 취할 경우 판매가 일부를 공동체에 지불하는 내부 매입 규칙이 작동한다. 후속 정산에서는 마석과 전투 소득은 균등 현금화하고, 마법으로 보존한 약초는 특수 노동 가산을 적용하며, 포션은 판매하지 않고 공용 소모품으로 남긴다. 개인이 가져갈 장비는 시세보다 낮은 내부 가격을 공동체에 지불하지만, 미래 공략에 필요한 넘버스 아이템은 개인 물품에서 제외해 팀 공용으로 보관한다. 더 큰 원정대에서는 회수한 장비 대부분을 지휘자에게 맡겨 군자금으로 전환하되, 재가공 소재로 무엇을 만들지는 추후 구성원 모두가 납득할 이유를 제시해 공동 결정하기로 한다.
자유 이해: 공동으로 얻었다는 사실만으로 모든 물건을 같은 방식으로 나누지 않는다. 먼저 외부 집단과의 관계에서는 발견·사냥·마지막 타격 중 무엇이 소유권을 만드는지 관례와 공개 절차로 경계를 정한다. 소유권이 확정된 뒤에는 현금 수익권, 개인 사용권, 공용 보유권, 처분권을 다시 분리한다. 즉 개인이 물건을 들고 있다고 해서 완전한 사유재산이 되는 것이 아니며, 공동체에 내부 가격을 지급하거나 미래 공략에 사용할 의무가 붙을 수 있다. 규모가 커지면 처분 실무는 리더에게 위임되지만, 군자금의 목적과 희귀 소재의 최종 사용은 집단적 정당화를 요구한다.
조합 가설: REF-46 내부에서는 공동 획득물의 공정성을 동일 비율로 쪼개는 데서 찾지 않는다. 소유권을 먼저 확정한 뒤 현금 수익·개인 사용·공용 비축·처분 권한을 목적에 따라 분리하고, 개인화에는 공동체 보상이나 미래 사용 의무를 붙일 때 장기 파티의 자산이 보존된다.
현재 질문: 클랜 규모에서 개인 사용 희망자가 여럿일 때 가격 외에 공략 적합성·기여·위험 부담을 어떤 절차로 비교하는지, 공용 물품을 처분하거나 개인화할 때 누가 거부권을 갖는지 추가 확인한다.
확인 범위: 167화의 외부 팀 개입으로 발생한 정수 소유권 분쟁·관례와 위원회 판단 가능성·팀 내부 판매 결정, 202화 전후의 최종 결산에서 균등 현금·특수 전리품 가산·공용 소모품·개인 전리품 내부 매입·팀 공용 아이템 구분, 447화의 원정대 전리품 군자금 전환·재가공 소재의 공동 사용 결정권을 직접 확인했다. 전체 순차 완독과 동일하지 않다.

## 해결하는 문제

희귀 전리품을 무조건 판매하거나 리더가 독점하지 않고, 파티와 조직의 장기 목표에 맞춰 서로 다른 소유·사용 권리로 전환하는 문제.

## 작동 사슬

외부 팀 개입과 소유권 충돌 → 관례·위원회·평판 비용 확인 → 공동체 소유 확정 → 판매와 흡수 선택 협의 → 개인 사용 시 내부 매입 → 일반 현금·특수 노동·공용 소모품 분리 → 개인 장비와 팀 공용 장비 분류 → 원정 전리품의 군자금 통합 → 처분 실무 위임 → 희귀 소재 사용은 공동 정당화.

## 표현 구현

소유권 분쟁과 사용권 논의를 한 장면에서 섞지 않고, 먼저 외부 권리 경계를 해결한 뒤 팀 내부 회의를 연다. 정산 서류에는 현금화 항목, 공용 보관 항목, 개인 매입 가격, 특수 노동 가산을 별도 줄로 적는다. 공용 지정에는 사용할 미래 상황을 구체적으로 제시하고, 조직 규모에서는 리더에게 처분을 맡기더라도 희귀 소재의 최종 제작 대상을 다시 회의에 올린다.

## 독자 경험
