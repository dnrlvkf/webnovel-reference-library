# 외부 전문 인력을 단기 대행자로 쓰지 않고 교육·감독 단위와 결정권 위임까지 설계하는 장면

REF 코드: REF-46
감정 증거: 외부 전문가는 내부 작업자의 힘을 인정하면서도 지속 불가능성을 지적한다. 대표의 전면 위임에 놀라지만 전문성 신뢰를 확인한 뒤 책임을 수락한다.
대사·행동 배열: 외부 전문가 투입 → 단순·전문 노동 분업 → 내부 교육 부재 인식 → 기술 시범 → 학습 확인 → 전문가 1인당 작업자 10인 감독 구조 → 준비 전체 위임 → 전문성 신뢰 발화

## 작가의 핵심 선택

외부 전문가가 일을 대신해 주는 데서 멈추지 않고, 교육 시범·감독 비율·결정권 위임을 연속해서 보여 준다.

## 독자 판단 변화

외부 도움에 의존하는 임시방편 → 내부 인력의 학습 가능성 → 감독 구조의 지속성 → 전문성을 인정하는 실질적 권한 이동.

## 원문 재독 이유

분업이 교육으로 바뀌는 시점과, 대표가 중요한 일을 완전히 맡기는 대사 순서를 확인해야 한다.

## 기존 장면과 차이

행정 전문가를 조직 내부 권한자로 편입하는 장면과 달리, 외부 전문가가 교육자·감독자·한시적 결정권자로 기능한다.
