# 형식상 성공과 높은 보상을 당사자의 불만족 표정으로 거절하고 현재 욕망을 다시 묻는 장면

REF 코드: REF-46
감정 증거: 공략자는 쉬운 종료를 거부하고, 현지 인물은 체념과 두려움 속에서 긴 침묵 끝에 자기 욕망을 처음 드러낸다.
대사·행동 배열: 과거 기억 상영 → 성공·점수·보상 제안 → 종료 발화 차단 → 포탈 개방 저지 → 왜 불만족하냐는 질문 → 당사자의 표정 지적 → 이전 소망 복기 → 평화로운 탈출 답변 거절 → 힘 없음 고백 → 선택 책임 제시 → 복수 질문 → 긴 침묵 → 현재 의사 확인 → 새 루트 선언
대표성: 대표

상황군: 관계 갈등, 권한·위계, 정보·비밀, 평가·판정
