# C-REL-01 · 손상된 관계를 원상복구하지 않고 권리를 반환한 뒤 다시 선택하게 한다

갱신 상태: 현행 유지
검증 메모: 단일 REF 근거이지만 사용자의 명시 승인으로 활성화한다. 자동 적용은 선택 엔진의 조건 일치 시 후보로 선택되는 의미이며, 원문·정사·관계 권리 잠금과 NO_OP 허용을 유지한다.
검증 판정: 운영 규칙 확정
근거 단계: S1 · 단일 REF
근거 범위: REF-45의 강제 약혼·진로 통제·공식 관계 해체·독립 목표 선택·새 수호 관계까지 떨어진 구간의 반복과 반례.
금지 조건: 희생의 진실로 과거 가해를 면제하지 않는다. 관계 해체 직후 자동 재결합시키지 않는다. 감사·부채·의존을 자유의지와 동일시하지 않는다.
기능 대분류: 관계·대화
누적 방식: 장기 회수형
독자 효과: 재결합의 즉각적 안도 대신 상실을 보존하면서, 피해자가 실제 선택권을 되찾는 더 강한 관계 보상을 체감한다.

비정사 참고: Yes
상위 원리·수정 연결: MC-REL-01과 인접하나, 신뢰 갱신이 아니라 기존 관계 권리의 폐기와 재부여를 다룬다.
상태: 활성
세부 기능·태그: 관계 해체 · 선택권 반환 · 원상복구 거부 · 재선택 · 관계 종결
실행 완료 조건: 기존 관계가 주던 간섭·소유·명령권 중 하나 이상이 실제로 소멸한다. 상대가 관계 밖의 독립 목표나 행동을 선택한다. 새 관계가 생기면 피해 당사자의 발화나 행동으로 권리가 다시 부여된다.
심층 적용 메모: 감정 고백보다 권리 변화를 먼저 확정한다. 관계 해체 뒤 상대가 혼자 선택하는 구간을 확보하고, 새 관계가 없다면 결별도 완료로 인정한다.
심층 증거 스레드: TH-REF45-09 · 강요된 약혼을 공식 해체한 뒤 상대가 자유의지로 수호 관계를 새로 선택하는 장기 구성 (https://app.notion.com/p/TH-REF45-09-3b2baa79eaae814da0b7faf89d1dfb83?pvs=21)

적용 조건: 과거의 통제·강요·의존 조작 때문에 진실 공개나 사과만으로 이전 관계를 복구하면 피해자의 선택권을 다시 침해하는 장면.

충돌 조건: 기존 관계에 실질적인 강요나 권리 침해가 없거나, 긴급 생존 행동이 관계 정산보다 우선인 장면.
