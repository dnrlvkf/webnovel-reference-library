- `CONTRACT_ID`: REFERENCE_USAGE_CONTRACT_v2
- `VERSION`: 2
- `STATUS`: ACTIVE
- `EFFECTIVE_AT`: 2026-08-05
- `SUPERSEDES_FOR_NEW_ADOPTION`: REFERENCE_USAGE_CONTRACT_v1
- `SCOPE`: REF 후보 검색, 준비 상태 판정, 원문 재독, 초고 전후 참고작 활용, 사용 영수증
- `NOT_AUTHORITY_FOR`: 작품 정사, 인물 성격, 말투, 문체, 사건 순서, 화말, 상태 변화, 대사·행동 배열

## 핵심 원칙

> **원문은 사용 자격이어야지 검색 자격이어서는 안 된다.**
> 
- 모든 검색 가능한 REF는 경량 후보 검색 모집단에 포함한다.
- 모든 REF를 매번 깊게 읽지 않는다.
- 후보 탐색과 집필 사용을 분리한다.
- 깊은 원문 재독 비용은 실제로 유력하고 사용 자격이 있는 후보에게만 지불한다.

## 권위 순서

1. 사용자의 현재 명시 지시와 승인
2. 최신 확정 한국판 원고
3. 작품별 ACTIVE-RULES
4. 작품별 연속성 위키와 CURRENT-PACKET
5. 작품별 승인 문체 프로필
6. 해당 작품의 원문 사건·인과·선택자·정보 공개 순서
7. 이 공통 계약과 공용 참고작 라이브러리

충돌 시 상위 자료를 따른다. 이 계약은 작품별 ACTIVE-RULES와 정사를 자동 변경하지 않는다.

## 적용과 로딩 경계

각 프로젝트는 `ADOPTED`, `ADOPTED_WITH_EXCEPTIONS`, `NOT_APPLICABLE` 중 하나와 계약 ID·버전을 기록한다.

- 계약 버전 변경은 기존 프로젝트에 자동 적용하지 않는다.
- 평상시 콜드 스타트에서는 계약 전문과 참고작 허브를 미리 읽지 않는다.
- 프로젝트에 저장된 계약 ID·버전·채택 상태만 확인한다.
- 참고작 단계가 실제로 활성화되었거나 저장된 버전과 최신 정본이 불일치할 때만 계약 전문을 직접 조회한다.

## 1단계 · 현재 작품 잠금

참고작 검색 전에 다음을 잠근다.

- 원문 사건·인과·선택자·생사·자원·정보 공개 순서와 암시 강도
- 최신 확정 정사와 관계 이력
- 현재 장면의 구체적 압력, 욕망, 지식 경계, 감정 잔여
- 작품별 문체 프로필과 ACTIVE-RULES

참고작은 이 잠금을 변경할 수 없다.

## 2단계 · 전체 REF 경량 후보 검색

현재 장면의 실제 조건으로 전체 검색 가능 REF를 얕고 넓게 검색한다.

- 원하는 기법명이나 원하는 결과를 검색어로 삼지 않는다.
- TH·Macro·Micro·카드 전문과 원문 전체를 펼치지 않는다.
- 색인 메타와 짧은 연구 좌표만 사용한다.
- 상위 후보는 최대 3개로 제한한다.

각 후보는 최소한 다음을 표시한다.

- `REF_CODE`
- 현재 조건과 맞는 이유 1~2줄
- `READINESS_STATUS`
- 원문 또는 연구 위치
- 최근 사용·반복 위험

## 준비 상태

### SOURCE_READY

다음을 모두 충족한다.

- 실제 원문 범위를 새 채팅에서도 다시 읽을 수 있다.
- 정확한 위치, 실제 인물·조직, 필요한 전후 맥락이 보존돼 있다.
- 핵심 외에 대비·이탈·실패·오해·미해결 장면을 구성할 수 있다.

집필 전 원문 재독과 임시 독서 묶음 사용이 허용된다.

### RESEARCH_READY

TH·Macro·Micro 등 연구 근거는 충분하지만 실제 원문이 집필 시점에 재독 가능한 형태로 준비되지 않았다.

허용:

- 후보 검색
- 적합도 판단
- 원천 복구 위치 지정
- 초고 후 질문형 진단

금지:

- 연구 결론을 초고 전 집필 지시로 전달
- Macro 배열이나 TH 결론을 완료 조건으로 사용

### INDEX_ONLY

작품·장면 위치, 약한 요약, 카드 연결 등 검색 좌표만 있다.

허용:

- 연구 대기열과 원천 복구 좌표

금지:

- 초고 전 사용
- 초고 후 구체 수정 지시
- 다른 준비된 REF의 근거로 간주

## 3단계 · 후보 선택과 대체 금지

- 적합도가 가장 높은 후보를 준비 상태와 함께 그대로 기록한다.
- 최적 후보가 미준비라는 이유로 숨기거나 순위를 낮추지 않는다.
- 준비된 다른 REF를 자동 대체하지 않는다.
- 낮은 순위의 SOURCE_READY 후보는 현재 문제에도 실제로 충분히 적합할 때만 별도 선택할 수 있다.
- 이 경우 `FORCED_READY_SUBSTITUTION: false`를 설명할 수 있어야 한다.
- 안전한 SOURCE_READY 후보가 없으면 `DRAFT_FIRST_DIAGNOSTIC` 또는 `NO_OP`으로 전환한다.

## 4단계 · SOURCE_READY 원문 독서

선택된 하나의 REF 안에서 실제 원문 장면 2~4개를 임시 묶음으로 읽는다.

- 핵심 장면 외에 대비·이탈·실패·오해·미해결 중 하나 이상을 포함한다.
- 필요한 선행·결과 문맥을 함께 읽는다.
- 집필부에는 실제 원문 범위와 짧은 관찰 좌표만 전달한다.
- 카드·TH 결론·일반화 문장·실행 순서·완료 조건은 전달하지 않는다.
- 서로 다른 REF의 장면을 한 초고 전 묶음에 성급히 혼합하지 않는다.
- 묶음은 해당 초고 뒤 만료하며 다음 회차에 자동 승계하지 않는다.

## 5단계 · 선택부와 집필부 분리

선택부는 전체 REF 색인을 볼 수 있다. 집필부는 다음만 받을 수 있다.

- 현재 작품 잠금 자료
- SOURCE_READY로 선택된 실제 원문 범위와 짧은 관찰 좌표
- 또는 초고 후의 비처방 질문

집필부에 전달하면 안 되는 것:

- 대사·행동·침묵의 실행 순서
- 특정 인물의 반응 전술
- 필수 상태 변화
- 화말 형식
- 성공 기준과 완료 조건
- `이렇게 써라` 형식의 Macro·Micro·TH 결론

## 6단계 · 자연 초고와 fallback

- SOURCE_READY 묶음을 읽었다면 참고작을 닫고 현재 작품 원문·정사·관계·감정 잔여를 다시 읽은 뒤 초고를 쓴다.
- 안전한 묶음이 없으면 참고작 없이 자연 초고를 먼저 쓴다.
- RESEARCH_READY 후보는 초고 뒤 실제 결함이 확인된 경우에만 질문형 진단에 사용한다.
- 질문은 현재 작품의 결함을 확인할 뿐 수정 방향이나 표현 배열을 명령하지 않는다.
- INDEX_ONLY 후보는 집필 진단에 사용하지 않는다.

## 질문형 진단 예

- 현재 인물들이 상황보다 지나치게 정확하고 기능적으로 반응했는가?
- 관계 이력보다 설명 책임이 먼저 작동했는가?
- 원문에 없는 보상·권리·약속을 참고작 때문에 추가했는가?
- 미해결 감정이나 오해를 인위적으로 정산했는가?
- 최근 회차와 같은 기능 사슬을 외형만 바꾸어 반복했는가?

질문에 해당해도 수정은 현재 작품의 원문·욕망·관계·감정에서 새로 판단한다.

## 원천 복구 대기열

미준비 후보가 반복적으로 최상위에 오르거나 중요한 장면에서 필요하면 별도 복구 작업으로 전환할 수 있다.

권장 복구 조건:

- 장기 아크 전환
- 핵심 관계나 권한 변화
- 인물 정체성을 결정하는 장면
- 최근 3회 검색 중 2회 이상 같은 미준비 REF가 최상위 후보
- 같은 결함이 반복되어 원문 비교 가치가 커짐

평상시 회차 작업 도중 모든 미준비 후보를 즉시 복구하지 않는다.

## 표면 모방·기계화 금지선

다음이 발생하면 참고작 적용을 중단하고 자연 초고와 비교한다.

- 참고작의 문장·비유·호칭·고유 물건·대사 순서·관계 외형이 남음
- 인물들이 연구 카드의 기능을 수행하듯 반응함
- 모든 대사와 행동이 다음 상태 변화를 만듦
- 대표 장면 하나가 모범 답안처럼 반복됨
- 현재 작품의 오해·망설임·헛된 대화·미해결 감정이 제거됨

## 후보 검색 영수증

모든 서사 회차는 참고작 단계가 활성화되었을 때 다음을 기록한다.

- `CANDIDATE_POOL_SCOPE: ALL_SEARCHABLE_REF`
- 현재 장면 검색 조건
- 상위 후보 최대 3개와 각 준비 상태
- 최적 후보와 선택 후보
- 미선택 이유
- `FORCED_READY_SUBSTITUTION`
- `REFERENCE_PATH: SOURCE_READING / DRAFT_FIRST_DIAGNOSTIC / NO_OP`
- 원천 복구 대기열 추가 여부

## 실제 사용 영수증

SOURCE_READY 원문을 실제 사용한 경우 추가로 기록한다.

- 다시 읽은 REF와 원문 장면
- 핵심 외에 함께 읽은 대비·이탈·실패·오해·미해결 장면
- 현재 작품에 새로 판단한 내용
- 표면 모방·기계화 감사 결과
- 적용 결과: 도움 / 부분 도움 / 효과 불명 / 기계화·모방 발생 / NO_OP

## 금지되는 우회

- SOURCE_READY REF만 먼저 걸러 검색하기
- 최적 미준비 후보를 숨기고 준비된 후보를 자동 선택하기
- RESEARCH_READY의 결론을 초고 전 전달하기
- 질문형 진단을 수정 명령으로 바꾸기
- 실제 원문 복구 없이 SOURCE_READY로 승격하기
- 매 회차 모든 REF의 전문과 원문을 읽기

## 변경 경계와 기존 프로젝트

- 이 계약은 공용 활용 절차만 바꾼다.
- 프로젝트별 정사·ACTIVE-RULES·문체 프로필·원고·CURRENT-STATE를 자동 변경하지 않는다.
- 기존 `v1` 채택 프로젝트는 명시적 마이그레이션 전까지 기존 채택이 유효하다.
- `v2` 채택 시 프로젝트에는 계약 ID·버전·채택 상태·작품 고유 예외만 기록하고 계약 본문을 복제하지 않는다.
- 작품 고유 사용자 피드백과 실패 교정은 공통 계약과 유사해도 자동 삭제·강등하지 않는다.
