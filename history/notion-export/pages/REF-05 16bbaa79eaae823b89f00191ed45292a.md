# REF-05

감사 메모: U0001-U0912의 source-explicit 회차 경계를 직접 확인했다. 초·중·후반 의미 창을 대조했으며, 지식 수정·파티 권한·관계 시험·캐릭터 재분류·사건 잔여를 확인했다. 저장본 최신 경계는 작품 종결로 간주하지 않는다.
구간 공백: U0004-0049, U0051-0299, U0301-0599, U0601-0849, U0851-0911의 연속 독해가 남음. 후기 비전투·정치 관계에서 오답 수정과 동료 독립성이 유지되는지 미확인.
근거 스레드: TH-REF05-KNW-01 · 지식 우위가 오답과 수정 비용을 통과한다 (https://app.notion.com/p/TH-REF05-KNW-01-988baa79eaae82a6a97981111bc986e5?pvs=21), TH-REF05-GRP-01 · 역할 분담이 자원·안전·발언권으로 변한다 (https://app.notion.com/p/TH-REF05-GRP-01-62bbaa79eaae82b1847f813bda15db84?pvs=21), TH-REF05-REL-01 · 위험한 비밀과 도덕 이견이 관계 권리를 바꾼다 (https://app.notion.com/p/TH-REF05-REL-01-fbabaa79eaae831a8e2d8104dcda3372?pvs=21), TH-REF05-CHR-01 · 대상이 현재 선택을 가진 사람으로 재분류된다 (https://app.notion.com/p/TH-REF05-CHR-01-de5baa79eaae838f9b888146cf2db94b?pvs=21), TH-REF05-RES-01 · 실패·이탈·손실이 다음 집단 선택에 남는다 (https://app.notion.com/p/TH-REF05-RES-01-74fbaa79eaae832aa74c010657992348?pvs=21)
기능 공백: 비전투 협상에서의 대사 수용 변화, 장기 관계 파열 뒤 권한 회수, 후기 조연 독립 욕망, 상실의 정서 잔여와 시스템 학습의 비율, 최신 경계 이후 추적.
다음 자유 질문: 후기 규모가 커질수록 동료가 기술 슬롯과 원격 지원으로 평탄화되는가, 아니면 주인공의 공략 모델을 거부·수정할 독립 권한을 유지하는가?
