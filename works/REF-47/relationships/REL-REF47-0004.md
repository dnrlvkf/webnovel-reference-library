# 주인공 A ↔ 제자 A — 독립 판단·이탈·대립 가능성을 없애지 않는 사제 신뢰

## 관계 질문

스승이 제자를 믿는다는 것은 소속·복종·현재 판단 일치를 기대하는가. 아니면 제자가 잘못하거나 이탈·대립하더라도 제자 역할과 완성 가능성을 별도로 유지하는가. 실패 뒤 어떤 권리를 회수하고 어떤 의무를 남기는가.

## 초기/중기 관계 변화

- `DIRECT / ep124`: 제자 A는 학교를 떠나고 주인공 A의 반대편에 설 생각까지 했음을 스스로 배신으로 인식한다.
- `DIRECT / ep124`: 그 시점에도 장기 학업을 가능하게 하는 지원·응원 정보가 유지된다.
- `DIRECT / ep124`: 다시 마주친 주인공 A는 관계 파기나 특별 보복이 아니라 연구실 불참이라는 실제 의무 위반에 통상 벌점을 준다.
- `SUPPORTED`: 배신·이탈 가능성이 `제자 역할 전체 회수`로 곧장 이어지지 않고, 구체 의무 위반만 규율된다.
- `DIRECT / ep132`: 제자 A는 자신의 잘못과 배신을 주인공 A가 알면서도 자신을 제자로 취급했다고 후속 시점에서 이해한다.
- `SUPPORTED`: ep124의 역할 유지가 장면 일회성 예외가 아니라 당사자 관계 인식에도 남는다.

## 후반 관계 변화

- `DIRECT / ep286`: 제자 A가 공개적으로 사제 관계를 끊고 이름 사용을 거절한 뒤에도, 주인공 A는 그 이탈이 제자에게 더 안전할 수 있다고 평가하고 남긴 연구물을 계속 첨삭한다.
- `DIRECT / ep323`: 주인공 A는 제자 A의 현재 구제 방법을 잘못된 방식이라고 판정한다.
- `DIRECT`: 제자 A는 흔들린 뒤 자기 이유를 다시 세워 현재 방법을 방어한다.
- `DIRECT`: 판단 불일치와 실제 대립 준비가 남아 있어도 주인공 A는 제자를 믿겠다고 말한다.
- `DIRECT / ep324`: 믿음의 대상은 복종·소속·현재 방법 승인이 아니라 제자 A의 가능성·재능·독립적 완성으로 설명된다.

## 권리와 의무

### 제자 역할·교육권

- ep124의 이탈 준비 뒤에도 지원과 제자 관계는 유지된다.
- ep286의 공개 단절 뒤에도 교육 기능은 비공개 첨삭으로 지속된다.
- `SUPPORTED`: 관계 표면의 이탈과 교육 역할의 완전 소멸은 동일하지 않다.

### 통상 규율

- `DIRECT / ep124`: 실제 연구실 불참에는 통상 벌점이 붙는다.
- `SUPPORTED`: 지원·관계 유지가 의무 위반 면책을 뜻하지 않는다.

### 이탈·거절권

- `DIRECT / ep286`: 제자 A는 사제 관계를 끊고 이름 사용을 거절하며 독립할 수 있다.
- 주인공 A는 그 이탈을 즉시 배신 처벌이나 연구 폐기로 전환하지 않는다.

### 독립 판단권

- `DIRECT / ep323`: 주인공 A는 제자의 방법을 비판하고 이유를 다시 묻는다.
- 제자 A는 자기 기준으로 반박한다.
- 판단 불일치가 끝나지 않은 채 관계 신뢰가 유지된다.
- `SUPPORTED`: 인물·가능성에 대한 신뢰와 현재 판단 승인은 분리된다.
- `HOLD`: ep323의 방법 충돌에서 누가 작품 객관적 정답인지는 확정하지 않는다.

### 대립 가능성

- `DIRECT / ep323`: 제자 A는 주인공 A와 싸울 각오를 유지한다.
- `DIRECT / ep324`: 작품 내부 사제 관행은 훗날 서로 죽고 죽이는 관계가 되어도 가르침·사사의 과거 가치를 자동 폐기하지 않는 것으로 설명된다.

## 장기 사슬

이탈·반대편 선택 준비
→ 지원 지속 + 실제 의무 위반에는 통상 규율(ep124)
→ 잘못·배신 이력과 제자 역할이 함께 기억됨(ep132)
→ 공개 단절 뒤에도 교육 기능 지속(ep286)
→ 현재 방법 정면 충돌 + 제자 자기 기준 재확인(ep323)
→ 대립 가능성 속 신뢰 유지
→ 신뢰 대상을 제자의 가능성·완성으로 명시(ep324)

## 실패·복구 판정

- `CONTRADICTED`: 제자의 배신·이탈 가능성이 생기면 제자 역할과 지원을 자동 철회한다.
- `CONTRADICTED`: 스승이 제자를 믿으면 현재 판단과 방법도 승인한다.
- `SUPPORTED`: 이 관계에서는 **역할 유지 + 국소 규율 + 교육 기능 지속 + 현재 판단 반박**이 서로 병존할 수 있다.
- `SUPPORTED / cost`: 관계 단절·오해·판단 충돌·실제 전투 가능성을 감수한다.
- `HOLD`: 실제 역할 권리 전면 회수로 넘어가는 임계 조건은 아직 확인하지 못했다.

## 표현·제시 순서

- ep124은 제자 A의 배신·이탈 자기인식을 먼저 보여 주고 지원 정보와 통상 벌점을 붙여 `관계 유지 ≠ 면책`을 한 장면에서 분리한다.
- ep132은 그 복잡한 상태를 제자 A의 후속 인식으로 압축 회수한다.
- ep286은 공개 단절 뒤 비공개 교육 지속을 뒤늦게 보여 준다.
- ep323은 방법 부정→제자 반론→대립 준비→짧은 신뢰 선언 순으로 현재 판단과 관계 신뢰를 분리한다.
- ep324은 무엇을 믿는지 다음 회차에서 확대 설명한다.
- 모두 observed chain이며 집필 템플릿이 아니다.
