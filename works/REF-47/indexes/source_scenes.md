# REF-47 통합 Source Scene 검색 인덱스 — pilot

이 인덱스는 새 기법 체계가 아니다. 기존 Source Scene을 CHARACTER·RELATIONSHIP·EVENT·PROSE가 만나는 재독 허브로 사용하기 위한 파일럿 검색층이다. 장면마다 독립 CHR/REL/EVT 파일을 강제 생성하지 않는다.

**중요:** 아래 `표현 결합`과 beat 사슬은 모두 `observed_chain`이다. 집필 때 같은 결합·순서·채널을 재현하라는 추천안이 아니다. 실제 사용은 루트 `indexes/scene_retrieval_contract.md`의 부분 일치·불일치 경계·결합 강제 감사 규칙을 따른다.

## beat 주소 규칙
- 파일럿에서는 새 ID를 만들지 않고 `SC-REF47-0005#B1` 같은 장면 내부 주소만 사용한다.
- beat는 `포착/관찰 → 판단 → 대사·지문·행동·침묵·효과음 → 상대 수용/재판단 → 상태 변화 → 독자 그림` 중 실제로 연결된 부분을 묶는다.
- 문장 하나나 대사 한 줄마다 beat를 만들지 않는다. 판단 또는 상태가 움직이는 결합 단위만 주소화한다.
- beat 사이의 연결은 원문 관찰값이다. 반복·변형·반례 근거 없이 `필수 순서`로 승격하지 않는다.

## 집필 검색 — 부분 문제 우선
1. 먼저 현재 작품의 캐릭터·관계·사건 조건을 잠근다.
2. 현재 문제를 `무엇을 먼저 보는가 / 어떤 권리가 충돌하는가 / 어떤 선택이 상태를 바꾸는가 / 독자가 무엇을 재분류해야 하는가 / 어떤 표현 실현이 필요한가`로 분해한다.
3. 이 인덱스에서는 장면 전체 일치가 아니라 필요한 열 하나 또는 beat 일부만 일치해도 후보로 읽을 수 있다.
4. 후보마다 `matched_problem / mismatch_boundary / usable_judgment / do_not_import`를 적는다.
5. 해당 SC의 observed chain을 읽고 원문으로 재진입한다.
6. 장기 캐릭터/관계/사건 모델이 이미 있으면 연결 기록을 확인한다. 없으면 장면 근거만 사용하고 새 파일을 강제 생성하지 않는다.
7. 실제 문장·대사·효과음 실현이 필요할 때만 연결 PSE/PVAR를 읽고 다른 실현 가능성을 확인한다.
8. 외부 사례를 닫고 현재 작품 조건으로 장면을 새로 조립한다.

## 사용 경계 예시
- `SC-REF47-0005`에서 `행동이 이미 끝난 결정을 먼저 보여 준다`만 참고할 수 있다. 현재 장면에 기술 반론·마지막 질문·침묵이 필요하다는 뜻은 아니다.
- `SC-REF47-0007`에서 `관찰 차이가 질문을 발생시킨다`만 참고할 수 있다. 현재 관계까지 수업 역할의 질문 차단 구조를 가져오지 않는다.
- `SC-REF47-0015`에서 `같은 사건을 서로 다른 비용 기준으로 본다`만 참고할 수 있다. 현재 장면이 보고 거부·파벌 이탈까지 따라갈 필요는 없다.
- `SC-REF47-0017`에서 `자기에게 익숙한 표정을 증거로 삼는다`만 참고할 수 있다. 짧은 질문→손짓→결론 대사 순서를 재현하지 않는다.
- `SC-REF47-0018~0021`에서는 `정체 확정과 현재 권리 배분을 분리한다`, `반대 행동과 비밀 보존이 공존한다`, `감시 적발 뒤 정보 경계를 다시 정한다` 같은 부분 문제만 검색한다. 사적 공간 축소나 감시 장치, 기록 전달의 표면 배열을 그대로 가져오지 않는다.
- `SC-REF47-0022~0027`에서는 `관계 역할의 최고 기준이 무엇인지`, `그 기준 때문에 어떤 판단권이 남는지`, `신뢰가 대립 또는 정렬 중 어느 쪽으로 구현되는지`만 검색한다. 황제-신하·사제·검 역할의 표면 설정은 가져오지 않는다.
- `SC-REF47-0028~0033`에서는 `과거 잘못 뒤 재위임`, `실행 실패와 판단 실패 구분`, `실패 뒤 독립 해석`, `교정 책임`, `역할 기준 오독` 같은 실패 판별 문제만 검색한다. 위험 인물·조직·감정 표면을 현재 장면에 복제하지 않는다.

## 실패 감사
- **인물 교체 테스트:** A/B를 다른 인물로 바꿔도 판단·대사·행동 사슬이 거의 그대로면 캐릭터 결합 근거가 약하다.
- **채널 분리 테스트:** 대사만 또는 지문만 떼어도 동일한 캐릭터/사건 의미가 완성되면 결합 분석이 약할 수 있다.
- **사건 운동 테스트:** 장면 종료 후 정보·권리·목표·선택지·참여자 행동 중 아무것도 바뀌지 않으면 EVENT 연결을 재검토한다.
- **독자 그림 테스트:** 각 핵심 beat 뒤 독자가 새로 보거나 재분류한 물리·상황·캐릭터·관계·사건 그림을 말할 수 있어야 한다.
- **결합 강제 테스트:** 외부 SC의 beat 순서·역질문·침묵·효과음·권리 구조를 현재 장면의 필요 없이 재현했다면 삭제하고 현재 작품 조건에서 다시 선택한다.
- **신뢰 일반화 테스트:** `신뢰=반대 허용` 또는 `신뢰=행동 정렬` 중 하나로 고정하지 않고, 해당 관계가 지켜야 할 최고 기준과 실제 권리 결과를 먼저 확인한다.
- **실패 분류 테스트:** 위임 뒤 나쁜 결과를 곧바로 상대 판단 실패로 부르지 않고 `판단 불일치 / 실행·통제 실패 / 과거 잘못 / 역할 기준 오독`을 분리한다.

## 스키마 승격 보류
현재 SOP v7.1과 schema v2에는 이미 연결 근거·Source Scene 역할·cross-track link를 담을 수 있는 여지가 있다. 현재 장면 추가 역시 새 최상위 레코드나 Schema v3 없이 기존 Source Scene·REL·TH 연결로 손실 없이 왕복된다.
