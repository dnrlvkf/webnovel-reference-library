# REF-47 통합 Source Scene 검색 인덱스 — pilot

## 검색·감사 규칙

1. 현재 작품의 캐릭터·관계·사건 조건을 먼저 잠근다.
2. 장면 전체가 아니라 필요한 문제 열/beat만 부분 일치로 사용할 수 있다.
3. `matched_problem / mismatch_boundary / usable_judgment / do_not_import`를 적는다.
4. Source Scene은 원문 재진입 좌표이며 observed chain을 권장 chain으로 바꾸지 않는다.
5. **신뢰 일반화 테스트:** `신뢰=반대 허용`, `신뢰=행동 정렬`, `신뢰=현재 판단 승인` 중 하나로 고정하지 않는다.
6. **실패 분류 테스트:** `판단 불일치 / 실행·통제 실패 / 과거 잘못 / 감정·관계 상태 오독 / 역할 최고 기준 오독`을 분리한다.
7. **복구 범위 테스트:** 실패 뒤 관계 전체가 아니라 실제로 어느 권리·의무 층이 회수·조정되었는지 확인한다.
8. 인물 교체·채널 분리·사건 운동·독자 그림·결합 강제 테스트를 기존 계약대로 적용한다.

## 스키마 승격 보류

SOP v7.1과 schema v2의 기존 Source Scene·REL·TH 연결로 이번 경계/복구 연구를 손실 없이 왕복할 수 있어 Schema v3나 새 최상위 레코드는 만들지 않는다.
