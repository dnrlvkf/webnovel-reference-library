# 신뢰는 관계 최고 기준에 맞는 판단권을 남기고, 실패 뒤에도 실패한 층만 조정하는 방식으로 변형된다

## 연구 질문

1. 신뢰가 왜 항상 동조·복종으로 수렴하지 않는가.
2. 판단권을 남긴 뒤 결과가 나쁘거나 배신·오해가 발생하면 무엇을 실제 신뢰 실패로 판정해야 하는가.
3. 실패 뒤 관계 권리는 전부 회수되는가, 아니면 실패한 층만 규율·수정되는가.
4. 주인공 A가 상대의 역할 최고 기준을 잘못 읽어 판단권을 오배분한 직접 사례가 있는가.

## 핵심 판정

`SUPPORTED`: REF-47의 신뢰는 `항상 내 편`, `항상 옳음`, `모든 현재 판단 승인`이 아니다. 관계가 무엇을 지키기 위해 존재하는지에 따라 거절·이탈·감시·저지·판정·정렬 권리가 달리 남는다.

`SUPPORTED`: 실패가 발생해도 관계 전체를 자동 폐기하기보다 **실패한 층을 먼저 진단하고 그 층에만 규율·정보 경계·조건·책임을 추가하면서 영향받지 않은 역할 권리를 유지**하는 변형이 반복된다.

`HOLD / negative result`: 1-350 전체 경계를 직접 확인하고 초반까지 역검색했지만, `주인공 A가 상대의 역할 최고 기준을 잘못 읽어 판단권을 맡겼고 그 위임 자체가 잘못이었다고 직접 수정하는` 명시 사례는 확인하지 못했다.

`DIRECT / boundary`: 주인공 A가 상대의 **감정·현재 관계 상태**를 잘못 읽는 사례는 ep163에서 확인된다. 따라서 `주인공은 타인을 오독하지 않는다`는 해석도 성립하지 않는다. 다만 감정 오독을 역할 기준 위임 오독으로 확대하지 않는다.

## 기본 작동 사슬

관계마다 최고 기준이 있음
→ 신뢰가 생겨도 상대의 판단 주체가 사라지지 않음
→ 명령·소속·감정·현재 방법과 최고 기준이 충돌할 수 있음
→ 거절·이탈·감시·저지·최종 판정 또는 행동 정렬이 관계별로 배분됨
→ 실패/비용 발생
→ `현재 판단 불일치 / 실행 실패 / 과거 잘못 / 감정·관계 상태 오독 / 역할 기준 오독`을 분리
→ 실패한 층만 규율·조건 수정·정보 경계·책임 추가
→ 영향받지 않은 역할·정보·교육·분석 권리는 유지 가능
→ 후속 행동으로 관계 기준을 다시 검증

### 4. 실행·통제 실패 — ep250→251

### 6. 과거 잘못 + 교정 책임 — ep267

## STORY

- ep78은 불확실성을 먼저 열어 둔 뒤 신뢰·승격을 배치해 이후 정체 공개를 단순 반전으로 만들지 않는다.
- ep124→132는 배신 인식 직후 지원·규율을 병치하고, 후속 회상에서 `잘못과 역할 유지`를 함께 압축 회수한다.
- ep247→250→251→253은 신뢰 시험 뒤 즉시 성공 대신 장기 실행 실패→재해석→관계 재분류로 간다.
- ep297은 처벌 뒤 자기 투영 오독을 공개해 `배신` 감정의 인과를 다시 읽게 한다.
- ep323→324은 판단 충돌과 대립 가능성을 먼저 장면화하고 신뢰 대상을 다음 회차에서 확대 설명한다.

## PROSE

- 핵심은 특정 문형이 아니라 `불확실성 공개→권리 부여`, `배신 인식→지원 유지+통상 규율`, `감정 판정→제3자의 착각 지적`, `실패→권리 국소 조정`의 장면 배열과 상태 결과다.
- 신규 PSE/PVAR/Micro를 만들지 않는다.
- `믿는다`, `배신`, `착각` 같은 단어를 표면 공식으로 저장하지 않는다.

## TECHNIQUE / 작가 선택

`SUPPORTED`: 작가는 신뢰를 무오류 보증으로 만들지 않고, **어떤 판단권을 남길지와 실패 뒤 무엇만 수정할지**로 관계를 운용한다.

`HYPOTHESIS / why this choice`: 실패마다 관계 전체를 파기하지 않고 실패한 층만 조정하면 기존 관계가 소모되지 않은 채 새 규율·책임·정보 비대칭이 다음 사건의 원인이 될 수 있다. 작가 의도로 확정하지 않는다.

## 적용 경계

- `신뢰 = 반대 허용`, `신뢰 = 행동 정렬`, `신뢰 = 현재 판단 승인` 중 하나로 고정하지 않는다.
- `위임 뒤 나쁜 결과 = 신뢰 실패`로 압축하지 않는다.
- 불확실성을 이미 알고 준 권리를 후속 정체 공개 때문에 오독으로 소급하지 않는다.
- 감정·관계 상태 오독과 역할 최고 기준 오독을 구분한다.
- 현재 검증군의 국소 조정을 작품 전체의 보편 법칙으로 확대하지 않는다.
