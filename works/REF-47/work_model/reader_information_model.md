# REF-47 독자 정보 모델

## ep1 초기 온보딩

### 독자가 주인공 A보다 먼저 보는 정보

- `DIRECT / ep1 lines 473-497`: 주인공 A의 일주일 칩거가 저택 구성원들에게 비정상적 변화로 인식되며, 평소에는 청소 확인과 닦달이 잦았다는 사실이 먼저 제시된다.
- `DIRECT / ep1 lines 511-591`: 친족 A가 하인들과 다른 접근·발언 권리를 행사하고, 주인공 A에게 거친 말을 해도 주변 하인들이 그 충돌 자체를 이례적 권리 구조로 받아들인다.
- `DIRECT / ep1 lines 553-569`: 주변 인물들은 주인공 A의 칩거와 발화를 약혼 관계의 파탄으로 해석한다. 독자는 이 해석을 먼저 받지만 아직 주인공의 실제 문제를 모른다.

### 독자와 주인공 A가 뒤늦게 공유하는 정보

- `DIRECT / ep1 lines 641-667`: 주인공 A의 실제 문제는 약혼 관계가 아니라 낯선 세계·신체에 갇혔다는 정체성 문제와 알려진 죽음 경로다.
- `DIRECT / ep1 lines 673-689`: 강연 참석은 직업 의무만이 아니라 정보 획득, 활동 재개, 생존 목표와 연결된다.
- `DIRECT / ep1 lines 727-757`: 신체에 결부된 성격·특성이 실제 감정과 행동 편의에 영향을 주며, 주인공 A는 기존 자아를 의식적으로 붙든다.

### 주인공 A만 알고 주변 인물은 모르는 정보

- 현재 의식이 기존 악역 인물 A와 다르다는 사실.
- 게임 지식상 자신에게 다수의 죽음 경로가 있다는 사실.
- 시스템의 생존 목표·사이드 과제·보상 자원.
- 칭찬이나 예절 같은 작은 행동조차 신체 성격과 기존 자아 사이의 충돌 결과일 수 있다는 사실.

### 의도된 초기 오해

- `DIRECT`: 저택 구성원과 친족 A는 주인공 A의 칩거를 약혼 관계 문제로 읽는다.
- `DIRECT`: 독자는 먼저 이 외부 해석과 기존 평판을 학습한 뒤, 1인칭 전환 이후 그것이 핵심 원인이 아니었음을 재분류한다.
- `SUPPORTED`: 이 순서 때문에 주인공의 현재 행동은 단순한 빙의자 독백이 아니라 이미 굳어진 사회적 평판과 충돌하는 행동으로 읽힌다.

## ep1 종료 시 독자 상태

독자는 다음을 안다.
- 주인공 A가 기존 악역 인물 A의 위치에서 살아남아야 한다.
- 주변 세계는 주인공 A를 과거의 평판·관계로 계속 분류한다.
- 신체 성격이 내부 판단에 실제 압력을 준다.
- 주인공 A는 칩거를 끝내고 직업 공간으로 복귀했다.

독자는 아직 모른다.
- 활동 재개가 실제 죽음 경로를 줄이는지 늘리는지.
- 외부 인물들이 현재 행동 변화를 어떻게 재평가할지.
- 시스템과 게임 지식이 현실에서 어느 정도 신뢰 가능한지.

## 후속 첫 제시·압축 회수 왕복 비교

이번 비교는 `SRC-DIRECT-001`의 ep235, ep269, ep275, ep318, ep350을 회차 전체로 직접 재독했다. 비교 목적은 ep1 표면을 작품의 기본 공식으로 만들지 않고, 독자가 이미 아는 것과 지금 새로 분류해야 하는 것에 따라 제시량과 순서가 어떻게 달라지는지 확인하는 것이다.

### ep235 — 기존 정체성 문제를 재온보딩하지 않고 새 판단 문제로 전환

- `DIRECT / lines 126557-126607`: 과거 자아 A의 직업과 세계 제작 경험은 짧은 설명과 독립 과제 UI로 회수된다. ep1의 일주일 혼란·죽음 경로·자기 이름 반복을 다시 설명하지 않는다.
- `DIRECT / lines 126619-126633`: 주인공 A는 과거 자아 A와 현재 신체 인물 A를 모두 자신의 일부로 말하고, 어느 한쪽에도 휘말리지 않겠다는 기준을 세운다. 신체 성격에서 비롯되었다고 인식하는 귀족적 확신과 책임도 현재 선택의 기준으로 사용한다.
- `SUPPORTED`: ep1에서 `과거 자아를 지키기 위해 신체 성격을 경계한다`는 문제가, ep235에서는 `둘을 모두 가진 현재 자신이 무엇을 선택할 것인가`라는 문제로 재분류된다. 같은 정체성 정보를 다시 가르치는 대신 달라진 판단 기준을 전경화한다.

### ep269 — 새 인물·직업·사회 질서를 권리와 업무 마찰로 첫 제시

- `DIRECT / lines 143235-143267`: 새 국가·귀족 구조는 필요한 범위만 짧게 제시되고, 새 인물 A의 휴일 출근 준비와 가족 대화로 곧바로 이동한다. 중요하지 않은 가문 목록은 서술자가 명시적으로 생략한다.
- `DIRECT / lines 143273-143389`: 새 인물 A의 직업은 직장 동료의 민원 정정, 현상수배 행동, 귀족 신분에 대한 주변의 거리 두기, 주인공 A 경호 업무 배정으로 구체화된다.
- `DIRECT / lines 143391-143399`: 이 인물의 현재 업무는 도난 사건의 긴급 소집으로 즉시 사건 동력에 연결된다.
- `SUPPORTED`: 독자는 새 인물의 성격 설명을 먼저 받기보다 `무슨 일을 스스로 하려 하는가 / 조직은 어디까지를 직무로 인정하는가 / 귀족 신분이 어떤 업무와 시선을 강제하는가`를 통해 판단 기준과 권리 경계를 학습한다. ep1의 `외부 오독 → 내부 진상` 배열은 반복되지 않는다.

### ep275 — 새 제도는 현재 장면의 권한만 이해할 만큼 압축

- `DIRECT / lines 146205-146217`: 새 박람회 등급·배정·승격 규칙은 세 문장의 설명으로 제시되고, 곧바로 주인공 A가 평가 권한을 가진 심사자라는 현재 역할과 대화로 연결된다.
- `DIRECT`: 회차는 제도 규칙을 완결된 백과사전처럼 확장하지 않고, 현재 행동과 권한을 이해하는 데 필요한 수준에서 멈춘다.
- `SUPPORTED`: `새 정보`라는 이유만으로 설명량이 커지지 않는다. 독자가 당장 판단해야 하는 것은 제도 전체가 아니라 현재 인물이 어떤 위치에서 평가권을 행사하는가이기 때문에 설명 범위가 좁다.

### ep318 — 이미 학습한 파국 규칙은 현재 적대 판단을 여는 두 문장으로 회수

- `DIRECT / lines 169915-169941`: 이미 알려진 장치 A의 파국 기능을 짧게 회수한 뒤 곧바로 `따라서` 관찰자 A의 의심·적대와 질문으로 전환한다.
- `DIRECT`: 장치 A의 설정을 재온보딩하는 대신, 주인공 A가 그 장치를 수리하는 현재 행동이 관찰자 A의 기존 인물 분류와 충돌한다.
- `SUPPORTED`: 압축 회수의 기능은 정보 전달 자체보다 `이미 아는 규칙 + 지금 보는 행동`의 모순으로 현재 인물 판단을 다시 여는 데 있다.

### ep350 — 오래된 정체성 정보는 이름 하나로 활성화되고 관계 해석으로 이동

- `DIRECT / lines 185227-185265`: 관찰자 A가 과거 자아 A의 이름을 한 번 말하고 주인공 A의 미세 반응을 검사한다. 긴 과거 설명 없이 이름 자체가 독자의 누적 지식을 호출한다.
- `DIRECT / lines 185277-185289`: 주인공 A는 반대로 관찰자 A의 과거 자아 이름을 사용한다. 이 정보는 현재의 긴급 상황과 사적 관계 판단을 동시에 연다.
- `DIRECT / lines 185409-185499`: 둘만 남은 대화에서 관찰자 A는 현재 고백을 `과거 자아 A가 과거 자아 B에게 하는 말`이 아니라 `현재 신체 인물 A가 과거 자아 B에게 하는 말`로 재분류한다.
- `SUPPORTED`: 작품 후반부의 정체성 회수는 `누가 누구인가`를 다시 설명하는 데 분량을 쓰지 않고, 이미 학습된 이름과 기억을 현재 관계의 소유권·감정 주체를 판정하는 데 사용한다.
- `HOLD`: 이 장면은 관찰자 A의 판정이므로 주인공 A가 과거 자아 기억을 완전히 잃었다고 확정하지 않는다.

## 작품 내부 비교 판정

- `CONTRADICTED`: ep1의 `외부 사회적 분류 → 오독 → 내부 진상 공개` 표면 배열이 REF-47의 모든 첫 제시에 반복되는 기본 템플릿이라는 가설.
- `SUPPORTED`: 작가는 독자가 **현재 새로 분류해야 하는 대상과 판단**에 필요한 정보는 확대하고, 이미 학습된 정보는 짧은 표지·행동·이름·결과로 압축 회수한 뒤 현재 선택과 관계 판단으로 이동한다.
- `SUPPORTED`: 첫 제시의 표면은 하나가 아니다. ep269는 새 인물의 권리·직무 마찰, ep275는 제도 속 현재 평가권, ep1은 사회적 인물과 내부 자아의 대규모 정보 비대칭을 각각 우선한다.
- `HYPOTHESIS`: 설명 밀도는 단순한 `새 정보/옛 정보` 구분보다, 현재 장면에서 잘못 분류했을 때 생기는 선택·관계 비용과도 함께 조절된다. 이 가설은 설명 부족으로 재설명·오판 비용이 발생하는 반례를 더 찾아야 한다.

## 작가 선택 가설

- `SUPPORTED`: ep1은 동시에 처음 배워야 할 층이 많다. 독자는 기존 사회적 인물, 현재 의식, 생존 위험, 신체 성격, 직업 복귀를 한 회차 안에서 분리해야 하므로 외부 그림과 내부 진상을 두 단계로 넓혀 제시한다.
- `SUPPORTED`: 후속 회차에서 같은 양의 설명을 반복하지 않는 이유는, 이미 확보된 독자 지식을 다시 가르치는 대신 그 지식을 **현재 인물의 선택·권리·의심을 판정하는 전제**로 재사용하기 위해서다.
- `HYPOTHESIS`: 이런 압축이 실패하는 장면, 즉 독자 선행 지식이 충분하지 않아 다시 설명하거나 다른 인물이 잘못 분류하는 비용이 발생하는 장면을 찾으면 메커니즘의 적용 경계를 더 좁힐 수 있다.
