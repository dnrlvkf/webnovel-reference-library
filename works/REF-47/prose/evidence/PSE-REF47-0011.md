# 반복 시계음이 독백을 끊고 질문에 대한 사물의 응답처럼 기능하는 배열

## 원문 재진입
- source scene: `SC-REF47-0011`
- source location: `SRC-DIRECT-001 / ep307 / lines 164109-164149`

## 장면 조건
- 주변의 시간이 멈춘 상태에서 초점 인물은 상황을 자기합리화하며 이동하려 한다.
- 말할 수 없는 사물 하나만 정상적으로 움직이며 해결 단서가 된다.

## 의미 단위와 채널 배분
1. 초점 인물이 상황을 가볍게 넘기려는 말을 한다. → 대사
2. 단발 시계음이 그 말을 끊는다. → 효과음
3. 초점 인물이 의문 반응을 보인다. → 짧은 대사/반응
4. 지문이 소리의 물리적 위치를 뒤늦게 특정한다. → 감각/행동 지문
5. 같은 시계음이 다시 난다. → 효과음
6. 지문이 움직이는 사물과 비정상 상태를 판정한다. → 관찰/판단 지문
7. 초점 인물이 사물에게 직접 질문한다. → 대사
8. 반복 시계음이 다시 이어진다. → 효과음

## 효과음 실현
- 첫 효과음은 정보 제공 전에 주의를 낚아채는 신호다.
- 이후 반복음은 질문 직후에도 배치되어, 실제 언어 답변이 없는 사물을 대화 상대처럼 기능하게 한다.
- 지문은 소리의 출처와 의미를 해석하지만, 질문-반복음 순서가 응답 감각을 만든다.

## 대사·지문과의 교차
- `말 → 소리 → 의문 → 행동 → 소리 → 판정 → 질문 → 소리` 순서다.
- 효과음을 지우고 사물 설명만 남기면 발견은 가능하지만, 초점 인물이 사물과 상호작용하는 턴 구조가 약해진다.

## 직접 확인과 해석
- DIRECT: 첫 소리가 자기합리화 발화 직후 등장하고, 이후 질문 뒤에도 같은 소리가 반복된다.
- SUPPORTED: 비언어적 대상이 정보를 전달하는 장면에서 반복 효과음은 `응답`과 유사한 대화 위치를 점유할 수 있다.
- HYPOTHESIS: 사물을 인격화하는 독자 감각까지 작가가 의도했는지는 확정하지 않는다.

## 원문을 다시 읽어야 하는 이유
효과음이 단순 소품 묘사가 아니라 대사의 빈 응답 자리를 채우고 있다는 점은 순서를 함께 읽어야만 보인다.
