# 대사 직후 환경음이 선언된 상태를 흔들고 새 판정을 여는 배열

## 원문 재진입
- source scene: `SC-REF47-0009`
- source location: `SRC-DIRECT-001 / ep228 / lines 123365-123415`

## 장면 조건
- 원격 대화 중 한 인물이 현재 장소의 상태를 짧게 판정한다.
- 그 판정 직후 외부 환경 변화가 시작되고, 변화 자체가 다음 관찰과 새로운 질문을 만든다.

## 의미 단위와 채널 배분
1. 상대가 장소 상태를 묻는다. → 대사
2. 초점 인물이 짧은 판정을 답한다. → 대사
3. 단발 환경음이 독립 블록으로 먼저 들어온다. → 효과음
4. 지문이 그 소리의 원인과 작은 물리 변화를 해석한다. → 환경 지문
5. 같은 계열의 소리가 반복되며 변화가 확대된다. → 효과음 반복
6. 초점 인물은 말없이 새 형상을 관찰한다. → 침묵/시선
7. 새로운 판정 질문이 나온다. → 대사
8. 환경음은 더 촘촘하게 이어지고, 대상은 다시 사라진다. → 효과음→환경 지문

## 효과음 실현
- 단발 → 2회 반복 → 3회 반복 → 더 촘촘한 연속음으로 밀도가 변한다.
- 효과음은 비의 존재를 설명하는 장식만이 아니라, 직전 대사의 정적 판정을 실제 장면 변화로 흔드는 첫 신호다.
- 지문은 효과음 뒤에서 소리의 원인과 시각적 결과를 해석한다. 따라서 `효과음 = 지문 대체`가 아니다.

## 대사·지문과의 교차
- 대사 직후 효과음이 오고, 독자는 초점 인물보다 먼저 혹은 동시에 환경 변화의 시작을 감각한다.
- 새 질문은 설명 지문이 아니라 소리→파문→형상이라는 연쇄 뒤에 발생한다.
- 마지막 연속음은 새 설명을 시작하기보다 생각 장면으로 넘어가는 배경 압력을 만든다.

## 직접 확인과 해석
- DIRECT: 효과음 반복 밀도가 환경 변화의 진행과 함께 증가한다.
- DIRECT: 효과음 뒤에 원인·결과 지문이 따라오므로 소리는 설명을 완전히 대체하지 않는다.
- SUPPORTED: 대사로 선언된 상태와 실제 환경 사이에 어긋남이 생길 때, 효과음을 먼저 배치해 판정 갱신의 감각적 시작점을 만들 수 있다.

## 원문을 다시 읽어야 하는 이유
효과음만 떼면 단순 빗소리 반복처럼 보이지만, 실제 기능은 `짧은 답변 → 감각적 균열 → 침묵 → 새 질문`의 순서를 만드는 데 있다.
