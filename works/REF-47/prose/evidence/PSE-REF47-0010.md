# 반복 금속음이 비언어적 거래 턴이 되어 추가 정보를 끌어내는 배열

## 원문 재진입
- source scene: `SC-REF47-0010`
- source location: `SRC-DIRECT-001 / ep269 / lines 143565-143609`

## 장면 조건
- 질문자는 상대가 가진 정보를 더 얻고 싶다.
- 상대는 처음에는 최소한만 답하며, 지불 행동이 반복될 때마다 정보 공개 범위를 넓힌다.

## 의미 단위와 채널 배분
1. 질문자가 대상 정보를 묻는다. → 대사
2. 상대는 모른다고 막는다. → 대사
3. 금속성 단발음이 독립 블록으로 들어온다. → 효과음
4. 지문이 작은 지불 행동을 확인한다. → 행동 지문
5. 상대가 첫 추가 단서를 준다. → 대사
6. 같은 효과음과 지불 행동이 반복된다. → 효과음→행동
7. 상대가 더 구체적인 단서를 공개한다. → 대사
8. 같은 구조가 한 번 더 반복되며 정보의 구체성이 증가한다. → 효과음→행동→대사

## 효과음 실현
- 같은 짧은 금속음을 같은 위치에 세 차례 반복한다.
- 반복은 단순 리듬 장식이 아니라 `비용 지불`이라는 비언어적 발화를 매번 독립 턴으로 만든다.
- 지문은 매번 지불 물체를 다시 확인하지만, 효과음이 먼저 와서 다음 대답이 돈과 교환된다는 관계를 즉시 감각시킨다.

## 대사 턴의 작동
- 질문자는 같은 요구를 장문으로 반복하지 않는다.
- 효과음+행동이 `더 말해라 / 더 지불하겠다`라는 발화 기능을 대신한다.
- 상대의 정보 공개는 효과음이 발생한 뒤 한 단계씩 확대된다.

## 직접 확인과 해석
- DIRECT: 동일한 효과음-행동-추가 답변 구조가 세 차례 반복된다.
- SUPPORTED: 물리적 행위가 상대의 다음 발화를 직접 바꾸는 거래 상황에서는 효과음이 비언어적 대화 턴으로 전경화될 수 있다.
- HYPOTHESIS: 반복되는 동일 음형이 거래의 단계를 독자가 별도 설명 없이 셀 수 있게 하는 효과까지 의도했는지는 추가 비교가 필요하다.
