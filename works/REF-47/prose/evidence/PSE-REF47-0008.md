# 최소 정정 뒤 설명보다 환경과 사건이 먼저 상대의 판단을 바꾸는 대화

- source scene: `SC-REF47-0008`
- source location: `SRC-DIRECT-001 / ep300 / lines 159995-160075`

## 장면 조건
- 집단이 이동 상황과 위협에 대해 잘못된 전제를 공유한다.
- 정정하는 인물은 불리한 위치에 있지만 현상을 더 정확히 알고 있다.
- 말만으로 설득하기보다 곧 확인 가능한 물리적 증거가 존재한다.

## 의미 단위와 채널 배분
1. 집단의 낙관적 판단이 대사로 나온다. → 대사
2. 정정자는 한 단어 수준의 부정으로 끊는다. → 대사
3. 상대가 무엇이 틀렸는지 잘못 재추론한다. → 대사
4. 정정자는 범위를 다시 좁힌 뒤 실제 이동 여부를 다시 묻는 질문을 던진다. → 대사/역질문
5. 장음 환경음이 먼저 들어와 주변 재관찰을 유도한다. → 효과음
6. 지문은 인물들이 주변을 다시 보고 기준점을 잃었다는 사실을 체감하게 한다. → 환경 지문
7. 정정자는 이제야 같은 곳을 맴돈다는 판정을 말한다. → 대사
8. 더 중요한 위협은 즉시 설명하지 않고 카운트다운과 실제 희생 사건으로 먼저 증명한다. → 대사→효과음/사건
9. 충격음 뒤 지문이 사건 결과를 확인하고, 증명 뒤에야 위협의 작동 방식을 설명한다. → 효과음→사건 지문→대사
10. 상대는 자기 몸을 확인하고 침묵한다. → 행동→침묵

## 대사 턴의 작동
- 정정자는 처음부터 완성된 설명을 하지 않는다.
- 질문이 상대의 시선을 환경으로 돌리고, 환경 관찰이 첫 재판정을 만든다.
- 두 번째 핵심 정보는 사건이 먼저 증명한 뒤 설명되므로, 발화가 독자용 예고문이 아니라 이미 바뀐 상태의 해석이 된다.

## 효과음 실현
- 첫 장음 환경음은 정정 대사와 구체 설명 사이에 들어가 상대가 주변을 다시 보게 만드는 감각적 단서다.
- 같은 환경음이 한 번 더 길게 반복된 뒤에야 주변 재관찰이 명시된다.
- 카운트다운 끝의 충격음은 위협 설명보다 먼저 실제 피해를 사건으로 확정한다.
- 효과음 뒤에는 원인·결과 지문이 이어지므로 소리는 지문을 대체하기보다 `먼저 듣게 하는 증거`로 기능한다.

## 지문 덩어리
- 지문은 `주변을 다시 봄`, `기준점 부재`, `물리적 희생`, `몸을 확인함`처럼 말로 대신할 수 없는 증거를 맡는다.
- 설명과 증명이 중복되지 않고 `질문 → 소리/체감 → 판정 → 카운트다운 → 소리/사건 → 해석` 순서로 분산된다.

## 직접 확인과 해석
- DIRECT: 첫 정정은 최소 발화이고, 환경음과 재관찰 뒤에 구체적 설명이 나온다.
- DIRECT: 두 번째 위협은 카운트다운과 충격음/사건 뒤에 작동 원리가 설명된다.
- SUPPORTED: 상대의 믿음을 바꿀 직접 증거가 곧 발생하는 조건에서는 설명을 뒤로 미루고 질문·효과음·사건이 먼저 기능할 수 있다.
