# 판단을 대화로 좁힐 때 무엇을 말하고 무엇을 말하지 않는가

## 공통 표현 문제
한 인물이 계획·사실·추론을 제시하고 다른 인물이 그것을 수정하거나 좁혀야 할 때, 모든 논리 단계를 완성된 설명 대사로 만들지 않고 대사·행동·지문·침묵·사건 증명에 나누어 배치한다.

## 비교 PSE
| PSE | 대사의 주된 역할 | 지문/행동의 역할 | 말하지 않은 것 |
|---|---|---|---|
| `PSE-REF47-0005` | 계획 추론, 기술 반론, 가치 프레임 전환, 대안 질문 | 계획을 먼저 노출하는 행동, 비공개 동기·위험 환경 | 계획자의 상세 논박; 마지막 질문 뒤 반론 |
| `PSE-REF47-0006` | 맞고 틀린 범위의 사회적 판정, 남은 비용 제시 | 수정된 기술 인과 압축, 시선 배치 | 현재 관찰의 세부 결론 |
| `PSE-REF47-0007` | 질문, 역질문, 감각 근거, 인정, 설명 의무 차단 | 증거의 실제 원인, 순간 반응 | 두 번째 추론의 근거 |
| `PSE-REF47-0008` | 최소 정정, 역질문, 사건 뒤 해석 | 환경 재관찰, 물리적 증명, 행동 반응 | 증명 전 완성 설명 |

## 공통 조건
- 대사는 독자에게 정보를 전달하는 것만으로 끝나지 않고 상대의 다음 질문·침묵·행동·판정을 바꾼다.
- 지문은 대사에서 이미 설명한 내용을 반복하기보다 인물 간 공유되지 않은 정보, 반응, 기술 인과, 물리적 증거를 맡는다.
- 중요한 논리 단계 일부는 의도적으로 말하지 않고 상대의 추론·환경·후속 사건에 맡긴다.

## 실제 변형 축
- 답변 방식: 직접 답변 ↔ 행동으로 답변 ↔ 역질문 ↔ 최소 정정 ↔ 답변 거부.
- 증거 제시: 화자 설명 ↔ 상대가 행동에서 추론 ↔ 감각 근거 ↔ 환경 관찰 ↔ 실제 사건.
- 설명 위치: 대사 안 ↔ 지문 압축 ↔ 증명 뒤 후행 설명 ↔ 완전 생략.
- 종료 방식: 동의 ↔ 침묵 ↔ 화제 전환 ↔ 역할 지시 ↔ 자기 몸/환경 확인.
- 지문 간격: 매 턴 반응 지문 ↔ 기술 인과 한 번 삽입 ↔ 환경 블록을 길게 둔 뒤 다음 대사.

## 선택 조건 판정
- SUPPORTED: 네 장면 모두 핵심 판단 이동을 대사만으로 완결하지 않고 다른 채널에 분산한다.
- SUPPORTED: 상대의 다음 선택을 바꾸는 발화는 `질문`, `범위 정정`, `근거 제시`, `역할 전환`처럼 상호작용 기능을 가진다.
- HYPOTHESIS: 상대가 행동만 보고 계획을 추론할 수 있을 때는 설명을 행동으로 선행시키는 경향이 있을 수 있다.
- HYPOTHESIS: 기술 메커니즘이 대화의 사회적 쟁점보다 중요도가 낮을 때 지문 압축으로 빠질 수 있다.
- SUPPORTED: 곧 확인 가능한 물리적 증거가 있는 장면에서는 설명보다 관찰/사건을 먼저 배치하는 사례가 존재한다.

## 반례와 실패 경계
- 대사를 늘린다고 자동으로 장면화되는 것은 아니다. 상대가 묻지 않아도 될 사실을 질문하고 화자가 독자용 설명을 답하면 지문 설명을 따옴표 안으로 옮긴 것뿐이다.
- 반대로 모든 기술 설명을 지문으로 빼면 대화의 판정권·책임·체면 변화가 사라질 수 있다.
- 현재 표본은 주로 추론·판정·위험 장면이며, 정서적 고백·협상·일상 대화에서 같은 분배 원리가 유지되는지는 미확인이다.

## 고정 공식으로 압축하면 사라지는 것
`질문 → 답변 → 설명 지문`으로 만들면, 행동이 답이 되는 장면, 역질문으로 정보 수준을 측정하는 장면, 침묵이 반론 종료가 되는 장면, 사건이 설명보다 먼저 증명하는 장면의 차이가 모두 사라진다.

## 집필 검색 질문
- 상대가 이미 행동만으로 알아낼 수 있는데 화자가 굳이 설명하고 있지 않은가.
- 이 대사는 상대의 다음 판단이나 행동을 실제로 바꾸는가.
- 지문이 방금 대사를 다시 풀어 쓰고 있지는 않은가.
- 기술 인과를 누가 실제로 말할 이유와 권리를 가지는가.
- 지금 설명하지 않고 질문·침묵·환경·사건에 맡겨도 되는 단계는 무엇인가.
