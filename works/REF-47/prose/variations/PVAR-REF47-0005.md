# 이미 아는 정보의 현재 의미를 다시 분류할 때 무엇을 길게 풀고 무엇을 짧게 끊는가

## 공통 기능 또는 가까운 표현 문제

독자에게 이미 알려진 사건·정체성·관계가 현재 장면에서 그대로 사용할 수 없을 때, 전체 과거를 재설명하지 않고 **이번에 틀어진 연결부**를 다시 분류한다. 세 사례 모두 `새 설정 소개`가 아니라 누적 정보를 현재 인과·기억·관계 주체에 다시 붙이는 문제다.

|---|---|---|---|

## 공통 조건

- reader prior knowledge 자체는 충분하다.
- 그러나 현재 판단에 필요한 `원인`, `체험 연속성`, `관계 발화 주체` 중 하나가 기존 정보와 호환되지 않는다.
- 작가는 과거 설정 전체를 동일한 분량으로 되풀이하지 않고, 현재 선택·관계 권리와 직접 충돌하는 연결부를 다시 연다.

## 달라진 조건

- ep328: 잘못된 것은 사건 사실이 아니라 **관찰자 A의 원인 해석**이다.
- ep331: 잘못된 해석보다 **현재 인물의 체험 기억 부재**가 문제다. 독자가 아는 관계를 당사자에게 자동 이전할 수 없다.
- ep350: 과거 기억을 복원하는 문제가 아니라 **현재 누가 그 관계의 말을 소유하는가**가 문제다.

## 실제 변형 축

- 절 결합: 과거 추론 반복 ↔ 시간·정체성 인과 블록 ↔ 짧은 부정/긍정 관계 대비.
- 조사·부사: `예전에는/이제`의 시간·판정 대비 ↔ 현재/과거 인물 슬롯의 지시 대비 ↔ 관계 주체/상대 슬롯의 대조.
- 연결·접속: `-는 줄 알았다` 반복 ↔ `그렇기에/하지만/따라서` 계열 인과 전개 ↔ `-가 아니라`, `-니까` 계열의 현재 분류 대조.
- 시제·상·양태: 과거 오독 회고→현재 재판정 ↔ 현재 질문 속 과거 10년의 체험 비교 ↔ 과거 감정 고백→현재 관계 소유권 판정.
- 종결: 반복 과거판정 ↔ 짧은 질문과 장문 자기판정 ↔ 짧은 정체 대비와 최소 응답.
- 문장 경계: 동일 방향의 오독을 여러 독립문으로 쌓음 ↔ 짧은 질문 뒤 이해 비용을 긴 블록에 결속 ↔ 하나의 관계 재분류를 여러 짧은 대비문으로 분해.
- 문단 경계·모바일 블록: 전환문을 작게 고립 ↔ 질문/지문 블록의 크기 대비 ↔ 이름·고백·정체 판정·응답을 짧은 화면 블록으로 수렴.

## 선택 조건 판정

- `DIRECT`: 같은 `누적 정보 재분류` 문제라도 ep328, ep331, ep350의 문장·문단 실현은 서로 다르다.
- `SUPPORTED`: **무엇이 빠졌는가**가 표면 차이를 설명한다. 원인 모델이 틀리면 과거판정과 현재판정을 대비하고, 체험 기억이 없으면 판단에 필요한 시간·정체성 맥락을 크게 묶으며, 관계 주체만 바뀌면 누적 설명을 다시 열지 않고 짧은 대조로 주체를 재배정한다.
- `SUPPORTED`: 오분류 비용이 크다고 반드시 문장이 길어지는 것은 아니다. ep350의 관계 비용은 크지만 누적 선행 지식이 충분해 재분류 문장 자체는 짧다.
- `HYPOTHESIS`: 현재 인물의 독자적 선택이 아직 없고 외부에서 정보만 주입되는 경우에는 어떤 크기의 재온보딩이 필요한지 추가 비교가 필요하다.

## 반복 표면과 반복 붕괴

- 짧은 독립문은 ep328의 전환과 ep350의 주체 대비에 모두 나오지만 기능이 다르다. 하나는 **판정 시점 전환**, 다른 하나는 **관계 주체 분리**다.
- 긴 지문 블록은 ep331에서 필요하지만 ep350에서는 오히려 과거 관계를 재설명하지 않는 편이 작동한다.
- 따라서 `중요한 재분류는 짧게 쓴다`나 `기억 문제는 길게 설명한다` 같은 길이 규칙으로 압축할 수 없다.

## 반례·미설명 변형

- 기존 reader information의 ep318은 이미 학습된 파국 규칙을 짧게 호출해도 현재 적대 판단이 바로 열린다. 기존 규칙과 현재 분류 과제가 호환되므로 재온보딩 확대가 필요하지 않은 반례다.
- ep275도 새 제도 자체는 짧게 설명되지만 현재 평가권을 이해하는 데 충분했다. `새 정보 = 긴 설명`은 성립하지 않는다.
- 아직 `압축이 실제 독자 혼란을 만들어 후속 회차에서 작가가 명시적으로 재설명하는` 사례는 별도 확인이 필요하다.

## 고정 문형으로 압축하면 사라지는 것

`오해 수정 = 과거판정 반복`, `정체성 = 긴 지문`, `관계 재분류 = 짧은 대조문`으로 공식화하면 각 사례의 reader prior knowledge와 현재 판단 문제가 사라진다. 필요한 것은 문형이 아니라 **현재 독자/인물에게 빠진 연결이 무엇인지 판정한 뒤 그 연결만 다시 열어 주는 선택**이다.
