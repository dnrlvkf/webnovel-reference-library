# 효과음이 대사·지문·행동 사이에서 어떤 업무를 맡는가

## 공통 기능 또는 가까운 표현 문제
물리적 소리가 존재하는 장면에서 그 소리를 단순 사실 묘사로 처리하지 않고 독립 효과음 블록으로 전경화할지, 반복해 비언어적 턴이나 증거로 쓸지, 혹은 아예 효과음을 생략하고 행동 지문에 흡수할지 선택한다.

|---|---|---|---|
| `PSE-REF47-0009` | 짧은 상태 판정 직후 환경 변화가 시작됨 | 단발 환경음이 점차 반복·밀도 증가 | 대사 판정 → 소리 → 환경 해석 → 침묵/새 질문 |

## 공통 조건
- 효과음은 실제 물리 소리의 존재만을 기록하는 장식이 아니다.
- 독립 효과음 뒤에는 소리의 원인·결과를 해석하는 지문이 자주 이어지므로 `효과음 = 지문 대체`로 일반화할 수 없다.
- 효과음이 대사 사이에 놓일 때는 상대의 다음 질문·답변·판정·행동을 바꾸는 턴 역할을 할 수 있다.

## 실제 변형 축
- 전경화: 독립 효과음 블록 ↔ 행동 지문 내부 흡수/효과음 생략.
- 순서: 효과음 → 원인 설명 ↔ 대사/행동 → 효과음 ↔ 질문 → 효과음 응답.
- 반복: 단발 ↔ 동일음 반복 ↔ 점층적 밀도 증가 ↔ 장음/충격음 전환.
- 대화 기능: 비언어적 요구, 응답 유사 기능, 판정 균열, 사건 증명, 장면 종료 신호.
- 지문 기능: 소리의 원인 특정, 시각적 결과, 기술적 의미 해석, 행동 확인.

## 선택 조건 판정
- DIRECT: 같은 작품 안에서 효과음이 거래 턴·환경 증거·사물 응답·장면 전환점으로 서로 다르게 배치되고, 인접 회차의 유사 행동에서는 효과음이 생략된다.
- SUPPORTED: `효과음을 넣을지`는 소리가 실제로 나는지보다 그 소리를 독자가 독립 사건/응답/증거/전환으로 먼저 받아야 하는지와 관련된다.
- HYPOTHESIS: 대사가 이미 핵심 전경을 차지할 때 부수 동작의 효과음을 덜 독립시키는 경향이 작품 전체에 지속되는지는 추가 반례가 필요하다.

## 반복 표면과 반복 붕괴
- 반복음은 여러 장면에서 보이지만 기능은 거래 단계, 환경 진행, 사물 응답처럼 서로 다르다.
- 따라서 `효과음은 반복하면 리듬이 산다`는 실행 규칙은 만들지 않는다.
- 직전 회차에 효과음이 있던 유사 수납 행동이 다음 회차에서는 소리 없이 처리되어, 물리행동별 고정 효과음 대응도 무너진다.

## 반례·미설명 변형
- 강한 충격·전투 장면인데도 효과음을 생략한 사례의 체계적 표본은 아직 부족하다.
- 대사와 효과음이 완전히 같은 문장 안에 결합되는 사례, 코믹 효과음과 정서적 효과음의 차이는 미조사.
- 동일 음형의 철자·장음표·문장부호 선택 자체를 스타일 규칙으로 확정하지 않는다.

## 고정 공식으로 압축하면 사라지는 것
`동작이 있으면 효과음을 넣는다`, `대사 사이에는 효과음을 넣어 리듬을 만든다`, `효과음으로 지문을 줄인다`로 컴파일하면 원문의 핵심 대비가 사라진다. 중요한 것은 소리 자체보다 **그 소리를 독립 정보 턴으로 전경화할 이유가 있는가**다.

## 연결 PROSE 모델과 갱신 후보
- `PRO-REF47-0003`: 효과음은 감각 장식이 아니라 대사·행동·지문 사이에서 사건·응답·증거·전환을 전경화하는 선택 슬롯이라는 모델 후보.
