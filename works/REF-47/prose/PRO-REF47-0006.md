# 누적 정보가 현재 판정과 어긋나면 전체 설정을 반복하지 않고 어긋난 인과·기억·관계 주체만 다시 확대한다

## 적용 조건

장기 연재에서 독자가 이미 인물·사건·정체성·관계를 알고 있지만, 현재 장면의 판단에 그 정보가 그대로 호환되지 않는 경우. 특히 과거 원인 해석이 틀렸거나, 현재 인물이 관계를 만든 체험 기억을 잃었거나, 같은 이름을 가진 현재 주체가 과거 관계 권리를 그대로 소유하지 않는 장면.

## reader prior knowledge와 재온보딩 경계

- `SUPPORTED`: 독자 선행 지식은 압축의 충분조건이 아니다. **현재 분류 과제, 인과 모델, 관계 주체/기억 연속성**이 기존 지식과 호환되어야 압축 회수가 그대로 작동한다.
- 호환되지 않으면 작가는 과거 설정 전체를 다시 가르치지 않고, 현재 선택이나 관계 권리를 잘못 판단하게 만드는 연결부만 재확대한다.
- ep297-298은 과거 관계의 사실보다 이탈 원인의 오해를 길게 다시 열고, ep320/331은 현재 인물에게 없는 체험 기억을 별도 문제로 만든다. ep350은 과거 관계사를 재설명하지 않고 현재 발화 주체만 짧게 다시 붙인다.

## 지문 운용

- 재확대 지문은 `전에 이런 일이 있었다`는 요약보다 **왜 과거 판정이 지금은 틀리는가**를 맡는다.
- 과거 인과 모델이 문제일 때는 과거 믿음과 현재 관찰을 비교하는 회고 지문이 늘어난다.
- 체험 기억이 문제일 때는 시간 차이·정체성 위험·관찰 증거를 여러 문장 블록으로 결속해 현재 선택의 이해 비용을 처리한다.
- 관계 주체만 다시 정해야 할 때는 장기 과거 설명을 반복하지 않고 신체 반응과 짧은 내적 판정만 남긴다.

## 문장 경계 운용

- ep328: 동일한 과거 오독을 `-는 줄 알았다` 계열의 독립문들로 누적하고, 짧은 현재 전환문을 별도 경계로 세운다.
- ep331: 짧은 가치 질문을 독립시킨 뒤 답변 사이에 시간·정체성·자기관찰을 긴 지문 블록으로 넣어, 질문 한 줄이 호출하는 판단 범위를 확장한다.
- ep350: 과거 자아와 현재 주인공 A를 구분하는 짧은 부정/긍정 판정, 과거 관계 발화와 현재 관계 발화를 구분하는 대조를 연속 독립문으로 분리한다.
- `SUPPORTED`: 문장 길이는 정보 중요도와 일대일 대응하지 않는다. **어떤 판단 경계를 독자가 하나씩 다시 붙여야 하는가**가 결속/분절을 더 잘 설명한다.

## 문단·화면 블록 운용

- 과거 오독 수정은 `회고 블록 → 짧은 전환 → 새 평가 블록`으로 움직인다.
- 기억 연속성 문제는 `짧은 질문 → 긴 판단 블록 → 관찰 행동 → 자기판정`처럼 블록 크기의 대비가 크다.
- 관계 주체 재배정은 이미 긴 선행 축적이 있어 이름·고백·짧은 정체 대비·최소 응답을 작은 화면 블록으로 수렴시킨다.
- 사고 단위, 문장 단위, 화면 문단은 일치하지 않는다. 하나의 `재분류` 사고가 여러 짧은 문장으로 쪼개지거나, 반대로 여러 판단 재료가 한 지문 블록으로 결속될 수 있다.

## 대사와 지문의 업무 분담

- 정체 주장·질문·고백은 대사가 관계 권리의 시험을 연다.
- 지문은 대사에 이미 나온 이름을 재설명하기보다 상대가 그 이름을 어떤 현재 주체·원인·기억과 연결하는지 보여 준다.
- 최종 상태는 설명문만으로 닫지 않고, 비격식 발화 시험, 질문 거부, 사적 공간 형성, 신뢰 수용, 기록 전달 같은 후속 행동으로 검증된다.

## 작동 결과

독자는 `이 이름/사건을 이미 안다`에서 멈추지 않고 **지금 이 정보가 누구의 현재 선택과 권리에 어떤 의미를 갖는가**를 다시 판정한다. 과거 정보를 통째로 반복하지 않으면서도 장기 연재에서 의미가 변한 부분을 놓치지 않게 된다.

## 대표 근거

- `PSE-REF47-0018`: 과거 사실은 유지하되 잘못된 원인 모델만 반복 과거판정과 짧은 전환문으로 수정.
- `PSE-REF47-0017`: 독자가 아는 10년 관계를 현재 인물에게 자동 이전하지 않고, 짧은 질문 사이 긴 정체성/관찰 블록으로 체험 공백을 처리.
- `PSE-REF47-0019`: 과거 이름과 관계사를 다시 설명하지 않고 짧은 부정/긍정 대비로 현재 발화 주체와 관계 소유권을 재배정.
- variation: `PVAR-REF47-0005`.

## 실패 경계

- `중요한 정보는 다시 길게 설명한다`는 규칙이 아니다. ep350은 관계 비용이 크지만 재분류 핵심은 짧다.
- `독자가 기억하면 설명하지 않는다`도 아니다. ep297-298처럼 독자가 사실을 알아도 기존 인과 모델이 현재 판정에 부족하면 다시 확대한다.
- `같은 이름이면 과거 관계의 말투·접근·보호 권리가 돌아온다`는 전제를 두지 않는다.
- 고유 이름·회상 장면·짧은 대조문을 표면 템플릿으로 가져오지 않는다. 현재 작품에서 먼저 누락된 연결 종류를 판정한다.

## 다음 질문

재분류가 성공한 뒤 새 정보·접근·보호·거절 권리가 후속 사건에서 실제로 유지되는지, 또는 긴급 상황이 끝나면 다시 이전 관계 경계로 복귀하는지를 추적한다.
