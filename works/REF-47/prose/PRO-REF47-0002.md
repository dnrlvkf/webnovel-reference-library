# 대사와 지문은 같은 정보를 나누는 것이 아니라 서로 다른 판단 업무를 맡는다

## 적용 조건
두 명 이상이 같은 사실·계획·위험을 두고 판단을 좁히는 장면. 핵심은 정보 전달량이 아니라 누가 무엇을 말할 이유와 권리를 가지며, 어떤 발화가 상대의 다음 반응을 실제로 바꾸는가에 있다.

## 대사 운용
- 질문은 단순 정보 요청뿐 아니라 상대의 정보 수준 측정, 대안 존재 여부 검사, 시선/판단 전환에 쓰인다.
- 답변은 항상 완성 설명이 아니다. 행동, 침묵, 역질문, 범위 정정, 화제 전환이 답변 기능을 대신한다.
- 장문 대사는 정보량 때문에 자동으로 길어지는 것이 아니라 상대의 프레임을 다른 판단 기준으로 바꿔야 할 때 길어질 수 있다.
- 상대가 이미 알 수 있는 정보는 화자가 다시 설명하지 않는 사례가 있다.

## 지문 운용
- 대화 상대에게 공개할 필요 없는 POV 내부 이유.
- 대사에 넣으면 강의가 되는 기술적 인과의 압축.
- 대사의 수용 여부를 보여 주는 시선·침묵·행동.
- 말보다 먼저 믿음을 바꾸는 환경·사건 증명.
- 같은 내용을 대사 뒤에서 한 번 더 해설하는 용도는 대표 표본에서 중심 기능이 아니다.

## 대사·지문 배열
`발화 → 해설` 하나로 고정되지 않는다.
- 행동 → 상대의 추론 대사 → 반론 → 질문 → 침묵.
- 판정 대사 → 기술 지문 → 남은 문제 대사 → 미완 발화.
- 질문 → 역질문 → 근거 대사 → 지문 확인 → 인정/화제 전환.
- 최소 정정 → 역질문 → 환경 관찰 → 판정 대사 → 사건 → 후행 설명.

## 작동 결과
독자는 완성된 설명을 받기보다 인물들이 서로의 정보·권리·판단을 시험하는 과정을 따라가며 결론을 갱신한다. 설명이 필요한 경우에도 그 설명은 대화의 모든 논리를 대신하지 않고, 상호작용이나 물리적 증명 사이에 필요한 만큼만 배치된다.

## 대표 근거
- `PSE-REF47-0005`: 행동이 계획 설명을 대체하고 마지막 질문이 침묵을 만든다.
- `PSE-REF47-0007`: 질문권/답변 의무가 같은 장면에서 역할에 따라 뒤집힌다.

## 대비 근거
- `PSE-REF47-0006`: 기술 인과는 지문, 사회적 판정은 대사.
- `PSE-REF47-0008`: 환경·사건이 설명보다 먼저 믿음을 바꾼다.

## 미확인
- 정서 고백, 친밀한 일상 대화, 장기 협상에서도 같은 분배가 유지되는지 미확인.
- 인물별 고정 말투 규칙으로 일반화하지 않는다.

## 집필에 사용할 판단
설명조가 강해졌을 때 `지문을 대사로 바꿀까`를 먼저 묻지 않는다. 먼저 각 의미 단위에 대해 `누가 말할 이유가 있는가`, `상대가 이미 추론할 수 있는가`, `이 발화가 다음 반응을 바꾸는가`, `행동·침묵·환경이 더 직접적인 증거인가`를 판정한다.
