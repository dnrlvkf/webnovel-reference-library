# 주인공 A · 1~80화 판단 지도

## 현재 판정

주인공 A를 `게임 지식으로 모든 것을 아는 냉정한 생존자`로 고정하면 초반 원문과 충돌한다.

1~80화의 핵심 변화는:

`게임 공략 최적화`
→ `현실 사망 위험 때문에 생존 역할 재설계`
→ `선행 지식을 현장 검증 가설로 낮춤`
→ `주어진 위험에 반응하는 것만으로는 부족하다는 강제 패배`
→ `통제 가능한 위험을 먼저 설계`
→ `공식 리더가 기능을 잃으면 생존 지휘 인수`
→ `제도·타인·자기 직감도 틀릴 수 있음을 비용으로 학습`
→ `파티·성장·분배·비밀을 권리 단위로 관리`
→ `현대인 윤리와 현지 재위협 계산이 충돌`
→ `공개 역할 수행이 실제 명성·감시·의뢰권으로 굳어짐`

이다.

그의 강점은 정답 보유량보다 **현재 정보의 신뢰도·실패 비용·가역성에 따라 행동 강도를 조정하고, 결과가 틀리면 판단 모델을 다시 쓰는 것**에 있다.

## 무엇을 먼저 확인하는가

- 지금 죽을 수 있는가.
- 현재 정보가 게임 데이터인지, 직접 관찰인지, 타인의 주장인지.
- 실패했을 때 손실이 회복 가능한가.
- 상대의 말보다 실제 행동·비용·이탈 선택이 무엇인가.
- 지금 누가 실제 기능을 수행할 수 있는가.
- 계약·소유·신체·성장·비밀 중 어떤 권리가 문제인지.

## 생존 기준의 변화

### 1~21화 · 살아남기 위해 취향과 정체를 버린다

게임에서는 고화력 무기를 선호했지만 실제 죽음 가능성이 생기자 방패를 고른다. 현지 전사 역할도 정체 은폐를 위해 연기한다.

이때 생존은 `최대한 강한 선택`이 아니라:

- 죽을 확률을 낮추고
- 실패해도 다음 행동이 남으며
- 정체 노출을 막는

선택의 묶음이다.

### 22~27화 · 반응형 생존의 한계를 인정한다

불안정 포탈을 효율적으로 이용해도 더 강한 약탈자에게 잡히면 선택권이 사라진다.

주인공 A는 이 패배를 `운이 나빴다`로 끝내지 않고:

> 상대가 만든 판에 들어가 최선의 대응만 해서는 언젠가 진다.

로 재판정한다.

이후 강제 균열처럼 자신이 위험의 형태를 먼저 고르는 능동 전략으로 이동한다.

### 31~40화 · 기능이 있으면 지휘권을 잡되 권리를 다 가져가지는 않는다

공포와 현실감 때문에 공식 리더·전문가가 기능을 잃으면 생존 지휘를 맡는다. 그러나 구조 공로와 전리품 소유권을 동일시하지 않는다.

반대로 제도가 잘못 판정하면 제도 자체를 부정하는 대신 공개 증거·관중·재검증 절차를 이용해 잘못된 판정 비용을 높인다.

## 지식과 오판

### 선행 지식은 출발점

게임 데이터는 몬스터 패턴·아이템·성장 조합에서 강력하다. 하지만 다음이 반복해서 붙는다.

- 실제 몸의 통증·공포·시야·동작 오차
- 약 150년의 사회·제도 변화
- 게임에 없던 현실 추가 효과
- 다른 인간의 선행 행동
- 현지 전문가의 축적 경험

따라서 `알고 있음`은 행동 개시권을 주지만 최종 판정권은 현장에 남는다.

### 자기 오판도 비용으로 남긴다

- 인간 배신 뒤 종족 일반화를 했다가 개인 행동으로 수정.
- 반복 성공 뒤 보스 단서를 늦게 보고 과신을 자각.
- 숨은 보스 조건에서 다른 사람의 선행 희생을 고려하지 못해 대형 위기를 촉발.
- 대형 조직을 무모한 탐욕으로 봤다가 비축·준비를 보고 기대값 전략으로 수정.
- 낯선 사람의 배신을 맞힌 뒤에는 그 성공을 `직감`으로 과대 기억하는 자기합리화도 보인다.

따라서 제한 1인칭의 판단은 항상 작품의 객관 진실이 아니다.

## 관계와 권리

### 계약을 신뢰보다 먼저 쓴다

초기 동행은 9:1 분배처럼 조건을 먼저 적는다. 친밀감이 생겨도 이전 약속을 없애지 않고, 다음 관계에서는 새 조건을 따로 협상한다.

### 도움과 강제는 함께 존재할 수 있다

주인공 A는 자기 신체·성장 슬롯에 타인이 동의 없이 개입하면 큰 손해로 계산한다.

그러나 59~60화에는 장기 성장 동료 A의 생존·성장 가능성을 크게 올리는 독점 수단을 쓰면서 충분한 사전 설명 없이 신체·장비에 개입한다.

따라서:

> 자기 선택권을 중시한다 = 타인의 선택권을 항상 같은 방식으로 존중한다

는 아직 성립하지 않는다.

77화에는 무기 변경을 강하게 설득하지만 제3자가 `선을 넘는다`고 지적하자 당사자가 최종 선택이 자기 것이라고 확인한다. 향후 강한 설득과 실제 강제의 경계를 계속 추적한다.

### 동료는 투자 대상이면서 구조 주체다

강한 정수를 자기보다 동료에게 주고, 장기 성장 설계를 직접 짠다. 동시에 61화 이후에는 정신 현혹에 걸린 자신이 동료에게 구조된다.

`주인공이 일방적으로 보호하는 파티`가 아니다.

## 윤리 판단의 이동

64화는 중요한 전환점이다.

과거 세계 기준:
- 한 번의 잘못만으로 사람을 죽이는 것이 옳은가.

현재 세계 기준:
- 이미 자신을 죽이려 했고 다시 위협할 확률이 높은 상대를 살려 두는 비용은 무엇인가.

주인공 A는 현재 위험을 우선해 제거한다.

하지만 죽인 뒤 상대를 `원래부터 절대악이었다`고 다시 쓰지 않는다. 즉 현지 생존 규칙을 선택하면서도 자기 선택의 불편함을 없애지는 않는다.

## 역할 연기와 실제 정체성

현지 전사 역할은 처음에는 처형 회피용 가면이다.

그러나:

역할 연기
→ 실제 전투 책임
→ 동료 구조
→ 공개 위기에서 다수 생존 통로 수행
→ 사회적 이명·명성
→ 공식 의뢰·기관 신뢰

가 누적된다.

75화에는 그 명성을 이용해 공개적으로 `현지 전사라면 할 행동`을 연기해 정체 감시를 역이용한다.

즉 역할은 거짓말이면서 동시에 실제 행동 이력이 만든 사회적 정체가 된다.

## 감정·피로의 변화

초반에는 거의 모든 인간관계를 생존 비용으로 계산한다.

78화에는 이전 동료가 `독기가 줄고 여유가 생겼다`고 외부에서 관찰하고, 주인공 A 자신도 모든 호의를 계산하며 관계를 관리하는 데 피로를 느낀다.

그는 이를 곧바로 `좋은 성장`으로 받아들이지 않고 생존에 불리한 감성 회복 가능성으로 경계한다. 그러나 감정을 삭제하거나 고립을 선택하지도 않는다.

현재 판정은 `냉혹함이 약해졌다`가 아니라 **생존 안정이 올라가면서 효율 계산 외의 욕구가 다시 의식에 들어오기 시작했다** 정도다.

## 명성의 양면성

65~80화에서 명성은:

- 구조받은 사람의 감사
- 공식 승급·의뢰 접근
- 추천과 사회적 신뢰
- 연구자의 관심
- 비밀 치안 조직의 감시
- 외부 인격 공동체의 초대

를 동시에 연다.

따라서 주인공 A는 명성을 순수 보상으로 보지 않는다. `공개 역할을 수행해야 살아남음`과 `유명해질수록 정체 위험이 커짐`이 함께 존재한다.

## 1~80화 장기 판단 사슬

즉사 위험
→ 역할 가면·방패 선택
→ 게임 지식의 현실 검증
→ 계약 기반 임시 동행
→ 강제 패배와 선택권 상실
→ 능동 위험 설계
→ 실전 지휘권 획득
→ 제도 오판을 공개 절차로 수정
→ 한정 성장 슬롯·신체권 자각
→ 역할형 파티와 결함 공개
→ 장기 성장 동료에게 강제성 있는 투자
→ 현대 윤리와 현지 생존 규칙 충돌
→ 대형 위기에서 기능 거래·다수 구조
→ 명성·감시·공식 의뢰가 동시에 발생.

## CONTRADICTED / HOLD

### CONTRADICTED

- `게임 지식이 있으면 현실 변수까지 자동으로 안다.`
- `항상 최악의 숨은 상태까지 가정한다.`
- `공식 지위가 높은 사람이 언제나 현장 지휘권을 가진다.`
- `도움을 크게 주면 상대 권리를 자동 존중한다.`
- `동일한 외부 인격 범주면 자동 연대한다.`
- `명성은 순수한 사회적 보상이다.`

### HOLD

- 타인의 신체·성장권 강제가 장기 관계에서 어떤 후속 비용으로 돌아오는가.
- 64화의 생존 윤리가 이후 인간 상대 판단의 일반 규칙으로 굳어지는가.
- 감정적 여유가 생존 판단을 실제로 약화시키는 실패가 생기는가.
- 외부 인격 커뮤니티 가입 뒤 익명성·정보권·관계권이 어떻게 재편되는가.
- 공식 의뢰와 행정기관 신뢰가 파티 밖 지휘권으로 이어지는가.

## 다음 직접 순회 질문

81~160화에서:

1. 능동 위험 설계가 계속 성공하는가, 아니면 새로운 통제 실패를 만드는가.
2. 장기 성장 동료 A의 신체·성장권과 파티 내 선택권이 재협상되는가.
3. 명성·공식 의뢰·정체 감시가 실제 권한과 의무로 바뀌는가.
4. 게임 지식과 현지 전문가 지식의 권위가 더 큰 사건에서 어떻게 경쟁하는가.
