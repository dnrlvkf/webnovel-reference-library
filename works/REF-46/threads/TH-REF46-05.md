# 다중 신분은 서로 다른 증거의 누적으로 판정되지만 증거가 많아도 판정 모델이 틀리면 오답이 된다

## works-layer 보강

기존 `VERIFIED_THREAD`를 유지한다.

이번 1~80화 전체 직접 순회에서 특히 중요한 새 근거는 **75~76화의 두 독립 감시 체계가 서로 다른 증거를 사용하고도 동시에 주인공 A를 외부 인격 후보에서 잘못 제외하는 장면**이다.

이로써 기존 `증거 수집 정확도 ≠ 해석 모델 정확도` 판정이 초반부터 더 강하게 검증된다.

## 해결하는 문제

한 사람이:
- 현지 신분
- 외부 인격 여부
- 익명 공동체 신분
- 숨은 과거/본명

등 여러 정보층을 가질 때, 무엇을 근거로 어느 층까지 판정할 수 있는가.

## 작동 사슬

정체 확인 필요
→ 암구호 하나가 아니라 시기·행동·말투·성장·정보 출처·습관·공개 기록 같은 복수 증거 수집
→ 증거가 어떤 모델에서 기대되는 행동인지 비교
→ 동일 인물 여부·정체 범주·현재 목표를 각각 판정
→ 필요한 정보층만 선택적으로 공개
→ 질문권·연락권·감시권·협박 위험 변화
→ 후속 행동으로 판정 정확도 검증.

핵심은 **증거가 많아지는 것과 올바른 질문을 하는 것이 다르다**는 점이다.

## 1화 · 정체 분류가 곧 생존 조건이다

다른 외부 인격이 현지에서 즉시 처형되는 장면을 본다.

주인공 A는 타인의 반응을 관찰해 현지 전사처럼 행동한다.

이때부터 정체는 내면 고백이 아니라:
- 말투
- 행동
- 사회 규칙 이해

로 외부에서 판정되는 문제다.

## 36~40화 · 공식 진위 도구도 잘못된 입력을 만들 수 있다

공식 진위 검사 자체는 강한 제도 증거지만 주인공 A의 높은 저항 때문에 제대로 작동하지 않는다.

조직은 검사 실패를:
- 거짓말
- 낮은 신분의 수상함

과 연결해 잘못된 결론으로 간다.

도구가 객관적이어도 **현재 대상의 특성 때문에 신호가 왜곡될 수 있음**을 보여 준다.

## 44~50화 · 같은 비밀 범주라도 관계 권리는 자동 발생하지 않는다

주인공 A는 자신과 유사한 외부 인격 가능성을 가진 사람을 만난다.

그 사람의 취약함에 자기 과거를 겹쳐 일회성 도움을 주지만:
- 파티 동행
- 정체 공개
- 장기 보호

권리는 주지 않는다.

동일 출신/비밀 범주를 맞히는 것과 현재 목표·신뢰를 판단하는 것은 별개다.

## 75화 · 가짜 동향인 미끼를 판정한다

현지 비밀 치안 조직은 외부 인격인 척 접근해:
- 현대 국가명
- 게임 언어
- 외부 인격 특유의 연대 제안

을 던진다.

주인공 A는 내용 자체보다:
- 3년 생존자치고 지나치게 노골적인 접근
- 고유어 발음의 어색함
- 더 자연스러운 검증 방법을 쓰지 않는 행동

을 보고 `외부 인격이 아니라 외부 인격을 흉내 내는 감시자`라고 판정한다.

상대가 진짜로 무엇을 말했는가보다 **그 역할을 수행하는 방식이 그 사람의 주장과 맞는가**를 본다.

## 75~76화 · 현지 감시 조직의 합리적인 오판

주인공 A는 감시를 피하기 위해 공개적으로:
- 미끼 대상에게 외부 인격 여부를 다시 묻고
- 현지 전사 규범을 호출하며 공격하고
- 군중·경비에게 외부 인격을 잡았다고 신고한다.

비밀 치안 조직은 영상 기록을 반복 검토한다.

그들이 보는 증거:
- 질문에 대한 반응 속도
- 어휘·표정
- 현지 전사다운 폭력적 대응
- 이전의 제도 충돌 방식

결론:

`외부 인격이 아닌 현지 전사`.

추론 과정은 논리적이다. 하지만 **외부 인격이 현지 역할을 의도적으로 학습해 왔다는 모델이 빠져 있어 최종 결론은 틀린다.**

## 76화 · 실제 외부 인격 공동체도 별도 오판을 한다

실제 외부 인격 공동체는 익명 초대장을 보낸다.

그들은 특정 후보가 초대장을 받으면 빠르게 공동체에 들어올 것이라 기대한다.

주인공 A는:
- 함정 가능성
- 초대자가 가입 시점으로 후보를 좁힐 위험

을 계산해 즉시 사용하지 않는다.

공동체는 `이번 집회에 신규 가입이 없음`을 보고 특정 후보 가능성을 낮춘다.

따라서 같은 사람에 대해:

현지 감시 조직: 현지 전사라 판단
+
외부 인격 공동체: 찾던 외부 인격이 아니라고 판단

이 동시에 성립한다.

**독자는 두 체계의 정보와 실제 정체를 모두 알아 각 체계의 전제가 어디서 틀렸는지 볼 수 있다.**

## 150화 · 정확한 관찰과 잘못된 존재론 결론

기존 직접 근거를 유지한다.

베테랑 안내자 A는:
- 비정상적 정보량
- 책 읽기·계산 습관
- 짧은 경력과 맞지 않는 판단

을 정확히 포착해 외부 인격 가능성을 후보로 올린다.

그러나 `외부 인격이라면 인간을 도구처럼 대할 것`이라는 도덕적/종교적 전제를 적용해 후보를 기각한다.

현재 인격에 대한 신뢰는 맞을 수 있지만 존재론적 정체 판정은 틀릴 수 있다.

## 장기 변형

기존 레거시/works 연구에는:
- 익명 공동체 인증
- 진위 판정 장치와 질문 설계
- 정치 권력이 숫자·동선으로 동일 인물을 맞히되 부재 원인을 틀리는 사례
- 생활 습관·순간 반응을 결합한 정밀 추론
- 여러 신분을 맞힌 뒤에도 목표 불일치로 동맹이 실패하는 사례

가 존재한다.

## 판정 층 분리

앞으로 정체 장면에서는 최소 세 질문을 나눈다.

1. **동일 인물인가?**
2. **그 인물의 존재론적/사회적 정체가 무엇인가?**
3. **현재 목표·충성·관계 의도가 무엇인가?**

한 층을 맞혔다고 다른 층까지 맞힌 것으로 처리하지 않는다.

## 비용·반례

- 공식 진위 도구도 대상 특성 때문에 실패 가능.
- 현대 언어·암구호를 알아도 연기일 수 있음.
- 행동 습관이 강한 증거지만 의도적으로 학습된 역할이면 오판 가능.
- 같은 출신을 맞혀도 협력권은 자동 발생하지 않음.
- 질문 문구의 문자적 진실과 숨은 전제는 별개.
- 정체를 맞힌 조직도 현재 목표를 틀릴 수 있음.

- `TH-REF46-05`: 관찰자가 여러 신분을 어떤 증거 모델로 판정하며 왜 오판하는지.

75~76화에서는 `역할이 너무 잘 작동해서 정체 판정 모델을 속인다`는 방식으로 두 TH가 교차한다.
