# 선행 게임 지식은 현장 변수와 반례를 거쳐 갱신 가능한 가설로 운용된다

## works-layer 재검증

레거시 `TH-REF46-02`는 이미 작품 전체의 떨어진 구간에서 `VERIFIED_THREAD`였다.

이번 1~80화 전체 직접 순회는 그 스레드의 **초기 형성 과정과 실패 비용**을 고해상도로 다시 확인했다.

상태를 새로 승격하지 않는다. 기존 `VERIFIED_THREAD`를 보존하며 1~80화 직접 근거를 works 정본층에 연결한다.

## 해결하는 문제

선행 공략 지식을 `미래 예언`처럼 쓰면 긴장도 사라지고 현실 세계의 독립성이 사라진다.

반대로 매번 지식이 틀리기만 하면 9년 공략 경험이라는 캐릭터 자산도 무의미해진다.

이 작품은 둘을 분리한다.

## 기본 작동 사슬

게임 데이터로 위험 범위·첫 선택을 좁힘
→ 현재 현실에서 같은 조건인지 확인
→ 몸·시간·제도·타인 행동 같은 추가 변수 관찰
→ 데이터와 현상이 맞으면 제한 신뢰 상승
→ 다르면 `게임이 틀림` 하나가 아니라 시대차·현실 추가 규칙·타인 개입·선행 선택 효과 등의 가설 분기
→ 현재 생존 비용이 낮으면 실험
→ 비용이 높으면 전문가·기록·후속 탐색으로 넘김
→ 다음 선택 모델 갱신.

## 1~3화 · 지식보다 현실 사망 비용이 먼저다

게임에서는 공격적인 빌드를 선호했지만 실제 죽음이 생기자 방패를 선택한다.

`좋은 공략 선택`이 `현실에서 좋은 생존 선택`과 같지 않다는 첫 변형이다.

## 4~6화 · 실행 몸이 데이터에 없던 변수다

몬스터·지형의 큰 틀을 알아도:
- 방패 시야
- 실제 몸의 거리감
- 통증
- 동작 속도

때문에 계획이 무너진다.

실패 뒤 지식을 폐기하지 않고 실행 제약을 새 모델에 추가한다.

## 16~21화 · 게임 시대와 현재 시대를 분리한다

사라진 상호·새 도서관·세금·도시 구조를 보고 게임 배경이 현재와 약 150년 차이가 날 수 있음을 받아들인다.

정수도 게임 수치에 없던 현실 추가 효과를 직접 실험한다.

따라서:

> 데이터가 맞는 항목과 시대 변화가 가능한 항목을 분리한다.

## 22~27화 · 숨은 규칙을 반복 실험해 새 효율을 만든다

불안정 포탈의 작동을 관찰해 반복 가능한 경험치/성장 수단으로 바꾼다.

이 구간은 선행 지식이 현실에서도 실제 큰 우위를 준다는 성공 근거다.

다만 상위 약탈자 개입은 그 효율화 자체가 `외부 위험 구조`를 해결하지 못함을 보여 준다.

## 28~35화 · 지식은 있어도 실행 시점이 늦을 수 있다

작은 시각 단서를 통해 예상 밖 보스 정체를 알아차리지만 이미 상황이 악화된 뒤다.

반복 성공이 주인공 A에게 자신감을 주었고 단서 인식이 늦어진다.

선행 지식이 있다고 자동 선행 대응이 되는 것은 아니다.

## 36~43화 · 성장 결과가 사회 규칙에서 역효과를 낸다

높은 저항 수치는 전투에서는 장점이지만 공식 진위 마법에서는 검사 실패를 만든다.

게임의 성장 수치만으로는:
- 행정 판정
- 저신분 편견
- 처형 위험

을 예측할 수 없다.

능력의 효과 범위를 전투에서 사회 제도로 확장해 다시 배운다.

## 65화 · 가장 중요한 초반 반례

주인공 A는 숨은 보스 발동 조건을 알고 있었다.

그러나 다른 사람이 이미 조건을 일부 채웠을 가능성을 넣지 못했다.

즉 실패 원인은:

`규칙 무지`
아니라
`현재 세계 상태 추정 실패`.

이 장면은 선행 지식의 최종 판정권이 현재 상태 정보에 있다는 것을 강하게 증명한다.

## 65~71화 · 현지 전문가의 독립 권위 인정

대형 조직의 유료 보호와 위험한 공략을 처음에는 탐욕·과신으로 본다.

그러나 실제 비축·준비·역할 지식을 본 뒤 판단을 바꾼다.

주인공 A는 현지인이 수백 년 동안 쌓은 탐험 지식이 자기 게임 데이터와 다른 독립 자산임을 인정한다.

`나만 안다`는 자기모델을 직접 수정한다.

## 75~76화 · 정보 수급도 즉시 쓰지 않는다

외부 인격 공동체 초대는 주인공 A에게 매우 가치 있는 최신 정보 가능성을 준다.

그러나:
- 초대자가 가입 시점을 추론할 수 있음
- 정체 감시 수법일 수 있음

을 계산해 전문가에게 먼저 물어보고 몇 달 지연 후 사용하기로 한다.

새 정보의 가치가 커도 검증과 상관관계 위험을 먼저 본다.

## 실패·비용·반례

- 몸이 실행하지 못하면 정답 지식도 실패.
- 실제 감정 공포가 전문 역할을 정지시킬 수 있음.
- 시대가 달라 제도·상호·사회 규칙이 바뀜.
- 다른 행위자의 숨은 선행 상태를 모르고 조건 계산을 틀릴 수 있음.
- 반복 성공이 과신을 만들어 단서 인식을 늦출 수 있음.
- 현지 전문가가 특정 현재 정보에서는 더 높은 권위를 가질 수 있음.
- 정보 수집 자체가 정체 노출 위험을 만들 수 있음.

## 레거시와의 연결

레거시 TH에는 중·후반의:
- 게임에 없던 현실 구조
- 숨은 역사
- 정수 획득 순서 변화
- 개량된 물품
- 후반 반복/분기

근거가 존재한다.

이번 배치는 그 결론을 새로 증명한 것이 아니라 **초기 1~80화 전체 직접 순회로 기초 작동 사슬과 반례를 재확인**했다.

## 현재 질문

81~160화에서:
- 현지 전문가 지식과 게임 지식이 직접 충돌할 때 어느 증거를 우선하는가.
- 틀린 가설을 오래 유지해 큰 비용을 치르는 사례가 생기는가.
- 다른 외부 인격과 정보 교환이 주인공 A의 독점 지식 권위를 어떻게 낮추는가.
