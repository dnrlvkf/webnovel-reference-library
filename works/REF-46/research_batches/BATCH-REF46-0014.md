## 핵심 판정

### 1. 지지도는 직위가 아니라 실행 효율을 조절한다

452화에서 지지도는 다음을 바꾸는 상태값으로 제시된다.
- 통솔력
- 반대 세력 규모
- 정책 성공률
- 지시 수행률

그러나 대표직 상실은 같은 구간에서 `언제든 도전 가능 → 패배하면 직위 상실`과 연결된다. 주인공 A는 `지지 않는 한 자리에서 내려갈 일이 없다`고 이해한다.

780~781화에는 선택을 거절하면 지지도가 하락할 수 있다는 계산이 직접 나오지만, 직위 박탈은 예상 비용으로 등장하지 않는다.

판정:
- `낮은 지지 → 통치 효율·정서 비용`: `DIRECT / SUPPORTED`.
- `낮은 지지 → 대표직 자동 해임`: `NOT_OBSERVED_WITHIN_SOURCE_BOUNDARY`.

### 2. 정책 이견은 즉시 veto·해임으로 작동하지 않는다

455화에서 대표가 성인식 전통을 변경하자 구성원이 `전통`을 근거로 이의를 제기한다. 그러나 결정은 유지되고, 장로가 제시하는 장기 변경 경로는 `현재 대표를 따름 → 불만이면 훗날 스스로 대표가 되어 바꿈`이다.

기존 452~454화의 공금·행정 문제 역시 대표를 교체하기보다 전문 실무 위임과 기능 재설계로 처리된다.

판정:
- `정책 문제 → 조정·위임·수행 비용`: `SUPPORTED`.
- `정책 실패·내부 이견 → 현 대표 자동 해임`: `NOT_OBSERVED_WITHIN_SOURCE_BOUNDARY`.
- 공식 회의·투표·불신임 절차: `HOLD`.

### 3. 장기 업무 공백도 자동 직위 회수가 아니다

861~862화에서 대표는 약 한 달 칩거한다.
- 행정 담당자가 업무를 사실상 혼자 떠맡음.
- 전사들의 불안이 누적됨.
- 대표 자신도 이를 책임 비용으로 인정함.

그러나 자동 해임은 없다. 가까운 구성원이 `대표 자리`를 가져가겠다고 말할 때도 곧바로 결투·도전 전통을 호출한다. 복귀는 새 임명·재승인이 아니라 기존 대표가 밀린 책임을 다시 처리하는 방식이다. 896화에서도 대표 호칭이 지속된다.

판정:
- `부재·무능 → 실무 공백·집단 불안`: `DIRECT`.
- `부재·무능 → 자동 직위 회수`: `NOT_OBSERVED_WITHIN_SOURCE_BOUNDARY`.
- `부재·무능이 실제 도전을 촉발하는가`: `HOLD`.

### 4. 외부 정치·법적 압력은 내부 대표직이 아니라 관할 범위를 제한한다

494~495화에서 대표는 공동체를 대규모로 동원할 수 있으나, 외부 전문 조직의 적법한 연구를 `대표이므로` 곧바로 중단시킬 법적 관할은 없다. 왕국 기관도 현장 권한 범위가 제한돼 즉시 조사·판정을 못 한다. 주인공 A는 내부 지지·귀족 지위·공개 명분·여론을 결합해 외부 행동 선택지를 바꾼다.

641화에서 다른 종족 대표·왕가의 균형 논리가 정치 압력으로 작동하지만, 다른 대표는 주인공 A의 상급자도 내부 명령권자도 아니다. 왕실은 이미 `작위를 가진 종족 대표` 상태 자체를 문제 삼지 않는 결정을 내렸다.

판정:
- `외부 권한 → 외부 사안 행동 범위 제한`: `DIRECT / SUPPORTED`.
- `외부 압력 → 공동체 내부 대표·자원·접근·교육 권한 회수`: `NOT_OBSERVED_WITHIN_SOURCE_BOUNDARY`.
