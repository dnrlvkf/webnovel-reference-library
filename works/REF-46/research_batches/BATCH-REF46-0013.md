## 질문 전제 감사

기존 `ORG-REF46-0001`, `TH-REF46-01`에는 `후반 정체 공개 뒤 대표권 유지 여부`가 HOLD로 남아 있었다. 이번 배치는 그 HOLD를 채우기 전에 **실제 외부 영혼/악령 정체가 공동체 A에 공개·수신·승인됐는지**부터 원문으로 재검증했다.

결과:

- 434화 국가 권력의 악령 공표: `DIRECT`.
- 공동체 A가 해당 공표를 실제 정체 사실로 승인함: `CONTRADICTED BY SOURCE SCENE`에 가까운 직접 반대 증거. 공동체는 외부 권력의 잘못된 판정으로 처리한다.
- 490화 개인 고백 시도: 발화는 있으나 수신자가 듣지 못해 정보 상태 변화 없음.
- 521화 핵심 공동체 구성원들의 실제 악령 정체 비인지: `DIRECT`.
- 867화 공적 반악령 규범이 여전히 비용으로 작동하며 대표 개인의 비밀 예외 판단과 분리됨: `DIRECT`.
- 872화 실제 정체 비공개 상태에서 대표·성인식·교육 권한 계속 행사: `DIRECT`.
- 873~917화 공동체 대상 실제 정체 공개: 관련 장면 `NOT_OBSERVED_WITHIN_SOURCE_BOUNDARY`.

따라서 기존 질문의 `공개 뒤` 전제는 source boundary 안에서 성립하지 않는다.

434화 외부 악령 공표
→ 공동체가 공표를 사실로 채택하지 않음
→ 주인공 A의 공동체 구성원 자격 유지
→ 449화 대표 도전

강함·판단력·누적 행동·자연스러운 추종은 높은 사회적 지지를 보강하지만, 실제 외부 영혼 정체를 알고도 대표권을 유지시키는 최종 우선 기준으로 확인되지 않는다.
