## 현재 연구 질문

이번 배치는 **후반 실제 정체 공개 뒤 공동체 A의 대표·자원·접근·교육 결정권이 유지되는가**를 검증하려 했으나, 원문 재독에서 질문의 전제부터 교정됐다.

통합 판정:

- 434화 국가의 악령 공표: `DIRECT`.
- 공동체 A가 그 공표를 실제 정체 사실로 승인: `CONTRADICTED`; 공동체는 외부 권력의 잘못된 판정으로 처리.
- 449~452화 대표권 생성: `인정된 공동체 구성원 자격 → 공식 도전 수락 → 승리 → 공개 승계` — `DIRECT / SUPPORTED`.
- 강함·판단력·누적 행동·자연스러운 추종: 높은 사회적 지지 보강 — `SUPPORTED`.
- 490화 실제 정체 고백 시도: 수신 실패.
- 521화 핵심 공동체 구성원의 실제 악령 정체 비인지: `DIRECT`.
- 867~872화: 실제 정체는 비공개인 채 공적 반악령 규범과 대표 개인의 비밀 판단이 갈리고 대표·성인식·교육 권한은 유지.
- 873~917화 공동체 대상 실제 외부 영혼 정체 공개·승인: `NOT_OBSERVED_WITHIN_SOURCE_BOUNDARY`.
- `실제 정체를 공동체가 알게 됐을 때 대표권 유지 여부`: `HOLD / UNTESTED`.
- `누적 책임이 알려진 실제 악령 정체를 압도하는 최종 대표 자격 기준`: 사용 금지 / 미검증.

따라서 `혈통 vs 영혼 vs 누적 책임`만 비교하는 질문을 중단하고, 직접 관찰된 **내부 구성원 인정 + 공식 도전·승계 절차**를 대표권 생성 기준으로 분리한다.
