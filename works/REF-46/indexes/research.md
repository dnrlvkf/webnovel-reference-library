## 현재 연구 질문

이번 배치는 베테랑 안내자 A의 교육 역할을 다음 대칭 사슬로 검증했다.

> 양성: `자신이 가르친 기술 → 특정 교육 대상 생환 → 감사 → 교육 성과 체감`
>
> 음성 후보: `자신이 가르친 대상 → 실패/사망 → 자기 교육 책임 귀속 → 교육 방식 또는 자기평가 수정`

1~917화 전체 왕복 결과 양성 사슬은 634화에서 직접 확인되지만, 음성 사슬은 확인되지 않았다.

- 473화: 시혜가 아니라 실제 전문성 수요를 확인한 뒤 젊은 공동체 구성원 대상 교육 역할 수락.
- 478화: 역할 수락 뒤 새 기수 사망이 발생하지만 사망자들을 베테랑 안내자 A의 직접 교육 대상으로 특정하는 근거는 없음. 외부 약탈자의 표적화가 원인으로 제시됨.
- 634화: 자신이 가르친 기술로 교육 대상이 살아 돌아오고 감사할 때 교육 역할 보상을 느낀다는 양성 사슬은 `DIRECT`.
- 741화: 공동체 전사들의 부상·사망을 직접 경험하고 최정예 전투원과의 격차도 다시 보지만, 과거 현장 부족을 인정해 새 직업을 찾았다는 자기분류를 유지함.
- 741화 사망자들이 자신의 교육 대상이라는 직접 연결과 교육 실패 자기귀속은 없음.
- 742화: 죽음 직전 내부에도 교육 실패 자기평가는 직접 제시되지 않음. 미언급을 교육 역할 무가치의 증거로 사용하지 않음.

판정:

- `자신이 가르친 기술 → 특정 교육 대상 생환 → 감사 → 교육 성과 체감`: `DIRECT`.
- `같은 공동체 사망자 = 자신의 교육 대상`: 직접 연결 없음.
- `교육 대상 실패·사망 → 자기 교육 실패 귀속 → 교육 역할 자기평가 하락`: `NOT_OBSERVED_WITHIN_SOURCE_BOUNDARY`.
- `전쟁 참여 = 교육 역할 실패 때문에 현장 정체성으로 복귀`: 성립하지 않음. 741화에는 새 직업 분류가 유지됨.
