# 주인공 A ↔ 전투 동료 A·B · 검증된 역할 협업에서 장기 투자·원거리 전술 문법으로

## 참여자와 관계 방향

주인공 A와 전투 동료 A·B는 초기에는 같은 의뢰에 우연히 배치된 산수였다. 이후 주인공 A가 불특정 집단보다 두 사람을 직접 선택하고, 실제 맹점을 보완받으며, 장기 공백 뒤에도 다시 고위험 임무의 동료로 고른다.

관계 핵심은 친밀한 호칭보다:

- 동료를 선택할 권리
- 역할을 맡길 신뢰
- 비밀을 캐묻지 않을 권리
- 위험에서 서로 구하는 행동
- 상대의 미래 역량에 자원을 투자하는 선택
- **장기 분리 뒤에도 공유된 전술 문법으로 제한 협력하는 능력**

이다.

## 초기 상호 분류 · 18~19화

- 동료 A·B → 주인공 A: 신참·하위자로 시작, 전투 뒤 동등한 동료로 재분류.
- 주인공 A → 동료 A·B: 자신의 수단과 다른 구속·광역 화력 기능을 가진 임시 협력자.

실전 성과 뒤 동등한 호칭까지 올라가지만 사적 배경 공개형 친교는 확대되지 않는다.

## 55~56화 · 직접 선택된 팀

주인공 A는 동맹 조직 A가 제공하는 불특정 산수와 함께 움직이는 것을 거부한다. 반대로 혼자 싸우겠다고 하지 않고 과거 실전에서 성향과 역할을 확인한 동료 A·B를 직접 부른다.

### 역할 분담

- 동료 A: 보안·진법·보조 기술과 주변 적 처리
- 동료 B: 넓은 범위 화력·독성 포자 소각
- 주인공 A: 핵심 책임자·상위 전력 제거와 급소 선택

56화에서 적의 최후 독포자가 지하 공간 전체에 퍼질 위기에서 동료 B의 광역 화력이 실제로 위험을 제거한다. 주인공 A도 혼자였다면 위험했음을 인정한다.

## 57화 · 관계 욕망과 실제 구조

주인공 A가 없는 자리에서 동료 A·B는 현재 관계가 서로 죽음 뒤 복수할 정도는 아니라고 인정하면서도 앞으로는 그런 사이가 되고 싶었다는 욕망을 드러낸다.

곧이어 두 사람이 보복 습격으로 죽음 직전까지 갔을 때 주인공 A가 약속 장소의 이상을 확인하고 즉시 구조한다.

독자는 동료들의 관계 욕망을 알지만 주인공 A는 듣지 못한다. 관계 상태는 즉시 의형제나 무제한 의무로 확정되지 않는다.

## 101~104화 · 장기 공백 뒤 재선택

시간이 지나 동료 A·B는 각자 제작·수련 기반을 키웠다. 주인공 A는 다음 상위 조직전에서 두 사람을 다시 직접 고른다.

### 권리와 비용 변화

- 이동·거점 접근 경로 연결
- 위험 역할에 명시 보수 지급
- 임무 보수 밖 비급·법기 등 성장 자원 추가 제공
- 추가 투자가 두 사람의 미래 성장과 자기 지원 능력에도 유리함을 인정
- 동료들은 자기 제작·기술 소유권과 독립 사업 유지

관계가 `필요할 때 부르는 용병`에서 **서로 독립 기반을 유지하면서 미래 전력까지 키우는 장기 협력 후보**로 이동한다.

## 생명 단위 의향의 경계

101~104화에서 동료 A·B는 주인공 A의 일이라면 큰 위험을 감수할 수 있다는 강한 의향을 말한다.

판정:

- 동료 측 의향: `DIRECT`
- 주인공 A가 같은 수준의 무제한 의무를 언어로 약속: 미확인
- 상호 생명 단위 보호 계약: `HOLD`

주인공 A는 실제 자원 투자와 구조 행동은 하지만 비상 능력·핵심 성장 자원을 포기하겠다고 약속하지 않는다.

## 138~149화 · 장거리 분리 뒤에도 전술 문법이 남는다

주인공 A는 가짜 신분 B와 다른 집단에 섞여 있는 상태에서 오래된 전투 동료 A와 마주친다. 둘은 관계를 공개하거나 긴 대화를 나누지 않는다.

대신:

- 상대가 왜 지금 이 집단에 있는지 대략 판정
- 서로의 공격 타이밍을 맞춤
- 공격 결과가 각자 일행을 다른 방향으로 이동시킬 명분을 만듦
- 두 사람 모두 자기 현재 신분·목적을 공개하지 않은 채 위험 거리 확보

가 일어난다.

중요한 변화는 **장기 관계가 정보 공유가 없어도 공동 전투 기억 자체로 제한 협업할 수 있다**는 점이다.

`장거리 분리 = 관계 기능 정지`가 아니다.

## 157~164화 · 옛 관계망에서 보증 신뢰로 연결

주인공 A가 정체를 숨긴 상위 동행자 A와 함께 돌아왔을 때 오래된 동료·관계망은 그 상위자를 경계한다.

주인공 A는 상위 동행자의 전체 신분을 공개하지 않는다.

자기 보증
→ 기존 동료가 일단 제한 신뢰 수용
→ 실제 임무 역할로 검증

으로 연결한다.

이때 옛 전투 동료 관계는 새 인물을 직접 아는 것이 아니라 **주인공 A의 판단을 일정 범위까지 빌려 주는 보증 경로**로 기능한다.

다만 보증이 틀리면 주인공 A가 책임을 져야 한다는 비용도 생긴다.

## 기본 권리와 의무 · 1~180화

- 동행 선택권: 각자 참가 여부 결정.
- 역할 제안권: 주인공 A가 전체 작전과 역할을 제안할 수 있으나 종문식 절대 명령권 없음.
- 정보 비공개권: 기연·성장 비밀을 짧게 설명한 뒤 더 캐묻지 않을 수 있음.
- 기술 소유권: 동료의 독립 기술·제작 기반 유지.
- 보수권: 위험 역할은 별도 보상 요구/수령 가능.
- 추가 투자: 계약 밖 성장 자원을 제공할 수 있으나 소유권·종속권으로 전환되지 않음.
- 구조 의무: 반복 행동은 확인되나 무제한 의무 계약 아님.
- 이탈권: 상위 위험에서 강제 동행 의무 없음.
- **원거리 전술 협력권**: 관계를 공개하지 않고도 공유된 실전 문법으로 제한 협력 가능.
- **보증 신뢰권**: 주인공 A가 제3자를 자기 판단으로 일정 범위 보증할 수 있음. 잘못된 보증의 책임은 주인공 A 쪽 비용.

## 표현 증거

### 57화

동료 POV
→ 현재 관계 한계 인정
→ 더 깊은 관계 욕망
→ 죽음 위기
→ 주인공 A의 실용적 구조 지시
→ 생환

감정 고백이 당사자에게 전달되지 않은 상태로 보호 행동만 먼저 발생한다.

### 101~104화

재회
→ 위험 임무 제안
→ 역할 확인
→ 추가 보상
→ 비급·법기 제공
→ 실제 합동전

작가는 `오랜 친구`라는 설명보다 **다시 자원과 위험을 함께 거는가**로 장기 관계를 증명한다.

### 138~149화

재회 대화·감정 확인 없음
→ 상대 위치·의도 빠른 추론
→ 공격 타이밍 동기화
→ 각자 그룹 분리
→ 관계 노출 없이 안전 확보

관계 표현이 대사에서 **공유된 전술 습관**으로 변주된다.

## 실패·오해·반례

- 동료들의 강한 의향과 주인공 A의 의무 수준이 비대칭일 수 있음.
- 고급 자원 투자 때문에 주인공 A 자신의 현재 자원량이 줄어듦.
- 팀 활동이 동료를 보복 표적으로 만듦.
- 장거리 이동과 상위 조직 침투로 즉시 지원이 어려워짐.
- 원거리 전술 문법은 상대의 현재 목표를 잘못 읽으면 위험한 오판이 될 수 있음.
- 제3자 보증이 틀리면 오래된 관계망 전체가 위험에 노출될 수 있음.
- 주인공 A가 두 사람을 위해 핵심 성장 기회 자체를 포기한 사례는 아직 없음.

## 현재 상태

`실전에서 검증된 임시 동료`
→ `직접 선택하는 반복 협업자`
→ `서로의 실패 조건을 실제로 제거하는 관계`
→ `장기 공백 뒤에도 재선택하고 성장 자원까지 투자하는 협력 후보`
→ `분리된 자리에서도 전술 문법으로 서로를 돕는 장거리 관계`
→ `주인공 A의 제3자 보증을 제한적으로 받아들이는 관계망`

으로 이동했다.

정서적 가족·의형제 관계나 상호 무제한 복수 의무는 아직 확정하지 않는다.
