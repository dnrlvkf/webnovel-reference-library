# 제한 거래에서 비밀권·이동권·신체 성장 책임·상계 공동 목표와 기존 의무의 공존으로

## 현재 판정

주인공 A와 장기 동업자 A의 관계는 `서로 비밀을 모두 털어놓는 친밀 관계`가 아니다.

1~200화의 변화는:

결과·보수 거래
→ 추천·정보 접근
→ 계약 밖 걱정·사과
→ 상대 부재 재추적
→ 위험한 장기 목적에 대안 제안
→ 서로의 비밀을 캐묻지 않는 권리
→ 각자 이동권과 미래 협업
→ 상위 수련법·신체 승급 책임 위임
→ 상대 비밀을 볼 수 있어도 묻지 않는 감지 비밀권
→ 상계 진입까지의 제한 공동 목표
→ **그럼에도 장기 동업자 A의 기존 조직 의무가 남아 즉시 동행을 막음**

이다.

관계의 깊이는 공개 정보량보다 **얼마나 큰 책임을 맡기면서도 상대가 갖지 않는 권리를 지킬 수 있는가**로 측정한다.

# 기본 권리와 의무 · 1~200화

- 질문권: 현재 계약·위험에 필요한 질문은 가능, 사적 장기 목적을 강제로 열 권리는 없음.
- 거절권: 소속·사적 친교·비밀 공개·자원 상납·동행 지속을 거절 가능.
- 접근권: 정보·추천·시설·협상 네트워크에서 상위 수련법·신체 조정까지 확대.
- 정보 비밀권: 거래 정보와 사적 배경을 분리.
- 감지 비밀권: 상대의 비밀을 볼 능력이 생겨도 자동 질문권이 되지 않음.
- 대표/중개권: 동업자 A가 상인·조직·상층 인물 연결 가능.
- 이탈권: 서로 다른 목적 때문에 다른 지역에 남거나 떠날 수 있음.
- 미래 협업권: 물리적으로 떨어져도 후속 상층부 협업을 약속 가능.
- 신체·성장 책임: 상위 승급 때 직접 신체 조정·자원 투입을 맡길 수 있음.
- 공동 목표: 적어도 상계 진입이라는 이정표까지 협력 의향 확인.
- **기존 의무권**: 새 공동 목표가 동업자 A의 과거 조직·은혜·책임을 자동 무효화하지 않음.

# 관계 변화

## 초기 · 제한 거래

서로 출신과 수법을 공개하지 않고 결과·보수·정보만 교환한다. 주인공 A는 수행 방법을 숨기고 상대도 장기 배경을 전부 말하지 않는다.

## 21~40화 · 추천 신뢰와 거래 완충

동업자 A가 정보·추천·상위 거래 접근을 제공하고 주인공 A는 그 값어치를 보답 의무로 인정한다. 사적 배경을 캐묻는 상황은 차단된다.

## 48~49화 · 계약 밖 감정 잔여

장기 부재 뒤 동업자 A가 죽었을 가능성을 걱정했다고 말한 뒤 손실 언어로 축소한다.

걱정
→ 손실 언어
→ 냉정함 지적
→ 반사 평가
→ 주인공 A의 사과
→ 비공식 소개 부탁.

당시 상대 내면이 열리지 않아 감정 명칭은 HOLD였지만 `부재를 문제 삼을 권리`와 `사과 받을 권리`가 실제로 생긴다. `MAC-REF02-0001`과 `MIC-REF02-0001`이 이 배열을 보존한다.

## 66~83화 · 부재 재추적과 위험 대안

주인공 A는 오래된 거래 상대가 사라진 사실을 단순 거래처 변경으로 넘기지 않고 추적한다.

동업자 A의 장기 목적에 위험한 상계 수단이 필요할 수 있음을 알고, 목적 전체를 캐묻지 않은 채 자신이 미래 대안이 될 수 있다고 제안한다.

`목적을 전부 알아야 돕는다`가 아니다.

## 84~116화 · 비밀권과 이동권

두 사람은 각각 핵심 수련 방식과 장기 목적을 숨긴 상태에서도 협상·소개·위험 판단을 함께 한다.

동업자 A의 관련 제3자 사적 정보도 자동 재판매하지 않는다.

114~116화에는 서로 다른 목적지를 선택하고 상시 보고/동행을 요구하지 않은 채 상층부 미래 협업을 갱신한다.

## 157~169화 · 거점·신체권과 다자 관계 조정

옛 거점과 관계망이 상위 조직의 신체 강탈 요구로 피해를 입자 동업자 A는 자기 신체·일·장기 목적을 지키기 위해 전쟁에 참여한다.

연합 승리 뒤에는 한 세력이 보상을 거부하면 다른 세력이 탐욕스럽게 보일 수 있다는 **해석 비용**까지 계산해 전리품 형식을 다시 조정한다.

관계 조정 역할이 가격 협상에서 다자 평판 조정으로 확장된다.

## 165~177화 · 신체·성장 책임

동업자 A는 독점 상위 수련법만 주는 것이 아니라:

- 몸 상태 진단
- 약물·영력 투입
- 법기 사용 시점 조정
- 직접 신체 보정
- 위험 단계 개입

까지 맡는다.

주인공 A는 자기 생명과 승급 성공을 상대의 기술 판단에 실제로 맡긴다.

관계 권한은 정보·소개보다 훨씬 커진다.

## 승급 뒤 · 알 수 있음 ≠ 물을 권리

새 감지력으로 주인공 A가 동업자 A의 더 깊은 과거 상태 일부를 알 수 있게 된다.

알게 됨
→ 즉시 폭로/질문하지 않음
→ 상대가 필요한 만큼 먼저 말함
→ 나머지는 말하지 않아도 됨을 확인
→ 자기 비밀에도 같은 권리 요구.

상호 비밀권이 명시적으로 대칭화된다.

후반 자기 발언으로 초기 부재 때의 감정이 단순 경제 손실 이상이었다는 근거도 강화되지만, 관계를 연애·가족으로 확정하지 않는다.

## 195~200화 · 새 관계가 기존 조직 의무를 삭제하지 않는다

상층부로 함께 갈 수 있는 시점에도 동업자 A는 자기 원래 조직에 남은 의무 때문에 즉시 동행하지 않는다.

현재 공동 목표
↔ 과거 조직 의무

가 실제 경쟁 기준으로 드러난다.

이것은 관계가 깊어지면 이전 관계·의무가 자동 사라진다는 해석을 `CONTRADICTED`한다.

## 기존 조직의 비밀권 침해

원래 조직 지도자는 동업자 A가 새 충성 때문에 정보를 숨긴다고 의심한다.

겉으로는 `직접 말로 배신시키지는 않겠다`는 식의 존중 명분을 유지하지만 실제로는 기억을 강제로 추출한다.

따라서:

- 배신을 말로 요구하지 않을 권리
- 기억/정보에 강제로 접근당하지 않을 권리

는 별개다.

이 장면은 장기 동업 관계의 비밀권이 외부 조직 권력 때문에 실제로 침해되는 첫 강한 비용이다.

동업자 A는 주변 인물을 보호하면서 그 비용을 버틴다.

## 제3자 신뢰를 협상 담보로

주인공 A는 원래 조직 지도자에게 `나만 믿으라`고 하지 않는다.

동업자 A가 주인공 A를 신뢰함
→ 조직 지도자가 동업자 A의 판단 역량을 앎
→ 그 관계 신뢰를 현재 임시 협상의 담보로 사용.

관계망이 직접 정보 제공이 아니라 **신뢰의 전이**로 실무 기능한다.

# 표현 증거

- 73~83화: 장기 목적 고백보다 위험 수단→대안 제안→동업 확인.
- 114~116화: 감정 폭발보다 서로 다른 목적지와 미래 협업 약속.
- 165~177화: `친하다`는 설명보다 실제 신체 승급 책임을 맡기는 행동.
- 195~200화: 새 관계 사랑/우정보다 기존 의무 때문에 `지금 같이 갈 수 없음`이라는 선택.
- 조직 지도자의 말과 기억 강제 행위를 대비해 비밀권 침해를 보여 줌.

# 실패·오해·비용

- 서로 비밀이 많아 위기 원인을 늦게 알 수 있음.
- 상대의 장기 목적과 주인공의 생존 목표 충돌 가능.
- 비공식 의무가 큰 자원 손실을 요구할 때 우선순위 미확인.
- 상위 승급 판단을 상대에게 맡겨 오판이 생명에 직접 연결될 수 있음.
- 새 공동 목표가 기존 조직 의무를 지우지 않아 즉시 동행/지원이 제한됨.
- 외부 조직이 기억을 강제로 읽으면 상호 비밀권이 실제 유출 위험에 놓임.
- `동업자` 호칭이 무제한 보호·공동 운명을 뜻하지 않음.

## HOLD

- 상계 공동 목표가 동업자 A의 기존 조직 의무와 최종적으로 충돌할 때 무엇을 우선하는가.
- 기억 강제 추출로 실제 어떤 비밀이 유출됐는가.
- 상층부 장기 분리 뒤 관계가 다시 합류하는가.
- 관계 명칭을 연애·가족·의형제 중 하나로 확정할 근거는 없음.
