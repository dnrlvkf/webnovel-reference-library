# 제한 거래에서 상호 비밀권·이동권·신체 성장 책임을 맡기는 장기 동업 관계로

## whole-work correction

181~240화 배치에서 `195~200화의 기존 조직 은의·즉시 비승 거절·기억 강제 추출`을 이 관계에 잘못 귀속했다.

작품 전체 원문 왕복 재독 결과 실제 당사자는 **상위 동행자 A (`REL-REF02-0006`)**다.

따라서 `SC-REF02-0074`는 이 관계의 근거에서 제거하며, 기존 `장기 동업자 A의 과거 조직 의무/기억 침해` 판정은 `CONTRADICTED_BY_REIDENTIFICATION`으로 폐기한다.

## 현재 판정

이 관계의 장기 핵심은 `비밀을 모두 공개하는 친밀함`이 아니다.

결과·보수 거래
→ 추천·정보 접근
→ 계약 밖 걱정·사과
→ 상대 부재 재추적
→ 위험한 장기 목적에 다른 수단 제안
→ 서로 캐묻지 않는 비밀권
→ 각자 이동권과 미래 협업
→ 상위 수련법·신체 승급 책임 위임
→ 상대 비밀을 볼 수 있어도 묻지 않는 감지 비밀권
→ 상계 진입까지의 제한 공동 목표

로 발전한다.

관계의 깊이는 공개 정보량보다 **얼마나 큰 실제 책임을 맡기면서도 상대가 갖지 않는 권리를 지킬 수 있는가**로 측정된다.

## 권리와 의무

- 질문권: 현재 계약·위험에 필요한 질문은 가능하지만 사적 장기 목적을 강제로 열 권리는 없음.
- 거절권: 소속·사적 친교·비밀 공개·자원 상납·동행을 거절 가능.
- 정보 비밀권: 거래 정보와 사적 배경을 분리.
- 감지 비밀권: 상대의 비밀을 감지할 능력이 생겨도 자동 질문권이 되지 않음.
- 대표/중개권: 협상·소개·상층 인물 연결을 맡길 수 있음.
- 이탈권: 서로 다른 목적 때문에 물리적으로 떨어질 수 있음.
- 미래 협업권: 상시 동행 없이도 후속 이정표에서 다시 협력하기로 약속 가능.
- 신체·성장 책임: 상위 승급에서 수련법·약물·법기·직접 신체 보정을 맡길 수 있음.

## 장기 변화

### 제한 거래 → 관계적 잔여

초기에는 수행 방법과 출신을 숨긴 채 결과·보수·정보만 교환한다.

장기 부재 뒤 상대는 주인공 A의 죽음 가능성을 걱정한 사실을 말하고 손실 언어로 축소한다. 주인공 A도 연락하지 않은 일을 사과한다. 감정 명칭은 완전히 고정하지 않지만 `부재를 문제 삼을 권리`와 `사과 받을 권리`가 생긴다.

### 부재 재추적 → 위험 목적의 대안 제안

주인공 A는 상대가 사라진 일을 단순 거래처 변경으로 넘기지 않고 추적한다. 상대의 장기 목표에 위험한 상계 수단이 필요할 수 있음을 알게 된 뒤 목적 전체 공개를 요구하지 않고 자기가 미래 대안이 될 수 있다고 제안한다.

### 이동 자유와 장거리 동업

두 사람은 서로 다른 목적지로 움직여도 상시 보고·동행을 요구하지 않는다. 향후 상층에서 다시 협력할 약속만 갱신한다.

### 신체·성장 책임

상위 승급 때 상대는 단순 비급 전달을 넘어:

- 몸 상태 진단
- 약물·영력 투입
- 법기 사용 시점 조정
- 직접 신체 보정
- 위험 단계 개입

까지 맡는다.

주인공 A는 자기 생명과 승급 성공을 상대의 기술 판단에 실제로 맡긴다.

### `알 수 있음 ≠ 물을 권리`

승급 뒤 주인공 A는 상대의 깊은 과거 상태 일부를 감지할 수 있게 된다.

알게 됨
→ 즉시 질문하지 않음
→ 상대가 필요한 만큼 먼저 말함
→ 나머지는 말하지 않아도 됨을 확인
→ 자기 비밀에도 같은 권리를 요구.

관계가 깊어질수록 비밀 공개량이 자동 증가한다는 공식은 여기서 명확히 무너진다.

## 핵심 작동 원리

> 권한 일부 위임
> ≠ 전체 정보 소유권 양도
> ≠ 영구 동행
> ≠ 상대 삶에 대한 포괄 지휘권.

이 관계는 선택적으로 더 큰 책임을 맡기면서도 서로의 비밀·이동·미래 선택을 남겨 둔다.

## 비용과 경계

- 비밀권을 존중하면 상대의 위험을 늦게 알 수 있음.
- 신체 승급 책임을 맡기면 상대 오판이 자기 생명에 직접 연결됨.
- 장거리 이동은 즉시 지원을 어렵게 함.
- 관계가 깊어져도 무제한 희생·복수 의무가 생긴 근거는 없음.
- `195~200화 기존 조직 의무/기억 강제`는 이 관계의 근거가 아님.

## whole-work 판정

`장기 동업 = 모든 것을 아는 관계`는 `CONTRADICTED`.

대신:

> **큰 실제 책임을 서로 맡기면서도 비밀권과 이탈권을 남기는 선택적 상호 의존**

이 1~180화에서 반복·변형된다.
