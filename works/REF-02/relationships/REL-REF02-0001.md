# 제한된 권리 거래에서 비밀권을 인정하는 장기 동업 관계로

## 현재 판정

주인공 A는 조직 소속을 거부하지만 관계 자체를 거부하지 않는다. 상대가 행사할 권리와 자신이 부담할 의무를 한정할 수 있을 때 임대·중개·임시 동료·보호·동업 관계를 수용한다.

41~50화에는 계약 기능이 끝난 뒤에도 감사·걱정·사과·비공식 부탁이 남을 수 있다는 사실이 확인됐다.

61~116화에는 중개자 A와의 관계가 더 변한다. 두 사람은 서로의 장기 목적과 비밀을 전부 공개하지 않아도 **비밀을 캐묻지 않을 권리, 협상·소개·분석을 맡길 권리, 각자 떠날 권리, 미래에 다시 협업할 권리**를 인정하는 동업 관계로 이동한다.

관계의 깊이를 `서로 얼마나 많이 아는가`만으로 측정할 수 없다.

## 기본 권리와 의무 · 1~116화

- 질문권: 필요한 계약·위험 질문은 가능하나 상대가 숨기려는 장기 목적·수법을 강제로 밝힐 권리는 없음.
- 거절권: 조직 소속·사적 친교·비밀 공개·자원 상납·동행 지속을 거절할 수 있음.
- 접근권: 정보·추천·시설·중층부·상층부 계약·협상 네트워크로 확대됨.
- 정보 비밀권: 거래에 필요한 정보와 사적 배경을 분리함.
- 대표/중개권: 중개자 A가 조직·상인·상층 인물과의 협상을 대신하거나 연결할 수 있음.
- 이탈권: 서로 다른 목적 때문에 다른 지역으로 떠날 수 있음.
- 미래 협업권: 즉시 동행하지 않더라도 후속 상층부에서 다시 협력하기로 약속할 수 있음.
- 비용 의무: 명시 보수뿐 아니라 소개 보답·선물·정보 교환·위험 공유가 존재함.

# 중개자 A → 장기 동업자 A

## 초기 분류

서로 출신과 수법을 공개하지 않는 거래 상대. 중개자 A는 결과·보수·정보를 관리하고 주인공 A는 수행 방법을 숨긴다.

## 21~40화 · 추천 신뢰와 거래 완충

- 사적 배경이 드러날 술자리를 차단
- 축기 자원·상위 세력 정보 접근 제공
- 반복 실적을 추천 신뢰로 전환
- 경쟁 조직 제안을 가격 경쟁에 사용
- 주인공 A는 정보와 추천의 값어치를 인정하고 보답 의무를 수용

## 48~49화 · 계약 밖 감정 잔여

한 달간 연락이 끊긴 뒤 중개자 A는 주인공 A가 죽었을 가능성을 걱정했다고 말한다. 곧 자신의 손해라는 거래 언어로 감정을 축소한다.

주인공 A가 그 냉정함을 지적
→ 같은 평가가 되돌아옴
→ 주인공 A가 연락하지 않은 일을 사과
→ 소개 부탁·보답 협상

으로 관계가 바뀐다.

상대 내면 POV가 열리지 않으므로 순수한 걱정인지 사업 손실인지 확정하지 않는다. 그러나 `부재를 문제 삼을 권리`와 `사과를 받을 권리`는 실제 행동으로 생긴다.

## 66~72화 · 부재 자체가 재추적 이유가 된다

주인공 A는 중개자 A가 기존 위치에서 사라진 사실을 단순 거래처 변경으로 넘기지 않는다. 게임 지식과 현재 사건 변형을 대조해 왜 상층으로 이동했는지 추적한다.

목적은 정보망 회복뿐 아니라 **오래 거래해 온 상대에게 무슨 일이 생겼는지 확인**하는 것도 포함된다.

다만 감정 이름을 확정하지 않고 실제 추적 행동만 기록한다.

## 정보 비밀권의 확장

중개자 A의 이동 사정과 관련된 제3자의 사적 배경을 알게 된 뒤, 주인공 A는 필요한 위치·계약 정보는 사용하지만 허락 없이 그 사적 배경을 다른 상대에게 공개하지 않는다.

관계망에서 얻은 정보는 자동으로 재판매 가능한 소유물이 아니다.

## 73~83화 · 위험한 수단 대신 자신을 대안으로 제안

중개자 A의 장기 목적에는 위험한 상계 유물이 필요할 수 있다. 주인공 A는 목적의 전부를 알지 못한 상태에서도 그 수단의 위험성을 확인하고, 자신이 향후 그 목적을 해결할 다른 수단이 될 수 있다고 제안한다.

둘은 자신들이 이미 동업 관계였음을 다시 확인한다.

중요한 점:

- 주인공 A가 상대 목적을 전부 알아야만 돕는 것은 아님.
- 상대도 주인공 A의 모든 비밀을 알지 못함.
- 위험한 수단을 쓰지 않는다는 합의가 상대의 자유를 완전히 통제하는 계약으로 변하지 않음.

## 84~98화 · 비밀을 묻지 않고 역할을 맡긴다

주인공 A가 상계 힘을 몸에 별도 저장한 방식은 공개하지 않는다. 중개자 A도 자기 장기 목적을 전부 설명하지 않는다.

그럼에도:

- 상대는 협상·소개 역할을 맡음
- 필요한 인물·조직과 연결함
- 주인공 A의 별도 성장법을 강제로 캐묻지 않음
- 주인공 A도 상대가 말하기 싫은 부분을 더 묻지 않음

비밀 비대칭이 곧 불신 증거가 아니다.

## 114~116화 · 각자 떠나면서 미래 협업을 갱신한다

주인공 A는 대륙 규모 사건으로 이동하고, 동업자 A는 자기 장기 목적 때문에 귀수성에 남는다.

둘은 동행·상시 보고를 요구하지 않는다. 대신 상층부에서 다시 만났을 때 협업하자는 미래 약속을 갱신한다.

관계 상태는:

`같은 장소의 중개 거래`
→ `장기 공백과 사과`
→ `위험 수단을 함께 판단하는 동업`
→ `서로 비밀과 이동 자유를 가진 장거리 협업 후보`

로 이동한다.

# 임대인 A와 가족 구성원 A

거주 계약은 비용과 방어 설비의 교환에서 시작했다. 생활 호의와 거주 위기 해결 뒤 연단 시설·기초 교육으로 접근권이 확대됐다.

43화에는 주인공 A가 신원 노출 때문에 이주하면서도 물건값 정산·선물·재회 가능성을 남긴다. 계약 종료와 관계 종료가 동일하지 않은 초기 반례다.

# 보호·임시 동료 관계

보호 계약에서는 생환 의무와 자원권을 분리하고 위험 정보 우위 때문에 일시 통제권을 사용한다.

임시 동료와는 작전 역할을 수용하되 사적 복종과 신원 공개를 분리한다. 이 관계의 후속 장기 발전은 `REL-REF02-0004`로 관리한다.

## 관계 전환 사슬

결과·보수 중심 거래
→ 추천·정보 접근권 확대
→ 방법·신원 비공개권 유지
→ 계약 밖 걱정·사과·소개 등장
→ 상대 부재를 재추적
→ 위험한 장기 목적에 대안 수단 제안
→ 서로의 비밀을 캐묻지 않는 권리 확인
→ 각자 이동 자유 유지
→ 미래 협업 약속

## 표현 증거

### 48화

걱정
→ 손실 언어
→ 냉정함 지적
→ 반사 평가
→ 사과
→ 실무로 복귀

### 73~83화

장기 목적의 상세 감정 고백보다:

위험 수단 확인
→ 대안 제안
→ `이미 동업자`라는 관계 확인
→ 실제 상위 위협 공동 대응

으로 관계를 증명한다.

### 114~116화

작별을 영구 이별이나 감정 폭발로 만들지 않는다. 서로 다른 목적지를 인정하고 **다음 상층부에서 다시 협업한다는 미래 권리**를 남긴다.

## 실패·오해·반례

- 서로 비밀이 많아 실제 위기 원인을 늦게 알 수 있음.
- 상대의 장기 목적이 주인공 A의 생존 목표와 충돌할 가능성 미확인.
- 비공식 관계 의무가 큰 자원 손실을 요구할 때 우선순위 미확인.
- `동업자`라는 호칭이 무제한 보호·공동 운명을 뜻하지 않음.
- 장거리 분리 뒤 실제 지원이 유지되는지 120화 현재 미확인.

## 다음 질문

121~180화에서 물리적으로 떨어진 동업자 A가 정보·소개·구조·자원 면에서 실제 장거리 동업자로 기능하는가. 서로의 비밀권이 위기에서 정보 부족 비용을 만드는 반례가 나타나는가.
