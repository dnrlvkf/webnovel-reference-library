- 주인공 A: 거대 외부체·인간 진체·내적 성체의 3단 구조를 운용.
- 최종 적 A: 인간형 육체가 소멸해도 뿌리/대지에 실존이 남음.
- 최종 세계 파괴수: 인간 관계 기억이 일부 남아 있어도 존재 구조 자체는 나무/세계로 변함.

따라서 TEC-08의 상위 메커니즘은:

`표면 전투 형상 파악 → 실제 실존 앵커 확인 → 표면 격파와 완전 종료 분리 → 경지/종족에 맞는 앵커 종결`

로 재정의할 수 있다.

## 비상 능력의 최종 변형

- 대승급 적의 진체를 직접 지정해 목격자 없는 내부에서 사용.
- 최종 세계 파괴수처럼 인간형을 잃은 존재에게도 관계 기억과 시선 조건을 이용해 실제 대상과 접속.
- `다른 동료도 모르는 비밀을 너에게만 보여 준다`는 제안으로 상대의 독점 욕망을 움직여 자발적 시선 고정을 만든 뒤 사용.

비상 능력은 마지막까지 단순 화력 버튼이 아니라 **대상 정체성·시선·행동권·정보 욕망을 조립한 뒤 쓰는 종결 수단**이다.

# CONTRADICTED / 수정

- `자율성을 중시한다 = 타인의 행동권을 언제나 존중한다` — `CONTRADICTED` 하위 해석.
- `상위 존재의 강제 임무를 수행한다 = 그 존재에게 충성한다` — `CONTRADICTED`.
- `같은 적/같은 반운명 명분 = 동맹 가능` — `CONTRADICTED`.
- `새 상위 기술을 이해하면 강적 상대로 항상 우위` — `CONTRADICTED`.
- `대승경 이상 전투도 표면 육신 격파가 죽음` — `CONTRADICTED`.
- `최종 보스급 화력 우위 = 근접 실전 우위` — `CONTRADICTED`.

# HOLD

- `TEC-07`의 순수 잘못된 구조 판독 실패는 284화 경계에서도 직접 확인되지 않음.
- 비상 능력이 분신/가짜 본체를 실제로 오지정하는 실패는 확인되지 않음.
- 상위 동맹 A의 후대 연구 의무 직접 회수는 확인되지 않음.
- 장기 동업자 A의 기존 조직 의무와 상계 공동 목표 최종 충돌은 이 범위에서 직접 회수되지 않음.
- 강제 상위 임무가 이후 장기 종속 관계로 이어지는지는 source boundary 이후 미확인.

# Macro / Payoff / Micro 판정

- Macro 후보 1: 같은 반운명 이념을 주장하는 최종 상위자의 동맹 제안을 `도피 vs 원인과 대결`이라는 방법 기준으로 거절.
- Macro 후보 2: 세계 파괴수로 변한 최종 적의 오래된 독점 정보 욕망을 이용해 시선 조건을 조립하고 비상 능력을 사용.
- Payoff 후보: 동료 A의 천둔/천안 봉인 → 사명 달성·봉인 해제 → 최종전 시간 정지 권능 공개.
- 신규 Micro 없음. 결정 기능은 단일 문구보다 장면 배열·행동 조건에 있음.
