# BATCH-REF02-0001 · 초기 1~10화 여섯 트랙 연구

- source: `SRC-COL2-027 / 1~10화 / 1~3224행`
- mode: `구간 정밀 분석`
- identity: `sealed`
- question: 압도적인 단일 대상 제거 능력을 왜 만능 해법으로 사용하지 않고 확장 가능한 생존 체계로 연결하는가.

## CHARACTER — SUPPORTED

주인공 A의 핵심은 냉혹함이 아니라 장기 생존 가능성을 늘리는 판단이다. 그는 현재 세계와 기존 지식의 일치, 상대 발언과 실제 정보의 일치, 다음 위협을 먼저 확인한다. 단일 능력은 즉시 죽음이 확실하고 대체 수단이 없는 경우에만 사용하고, 평상시에는 수련 자질·공법·법술·정보를 늘린다.

기본 사슬은 `기존 지식으로 선택지 생성 → 현재 정보로 검증 → 약함과 무지를 상대에게 믿게 함 → 숨은 수단을 결정적 순간에만 공개 → 결과를 성장 자원으로 전환`이다. 아직 게임 지식의 오류와 능력 보류가 실제 손실을 만드는 반례는 확인되지 않았다.

## RELATIONSHIP — DIRECT

주인공 A와 초기 스승 A의 관계는 표면상 사제지만 실제로는 상호 포식 관계다. 스승은 제자를 성장시켜 흡수하려 하고, 주인공은 공법·단약·은신처를 얻기 위해 제자 역할을 유지한다. 결정적 비대칭은 주인공만 양쪽 계획을 안다는 점이다.

`상호 분류 → 자원 제공 → 성취 속도 노출 → 양쪽의 살해 임계점 계산 → 상대 실행 준비 → 주인공의 선제 회수 → 공법·비급·은신처 통제권 이전`으로 관계가 종료된다. 절·호칭·축하·눈물은 신뢰의 증거가 아니며 실제 권리와 살해 준비가 의미를 확정한다.

## EVENT — DIRECT

### 세계 진입과 첫 생존 자원 전환

장수 욕망과 게임 경험을 가진 주인공 A가 세계에 진입한다. 구조 요청자의 발언을 상태 정보와 대조해 거짓을 확인하고 구조를 거절한다. 이어진 초월적 위협에는 단일 제거 능력을 사용한다. 승리 결과는 단순 전투 보상이 아니라 후천 수련 자질로 전환되어 일반 성장 체계에 진입하게 한다.

### 포식형 관계 이용과 종료

수련 자질은 얻었지만 공법·자원·은신처가 없다는 결핍 때문에 위험한 스승 관계에 진입한다. 관계를 즉시 파기하지 않고 성장 임계점까지 이용한 뒤, 상대의 독살·기습 준비가 확정되자 먼저 제거한다. 결과로 자원과 통제권을 회수하지만 흔적과 후속 조직 접촉이 새 문제를 연다.

## STORY — SUPPORTED

초기 아크의 질문은 ‘확정 제거 능력이 있는데 왜 여전히 수련·기술·정보·조직이 필요한가’다.

`오래 살고 싶다 → 즉시 생존을 위해 능력 사용 → 능력만으로는 수련 불가 → 후천 자질 확보 → 위험한 관계를 통해 공법 확보 → 상대 자원 회수 → 일반 전투 수단 구축 → 상위 성장 조직 접촉`으로 목표가 전환된다.

보상은 항상 다음 결핍을 연다.

- 초월 위협 제거 → 후천 자질 / 공법 부재
- 공법 습득 → 빠른 성장 / 스승의 포식 계획
- 스승 제거 → 자원 회수 / 추적과 외부 성장 경로
- 다수전 승리 → 실전 검증 / 상위 조직의 조사

반년 수련은 압축하고, 임계점·법술 첫 성공·실전 검증은 장면화한다.

## PROSE — SUPPORTED

초기 설명은 설정 소개로 끝나지 않고 `규칙 설명 → 현재 선택 → 즉시 시험 또는 결과 → 새 한계`로 닫힌다. 기본은 주인공 A 판단에 밀착한 3인칭이고, 포식형 관계와 전투 일부에서 상대 내면으로 이동한다. 초점 이동은 상대가 왜 합리적으로 오판했는지를 보여 준다.

감정은 직접 명명되지만 오래 머물지 않고 자원 계산·위험 판정·다음 목표로 전환된다. 질문 대사는 정보 검증 도구이며, 대사의 실제 의미는 상태 정보·상대 내면·뒤 행동이 판정한다.
