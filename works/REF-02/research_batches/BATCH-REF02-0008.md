# CHARACTER

## 1. 조직 자원 이용과 정보 충성은 분리된다 — DIRECT / SUPPORTED

가짜 신분 B는 상위 조직 A의 시험·급여·안전 공간·임무 접근을 수용한다. 그러나:

- 실제 탐지 수단을 공개하지 않음
- 적 조직의 더 넓은 계획을 조직이 알지 못하도록 현장 정보를 일부 소각함
- 조직 감시를 예상하고 거짓 수련 장면을 보여 줌
- 조직이 자신을 신뢰하도록 만들되 그 신뢰를 자기 신원·능력 전체에 대한 접근권으로 확장하지 않음

따라서 `조직 내부 역할을 받는다 = 조직의 정보 이익을 우선한다`는 명제는 성립하지 않는다.

## 2. 적대자 분류가 더 세분화된다 — DIRECT

잠입 조직 현장에서 주인공 A는 실제 적대 술자와 강제로 조종되었을 가능성이 높은 일반인을 같은 범주로 처리하지 않는다. 적대 구조의 중심을 제거한 뒤 후자는 도주하게 둔다.

이는 `적 조직과 같은 공간에 있다 = 제거 대상`이라는 평탄화를 반박한다.

## 3. 현재 진심과 미래 안전을 분리한다 — DIRECT

상위 조직 A가 가짜 신분 B의 공로에 실제로 감사하고 보호·휴식 자원을 준다. 주인공 A는 감사의 진정성을 부정하지 않지만 그것이 미래에도 자기 권리를 지켜 줄 보증이라고 보지 않는다.

판정:

- 현재 감사·보상: `DIRECT`
- 그 감사가 장기 안전권을 보장함: `CONTRADICTED` 해석

## 4. 비공개 정보는 공개 가능한 행동 증거로 변환한다 — SUPPORTED

실제 잠입자를 이미 알고 있어도 탐지 원리를 설명하지 않는다. 대신 상대가 회피할 것으로 예상되는 공개 규칙을 만들고, 실제 적의 반응이 제3자가 확인할 수 있는 증거가 되게 한다.

이는 기존 `상대의 선택을 조건으로 조립한다`는 CHARACTER 스레드의 정보전 변형이다.

## 5. 상대 자율성의 욕망을 이용하지만 결과 선택까지 소유하지 않는다 — SUPPORTED

주인공 A는 상위 후계자 A와 정치 후보 A가 기존 조직 통제를 싫어하거나 자기 삶을 선택하고 싶어 하는 기준을 알고 짧은 말·상황 설계로 그 욕망을 자극한다.

그러나 후속 선택은 서로 다르다.

- 정치 후보 A는 조직의 꼭두각시가 되는 명령을 스스로 거부함.
- 상위 후계자 A는 이용당한 사실을 알고도 주인공 A의 자유를 자기 삶의 모델로 재분류함.

`주인공 A가 조종했으므로 상대의 후속 선택도 전부 그의 명령이다`는 해석은 지지되지 않는다.

## 6. 관계 상대를 전략적 주의 분산으로 이용하는 실제 비용 — DIRECT

주인공 A는 상위 후계자 A를 완전히 끊거나 제거하지 않고, 그녀가 자신을 계속 추적하면 상위 조직 A의 시선을 일부 묶을 수 있다고 계산한다. 관계 상대의 욕망과 위험을 자기 이탈에 이용한 실제 사례다.

따라서 `타인 비용을 줄이려 한다`와 `관계 상대를 전략 자원으로 사용하지 않는다`는 별개다. 후자는 `CONTRADICTED`.

## 7. 승리 공로를 독점하지 않고 상대 목표의 소유권을 돌려준다 — DIRECT

위험한 상위 동행자 A의 복수전에 참가해 실질적 결정타를 담당하지만, 사후 공로를 자기 단독 승리로 명명하지 않는다. 복수 대상에게서 발견한 유해를 상대에게 돌려 주고 `공동 복수`로 정리한다.

상대의 목표를 이용해 협력했지만 목표의 감정적·관계적 소유권까지 빼앗지 않는다.

## 8. 상위 경지 진입 뒤 학습 가치 때문에 확정 제거를 다시 늦춘다 — DIRECT

원영경 진입 뒤 주인공 A는 상위 적 A를 즉시 비상 능력으로 제거하지 않는다. 새 법역·시간 인식·상위 전투 체계를 직접 시험할 학습 가치가 더 크다고 판단한다.

육신과 법역을 일반 수단으로 무너뜨린 뒤 도주 영혼에 비상 능력을 사용한다.

`대체 전투 수단의 실전 학습 가치`가 비상 능력 보류 조건으로 재강화된다.

## 9. 알 수 있는 능력과 물을 권리를 분리한다 — DIRECT / SUPPORTED

원영경 진입 뒤 주인공 A의 감지력이 올라 장기 동업자 A의 깊은 과거 상태 일부를 읽을 수 있게 된다. 그러나 즉시 폭로하거나 설명을 요구하지 않는다.

`알 수 있음 → 물을 권리 발생`이 아니라:

감지
→ 침묵
→ 상대가 필요한 만큼 먼저 공개
→ 나머지를 말하지 않아도 된다고 확인
→ 자기 비밀도 같은 권리로 존중받기를 요구

로 처리한다.

## 1. 내부 검증 성공을 안전이 아니라 다음 오해의 토대로 사용

121~132화는 상위 조직 A가 가짜 신분 B를 더 신뢰할수록 주인공 A가 안전해지는 구조가 아니다. 조직의 검증은 거짓 텔레메트리와 선별 정보 위에서 성공하고, 그 성공이 더 깊은 임무·감시·정치 사건으로 들어가는 통로가 된다.

## 2. 같은 행동의 의도를 관계 상대가 오독하게 둔다

상위 후계자 A는 주인공 A의 전술적 분리 행동을 자기희생으로 해석한다. 작가는 즉시 오해를 교정하지 않고 그 잘못된 해석이 실제 보호·집착·비밀권 존중 같은 후속 행동을 만들게 둔다.

오해가 틀렸다고 해서 사건 효과가 사라지지 않는다.

## 3. 짧은 자율성 질문을 후반 독립 선택으로 회수

정치 후보 A에게 던진 짧은 질문은 나중에 주인공 A가 없는 자리에서 조직 종속을 거부하는 선택으로 회수된다. 주인공 A는 선택 이후에 나타나 보호·확인만 한다.

`PAY-REF02-0003` 후보.

## 4. 승리의 종료 지점을 계속 뒤로 민다

- 전함 승리 → 적 영혼 분열·도주
- 상위 적 육신 제압 → 영혼 탈출
- 법역전 승리 → 영혼 도주
- 강적 제거 → 승자를 노리던 다른 상위 포식자 등장

따라서 후반 전투의 완료 조건은 `육신을 이겼는가`가 아니라 `탈출·잔존 위협까지 닫혔는가`로 바뀐다.

## 5. 관계 미스터리도 성장 뒤에만 더 많이 연다

장기 동업자 A의 과거·목적은 초반부터 전부 설명하지 않는다. 주인공 A의 감지 능력과 필요 수준이 높아진 뒤에야 일부가 공개되며, 공개는 관계를 닫기보다 `상계 진입까지 공동 목표`라는 더 큰 장기 약속을 만든다.

# PROSE

신규 `PRO-REF02-0006` 후보.

## 1. 비공개 사실을 상대 반응으로 공개 증거화

121~126화는 주인공 A가 `나는 진실을 안다`고 설명하지 않는다.

비공개 탐지
→ 공개 규칙 제시
→ 상대 회피·도주
→ 주변 인물 재분류

로 정보 출처를 숨긴다. 대사는 사실 전달보다 반응 유도 장치다.

## 2. 관계 감정은 의도와 해석을 일부러 어긋나게 한다

133~149화 주인공 A의 전술적 행동과 상위 후계자 A의 자기희생 해석을 분리한다. 후계자 A의 해석이 틀렸어도 독자는 그 오해가 실제 관계 권리를 바꾸는 과정을 본다.

## 3. 침묵·행동으로 애도와 신뢰를 제시

150~156화 상위 동행자 A의 복수 완결 뒤 감정은 장황한 독백보다 유해를 받아드는 행동·침묵·몸의 반응으로 제시된다. 주인공 A는 상대 감정을 완전히 설명하지 않고 필요한 공로·유해 반환 행동만 수행한다.

## 4. 기술 지문의 관찰 대상이 `영기 흐름`에서 `법칙·시간층·세계 구조`로 상승

원영경 전후로 지문이 보는 대상이 변한다.

- 기존: 흐름·결합·압축·중추
- 원영경: 법역 경계·세계 규칙·미세 행동시간·의식의 반응층

캐릭터 성장 자체가 서술 어휘와 관찰 단위를 바꾼다.

## 5. `비어 있음`을 상대 오판 → 자기 재정의 → 즉시 증명으로 처리

상위 적 A는 주인공 A의 빈 법역을 상상력 부족으로 평가한다.

상대 판정
→ 주인공 A가 공백을 미할당 가능성으로 재정의
→ 실제 상계 심상 투사
→ 상대의 모방 법역 붕괴

추상 철학 설명만 두지 않고 바로 전투 상태 변화로 검증한다.

## 6. 초기 감정 애매함을 후반 직접 발화로 좁힌다

48화에는 장기 동업자 A의 걱정이 경제적 자기방어 언어와 섞여 객관적 감정 성격을 확정하지 않았다.

178화에는 상대가 과거 주인공 A 부재 때 실제로 크게 상실감을 느꼈다고 자기 발언으로 밝힌다. 관계가 깊어지며 초기 애매함 일부가 해소되지만 장기 목적의 모든 이유까지는 공개하지 않는다.

# TECHNIQUE

## 1. `TH-REF02-CHR-02` 보강

- 127~132화: 목격자 없는 고립 조건에서 중기 상위 적 제거.
- 150~156화: 일반 전투로 육신 승리를 얻은 뒤 분열 도주 영혼을 비상 능력으로 종결. `승리 수단 → 비가역 마무리` 변형.
- 170~177화: 원영경 진입으로 주인공 A 자신의 미세 행동시간 인지가 상승. 이전 후기 상위 적에게 위험했던 대상 지정 공백을 이제 스스로도 따라갈 수 있음.
- 새 법역을 연습할 학습 가치 때문에 즉시 사용을 보류하고, 상대 영혼이 도주할 때만 사용.

비상 능력 상한은 상대 경지만이 아니라 **주인공 자신의 시간층과 학습 목적**에도 의존한다.

## 2. `TH-REF02-TEC-02` 보강

- 조직 감시 장치를 거짓 수련 텔레메트리로 역이용해 내부 검증 성공.
- 공개 화염 프로필을 적이 카운터한 결과 폐쇄 공간이 생기고 숨은 수단 사용 조건이 됨.
- 얼굴을 바꿔도 오래된 적이 시선·행동 흔적으로 가짜 신분 B를 재식별함.
- 가짜 신분 B는 영구 신원이 아니라 임무 비용이 누적되면 폐기되는 소모층으로 확인.

## 3. `TH-REF02-TEC-05` 보강·경계

- 126화: 상위 공간 탈출 수단이 이미 있으면 진법 중추 분석을 고집하지 않음. `중추 파괴`는 목적이 아니라 비용 대비 해결 방식임.
- 165~169화: 대형 풍계 진법에 다른 고급 풍계 신호를 주입해 교차 반응·제어 혼란을 일으킴. 결합부 직접 파괴가 아니라 `제어 시스템의 입력 가정`을 깨는 변형.
- 170화대: 공간을 태우는 수단으로 적 법역 경계에 균열을 만들어 외부 진입. 장벽 전체 파괴보다 통로 생성에 목적을 축소.

## 4. `TH-REF02-TEC-07` 보강

- 적 혈계 기술을 기존 독·혈 연구와 합성해 자기 법기 운용으로 전환.
- 일회성 자동 방어 수단의 작동 원리를 자기 상시 방어술로 재구성.
- 여러 법역 관찰 + 자기 고유 내적 공간 + 장기 동업자 A 계통 수련법 + 직접 기억한 상계 심상을 합성해 `빈 법역 플랫폼`을 구축.
- 모방 품질은 기술 명칭보다 **원천을 얼마나 직접·정밀하게 관찰했는가**에 따라 달라짐. 상대보다 직접 본 심상을 더 정밀하게 투사해 우위를 얻음.

잘못된 구조 판독 때문에 발생한 본격 실패는 이번 범위에서도 부족하다. `HOLD` 유지.

## 5. 신규 `TH-REF02-TEC-08` 후보 · 육신 제압과 도주 영혼 종결을 분리한다

상위 경지 전투에서 육신 파괴가 전투 종료가 아니다.

육신 제압
→ 영혼/원영 도주 예상
→ 도주 방향·속도·수단 판정
→ 사전 배치한 다른 동료 또는 비상 능력에 종결 역할 부여
→ 도주 영혼 제거
→ 부활·도주·정보 유출 차단

반복:

- 150~156화: 주인공 A가 육신 승리 뒤 분열 영혼을 직접 비상 능력으로 종결.
- 165~169화: 상위 동행자 A가 육신을 제압하고, 주인공 A가 미리 배치한 다른 상위 동료가 도주 영혼을 제거.
- 170~177화: 주인공 A가 육신·법역을 무너뜨린 뒤 도주 영혼은 비상 능력 또는 매복 동료로 처리.
- 180화: 새 상층 포식자의 육신 제압 뒤 다른 동료의 넓고 빠른 공격이 도주 영혼을 제거.

비용:

- 영혼 도주 수단을 미리 예측해야 함.
- 종결자 배치가 실패하면 육신 승리가 무효화될 수 있음.
- 상대 법역·봉인 때문에 퇴로가 바뀔 수 있음.
- 넓고 빠른 영혼 공격 수단이 부족하면 추적 비용이 커짐.

다른 적·다른 장소에서 반복되어 `VERIFIED_THREAD` 후보로 판단한다.

# Payoff·Macro·Micro 판정

## PAY-REF02-0003 후보

초기: 정치 후보 A에게 `조직이 너를 이용하려 한다면 너도 조직을 네 이익에 쓰면 된다`는 자율성 질문을 던짐.

후기: 주인공 A가 없는 자리에서 정치 후보 A가 조직의 통제 장치를 버리고 살아 있는 지배자를 죽여 꼭두각시가 되는 선택을 거부함.

주인공 A는 선택 이후에야 도착해 결과를 보호한다.

`말 → 복종`이 아니라 `질문 → 자기 판단 → 독립 선택`으로 회수되므로 장기 Payoff 가치가 있다.

## MAC-REF02-0004 후보

170~177화 빈 법역 장면.

- 상대는 `비어 있음`을 결핍으로 분류.
- 주인공 A는 결핍 판정을 정정하기보다 공백의 기능을 설명.
- 즉시 상계 심상을 구현해 공백이 미할당 용량이었음을 증명.
- 독자의 약함/미완성 판정이 확장성/플랫폼 판정으로 전환됨.

원문에서 상대의 조롱 → 자기 재정의 → 구현 결과 순서를 다시 읽어야 하므로 독립 Macro 가치가 있다.

## Micro

신규 없음. 이번 범위의 결정적 작동은 한 문장보다 다중 장면 정보권·관계 오독·법역 재분류의 배열에 있다.

# CONTRADICTED / HOLD / 비용

## CONTRADICTED

- `현재 조직의 진심 어린 감사 = 미래에도 안전권 보장` — 후속 조직 구조상 성립하지 않음.
- `가짜 신분 검증 성공 = 실제 능력/수련 정보가 검증됨` — 거짓 텔레메트리로 검증 성공 가능.
- `관계 심화 = 비밀 공개량 증가` — 장기 동업자 A는 더 큰 신체·성장 책임을 맡아도 비밀권이 유지·대칭화됨.
- `육신 격파 = 상위 적 전투 종료` — 반복 영혼 도주로 반박.
- `관계 상대를 전략 자원으로 사용하지 않는다` — 상위 후계자 A의 추적을 이탈용 주의 분산으로 사용.

## HOLD

- 상위 후계자 A와 주인공 A가 상호 친구·연인·가족 중 어떤 장기 관계로 귀결되는지.
- 장기 동업자 A의 상계 진입 이후 공동 목표가 계속 유지되는지.
- `TEC-07`의 본격적인 잘못된 구조 판독 실패.
- 비상 능력 자체가 상계 존재에게 감지되는지.
- 다중 본체/가짜 본체를 직접 대상으로 할 때 대상 지정이 어떻게 실패하는지.
- 상위 동행자 A의 개인적 부채가 장기 의무로 남는지.
