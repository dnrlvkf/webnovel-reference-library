# 주인공 A

## 현재 연구 판정 · 1~120화

주인공 A는 고정된 냉혹함·계산성·겁 없음으로 설명되지 않는다.

1~120화에서 가장 안정적으로 확인되는 것은 **장기 생존과 자기 경로 선택권을 기본축으로 삼되, 인간다움·초월 성장·관계 의무·학습 기회·타인의 비용이 조건에 따라 경쟁하는 판단 지도**다.

초기에는 `죽지 않고 성장할 일반 경로를 만든다`가 중심이었다. 후반으로 갈수록 생존의 의미가 넓어진다.

> 당장 위험을 피한다
> → 장기 성장과 거절권을 유지한다
> → 검증된 관계를 선택한다
> → 필요하면 위험을 직접 받아 학습한다
> → 조직 자원을 쓰되 조직이 삶 전체를 소유하게 하지는 않는다
> → 더 높은 단계에서는 자기 길과 선택권을 유지하는 것이 생존 자체의 일부가 된다

게임 지식, 비상 능력, 조직, 관계, 장비, 상계 힘 중 어느 것도 자동 정답으로 취급하지 않는다. 새 문제가 생기면 기존 수단의 기능과 한계를 다시 정의한다.

# 1. 먼저 확인하는 것

- 기존 지식과 현재 현실의 일치 여부
- 상대의 말·현재 행동·과거 이력의 일치 여부
- 표면 정보와 깊은 정보의 불일치
- 상대 목적·탐욕·공포·충성·회복 상태·미확인 수단
- 계약의 실제 권리·의무와 비용 부담자
- 목격자·추적자·후속 상위 위협
- 재사용 시간·사건 제한 시간·상대 행동시간
- 저장 용량·회복률·생산량·보급량
- 힘의 결합부·순환·중추·발원점
- 공격이 실패했을 때 무엇을 새로 관찰할 수 있었는지
- 자신의 행동 흔적이 어떤 신원 가설을 만들지
- 전투력이 아니라 생산·보급·재생산 능력이 어디서 나오는지
- 동료가 자기와 다른 어떤 실패 조건을 덮는지
- 지금 위험을 감수할 학습/성장 가치가 실제로 있는지

# 2. 기본 우선순위와 경쟁 기준

## 기본축

1. 되돌릴 수 없는 죽음 방지
2. 수명 연장과 일반 성장 경로
3. 거절권·이동권·비밀권·선택권 보존
4. 회복 가능한 전투 상태
5. 비상 능력·지식 출처·실제 신원의 불필요한 노출 방지
6. 성과를 성장·방어·정보·생산·관계 권리로 복수 기능화

## 인간다움 유지 — DIRECT / SUPPORTED

43화에서 강해지는 효율만으로는 장생 목표가 완성되지 않는다고 직접 판단한다. 계약이 끝난 생활 관계에도 공정한 정산·선물·재회 가능성을 남긴다.

51화에는 자기 선택이 오해된 순간 생존에 필요 없는 개인 과거 기억을 제한적으로 공개해 의미를 교정한다.

인간다움은 항상 최우선은 아니지만 **효율로 자동 삭제하지 않는 별도 판단 기준**이다.

## 초월을 위한 위험 수용 — DIRECT / SUPPORTED

47화 축기에서는 본능적 죽음 공포를 인정한 채 장기 성장 기준을 선택한다.

88~89화에는 위험한 시험을 자기 대응 수단이 있다는 판단 때문에 받아들인다. 같은 위험을 자존심 때문에 떠안은 다른 인물의 실패를 바로 붙여 `위험 감수 자체 = 용기`라는 해석을 부정한다.

94화에는 안전한 이탈보다 향후 성장 자원과 자기 길을 위해 다음 조직 갈등을 선택한다.

105화에는 더 강한 지원자를 부를 수 있는데도 강적과 직접 싸우며 구조를 읽을 학습 기회를 다른 사람에게 넘기지 않으려 한다.

109~110화에는 결단 실패처럼 느껴지는 죽음/운명을 `정해진 결과`로 받아들이지 않고 자기 생존 의지를 다시 선택한다.

현재 판정:

> 위험 수용은 무모함이 아니라 **대응 수단 + 학습/성장 가치 + 자기 길**이 충분할 때 선택 가능한 출력이다.

## 관계 의무 — SUPPORTED

중개자/동업자 A, 임대인 A, 검증 동료 A·B와의 관계는 공식 독점 계약 없이도 실제 선택 비용을 만든다.

- 영입 거절에 비공식 관계 의무가 작동함
- 오랜 거래 상대의 부재를 직접 추적함
- 위험한 외부 수단 대신 자신이 대안 수단이 될 수 있다고 제안함
- 검증 동료에게 임무 보수 밖 성장 자원까지 투자함
- 관계 상대가 자기 때문에 조직 전체 전쟁을 벌이지 않기를 바람

다만 무제한 희생·복수 의무는 아직 확정하지 않는다.

# 3. 독립성의 변화

## 초기

`강한 조직에 속하지 않고 자기 수단과 거절권을 지킨다.`

## 51~60화

`독립성 = 혼자 해결`이 아님이 확인된다. 검증된 동료를 직접 선택하고 실제 맹점을 보완받는다.

## 61~120화

독립성은 더 복잡해진다.

- 우호 조직 전체를 자기 전쟁에 끌어들이지 않음
- 가입하지 않고도 개인 비경·신물 접근권을 얻음
- 전 적대자 C의 기술 소유권과 지휘 독립성을 인정함
- 동업자 A와 서로 비밀을 가진 채 장거리 협업 약속 유지
- 117~120화에는 **자기를 추적하는 상위 조직이 가짜 신분 B를 먼저 고용하도록 유도**함

따라서 현재 가장 정확한 정의는:

> 독립성은 조직·관계를 거부하는 것이 아니라 **누가 자기 삶에 어떤 권리를 갖는지 스스로 설계하는 능력**이다.

# 4. 위험과 타인 비용

주인공 A는 타인의 비용을 중요하게 보지만 타인을 전혀 이용하지 않는 인물은 아니다.

## 비용 제한

95~97화에는 우호 조직 A 전체 참전을 요구하지 않고 자기에게 필요한 수련 자원·신물 접근만 요청한다.

108~110화에는 관계 상대 C가 `주인공 A가 전쟁을 원하지 않는다`는 의사를 존중해 대규모 충돌을 막는다.

## 능동적 이용

117~120화에는 상위 후계자 A의 자유 욕망·호기심을 알고 의도적으로 자극한다. 상대가 자발적으로 가짜 신분 B를 상위 조직에 추천하도록 만들려 한다.

따라서:

- 무관한 비용을 줄이려 함 — `SUPPORTED`
- 상대 욕망을 자기 목표에 이용하지 않음 — `CONTRADICTED`

이다.

# 5. 정보와 오해

## 게임 지식

게임 지식은 후보·위험 좌표·인물 가능성을 제시한다. 현재 현실이 다르면 기억을 보호하지 않는다.

105~107화가 중요한 확장이다. 주인공 A는 과거 지식상 상위 관찰자 B가 다른 관계가 될 가능성을 알지만, 현재의 B가 자기 충성을 다시 선택하자 그 선택을 우선한다.

> 미래를 안다 ≠ 상대가 무엇을 원해야 하는지도 안다.

## 유용한 오해

상대가 주인공 A를 약자·숨은 고경지·법기 의존자·강한 배후가 있는 자로 잘못 분류해도 유리하면 정정하지 않는다.

44~46화에는 별도 활동 신원 A를 만들고 상위 추적을 그 신원에 전가한다.

114~116화에는 공개 전투에서 일부 힘만 보여 주고 목격자가 그 일부를 전체 전력으로 오판하도록 둔다.

117~120화에는 외모뿐 아니라 문서·신분패·개조 법기·대표 법술 억제까지 묶은 **제도권 가짜 신분 B**를 만든다.

## 장기 은폐 실패

106화의 깊은 관찰자 B는 현재 표면보다 더 깊은 체질 흔적을 읽어 오래 전 사건과 현재 주인공 A를 연결한다.

따라서 신원 은폐는 `위험 삭제`가 아니라 **관찰층별 위험 분산**이다.

# 6. 비상 능력 사용 기준

비상 능력은 일반 성장·전술을 시험할 시간을 보장하는 최후 안전망에서, 상위 경지의 행동시간과 자원 보존까지 계산하는 제한 자원으로 확장됐다.

현재 사용 기준:

1. 즉시 치명성
2. 일반 기술·도주·협업의 대체 가능성
3. 상대 미확인 수단
4. 외부 목격·추적 가능성
5. 정면 시선·대상 지정 조건
6. 재사용 시간과 사건 제한 시간
7. 후속 더 큰 위협
8. 학습을 위해 일반 대응을 시험할 가치
9. 상대가 대상 지정 시간보다 빠르게 개입할 수 있는가
10. 자폭·파괴 전에 온전히 보존해야 할 자원이 있는가

## 61~107화의 핵심 수정

- 원영경 중기: 직접 제거 성공.
- 원영경 후기: 평상시 행동시간 우위 때문에 사용 곤란.
- 같은 원영경 후기 상대가 스스로 행동 층위를 낮춘 순간: 사용 성공.
- 높은 경지라도 공격 동작이 단순·예측 가능하면 사용 가능 사례 존재.
- 107화: 주인공 A 생존보다 **상대 자폭 전에 극양 자원을 온전히 보존**하려고 사용.

`원영경 후기 이상이면 안 통한다`는 고정 상한 가설은 `CONTRADICTED`다.

# 7. 기술 학습과 전투 판단

## 전체 시스템보다 구조를 본다

초기에는 진법·법역의 전체 이론을 몰라도 결합부·발원점·중추만 끊었다.

61~120화에는 여기서 더 나아가 적 기술을:

노출
→ 구조 관찰
→ 파훼
→ 재현
→ 개량
→ 다른 분야 원리 합성

의 학습 체계로 바꾼다.

저주·빙결·이동술·자동 방어·순양 화염·자기 광역 화염에서 반복된다.

## 실패를 정보로 바꾼다

101~104화의 여러 공격은 상대에게는 실패로 보이지만 주인공 A에게는 속성별 방어 순환을 읽는 진단이다.

91~93화에는 이동술 재현에 성공해도 몸이 속도를 버티지 못해 큰 손상을 입는다. 기술 이해와 신체 적응을 분리하고, 후속 연체 수련이라는 새 목표를 만든다.

강적을 직접 상대하려는 이유 중 하나가 **전투 경험 자체를 학습 자원으로 본다**는 점이다.

# 8. 자원 처리

보상의 이름보다 현재 결핍을 해결하는 기능으로 재분류한다.

- 제한 부보: 잠입 화력 → 연단용 미세 화력
- 숨은 법기 A: 독 전달 → 이치 전달 인프라
- 고가 영차: 소비재 → 종자·묘목의 생산 자산
- 독물 서책·재료: 전리품 → 후속 독술 대응 연구
- 오행 법보: 고급 무기 → 단일 영근 밖 속성의 외부 저장 인프라
- 상계 힘: 즉시 통합할 힘 → 별도 저장 후 몸 강화 전용 자원
- 적의 순양 자원: 적 전력 → 결단의 극양 구성요소
- 조직의 비밀 비경: 소속 보상 → 가입 없이 빌리는 장기 수련 인프라

## 통합이 위험하면 분리한다

63~65화에 다속성 기운을 몸으로 직접 쓰면 손상된다. 84화의 상계 힘도 기존 영기와 억지로 합치지 못한다.

주인공 A는 `모든 힘을 자기 안에 완전 동화`하려 하지 않고:

한계 확인
→ 별도 저장소 마련
→ 역할 분할
→ 사용할 몸/법술 축을 따로 강화

한다.

# 9. 적대·책임 판단의 수정

초기에는 `상대가 치명적 욕망을 행동으로 확정 → 반격 → 결과 책임을 상대 선택에 귀속`하는 사례가 반복됐다.

61~120화에는 하위 명제가 수정된다.

- 현재 장면 선공이 없어도 충분한 포식 이력·조직 역할 때문에 제거할 수 있음.
- 94화 이후에는 성장 자원을 얻기 위해 조직 갈등 자체를 의도적으로 키움.
- 반대로 105~107화에는 적대 이력이 있어도 현재 선택을 한 번 다시 확인함.

따라서 현재 판단은:

> 상대의 현재 선택·과거 이력·역할을 확인하고 **자기 행동이 허용되는 범위를 구성한다.** 필요하면 그 조건을 능동적으로 조립한다.

이다.

`항상 현재 선공을 기다린다`는 하위 명제는 `CONTRADICTED`.

사후 모든 도덕 책임을 상대에게 돌리는 자기설명의 객관적 정당성은 여전히 `HYPOTHESIS`다.

# 10. 말하기·침묵하기

## 말하기

- 짧은 질문으로 상대 욕망·위계·정보 수준 확인
- 높은 경지의 명령도 계약이 아니면 바로 거절
- 보수 액수뿐 아니라 즉시 지급 여부까지 확인
- 상대의 자유 욕망처럼 이미 드러난 기준에는 짧은 문장만 넣어 행동 방향을 자극
- 과거 기억과 현재 선택이 충돌하면 다른 선택 가능성을 한 번 제시하되 강요하지 않음

## 침묵하기

- 비상 능력·상태 정보·지식 출처·실제 신원 비공개
- 동업자 A의 말하기 싫은 장기 목적을 캐묻지 않음
- 적 수장 B의 장황한 자기정당화 동안 새 몸과 금단을 시험함
- 공개 목격자들의 잘못된 전력 추론을 정정하지 않음

침묵은 냉정함이라는 성격 장식이 아니라 **회복·관찰·정보권 존중·오판 유지**의 반응 채널이다.

# 11. 조직 처리

## 1~60화

실제 선금·도주권·작전 자율권을 주는 조직과 제한 협력하고, 사적 위계·종속은 거절한다.

## 95~116화

가입 없이도 조직 핵심 비경과 신물 접근권을 얻는다. 해결한 비밀 부담과 실제 비용을 바탕으로 접근권을 협상한다.

## 117~120화

조직 거부 단계에서 더 나아가 **가짜 신분으로 상위 조직이 먼저 자기를 고용하게 만드는 단계**로 이동한다.

목표는:

- 원영경 성장 자원 접근
- 조직 내부 정보
- 향후 적대 조직을 안에서 흔들 기회

이다.

독립성이 조직 외부에만 있는 것으로 정의되지 않는다. 내부 역할을 받더라도 실제 권리·의무가 제한되고 이탈권이 남는다면 수단으로 사용할 가능성이 열린다.

# 12. 관계별 변주

- 조직 추천자 A: 비가역 종속 거부, 포식 관계 종료
- 임대인 A: 계약 종료 뒤 감사·정산·재회 가능성 보존
- 중개자/동업자 A: 정보·추천·사과에서 비밀권·장기 목적 대안·미래 협업으로 확대
- 검증 동료 A·B: 직접 선택 → 실제 맹점 보완 → 구조 → 장기 재선택 → 성장 자원 투자
- 보호 대상 집단 A: 생환 의무와 자원권 분리, 위험 때문에 이동권 일시 제한
- 제작자 A: 약점을 협박에 쓰지 않지만 협상 주도권 유지
- 행동대장 A: 소개 신뢰를 절차적 접근권으로 전환
- 동맹 조직 A: 보수·도주권·작전 자율권을 실제로 보장할 때 협력 확대
- 전 적대자 C: 핵심 기술 소유권과 지휘 독립성을 유지한 채 제한 교육·장비 대여·합동전
- 상위 후계자 A: 아직 안정 관계 아님. 자유 욕망·호기심을 의도적으로 자극해 상위 조직 접근 경로로 사용 중
