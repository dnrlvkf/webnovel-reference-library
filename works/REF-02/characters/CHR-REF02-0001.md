# 주인공 A

## 현재 연구 판정 · 1~240화

주인공 A는 냉혹함·계산성·겁 없음 같은 고정 성격으로 설명되지 않는다.

가장 안정적인 기본축은 **장기 생존과 자기 경로 선택권**이지만, 실제 선택에서는 다음 기준이 계속 경쟁한다.

- 죽음 방지와 수명 연장
- 거절권·이동권·비밀권·행동권
- 인간다움과 자기 정체성
- 초월 성장·학습 기회
- 관계 의무와 기존 약속
- 타인/제3자의 비용
- 현재 자원과 미래 자원
- 정보 노출·추적 위험
- 조직/상위 존재가 자기 삶에 얻는 권리

1~240화의 장기 변화는:

당장 위험 회피
→ 일반 성장 경로 구축
→ 조직 종속 대신 권리 제한 거래
→ 검증 관계에 선택 의존
→ 위험을 학습 자원으로 사용
→ 조직 자원을 쓰되 삶 전체 권리 통제
→ 조직 내부 역할과 정보 충성 분리
→ 관계가 깊어져도 비밀 질문권을 제한
→ 상층부에서는 자기 약한 감정까지 삭제하지 않고 이해
→ 문제에 개입하되 사후 통치권까지 자동 수용하지 않음
→ 초월 힘의 사용이 실제 원본의 채무/강제 관계를 만들 수 있음을 경험
→ 심지어 행동권 자체를 잃으면 최후 수단도 사용할 수 없음을 확인

으로 확장된다.

게임/과거 지식, 비상 능력, 조직, 관계, 법기, 상계 힘, 법역 중 어느 것도 자동 정답으로 보호하지 않는다.

# 1. 먼저 확인하는 것

- 기존 지식과 현재 현실이 일치하는가.
- 상대의 말·현재 행동·과거 이력이 일치하는가.
- 상대 행동이 자발적 적대인가 강제 상태인가.
- 표면 정보와 깊은 정보가 무엇을 다르게 보여 주는가.
- 상대 목적·탐욕·공포·충성·회복 상태·미확인 수단.
- 계약의 실제 권리·의무와 비용 부담자.
- 목격자·추적자·후속 상위 위협.
- 재사용 시간·사건 제한 시간·상대 행동시간·자기 행동시간.
- 저장 용량·회복률·생산량·보급량.
- 힘의 결합부·순환·중추·입력 가정·경계가 실제 존재하는가.
- 실패 공격/피격/도구 사용이 무엇을 새로 보여 주는가.
- 자신의 행동·시선·수련·기술 모사가 어떤 신원/귀속 가설을 만드는가.
- 동료가 자기와 다른 어떤 실패 조건을 덮는가.
- 지금 위험을 감수할 학습/성장 가치가 있는가.
- 현재 감사·호의와 미래의 제도적 권리가 같은가.
- 내가 알 수 있는 정보와 상대에게 공개를 요구할 권리가 같은가.
- **내가 문제를 해결할 책임과 그 뒤 사회/조직을 지배할 책임이 같은가.**
- **빌리거나 모사한 상위 힘이 실제 원본과 어떤 권리 관계를 만드는가.**
- **최후 수단을 쓸 최소 행동권이 현재 남아 있는가.**

# 2. 기본 우선순위와 경쟁 기준

## 기본축

1. 되돌릴 수 없는 죽음 방지.
2. 수명 연장과 일반 성장 경로.
3. 거절권·이동권·비밀권·선택권·행동권 보존.
4. 회복 가능한 전투 상태.
5. 비상 능력·지식 출처·실제 신원 불필요 노출 방지.
6. 성과를 성장·방어·정보·생산·관계 권리로 복수 기능화.

## 인간다움 유지 — SUPPORTED

43화에 효율만 남은 장생을 원하지 않는다고 직접 판단한다.

51화에는 자기 선택이 오해된 순간 생존에 필요 없는 과거 기억을 제한적으로 공개해 의미를 교정한다.

150~156화에는 자신이 복수전을 사실상 완결했어도 공로를 독점하지 않고 상대의 유해·애도 권리를 돌려준다.

225~230화에는 더 높은 변형이 나온다.

주인공 A는 생존을 위해 외로움·취약함을 밀어 두어 왔지만:

- 모든 관계에 끝까지 공개할 수 없는 비밀이 있음.
- 누구도 영원히 동행한다는 보장이 없음.
- 그 사실이 외로움을 만든다는 점.

을 인정한다.

그 감정을 제거하거나 냉혹함으로 덮지 않고 자기 일부로 이해한다.

현재 판정:

> 인간다움 유지 = 효율에 필요 없는 관계를 남기는 것뿐 아니라 **강해지기 위해 약한 감정과 평소 인격을 잘라내지 않는 것**.

`MAC-REF02-0006`에서 재독한다.

## 초월 위험 수용 — SUPPORTED

47화: 죽음 공포를 인정한 채 성장 선택.

88~89화: 대응 수단이 있는 위험 시험 수용, 자존심형 무모함과 대비.

94화: 안전 이탈보다 성장 자원·자기 길을 위해 조직 갈등 선택.

105화: 더 강한 대리 지원을 부르지 않고 직접 싸워 구조 학습.

109~110화: 정해진 죽음/운명 해석 거부.

170~177화: 새 법역을 실전에서 배우기 위해 비상 능력 즉시 사용 보류.

201~206화: 적 포획 장치를 예상하고 내부 시간/자원을 쓸 수 있어 의도적으로 진입.

현재 판정:

> 위험 수용은 **대응 수단 + 학습/성장 가치 + 자기 길 + 실패를 닫을 안전장치**가 충분할 때 가능한 출력.

단, 195~200화 승급 충격파 계산 누락처럼 실행 오차는 실제로 발생한다.

## 관계 의무 — SUPPORTED

- 장기 부재를 추적하고 사과함.
- 검증 동료에게 계약 밖 성장 자원 투자.
- 관계 상대가 자기 때문에 전면전을 벌이지 않기를 바람.
- 장기 동업자 A에게 상위 승급의 신체·성장 책임을 맡김.
- 상위 동행자 A에게 복수 공로·유해 처리권 반환.
- 상위 동맹 A와 현재 기술↔미래 후대 연구 의무 계약 수용.

그러나 새 관계가 기존 조직 의무를 자동 삭제하지 않는 반례가 195~200화에 확인된다.

# 3. 독립성의 변화

## 초기

`강한 조직에 속하지 않고 자기 수단과 거절권을 지킨다.`

## 51~60화

독립성 ≠ 혼자 해결. 검증한 동료를 직접 선택하고 실제 맹점을 보완받는다.

## 61~120화

- 가입 없이 비경·신물 접근.
- 전 적대자와 지휘 독립 협력.
- 동업자와 비밀을 가진 채 장거리 협업.
- 자기를 추적하는 조직이 가짜 신분의 자신을 고용하도록 유도.

## 121~180화

- 조직 급여·임무·보호 공간 수용.
- 실제 탐지법·전체 적 정보는 선택 비공개.
- 감시에는 거짓 텔레메트리로 공개 범위 통제.
- 신체 승급 책임을 동업자에게 크게 맡겨도 비밀권 유지.

## 207~212화

상층 조직에서 최고급 전투 직위를 받아도:

- 운영권 없음.
- 행정 지휘권 없음.
- 영구 종문 소속 없음.
- 전투 기능과 자원 접근만 확대.

따라서 현재 정의:

> 독립성 = 조직·관계를 거부하는 것이 아니라 **누가 자기 삶·정보·신체·이동·행동에 어떤 권리를 갖는지 기능별로 설계하는 능력**.

## 238~240화의 하드 경계

상위 존재 A는 협상 없이 주인공 A의 행동 자체를 봉쇄하고 강제 소환·승급한다.

여기서는 기존 `권리를 설계한다`는 독립성 기술이 일시적으로 작동하지 않는다.

즉 독립성은 성격적 선언이 아니라 **실제 강제력을 버틸 수 있을 때만 행사 가능한 권리**라는 경계가 생긴다.

# 4. 위험과 타인 비용

주인공 A는 타인 비용을 줄이려 하지만 타인을 이용하지 않는 인물은 아니다.

- 우호 조직 전체를 자기 전쟁에 끌어들이지 않음.
- 강제 상태 일반인과 적대 술자 분리.
- 상위 후계자 A의 추적 욕망을 자기 이탈의 주의 분산에 이용.
- 181~188화 상위 동맹 A의 복귀 과정은 제3자 사상자를 완전히 막지 못함.
- 231~237화 현지 피해 집단을 돕고 억압 조직을 해체하지만 이후 사회 통치 책임은 맡지 않음.

현재 판정:

- 무관한 비용을 줄이려 함 — `SUPPORTED`.
- 상대 욕망을 자기 목표에 이용하지 않음 — `CONTRADICTED`.
- 관계 상대를 전략 자원으로 사용하지 않음 — `CONTRADICTED`.
- 문제 해결에 개입하면 결과 사회를 영구 통치해야 함 — `CONTRADICTED` 하위 해석.

# 5. 정보와 오해

## 게임/과거 지식

후보·위험 좌표·가능 미래를 제시하지만 현재 현실이 다르면 기억을 보호하지 않는다.

105~107화: 과거 가능성보다 현재 선택 우선.

189~194화: 과거에 다른 미래가 가능한 적에게 다른 선택을 제안해도 현재 관계·신뢰 기반이 없어 실패.

현재 판정:

> 미래를 안다 ≠ 상대가 무엇을 원해야 하는지 안다 ≠ 상대가 내 말을 믿을 관계권이 있다.

## 유용한 오해와 검증 데이터

- 활동 신원·제도권 가짜 신원 운영.
- 공개 전력 일부를 전체로 오판하게 함.
- 비공개 탐지 결과를 상대 반응으로 공개 증거화.
- 감시자가 볼 텔레메트리를 설계.
- 행동 흔적으로 가짜 신원이 다시 연결될 수 있음.
- 231~237화에는 두 독립 잠입팀의 표면 흔적이 하나의 적으로 압축되어 방어 오배치를 유발.

## 상위 힘의 귀속

238~240화에는 다른 상위 존재 A의 형상/힘 모사를 위장으로 쓰지만 실제 원본이 그 사용을 자기 흔적으로 감지한다.

정보 조작이 **원본에게는 추적 좌표**가 될 수 있다.
