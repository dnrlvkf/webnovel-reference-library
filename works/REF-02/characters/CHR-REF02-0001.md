# 주인공 A

## 현재 연구 판정 · 1~180화

주인공 A는 고정된 냉혹함·계산성·겁 없음으로 설명되지 않는다.

1~180화에서 가장 안정적으로 확인되는 것은 **장기 생존과 자기 경로 선택권을 기본축으로 삼되, 인간다움·초월 성장·관계 의무·학습 기회·타인의 비용·정보권이 조건에 따라 경쟁하는 판단 지도**다.

초기에는 `죽지 않고 성장할 일반 경로를 만든다`가 중심이었다. 후반으로 갈수록 생존과 독립의 의미가 넓어진다.

> 당장 위험을 피한다
> → 장기 성장과 거절권을 유지한다
> → 검증된 관계를 선택한다
> → 필요하면 위험을 직접 받아 학습한다
> → 조직 자원을 쓰되 조직이 삶 전체를 소유하게 하지는 않는다
> → 조직 내부 역할도 정보 충성과 분리해 사용할 수 있다
> → 관계가 깊어져도 상대 비밀을 알 능력과 물을 권리를 분리한다
> → 더 높은 단계에서는 자기 길·선택권·정보권을 유지하는 것이 생존 자체의 일부가 된다

게임 지식, 비상 능력, 조직, 관계, 장비, 상계 힘 중 어느 것도 자동 정답으로 취급하지 않는다. 새 문제가 생기면 기존 수단의 기능과 한계를 다시 정의한다.

# 1. 먼저 확인하는 것

- 기존 지식과 현재 현실의 일치 여부
- 상대의 말·현재 행동·과거 이력의 일치 여부
- 표면 정보와 깊은 정보의 불일치
- 상대 목적·탐욕·공포·충성·회복 상태·미확인 수단
- **상대가 자발적 적대자인지 강제 조종·역할 강요 상태인지**
- 계약의 실제 권리·의무와 비용 부담자
- 목격자·추적자·후속 상위 위협
- 재사용 시간·사건 제한 시간·상대 행동시간·자기 행동시간
- 저장 용량·회복률·생산량·보급량
- 힘의 결합부·순환·중추·발원점·입력 가정
- 공격이 실패했을 때 무엇을 새로 관찰할 수 있었는지
- 자신의 행동·시선·수련 흔적이 어떤 신원 가설을 만들지
- 전투력이 아니라 생산·보급·재생산 능력이 어디서 나오는지
- 동료가 자기와 다른 어떤 실패 조건을 덮는지
- 지금 위험을 감수할 학습/성장 가치가 실제로 있는지
- **현재 감정·감사와 미래의 제도적 권리가 같은 것인지 다른 것인지**
- **내가 알 수 있는 정보와 상대에게 공개를 요구할 권리가 같은지**

# 2. 기본 우선순위와 경쟁 기준

## 기본축

1. 되돌릴 수 없는 죽음 방지
2. 수명 연장과 일반 성장 경로
3. 거절권·이동권·비밀권·선택권 보존
4. 회복 가능한 전투 상태
5. 비상 능력·지식 출처·실제 신원의 불필요한 노출 방지
6. 성과를 성장·방어·정보·생산·관계 권리로 복수 기능화

## 인간다움 유지 — DIRECT / SUPPORTED

43화에서 강해지는 효율만으로는 장생 목표가 완성되지 않는다고 직접 판단한다. 계약이 끝난 생활 관계에도 공정한 정산·선물·재회 가능성을 남긴다.

51화에는 자기 선택이 오해된 순간 생존에 필요 없는 개인 과거 기억을 제한적으로 공개해 의미를 교정한다.

150~156화에는 복수전을 사실상 자기가 완결했음에도 복수 공로를 독점하지 않고, 상대가 찾던 유해와 애도 권리를 돌려준다.

인간다움은 항상 최우선은 아니지만 **효율로 자동 삭제하지 않는 별도 판단 기준**이다.

## 초월을 위한 위험 수용 — DIRECT / SUPPORTED

47화 축기에서는 본능적 죽음 공포를 인정한 채 장기 성장 기준을 선택한다.

88~89화에는 위험한 시험을 자기 대응 수단이 있다는 판단 때문에 받아들인다. 같은 위험을 자존심 때문에 떠안은 다른 인물의 실패를 붙여 `위험 감수 자체 = 용기`라는 해석을 부정한다.

94화에는 안전한 이탈보다 향후 성장 자원과 자기 길을 위해 다음 조직 갈등을 선택한다.

105화에는 더 강한 지원자를 부를 수 있는데도 강적과 직접 싸우며 구조를 읽을 학습 기회를 다른 사람에게 넘기지 않으려 한다.

109~110화에는 결단 실패처럼 느껴지는 죽음/운명을 `정해진 결과`로 받아들이지 않고 자기 생존 의지를 다시 선택한다.

170~177화에는 원영경 진입 직후 새 법역을 직접 시험할 학습 가치 때문에 비상 능력 즉시 사용을 보류한다.

현재 판정:

> 위험 수용은 무모함이 아니라 **대응 수단 + 학습/성장 가치 + 자기 길 + 실패를 닫을 안전장치**가 충분할 때 선택 가능한 출력이다.

## 관계 의무 — SUPPORTED

동업자 A, 임대인 A, 검증 동료 A·B와의 관계는 공식 독점 계약 없이도 실제 선택 비용을 만든다.

- 영입 거절에 비공식 관계 의무 작동
- 오랜 거래 상대의 부재 직접 추적
- 위험한 외부 수단 대신 자신이 대안 수단이 될 수 있다고 제안
- 검증 동료에게 임무 보수 밖 성장 자원 투자
- 관계 상대가 자기 때문에 조직 전체 전쟁을 벌이지 않기를 바람
- 장기 동업자 A에게 상위 승급의 신체·성장 책임을 실제로 맡김
- 상위 동행자 A의 복수 공로와 유해 처리권을 반환

다만 무제한 희생·복수 의무는 아직 확정하지 않는다.

# 3. 독립성의 변화

## 초기

`강한 조직에 속하지 않고 자기 수단과 거절권을 지킨다.`

## 51~60화

`독립성 = 혼자 해결`이 아님이 확인된다. 검증된 동료를 직접 선택하고 실제 맹점을 보완받는다.

## 61~120화

- 우호 조직 전체를 자기 전쟁에 끌어들이지 않음
- 가입하지 않고도 개인 비경·신물 접근권 획득
- 전 적대자의 기술 소유권과 지휘 독립성 인정
- 동업자 A와 서로 비밀을 가진 채 장거리 협업 약속 유지
- 가짜 신분 B로 자기를 추적하는 조직이 먼저 자기를 고용하도록 유도

따라서:

> 독립성은 조직·관계를 거부하는 것이 아니라 **누가 자기 삶에 어떤 권리를 갖는지 스스로 설계하는 능력**이다.

## 121~180화

독립성은 조직 내부 역할까지 포함한다.

- 조직의 급여·임무·보호 공간 수용
- 그러나 실제 탐지법과 적 전체 정보는 선택적으로 비공개
- 조직 감시에는 거짓 텔레메트리를 제공해 검증 범위를 자기 통제 아래 둠
- 공개 전력 프로필과 실제 숨은 전력 분리
- 조직이 진심으로 감사해도 미래 안전권을 자동 추론하지 않음

즉 **역할 수용과 정보 충성은 분리**된다.

후반에는 장기 동업자 A에게 신체·승급 책임을 크게 맡기면서도 비밀권은 유지한다. 권한을 일부 위임하는 것과 자기 전체 선택권을 넘기는 것도 별개다.

# 4. 위험과 타인 비용

주인공 A는 타인의 비용을 중요하게 보지만 타인을 전혀 이용하지 않는 인물은 아니다.

## 비용 제한

95~97화에는 우호 조직 전체 참전을 요구하지 않고 자기에게 필요한 수련 자원·신물 접근만 요청한다.

108~110화에는 관계 상대가 `주인공 A가 전쟁을 원하지 않는다`는 의사를 존중해 대규모 충돌을 막는다.

121~126화에는 적 조직에 강제 조종됐을 가능성이 높은 일반인과 실제 적대 술자를 분리해 후자만 제거한다.

## 능동적 이용

117~120화에는 상위 후계자 A의 자유 욕망·호기심을 알고 의도적으로 자극한다.

138~149화에는 후계자 A가 자신을 계속 추적하면 상위 조직의 주의를 묶어 실제 신원 이탈에 유리하다고 계산한다.

따라서:

- 무관한 비용을 줄이려 함 — `SUPPORTED`
- 상대 욕망을 자기 목표에 이용하지 않음 — `CONTRADICTED`
- 관계 상대를 전략 자원으로 사용하지 않음 — `CONTRADICTED`

이다.

중요한 비용은 그 이용이 상대를 추적·조직 보복의 표적으로 남길 수 있다는 점이다.

# 5. 정보와 오해

## 게임 지식

게임 지식은 후보·위험 좌표·인물 가능성을 제시한다. 현재 현실이 다르면 기억을 보호하지 않는다.

105~107화에는 과거 지식상 다른 관계가 될 가능성이 있어도 현재 당사자의 선택을 우선한다.

> 미래를 안다 ≠ 상대가 무엇을 원해야 하는지도 안다.

## 유용한 오해

상대가 주인공 A를 약자·숨은 고경지·법기 의존자·강한 배후가 있는 자로 잘못 분류해도 유리하면 정정하지 않는다.

44~46화에는 별도 활동 신원 A를 만들고 상위 추적을 그 신원에 전가한다.

114~116화에는 공개 전투에서 일부 힘만 보여 주고 목격자가 그 일부를 전체 전력으로 오판하도록 둔다.

117~120화에는 문서·신분패·개조 법기·대표 법술 억제까지 묶은 제도권 가짜 신분 B를 만든다.

121~126화에는 **비공개 탐지 결과를 공개 가능한 가짜 검증 규칙으로 바꿔 상대가 스스로 반응 증거를 만들게 한다.**

127~132화에는 조직 감시가 보는 데이터 자체를 설계해 내부 검증을 거짓 텔레메트리 위에서 성공시킨다.

## 장기 은폐 실패와 수명 관리

106화의 깊은 관찰자 B는 체질 흔적으로 과거와 현재를 연결한다.

138~149화에는 오래된 적이 얼굴·법술보다 시선·행동 방식의 지속성을 단서로 가짜 신분 B를 재의심한다.

따라서 신원 은폐는:

`위험 삭제`
이 아니라
`관찰층별 위험 분산 + 일정 수명 뒤 신원 폐기`

에 가깝다.

# 6. 비상 능력 사용 기준

비상 능력은 일반 성장·전술을 시험할 시간을 보장하는 최후 안전망에서, 상위 경지의 행동시간과 자원 보존·영혼 종결까지 계산하는 제한 자원으로 확장됐다.

현재 사용 기준:

1. 즉시 치명성
2. 일반 기술·도주·협업의 대체 가능성
3. 상대 미확인 수단
4. 외부 목격·추적 가능성
5. 정면 시선·대상 지정 조건
6. 재사용 시간과 사건 제한 시간
7. 후속 더 큰 위협
8. 학습을 위해 일반 대응을 시험할 가치
9. 상대가 대상 지정 시간보다 빠르게 개입할 수 있는가
10. **주인공 A가 그 행동시간을 인지·따라갈 수 있는가**
11. 자폭·파괴 전에 온전히 보존해야 할 자원이 있는가
12. **육신 승리 뒤 영혼/원영을 비가역 종결해야 하는가**

## 61~107화의 수정

- 상위 중기: 직접 제거 성공.
- 상위 후기: 평상시 행동시간 우위 때문에 사용 곤란.
- 같은 후기 상대가 스스로 행동 층위를 낮춘 순간: 사용 성공.
- 높은 경지라도 공격 동작이 단순·예측 가능하면 사용 가능 사례.
- 107화: 생존보다 상대 자폭 전에 극양 자원을 온전히 보존하려고 사용.

`상위 후기 이상이면 안 통한다`는 고정 상한 가설은 `CONTRADICTED`.

## 121~177화의 수정

- 목격자 없는 고립 조건에서 상위 적 제거.
- 일반 전투로 육신 승리 뒤 분열 영혼을 종결하는 용도로 사용.
- 원영경 승급 뒤 주인공 A 자신의 시간 인지가 올라 이전 시간차 일부가 사라짐.
- 새 법역을 직접 시험할 학습 가치 때문에 즉시 사용을 미루고 영혼 단계에만 사용.

상한은 경지 이름보다 **상대와 자기의 상대적 행동시간**이다.

# 7. 기술 학습과 전투 판단

## 전체 시스템보다 현재 필요한 구조를 본다

초기에는 진법·법역의 전체 이론을 몰라도 결합부·발원점·중추만 끊었다.

121~180화에는 이마저 절대 공식으로 두지 않는다.

- 상위 우회 수단이 더 싸면 중추 분석 포기
- 대형 진법이 기대하는 입력 규칙을 깨 교차 반응 유도
- 법역 전체 해제보다 경계에 통로만 생성

현재 목적을 만족시키는 최소 개입이 기준이다.

## 파훼 → 재현 → 개량 → 합성

61~120화에는 적 기술을:

노출
→ 구조 관찰
→ 파훼
→ 재현
→ 개량
→ 다른 분야 원리 합성

의 학습 체계로 바꾼다.

121~177화에는:

- 혈계 기술 + 기존 독/혈 연구 합성
- 일회성 자동 방어 원리의 상시 방어 재구성
- 여러 법역·내적 공간·상위 수련법·상계 심상을 `빈 법역 플랫폼`으로 통합

까지 올라간다.

학습 결과가 개별 필살기에서 **새 기술을 담는 실행 환경**으로 발전한다.

## 실패를 정보로 바꾼다

91~93화에는 이동술 재현에 성공해도 몸이 속도를 버티지 못해 큰 손상.

101~104화에는 실패 공격을 상대 방어 순환을 읽는 진단으로 사용.

121~180화에도 본격적인 `잘못된 구조 판독` 실패는 아직 부족하다. 이 미확인은 유지한다.

# 8. 자원 처리

보상의 이름보다 현재 결핍을 해결하는 기능으로 재분류한다.

- 제한 부보: 잠입 화력 → 연단용 미세 화력
- 숨은 법기 A: 독 전달 → 이치 전달 인프라
- 고가 영차: 소비재 → 종자·묘목의 생산 자산
- 독물 서책·재료: 전리품 → 후속 독술 대응 연구
- 오행 법보: 고급 무기 → 단일 영근 밖 속성의 외부 저장 인프라
- 상계 힘: 즉시 통합할 힘 → 별도 저장 후 몸 강화 전용 자원
- 적의 순양 자원: 적 전력 → 결단의 극양 구성요소
- 조직 비경: 소속 보상 → 가입 없이 빌리는 장기 수련 인프라
- 상위 복수 대상의 숨은 자원: 전투 중 즉시 파괴할 대상 → **노출될 때까지 승리 시점을 미루는 회수 목표**
- 장기 동업자 A의 상위 수련법: 비급 → 신체 승급 책임과 공동 목표를 묶는 관계 자원

## 통합이 위험하면 분리한다

여러 속성·상계 힘을 억지로 몸에 합치지 않고 별도 저장·역할 분할한다.

170~177화의 빈 법역도 비슷한 방향이다. 여러 심상을 한 고정 세계로 미리 굳히지 않고 미할당 플랫폼으로 두어 선택권을 남긴다.

# 9. 적대·책임 판단의 수정

초기에는 `상대가 치명적 욕망을 행동으로 확정 → 반격 → 결과 책임을 상대 선택에 귀속`하는 사례가 반복됐다.

61~120화에는:

- 현재 장면 선공이 없어도 충분한 포식 이력·조직 역할이면 제거 가능.
- 성장 자원을 얻기 위해 조직 갈등 자체를 의도적으로 키움.
- 과거 적대 이력이 있어도 현재 선택을 다시 확인하는 예외.

121~180화에는 분류가 더 세분화된다.

- 적 조직 공간에 있어도 강제 조종 가능성이 높은 일반인은 실제 술자와 분리.
- 조직의 진심 어린 감사와 미래 안전을 분리.
- 안정된 복수 동기를 가진 위험한 상위자는 제거보다 계약 가능.
- 관계 상대의 추적·애착을 자기 이탈에 이용하는 비용도 수용.

따라서 현재 판단:

> 상대의 현재 선택·과거 이력·역할·강제성·욕망을 확인하고 **자기 행동이 허용되는 범위를 구성한다.** 필요하면 그 조건을 능동적으로 조립한다.

`항상 현재 선공을 기다린다`는 하위 명제는 `CONTRADICTED`.

사후 모든 도덕 책임을 상대에게 돌리는 자기설명의 객관적 정당성은 여전히 `HYPOTHESIS`.

# 10. 말하기·침묵하기

## 말하기

- 짧은 질문으로 상대 욕망·위계·정보 수준 확인
- 높은 경지 명령도 계약이 아니면 거절
- 보수 액수뿐 아니라 즉시 지급 여부 확인
- 상대 자유 욕망처럼 이미 드러난 기준에는 짧은 문장만 넣어 방향 자극
- 과거 기억과 현재 선택이 충돌하면 다른 가능성을 한 번 제시하되 강요하지 않음
- 실제 탐지법을 말하지 않고 **거짓 공개 검증 규칙으로 상대 반응을 유도**
- 관계 상대가 자기 목표를 직접 선택하게 하되 결과 선택까지 대신 말하지 않음

## 침묵하기

- 비상 능력·상태 정보·지식 출처·실제 신원 비공개
- 동업자 A의 말하기 싫은 장기 목적을 캐묻지 않음
- 공개 목격자의 잘못된 전력 추론을 정정하지 않음
- 승급 뒤 상대의 깊은 비밀을 볼 수 있어도 당장 묻지 않음
- 상위 동행자 A의 애도를 장황한 해설로 대신하지 않음

침묵은 냉정함 장식이 아니라 **회복·관찰·정보권 존중·오판 유지·상대 감정 소유권 보존**의 반응 채널이다.

# 11. 조직 처리

## 1~60화

실제 선금·도주권·작전 자율권을 주는 조직과 제한 협력하고 사적 위계·종속은 거절.

## 95~116화

가입 없이도 조직 핵심 비경과 신물 접근권을 얻음.

## 117~120화

가짜 신분으로 상위 조직이 먼저 자기를 고용하게 만드는 단계로 이동.

## 121~149화

조직 내부 역할을 실제로 수행한다.

그러나:

- 탐지 원리 비공개
- 적 조직 전체 정보 일부 비공개
- 감시 텔레메트리 조작
- 공개 전력 프로필 제한
- 상위 후계자 A와 조직의 관계 오해 이용

으로 **내부 역할 ≠ 정보 충성 ≠ 삶 전체 종속**을 분리한다.

가짜 신분의 비용이 커지면 신분 자체를 폐기한다.

# 12. 관계별 변주

- 조직 추천자 A: 비가역 종속 거부, 포식 관계 종료
- 임대인 A: 계약 종료 뒤 감사·정산·재회 가능성 보존
- 장기 동업자 A: 정보·추천·사과 → 비밀권·미래 협업 → 상위 수련법·신체 승급 책임 → 상호 비밀권 대칭화 → 상계 진입까지 공동 목표
- 검증 동료 A·B: 직접 선택 → 실제 맹점 보완 → 구조 → 장기 재선택 → 성장 자원 투자 → 장거리 전술 문법
- 보호 대상 집단 A: 생환 의무와 자원권 분리, 위험 때문에 이동권 일시 제한
- 제작자 A: 약점을 협박에 쓰지 않지만 협상 주도권 유지
- 행동대장 A: 소개 신뢰를 절차적 접근권으로 전환
- 동맹 조직 A: 보수·도주권·작전 자율권 보장 시 협력 확대
- 전 적대자 C: 기술 소유권·지휘 독립성 유지한 제한 협력
- 상위 후계자 A: 조직 배정 동료 → 친구 욕망·경계 충돌 → 보호·비밀권 존중 → 이용 사실 인식 → 자기 자율성 모델로 재분류
- 상위 동행자 A: 위험한 추적자 → 복수 계약 → 주인공이 복수 실패 조건 제거 → 공로·유해 권리 반환 → 자발적 원조·잠입·영혼 종결 협력

# 14. 반복되는 성공 방식 · 1~180화

기존 지식으로 후보 생성
→ 현재 조건·권리·정보층·시간차 확인
→ 자발적 적대와 강제 상태 분리
→ 상대 오분류를 유지하거나 필요한 정보만 교정
→ 비공개 사실은 직접 설명 대신 상대 반응으로 공개 증거화할 수 있음
→ 전체 시스템보다 현재 목적에 필요한 최소 구조 개입 선택
→ 실패/피격/소모품 사용을 관찰 자료로 전환
→ 적·자기 기술을 파훼·재현·개량·합성
→ 일반 기술·장비·검증 관계를 먼저 사용
→ 비상 능력을 후속 위협·행동시간·자원 보존·영혼 종결 기준으로 배분
→ 통합 위험 자원은 외부/별도 저장으로 역할 분할
→ 성과를 성장·생산·정보·관계 권리로 분해
→ 조직 전체 종속 대신 필요한 역할·접근권만 획득
→ 필요하면 상대 욕망과 오해를 다음 접근 경로로 조립
→ 관계 상대의 목표·감정 소유권은 필요한 만큼 반환
→ 알 수 있는 정보와 공개를 요구할 권리를 분리
→ 새 성과가 만든 추적·관계 비용·자원 결핍을 다시 계산

# 15. 실패·오판·비용

- 비상 능력 대상 지정 전에 상위 상대가 개입할 수 있음
- 일반 기술·연체·법기·독 연구에 대량 자본·시간 필요
- 새 기술을 이해해도 몸이 못 버티는 실패
- 깊은 체질·행동 흔적은 여러 가짜 신원 뒤에도 재연결 가능
- 조직 갈등을 성장 자원으로 이용하면 제3자·우호 조직이 보복 비용을 부담할 수 있음
- **관계 상대를 주의 분산으로 사용하면 그 상대에게 추적·조직 보복 위험이 남음**
- 관계 상대에게 고급 자원을 투자하면 자기 현재 자원 감소
- 비밀권 존중 때문에 상대의 위험·목적을 늦게 알 수 있음
- 가짜 신분 내부 역할이 정체 노출 시 배신 비용을 확대
- 공개 프로필을 일부러 남기면 적 맞춤 카운터가 생김
- 상위 동행자에 대한 보증이 틀리면 기존 관계망 전체 위험
- 상위 승급을 동업자 판단에 맡기면 상대 오판이 자기 생명에 직접 연결
- 빈 법역 플랫폼의 심상 충돌 비용 미확인
- 상계 존재 관심의 장기 비용 미확인

# 16. 예외 조건과 복귀

- 조직이 실제 비용을 내고 계약 범위를 지키면 협력 가능
- 조직 내부 역할도 정보 충성·영구 소속과 분리 가능
- 가입하지 않아도 문제 해결 대가로 핵심 접근권 수용 가능
- 사적 복종·강탈·무제한 감시 요구 시 거절/이탈/거짓 데이터로 범위 제한
- 전체 이론이 부족하면 목표를 최소 구조 개입으로 축소
- 더 싼 우회가 있으면 구조 분석 자체를 포기
- 구조를 충분히 읽으면 파훼에서 재현·개량·플랫폼 합성으로 확대
- 통합이 위험하면 자원 별도 저장
- 본능적 공포가 자기 길과 충돌하면 공포를 인정한 채 장기 기준 선택
- 과거 지식이 현재 당사자 선택과 충돌하면 현재 선택 우선
- 불특정 집단보다 검증 관계에 선택적으로 의존
- 과거 적대자라도 현재 역할·권리 경계가 맞으면 제한 협력 가능
- 위험한 상위자도 안정된 동기가 있으면 제한 계약 가능
- 상대 비밀을 알 수 있어도 당장 판단에 불필요하면 질문을 보류

# 18. 반례와 미확인

- 인간다움이 극단적 생존 손실과 직접 충돌할 때 우선순위 미확인
- 관계 상대를 위해 비상 능력·핵심 성장 자원 자체를 포기하는지 미확인
- 동료 A·B의 강한 도움 의향이 상호 무제한 의무로 바뀌는지 미확인
- 장기 동업자 A와의 비밀권이 실제 정보 부족 실패를 만드는지 미확인
- 갈등 설계·관계 이용 때문에 무관한 제3자가 더 큰 피해를 입는 반례 추가 추적
- 상계 존재 관심의 장기 비용 미확인
- `파훼→재현→개량`이 잘못된 구조 판독 때문에 실패하는 본격 반례 부족
- 빈 법역의 여러 심상이 충돌하거나 플랫폼 자체를 역이용당하는지 미확인
- 비상 능력 대상 지정이 분신·가짜 본체 때문에 실패하는지 미확인
- 상위 후계자 A의 자율성 선택이 장기적으로 우호·적대 중 무엇으로 돌아오는지 미확인
- 상위 동행자 A의 개인 부채가 상층부에서 지속되는지 미확인
- 장기 동업자 A의 상계 공동 목표가 과거 의무와 충돌하는지 미확인
