# 주인공 A

## 현재 연구 판정

주인공 A는 고정된 냉혹함이나 계산성으로 설명되지 않는다. 1~60화에서 확인되는 핵심은 **장기 생존과 자율성을 기본축으로 삼되, 인간다움·초월을 위한 위험 수용·관계 의무·검증된 동료와의 상호 보완이 조건에 따라 경쟁하는 판단 지도**다.

게임 지식, 비상 능력, 조직, 관계, 장비 중 어느 것도 자동 정답으로 취급하지 않는다. 현재 정보·시간·권리·노출·다음 위협·생산 기반을 다시 계산하고, 기존 수단이 새로운 문제를 만나면 기능을 재정의한다.

51~60화는 특히 `독립성 = 혼자 해결`이라는 단순 해석을 무너뜨린다. 불특정 집단과 강제 협업은 피하지만, 실전에서 검증된 동료 A·B는 직접 선택하고 서로의 실패 조건을 역할로 보완한다.

## 핵심 판단 기준

### 먼저 확인하는 것

- 기존 지식과 현재 현실의 일치 여부
- 상대 발언과 행동의 일치 여부
- 표면 정보와 본질 정보의 불일치
- 상대의 목적·탐욕·공포·회복 상태·미확인 수단
- 계약의 실제 권리·의무와 비용 부담자
- 목격자·추적자·후속 상위 위협
- 시간 제한·재사용 주기·저장 용량·회복률
- 힘의 결합부·공급 발원점·네트워크 중추
- 자신의 행동 흔적이 어떤 신원 가설을 만들지
- 전투력만이 아니라 생산·보급·재생산 능력이 어디서 나오는지
- 동료가 자기와 다른 어떤 실패 조건을 덮을 수 있는지

### 기본 우선순위

1. 되돌릴 수 없는 죽음 방지
2. 수명 연장과 일반 성장 경로
3. 거절권·이동권·비밀권 보존
4. 회복 가능한 전투 상태
5. 비상 능력과 지식 출처의 불필요한 노출 방지
6. 사건 보상의 복수 기능화

### 경쟁 판단 기준

#### 인간다움 유지 — DIRECT / SUPPORTED

43화에서 효율적으로 강해지는 것만으로는 장생의 목표가 완성되지 않는다고 직접 판단한다. 계약이 끝난 임대인 A와 가족 구성원 A에게 값을 치르고 감사·선물·재회 가능성을 남긴다.

51화에는 중개자 A의 선물 비판에 자신의 개인 과거 기억을 제한적으로 공개한다. 생존에 필요 없는 사적 정보지만, 관계에서 자기 선택이 오해된 순간에는 최소한의 기억을 열어 의미를 교정한다.

#### 초월을 위한 위험 수용 — DIRECT

47화 축기 과정에서 본능적 죽음 공포를 느끼지만 이를 오류로 지우지 않는다. `자연을 두려워하는 본능`과 `자연을 받아들이고 초월하려는 수도자의 목표`를 경쟁시킨 뒤 후자를 선택한다.

#### 관계 의무 — SUPPORTED

49화에서는 중개자 A와의 관계를 공식적으로는 거래라고 축소하면서도 다른 조직의 영입 제안을 `중개자 A를 배신하는 일`이라고 거절한다.

55~57화에는 과거 실전 동료 A·B를 직접 골라 반복 협업하고, 적의 보복 습격에서 실제 구조 행동을 수행한다. 다만 동료 측의 더 깊은 관계 욕망은 주인공 A에게 아직 전달되지 않았다.

#### 검증된 동료에 대한 선택적 의존 — SUPPORTED

주인공 A는 불특정 용병 집단보다 검증한 동료를 선호한다. 56화에는 자신이 핵심 적을 압도했음에도 적의 최후 독포자에 즉시 대응하기 어려웠고, 동료 B의 광역 화력이 위험을 제거한다.

그는 이 도움을 축소하지 않고 실제로 필요했던 보완이라고 인정한다. 독립성은 `모든 것을 혼자 한다`가 아니라 **협력 대상을 스스로 고르고 관계 경계를 통제한다**는 쪽에 가깝다.

## 정보와 오해

### 지식 사용

게임 지식은 후보와 위험 좌표를 만들지만 현실의 수련·법술·연단·약초·법역·조직 계획은 직접 확인한다. 56~57화 생산 거점과 적 전략을 예측할 때도 게임 기억만 복제하지 않고 현재 생산량·비축분·방어진 비용과 대조한다.

### 유용한 오해와 타인 해석

상대는 주인공 A를 약자, 숨은 강자, 고급 법기 의존자, 강한 조직 소속, 고위 후원자가 있는 인물로 오분류한다. 방심·가격 상승·경계 완충에 유리하면 정정하지 않는다.

44~46화에는 얼굴·체형·복장뿐 아니라 주력 법기·대표 법술·기술 출처까지 바꿔 별도의 활동 신원 A를 만든다.

58화에는 동맹 상위자 A가 주인공 A의 침묵을 `상위 위협에도 흔들리지 않는 냉정함`으로 해석한다. 이 평가는 상대 POV의 해석이지 객관 사실이 아니다. 그러나 그 해석은 주인공 A에게 독립적인 급소 공격 권한을 부여하는 실제 결과를 만든다.

### 본질 판독의 경계

상태 정보는 변신·거짓 이름·경지 축소를 관통하지만 상대의 모든 기술·욕망·조직 계획은 보여 주지 않는다.

49화에는 축기 후 정신 처리 속도 변화 때문에 상위 존재에게는 비상 능력의 대상 지정 순간조차 대응 시간이 될 수 있다는 가설이 생긴다. 아직 직접 시험되지 않아 `HYPOTHESIS`다.

## 비상 능력 사용 기준

### 사용 조건

- 즉시 치명성이 높음
- 일반 기술·도주·협업 성공 가능성이 낮음
- 정면 시선과 발동 공백 확보
- 외부 목격·후속 추적 통제 가능
- 미확인 수단을 오래 관찰하는 비용이 더 큼

### 보류 조건

- 일반 기술·장비·단약·동료 역할로 해결 가능
- 다수 목격자 존재
- 사용 뒤 더 큰 위협 예정
- 일반 대응 체계를 검증할 가치가 있음
- 현재 적보다 다음 연속 위협에 남겨 두는 편이 생존 확률이 높음

### 41~42화의 확장

현재 적 A에게 일반·신규 술식을 사용해 비상 능력을 남기고, 영력 고갈 뒤 포식 의도를 드러낸 상위 협력자 A에게 사용한다. 제한 자원 배분 기준이 현재 적 하나가 아니라 위협의 순서로 확장된다.

51~60화에는 숨은 법기 A, 독 연구, 동료 역할, 구조적 중추 파괴가 늘면서 비상 능력 없이 해결하는 범위가 더 넓어진다.

## 기본 전술

### 말하기

짧은 질문과 건조한 응답으로 상대가 욕망·위계 기대·정보 수준을 드러내게 한다. 관계 오해가 실제 의미를 훼손할 때는 장황한 감정 설명보다 필요한 개인 정보만 제한적으로 공개한다.

### 침묵하기

비상 능력, 상태 정보, 지식 출처, 숨은 전리품, 실제 활동 신원을 공개하지 않는다. 상대가 말하는 동안 회복·감지·판단을 수행한다.

침묵을 타인이 냉정함이나 자신감으로 과대해석할 수 있지만 그 해석을 곧바로 자기 성격의 객관 사실로 받아들이지 않는다.

### 위협 처리

- 일반 기술·자율 법기·방어 장비·단약·지형을 먼저 조합
- 상대의 오해를 방심·공격 집중·잘못된 추적으로 유도
- 전체 이론이 없으면 구조적 결합부·중추만 공격
- 직접 목표 감지가 실패하면 `목표를 숨길 구조`를 찾도록 탐색 질문 변경
- 예상 포식자에게는 선공 조건을 행동으로 확정하게 한 뒤 반격
- 적 기술에 실제로 당한 뒤 자료·재료를 수집해 다음 변형의 대응책을 준비
- 생산 시설을 파괴해 적의 장기전 선택 자체를 없앨 수 있음

### 조직 처리

진영 명분보다 실제 지출과 요구 권리를 본다. 업무상 지시·공동 목표는 수용하지만 사적 위계·장기 소속·무제한 감시는 거부한다.

54화 장기 협력 요청에서는 비싼 선물도 즉시 받지 않고 전쟁 구조와 보상 조건을 먼저 본다. 57화 동맹 조직 A가 외부 고용자의 도주권을 인정하고 58화에는 독립 판단권까지 부여하자, 이 조직의 협력 범위를 더 넓게 수용한다.

### 보상 처리

보상의 이름보다 현재 결핍을 해결하는 기능으로 재분류한다.

- 제한 부보: 잠입용 화력 → 연단용 미세 화력
- 숨은 법기 A: 독 전달 → 광역 이치 전달 인프라
- 고가 영차: 한 번 마실 소비재보다 종자·묘목이라는 생산 자산으로 목표 변경
- 적 독물 서책·재료: 전리품보다 후속 육사독 연구 자원으로 보존

## 공로·계약 처리

53화는 주인공 A가 `모든 공을 독점하는 인물`도 `무조건 관대한 인물`도 아님을 보여 준다.

- 결단경 적을 직접 제거했지만 일반 고용자들이 양동에 기여한 만큼 보수를 받아야 한다고 의뢰자에게 말함.
- 반대로 자발적으로 내기에 동의한 고용자 A의 보수는 약속대로 집행하게 함.

판단 단위는 호감보다 **실제 기여와 명시된 합의**다.

## 자기합리화·책임 귀속

### DIRECT 자기설명

주인공 A는 반복적으로 `상대가 먼저 탐욕·포식·살해를 선택하지 않았다면 이런 결과가 없었다`는 식으로 사후 결과를 해석한다.

- 12화: 독점 욕망과 살해 의도
- 20~21화: 생포 욕망
- 42화: 상위 협력자의 포식 선택
- 50화: 독술사의 선제 살해 시도

54~55화에는 내기 상대를 언어로 자극하고 보수를 집행하지만, 상대가 모욕당했다는 이유만으로 즉시 살해하지 않는다. 이후 상대가 집단을 데려와 실제 생명 위협으로 선공한 뒤에야 연속 반격으로 제거한다. `언어적 갈등 = 살해 정당화`로 넓혀지지 않는 경계다.

### 판정 경계

상대 선공·포식 선택은 행동 순서로 직접 확인될 수 있다. 그러나 이후 모든 죽음과 자원 회수의 도덕적 책임이 상대에게 있다는 주인공 A의 자기설명까지 작품의 객관 판정으로 승격하지 않는다.

## 관계별 변주

- 조직 추천자 A: 비가역 종속 거부, 상대 탐욕을 고립 조건으로 전환
- 임대인 A: 계약 종료 뒤에도 감사·선물·공정한 정산을 남김
- 중개자 A: 정보·소개·사과·비공식 부탁에 더해 제한적 개인 기억 공개
- 전투 동료 A·B: 실전 역할을 검증한 뒤 직접 선택하며 상호 구조 행동 발생
- 보호 대상 집단 A: 생환 의무와 자원권 분리, 위험 때문에 이동권 일시 제한
- 제작자 A: 약점을 협박에 쓰지 않지만 협상 주도권 유지
- 정종 조직 A: 선금·안전·전장 접근을 받되 감시·위계 경계
- 마도 조직 A: 낮은 실제 비용의 포섭 거절, 살해 명령에 대응
- 행동대장 A: 소개자의 평판을 절차적 접근권으로 전환
- 동맹 조직 A: 보수·도주권·작전 자율권이 실제 행동으로 보장될 때 협력 확대
- 적 조직 A: 포섭·위세·생산망을 사람보다 우선하는 조직으로 판정하며 핵심 생산 기반을 공격

## 권한·책임 변화

- 초기: 혼자 생존하고 자기 수단을 숨기는 개인
- 11~20화: 거래·임무·협업의 권리 범위 설정
- 21~30화: 보호 계약의 현장 통제권과 생활 관계의 시설 접근권 획득
- 31~40화: 조직 경쟁을 가격으로 바꾸고 법역 위기에서 해결 방향 제시
- 41~50화: 독립 활동 신원 운영, 비공식 신뢰망을 통해 중층부 제도권 접근
- 51~60화: 스스로 고른 동료와 반복 작전을 수행하고, 동맹 조직 A로부터 전장에서 독립적으로 급소를 선택할 실질 작전권 획득

권한이 늘어도 조직 전체 책임은 받지 않는다. 다만 자신의 판단이 적의 전략 전환과 동료 위험까지 발생시키므로 선택의 파급 범위는 개인 생존을 넘어선다.

## 반복되는 성공 방식

기존 지식으로 후보 생성
→ 현재 조건·권리·정보층·물리 한계 확인
→ 상대가 유리한 오분류를 하도록 두거나 필요한 정보만 교정
→ 상대 욕망·자기설명을 위치·시간·추적 자원으로 전환
→ 일반 기술·장비·거래·검증된 협업으로 대응 범위 확대
→ 제한 능력을 위협 순서와 노출 조건에 맞춰 배분
→ 전체 시스템보다 구조적 중추·생산 기반 등 결정 지점 선택
→ 적 기술의 실패 비용을 후속 연구와 준비로 전환
→ 성과를 성장·방어·은폐·제작·정보·관계 권리·생산 자산으로 분해
→ 성과가 만든 추적·전략 전환·관계 의무·새 결핍을 다시 계산

## 실패·오판·비용

- 비상 능력 발동 전 선공당하면 사망 가능
- 일반 기술·연단·제작·독 연구에 대량 자본과 시간 필요
- 저장 용량 때문에 일부 전리품 포기
- 강한 평판이 영입·암살·감시를 동시에 부름
- 공로 은폐에도 생존자와 소문으로 노출 누적
- 별도 활동 신원에는 상위 추적이 축적됨
- 축기 성공 뒤 저순도 성장법 효율 급락
- 52화 독술 해석 중 실제 진액 소실
- 56화 최후 독포자는 동료 B가 없었다면 큰 위험이었음
- 생산 거점 파괴로 적 장기전을 약화했지만 동시에 단기 결전을 앞당김
- 육사독 대응 재료 자체도 정상 정기를 손상시킬 수 있음
- 60화에는 지상전 우세와 독진 파괴에도 상위 수장전 패배가 전쟁 전체 우위를 뒤집음
- 타인의 호의적 과대평가가 더 큰 역할·책임을 부를 수 있음

## 예외 조건과 복귀

- 조직이 실제 비용을 지불하고 계약 범위를 지키면 임시 협력 가능
- 감당 불가능한 위험에서 이탈권까지 인정하는 조직에는 더 큰 협업 가능
- 사적 복종·강탈·비밀 공개 요구 시 거래 관계 또는 적대로 복귀
- 전체 이론이 부족하면 목표를 통과·지원 차단·중추 손상으로 축소
- 본능적 공포가 장기 성장 기틀과 충돌하면 공포를 인정한 채 성장 기준을 선택할 수 있음
- 계약 기능이 종료되어도 인간적 감사가 남을 수 있음
- 혼자 움직이는 것이 안전한 상황이 많지만 역할이 검증된 동료가 실제 맹점을 덮으면 선택적 의존 가능

- 상대 탐욕을 이용하는 설계가 무고한 상대를 먼저 공격하도록 만드는 경계 미확인

- 활동 신원 A 추적이 실제 신원과 재연결되는지 미확인
- 원영경 후기 이상에게 비상 능력이 실제로 통하지 않는지 미확인
- 중개자 A의 걱정이 거래 손실 이상의 감정인지 객관적 내면 근거 미확인
- 동료 A·B의 관계 욕망이 주인공 A에게 전달되고 상호 의무로 바뀌는지 미확인
- 주인공 A가 동료를 위해 자기 생존·성장 자원을 실제로 포기하는지 미확인
- 생산 기반 파괴로 결전을 앞당긴 판단이 최종 승리와 비용 중 어느 쪽으로 판정되는지 60화 현재 미완
- 60화 말 새 술식 연구가 실제 성공하는지 미확인
