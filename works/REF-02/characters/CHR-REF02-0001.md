# 주인공 A

## 현재 연구 판정

주인공 A는 고정된 냉혹함이나 계산성으로 설명되지 않는다. 1~50화에서 확인되는 핵심은 **장기 생존과 자율성을 기본축으로 삼되, 인간다움·초월을 위한 위험 수용·관계 의무가 조건에 따라 경쟁하는 판단 지도**다.

그는 게임 지식, 비상 능력, 조직, 관계, 장비 중 어느 것도 자동 정답으로 취급하지 않는다. 현재 정보·시간·권리·노출·다음 위협을 다시 계산하고, 자신의 평소 기준과 경쟁하는 가치가 생기면 어느 쪽을 택했는지 사후에 스스로 해석한다.

## 핵심 판단 기준

### 먼저 확인하는 것

- 기존 지식과 현재 현실의 일치 여부
- 상대 발언과 행동의 일치 여부
- 표면 정보와 본질 정보의 불일치
- 상대의 목적·탐욕·공포·회복 상태·미확인 수단
- 계약의 실제 권리·의무와 비용 부담자
- 목격자·추적자·후속 상위 위협
- 시간 제한·재사용 주기·저장 용량·회복률
- 힘의 결합부·공급 발원점·숨은 보관 구조
- 자신의 행동 흔적이 어떤 신원 가설을 만들지

### 기본 우선순위

1. 되돌릴 수 없는 죽음 방지
2. 수명 연장과 일반 성장 경로
3. 거절권·이동권·비밀권 보존
4. 회복 가능한 전투 상태
5. 비상 능력과 지식 출처의 불필요한 노출 방지
6. 사건 보상의 복수 기능화

### 경쟁 판단 기준

#### 인간다움 유지 — DIRECT / SUPPORTED

43화에서 효율적으로 강해지는 것만으로는 장생의 목표가 완성되지 않는다고 직접 판단한다. 계약이 끝난 임대인 A와 가족 구성원 A에게 값을 치르고 감사·선물·재회 약속을 남긴다. 이 기준은 생존 효율과 별도이며, 관계 비용을 일부러 보존할 수 있게 한다.

#### 초월을 위한 위험 수용 — DIRECT

47화 축기 과정에서 본능적 죽음 공포를 느끼지만 이를 오류로 지우지 않는다. `자연을 두려워하는 본능`과 `자연을 받아들이고 초월하려는 수도자의 목표`를 경쟁시킨 뒤 후자를 선택한다. 즉각적 공포 회피보다 장기 성장의 기틀을 우선한 예외다.

#### 관계 의무 — SUPPORTED

49화에서는 중개자 A와의 관계를 공식적으로는 거래라고 축소하면서도 다른 조직의 영입 제안을 `중개자 A를 배신하는 일`이라고 거절한다. 독점 충성까지 확정할 근거는 없지만 비공식 관계 의무가 실제 선택 근거가 된 것은 직접 확인된다.

## 정보와 오해

### 지식 사용

게임 지식은 후보를 만들지만 현실의 수련·법술·연단·약초·법역·조직 계획은 직접 확인한다. 게임에 없거나 변형된 상황에서는 기억을 정답으로 보호하지 않는다.

### 유용한 오해

상대는 주인공 A를 약자, 숨은 강자, 고급 법기 의존자, 강한 조직 소속, 고위 후원자가 있는 인물로 오분류한다. 방심·가격 상승·경계 완충에 유리하면 정정하지 않는다.

44~46화에는 이 전략이 한 단계 확장된다. 얼굴·체형·복장뿐 아니라 주력 법기·대표 법술·기술 출처까지 바꿔 **별도의 활동 신원 A**를 만든다. 상위 추적자는 실제 주인공 A가 아니라 이 표면 신원을 추적하게 된다.

### 본질 판독의 경계

상태 정보는 변신·거짓 이름·경지 축소를 관통하지만 상대의 모든 기술·욕망·조직 계획은 보여 주지 않는다. 49화에는 축기 후 정신 처리 속도 변화 때문에 상위 존재에게는 비상 능력의 대상 지정 순간조차 대응 시간이 될 수 있다는 새 가설이 생긴다. 이는 아직 직접 시험되지 않아 `HYPOTHESIS`다.

## 비상 능력 사용 기준

### 사용 조건

- 즉시 치명성이 높음
- 일반 기술·도주·협업 성공 가능성이 낮음
- 정면 시선과 발동 공백 확보
- 외부 목격·후속 추적 통제 가능
- 미확인 수단을 오래 관찰하는 비용이 더 큼

### 보류 조건

- 일반 기술·장비·단약으로 해결 가능
- 다수 목격자 존재
- 사용 뒤 더 큰 위협 예정
- 일반 대응 체계를 검증할 가치가 있음
- **현재 적보다 다음 연속 위협에 남겨 두는 편이 생존 확률이 높음**

### 41~42화의 확장

41화 상위 적 A에게는 새 뇌법과 외부 기운을 사용하고 비상 능력을 보류한다. 영력이 고갈된 직후, 전투에 가세하지 않고 관찰하던 상위 협력자 A가 포식 의도를 드러내자 남겨 둔 비상 능력을 사용한다. 제한 자원 배분 기준이 현재 적 하나가 아니라 **위협의 순서**로 확장된다.

## 기본 전술

### 말하기

짧은 질문과 건조한 응답을 사용해 상대가 욕망·위계 기대·정보 수준을 드러내게 한다. 42화에는 포식 의도를 감지한 상대에게 공격 대신 보수 출처를 질문해 상층 관심과 자금 구조를 확인한다.

### 침묵하기

비상 능력, 상태 정보, 지식 출처, 숨은 전리품, 실제 활동 신원을 공개하지 않는다. 상대가 말하는 동안 회복·감지·판단을 수행한다.

### 위협 처리

- 일반 기술·자율 법기·방어 장비·단약·지형을 먼저 조합
- 상대의 오해를 방심·공격 집중·잘못된 추적으로 유도
- 전체 이론이 없으면 구조적 결합부만 공격
- 직접 목표 감지가 실패하면 목표 자체가 아니라 `목표를 숨길 구조`를 찾도록 탐색 질문을 바꿈
- 예상 포식자에게는 선공 조건을 스스로 확정하게 한 뒤 반격

### 조직 처리

진영 명분보다 실제 지출과 요구 권리를 본다. 업무상 지시·공동 목표는 수용하지만 사적 위계·장기 소속·무제한 감시는 거부한다. 44화에는 상위 존재의 원격 인식 위험 때문에 공식 탈환대 계약 자체를 거절하고 후행 개입으로 목표를 재구성한다.

### 보상 처리

보상의 이름보다 현재 결핍을 해결하는 기능으로 재분류한다. 45~46화의 제한 부보는 잠입용 광역 화력에서 축기단 연단용 미세 화력으로 다시 쓰인다. 50화에는 경쟁자가 살해를 선택할 가능성을 예상하고 그의 경매 자금까지 후속 단약 구매 자원으로 계산한다.

## 자기합리화·책임 귀속

### DIRECT 자기설명

주인공 A는 반복적으로 `상대가 먼저 탐욕·포식·살해를 선택하지 않았다면 이런 결과가 없었다`는 식으로 사후 결과를 해석한다.

- 12화: 상대의 독점 욕망과 살해 의도가 고립 조건이 됨
- 20~21화: 특수 자질을 생포하려는 욕망이 공격 중단을 만듦
- 42화: 상위 협력자 A의 포식 선택 뒤 반격
- 50화: 독술사 A가 낙찰자를 죽이려 할 것을 예상한 뒤 독 대비·고립 유인·반격

### 판정 경계

이 자기설명이 작품의 객관적 도덕 판정인지, 자기 행동을 정당화하는 자기합리화인지 아직 확정하지 않는다. 후속 죄책감·반박·실패 사례를 추적한다.

## 관계별 변주

- 조직 추천자 A: 비가역 종속 거부, 상대 탐욕을 고립 조건으로 전환
- 임대인 A: 계약이 끝나도 감사·선물·공정한 정산을 남김
- 중개자 A: 방법은 숨기되 정보·소개·사과·비공식 부탁 권리를 확대
- 임시 동료 A·B: 동등한 호칭은 수용하지만 신원 공개형 친교는 보류
- 보호 대상 집단 A: 생환 의무와 자원권을 분리하고 위험 때문에 이동권을 일시 제한
- 제작자 A: 과거 약점을 협박에 쓰지 않지만 협상 주도권은 유지
- 정종 조직 A: 실제 선금·안전·전장 접근을 받되 감시·위계를 경계
- 마도 조직 A: 낮은 실제 비용의 포섭 제안 거절, 살해 명령에 대응
- 행동대장 A: 중개자 A의 평판을 통해 접근권을 얻고, 영입은 비공식 관계 의무를 이유로 거절

## 권한·책임 변화

- 초기: 혼자 생존하고 자기 수단을 숨기는 개인
- 11~20화: 거래·임무·협업의 권리 범위 설정
- 21~30화: 보호 계약의 현장 통제권과 생활 관계의 시설 접근권 획득
- 31~40화: 조직 경쟁을 가격으로 바꾸고 법역 위기에서 경지 위계를 넘어 해결 방향 제시
- 41~50화: 조직 공로를 숨기고 독립 활동 신원을 운영하며, 비공식 신뢰망을 이용해 중층부 제도권에 접근

권한이 늘어도 조직 전체 책임은 받지 않는다. 그러나 인간다움·관계 의무 때문에 효율만으로는 설명되지 않는 선택이 생긴다.

## 반복되는 성공 방식

기존 지식으로 후보 생성
→ 현재 조건·권리·정보층·물리 한계 확인
→ 상대가 유리한 오분류를 하도록 둠
→ 상대 욕망·자기설명을 위치·시간·추적 자원으로 전환
→ 일반 기술·장비·거래·협업으로 범위 확대
→ 제한 능력을 위협 순서와 노출 조건에 맞춰 배분
→ 성과를 성장·방어·은폐·제작·정보·관계 권리로 분해
→ 필요하면 별도 활동 신원을 만들어 위험 흔적 분리
→ 성과가 만든 감시·관계 의무·새 결핍을 다시 계산

## 실패·오판·비용

- 비상 능력 발동 전 선공당하면 사망 가능
- 일반 기술·연단·제작에 대량 자본과 시간 필요
- 저장 용량 때문에 일부 전리품 포기
- 강한 평판이 영입·암살·감시를 동시에 부름
- 유용한 오해가 과대 기대를 부를 수 있음
- 공로 은폐에도 생존자와 소문으로 노출이 누적됨
- 공식 임무 회피는 원하는 자원 획득 시점을 늦춤
- 별도 활동 신원은 실제 신원이 아니라 가명 A 쪽에 상위 추적을 누적함
- 축기 성공 뒤 기존 저순도 성장법 효율이 급감해 새 자원 결핍 발생
- 인간다움과 관계 의무가 장기 생존 효율과 충돌할 가능성

## 예외 조건과 복귀

- 조직이 실제 비용을 지불하고 계약 범위를 지키면 임시 협력
- 사적 복종·강탈·비밀 공개 요구 시 거래 관계 또는 적대로 복귀
- 전체 이론이 부족하면 목표를 통과·지원 차단 등으로 축소
- 본능적 공포가 장기 성장 기틀과 충돌하면 공포를 인정한 채 성장 기준을 선택할 수 있음
- 관계의 계약 기능이 종료되어도 인간적 감사가 남을 수 있음

## 장기 아크 — 1~50화

장수 욕망
→ 비상 능력과 일반 성장 경로 확보
→ 포식형 관계 이용과 종료
→ 비가역 종속 거부·독립 거래망 구축
→ 특수 자질 노출과 상위 적 유인
→ 축기·방어·은폐·연단 인프라 확보
→ 보호 계약·조직 경쟁·법역 위기 경험
→ 상위 술식 관찰과 새 뇌법 창안
→ 현재 적보다 다음 포식자를 위해 비상 능력 보존
