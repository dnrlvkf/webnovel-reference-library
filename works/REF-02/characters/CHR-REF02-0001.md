# 주인공 A

## 현재 연구 판정

주인공 A의 핵심은 감정적 냉혹함이 아니라 **장기 생존 가능성과 자율성을 함께 늘리는 판단 체계**다. 강한 능력·조직·관계·지식·장비 중 어느 것도 그 자체로 정답 취급하지 않는다.

1~40화에서 확인된 판단 단위는 다음과 같다.

- 실제 죽음 가능성
- 비상 능력의 발동·재사용 제약
- 일반 기술과 장비의 대체 가능성
- 상대가 현재 무엇을 원하고 무엇을 오해하는가
- 계약 뒤 잃거나 얻는 거절권·이동권·비밀권·자원권
- 상대가 실제로 지출한 비용
- 저장 공간·시간·회복률 같은 물리적 한계
- 사건 결과가 다음 선택지를 얼마나 늘리는가

## 핵심 판단 기준

### 먼저 확인하는 것

- 기존 지식과 현재 현실의 일치 여부
- 상대 발언과 행동의 일치 여부
- 표면 정보와 본질 정보의 불일치
- 상대의 목적·욕망·회복 상태·미확인 수단
- 계약의 실제 권리·의무와 비용 부담자
- 목격자·추적자·후속 상위 위협
- 시간 제한·재사용 주기·저장 용량
- 힘이 집중되거나 공급되는 구조적 지점

### 우선하는 것

1. 되돌릴 수 없는 죽음 방지
2. 수명 연장과 일반 성장 경로
3. 거절권·이동권·비밀권 보존
4. 회복 가능한 전투 상태
5. 비상 능력과 숨은 수단의 불필요한 노출 방지
6. 사건 보상의 복수 기능화

### 감수 가능한 비용

- 높은 안전 비용
- 장기간 수련과 시행착오
- 위험한 임무와 임시 협업
- 계약 목적을 위한 제한적 통제
- 거의 전 재산에 가까운 제작 투자
- 실제 선금을 받은 계약의 전투 의무

### 감수하지 않는 비용

- 검증 없는 신뢰
- 신혼을 훼손하거나 묶는 비가역 계약
- 지속적 상납과 절대복종
- 비밀 수법·지식 출처의 불필요한 공개
- 보호 보상과 별개인 자원 상납
- 조직 명분만 있고 실제 지출은 없는 제안

## 정보와 오해

### 지식 사용

게임 지식은 선택지를 생성하지만 현실의 수련·법술·연단·약초 식별·법역은 직접 확인한다. 게임에 없던 사건이 발생하면 기억을 정답으로 고집하지 않고 현재 영기 흐름과 상태 정보를 우선한다.

### 유용한 오해

상대는 주인공 A를 다음처럼 오분류한다.

- 낮은 경지의 약자
- 경지를 숨긴 강자
- 고급 법기에 의존하는 수사
- 강한 조직 소속
- 숨은 고위 후원자가 있는 인물

주인공 A는 이런 오해가 방심·가격 상승·경계 완충에 유리하면 정정하지 않는다. 적극적인 거짓 설명보다 상대가 스스로 만든 가설을 유지하는 편을 선호한다.

### 본질 판독의 경계

상태 정보로 무생물 변신·거짓 이름·경지 축소는 관통하지만 상대의 모든 기술·욕망·조직 계획까지 알 수 있는 것은 아니다. 법역의 진짜 목적과 고위 법술은 현장에서 새로 추론해야 한다.

## 비상 능력 사용 기준

### 사용 조건

- 즉시 치명성이 높음
- 일반 기술·도주·협업의 성공 가능성이 낮음
- 정면 시선과 행동 공백을 확보함
- 외부 목격과 후속 추적을 통제할 수 있음
- 미확인 수단을 오래 관찰하는 비용이 더 큼

### 보류 조건

- 일반 기술·장비·단약으로 해결 가능함
- 다수 상대와 목격자가 존재함
- 사용 뒤 더 큰 위협이 예정됨
- 현재 상대를 직접 싸워 일반 대응 체계를 검증할 가치가 있음

### 21~33화의 확장

- 상위 적의 생포 욕망을 이용해 공격 중단과 정면 시선을 만듦.
- 변신 경비자의 미확인 수단을 오래 두지 않고 제거함.
- 24시간 재사용 주기를 비경 폐쇄 시각과 맞춰 보스 수확 일정으로 전환함.
- 직접 전투 시간이 길거나 명중이 어려운 대상에만 사용함.
- 저장 용량과 계약 목표 때문에 수확 계획을 중단할 수 있음.

비상 능력은 만능 버튼이 아니라 **시간표·표적 우선순위·정보 노출·자원 용량을 함께 결정하는 제한 자원**이 된다.

## 기본 전술

### 말하기

짧은 질문과 건조한 응답으로 상대가 욕망·위계 기대·정보 수준을 스스로 드러내게 한다. 계약 선택 이유도 이념보다 실제 선금처럼 검증 가능한 조건으로 말한다.

### 침묵하기

수행 방법, 비상 능력, 상태 정보, 지식 출처, 숨은 전리품을 공개하지 않는다. 상대가 말하는 동안 회복·감지·배후 명령을 수행한다.

### 위협 처리

- 일반 기술·자율 법기·방어 장비·단약·지형을 먼저 조합함.
- 상대의 오해를 공격 집중·방어 포기로 유도함.
- 숨은 상위 적은 포로로 바꿔 협력 조직의 정보 자원으로 넘길 수 있음.
- 구조 전체를 알 수 없으면 현재 목적에 필요한 결합부만 찾음.

### 조직 처리

- 진영 명분보다 실제 지출과 요구 권리를 봄.
- 업무상 지시와 공동 목표는 수용함.
- 사적 위계·장기 소속·무제한 감시는 인정하지 않음.
- 안전과 감시가 함께 제공될 수 있음을 계산함.
- 지도자의 탐욕과 하위 인원 소모를 장기 신뢰의 반대 근거로 기록함.

### 보상 처리

획득물의 원래 명칭보다 현재 결핍을 해결하는 기능을 분석한다.

- 핵심 영기 → 경지 상승
- 갑각·턱·골수·전지·영초 → 자율 전투 법기
- 고급 저장 도구 → 기파 은폐
- 상위 보물 → 광역 공격과 연단 화력
- 실제 선금 → 제작 비용
- 포로 → 조직 정보와 협력 신뢰
- 안전 공간 → 전투 준비, 단 감시 비용 포함

## 관계별 변주

- 조직 추천자 A: 비가역 종속 거부, 상대 탐욕을 고립 조건으로 전환.
- 임대인 A: 가족 우선 이해관계와 방어 공간을 근거로 비용·호의를 교환하고 시설·교육 접근권 획득.
- 중개자 A: 방법은 숨기고 결과·보수·정보 접근권을 확대하며 경쟁 제안을 가격 인상에 사용.
- 임시 동료 A·B: 동등한 호칭은 수용하지만 신원 공개가 필요한 친교는 보류.
- 보호 대상 집단 A: 생환 의무와 자원 소유권을 분리하고 현장 위험 때문에 이동권을 일시 제한.
- 제작자 A: 과거 약점을 협박에 쓰지 않지만 협상 주도권과 비밀은 유지.
- 정종 조직 A: 실제 선금·안전·전장 접근을 받되 감시·위계·탐욕을 경계.
- 마도 조직 A: 공법 제안의 낮은 실제 비용을 보고 거절하며 포섭 실패 뒤 살해 명령에 대응.
- 정종 지도자 A: 평시에는 탐욕스러운 상위자, 법역 위기에서는 시간을 벌어 주는 협력자.
- 마도 지도자 A: 포섭·살해·생포 욕망이 교체되는 직접 적대자이자 고위 술식 관찰 대상.

## 권한·책임 변화

- 초기: 혼자 생존하고 자기 수단을 숨기는 개인.
- 11~20화: 거래·임무·임시 협업의 권리 범위를 설정.
- 21~30화: 보호 계약의 현장 통제권과 생활 관계의 시설 접근권 획득.
- 31~40화: 조직 간 경쟁을 가격으로 바꾸고, 법역 위기에서는 경지 위계를 넘어 해결 방향을 제시하는 임시 권한 획득.

권한이 늘어도 조직 전체 책임을 수용하지 않는다. 계약 목적과 시간 범위를 제한한다.

## 반복되는 성공 방식

기존 지식으로 후보 생성
→ 현재 조건·권리·정보층·물리 한계 확인
→ 상대가 자신을 유리하게 오분류하도록 둠
→ 상대 욕망과 자기설명을 위치·시간 자원으로 변환
→ 일반 기술·장비·거래·협업으로 가능한 범위 확대
→ 제한 능력은 표적·시각·노출 조건에 맞춰 사용
→ 성과를 성장·방어·은폐·제작·정보·관계 권리로 분해
→ 전체 이론이 부족하면 구조적 결합부만 공격
→ 성과가 만든 감시·추적·소유권 요구를 다시 계산

## 실패·오판·비용

- 비상 능력 발동 전 선공당하면 죽을 수 있음.
- 일반 기술·연단·제작 체계 구축에 시간과 대량 자본이 필요함.
- 저장 용량 때문에 일부 전리품을 포기함.
- 자율 법기 제작으로 자본을 거의 소진함.
- 강한 평판이 영입·암살·감시를 동시에 부름.
- 유용한 오해가 상위 임무와 과대 기대를 부를 수 있음.
- 정종 조직의 안전 공간은 내부 감시를 동반함.
- 하위 인원을 소모하는 조직과 협력하면 공동 피해의 책임 문제가 생김.
- 법역 파훼는 완전 해결이 아니라 자동 복구 전의 시간창만 만듦.
- 새 술식의 안정성·재현성·영력 비용 미확인.

41~50화에서 새 뇌법과 법역 손상이 최종 승리로 이어지는가. 정종 지도자 A는 공로·전리품·주인공 A의 새 술식을 어떻게 분류하고 어떤 권리를 요구하는가. 유용한 오해와 임시 협력이 실제 비용으로 뒤집히는가.

## 변경 이력 요약

- 1~30화: 생존·자율성·비상 능력·제한 관계·보상 재배치 모델 형성.
- 31~40화: 재사용 일정, 유용한 오해, 실제 비용 기반 조직 선택, 구조적 결합부 파괴, 고위 술식 창안으로 확장.
