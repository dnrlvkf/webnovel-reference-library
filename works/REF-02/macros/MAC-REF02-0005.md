# 신념을 실제 붕괴와 비가역 비용의 복귀로 검증한다

## 원문 재진입

- source: `SRC-COL2-027`
- scene: `SC-REF02-0072`
- range: `181~188화 / 71267~74876행`
- identity: sealed

## 장면 조건

상위 동맹 A는 자기 생존보다 후대의 지속과 약속을 우선하는 기준을 오래 설명해 왔다. 그 기준은 과거 본능 실패와 상실에서 만들어졌다.

후속 전투에서 적의 현혹이 그가 억눌러 온 자기보존·소유 욕망을 확대해 실제 배신 욕망까지 끌어낸다.

## 작가의 핵심 결정

캐릭터 신념을 `유혹에도 흔들리지 않는 성격`으로 증명하지 않는다.

신념 언어 선행
→ 경쟁 욕망 증폭
→ 실제 판단 붕괴·배신 욕망
→ 본인이 붕괴 인식
→ 수련 기반·인격을 태우는 비가역 비용
→ 약속 기준 복귀
→ 실제 약속 이행
→ 자원·미래 의무 인계
→ 자기 실패에서 나온 마지막 경고.

신념의 강도를 **무오류가 아니라 복귀 비용**으로 측정한다.

## 독자 판정 변화

장면 전: 의리와 유산을 중시하는 강자.

현혹 중: 자기 보존 앞에서 실제로 무너질 수 있는 사람.

복귀 뒤: 본능이 없는 사람이 아니라 **본능과 실패를 안고도 자기 미래를 지불해 기준으로 돌아오는 사람**.

## 상태 변화

- 상위 동맹 A: 안정 조력자 → 판단 붕괴 가능한 독립 행위자 → 비용을 치른 유산 전달자.
- 주인공 A: 기술 거래 상대 → 후대 연구 의무와 자원·경고의 수탁자.
- 관계: 현재 협력 → 미래 세대까지 이어지는 제한 의무.

## CHARACTER 연결

`CHR-REF02-0002`에서 중요한 것은 무엇을 믿는가뿐 아니라 **그 믿음이 무너졌을 때 무엇을 버려 복귀하는가**다.

## STORY·PROSE 연결

외부 강제라고 책임을 완전히 지우지 않는다. 실제 내부 욕망을 먼저 보여 주고, 복귀도 긴 도덕 독백보다 수련 상태 파괴·행동 반전·약속 이행·자원 인계로 증명한다.

## 원문을 다시 읽어야 하는 이유

`의리 있는 조력자가 유혹을 이김`으로 줄이면:

- 내부 경쟁 욕망
- 실제 배신 판단
- 복귀의 영구 비용
- 마지막 경고와 과거 실패의 연결

이 사라진다.

## 기존 Macro와 차이

기존 Macro 0001~0004가 관계 협상·정보차·현재 선택·기술 재분류를 다룬다면, 이 Macro는 **선언된 판단 기준의 붕괴와 복귀 비용**을 연구한다.

## 향후 검색할 집필 상황

- 강한 신념의 조력자를 무결점으로 만들지 않을 때
- 세뇌/유혹을 경쟁 판단 기준의 시험으로 쓸 때
- 진심을 말보다 복귀 비용으로 증명할 때
- 조력자의 퇴장을 유산 의무로 연결할 때

## 표면 모방 경계
