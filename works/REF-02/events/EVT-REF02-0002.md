# 비경 수확을 자율 전투 체계로 바꾸고 조직 토벌을 법역 생존전으로 전환한다

## 사건 범위

- 시작: 31화 상위 마도 적 A와의 결전
- 중간 전환: 비경 수확·법기 제작·경쟁 영입
- 종료 지점: 40화 법역 지원 차단과 최종 결전 재개
- 현재 상태: 미완결 사건. 마도 조직 지도자 A 생존.

## 발생 조건

- 주인공 A가 비경에서 상위 적과 보스급 요괴를 제거할 수 있음
- 비상 능력에 24시간 재사용 주기가 있음
- 비경 체류 시간과 저장 용량이 제한됨
- 고위 요괴 재료를 다룰 제작자와 대량 자본이 필요함
- 정종·마도 양 조직이 외부 조력자의 정체를 추적함
- 마도 조직 A가 옛 법역을 재가동할 거점 의식을 준비함

## 촉발 선택

1. 상위 적의 오해를 공격 집중과 방어 포기로 유도해 제거함.
2. 비상 능력 재사용 시각을 비경 수확 일정으로 만듦.
3. 고위 재료와 거의 전 재산을 자율 법기 제작에 투자함.
4. 실제 선금을 낸 정종 조직 A의 토벌 제안을 수락함.
5. 법역 발동 뒤 정면 전투가 아니라 영기 공급의 발원점을 찾음.

## 참여자별 목표

### 주인공 A

- 비경 자원을 축기·제작 인프라로 전환
- 주력 수법을 숨긴 채 일반 전투 대응력 확대
- 조직 종속 없이 실제 보수와 안전 확보
- 법역에서 생존하고 마도 지도자 A의 지원 차단

### 정종 조직 A

- 마도 조직 A의 지역 거점화를 막음
- 외부 실전 인재를 토벌 전력으로 사용
- 지도자 A의 종문 입지와 공로 확보

### 마도 조직 A

- 비경 실패를 대체할 자원 거점 확보
- 주인공 A를 포섭하거나 제거
- 옛 법역을 재가동해 총본산 설치
- 다가올 환란을 위한 인재와 하층 세력 확보

## 충돌·방해

- 상위 적의 풍계 법술과 방어 판단
- 저장 도구 용량과 비경 폐쇄 시간
- 제작 비용과 숨은 배후에 대한 오해
- 양 조직의 영입·암살 경쟁
- 정종 조직 내부의 감시와 위계 갈등
- 정종 토벌대의 실전 부족과 무질서
- 마도 조직 A의 진짜 의식 목적 은폐
- 법역의 자동 복구와 지도자 A의 초월적 화력

## 결과

### 31~33화

- 상위 마도 적 A 제거
- 수 속성 축기 자원과 고위 요괴 제작 재료 확보
- 보호 계약 완료
- 비상 능력의 재사용 주기를 이용한 보스 수확 성공
- 저장 용량 한계로 수확 우선순위 확정

### 34~37화

- 자율 공격·방어 법기 여섯 개 제작
- 양 조직 영입 경쟁에서 대량 선금 확보
- 제작 비용 지급과 완성품 회수
- 마도 암살자 제거, 축기경 간부 포로화
- 정종 조직 A와 토벌 협력 확대

### 38~40화

- 금쇄진 파괴로 토벌대 진입
- 정종·마도 지도자와 하위 전력 대치
- 옛 법역 재가동으로 양측 하위 전력 대부분 붕괴
- 주인공 A가 법역 영기 발원점을 손상
- 마도 지도자 A의 법역 지원 일시 차단
- 정종 지도자 A의 반격으로 마도 지도자 A 중상
- 주인공 A의 새 뇌법 창안과 최종 결전 재개

## 비용

- 비경 자원을 담기 위해 낮은 가치의 물품 포기
- 자율 법기 제작에 거의 전 재산 투입
- 강해진 평판 때문에 영입·암살·감시 동시 발생
- 정종 분당 안전의 대가로 내부 관찰 수용
- 토벌대 하위 구성원 대량 사망
- 법역 파훼는 일시 손상이며 자동 복구 전까지의 짧은 시간창만 제공
- 주인공 A의 영력·정신력 반복 소모

## 상태 변화

### 정보

- 주인공 A의 존재가 양 조직 지도자에게 확인됨
- 실제 비상 능력과 상태 정보는 여전히 비공개
- 법역과 다가올 환란에 관한 상위 정보가 공개됨

### 관계·권한

- 중개자 A의 가격·정보 중개 권한 확대
- 정종 조직 A와 제한적 토벌 관계 성립
- 법역 위기에서 주인공 A의 사건 해결 권한이 경지 위계를 넘어 상승

### 자원

- 축기 자원 다섯 속성 이상 확보 진전
- 자율 전투 법기 체계 완성
- 선금 소진과 새 보수 기대

### 목표

- 단순 자원 수확에서 마도 조직 지도자 A 제거와 법역 탈출로 전환
- 결전 뒤 정종 조직 A와 공로·보수·전리품 정산 필요

## 후속 동력

- 법역 자동 복구 전에 마도 지도자 A를 끝내야 함
- 정종 지도자 A의 탐욕이 주인공 A의 새 술식·법기·전리품을 향할 가능성
- 마도 조직 A의 상위 후원이 주인공 A를 추적할 가능성
- 자율 법기와 축기 자원이 실제 경지 돌파에 어떻게 편입되는지 확인 필요

## 사건 기능

- 비상 능력의 제약을 사건 일정 엔진으로 전환
- 전리품이 다음 전투 방식으로 변하는 과정을 증명
- 조직 선택을 선악이 아니라 비용·권리 문제로 재구성
- 낮은 규모의 진법 파훼를 상위 법역 파훼의 예고로 사용
- 40화에서 승리 대신 시간창과 새 기술을 보상으로 제공

## 제시 방식

- 전투 결과를 먼저 보여 준 뒤 상대가 왜 오판했는지 복기함.
- 제작 설명 뒤 즉시 암살전을 배치해 성능을 검증함.
- 정종과 마도의 언쟁 뒤 양쪽 하위 인원 희생을 병치함.
- 법역의 표면 목적을 먼저 제시하고 공간 전환으로 진짜 목적을 확정함.
- 정종 지도자 A의 방어전과 주인공 A의 탐색을 교차해 시간 압박을 유지함.
