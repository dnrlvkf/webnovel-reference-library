# 유산 의무에서 강제 상위 승급까지 · 181~240화 사건 인과

## whole-work correction

195~200화의 기존 조직 은의·즉시 비승 거절·기억 강제 추출 당사자는 `장기 동업자 A`가 아니라 **상위 동행자 A (`REL-REF02-0006`)**다. 당시 관계 귀속을 바로잡고 사건 인과는 유지한다.

## 사건군 A · 유산 계약과 신념 붕괴

상위 동맹 A가 현재 기술/자원 제공 대가로 후대 연구 의무를 요구
→ 현혹으로 실제 배신 욕망 발생
→ 자기 수련 기반·인격을 태워 약속 기준으로 복귀
→ 유산·연구 의무를 주인공 A에게 인계.

상태 변화: 단기 거래가 세대 의무로 바뀌며, 신뢰는 무흔들림보다 복귀 비용으로 재판정된다.

## 사건군 B · 파편 재구성과 관계 기반 없는 구원 실패

유산 파편으로 직접 경험하지 않은 상위 심상을 재구성
→ 큰 인지 비용을 치르고 방어 성공.

과거 지식상 다른 미래가 가능했던 적에게 다른 선택 제안
→ 현재 관계 기반 부재
→ 거절
→ 적대 유지.

상태 변화: 지식은 기술 입력으로는 확장되지만 사람의 현재 선택을 자동 변경하지 못한다.

## 사건군 C · 상위 동행자 A의 기존 조직 의무와 정보권 침해

상위 동행자 A가 주인공 A·장기 동업자 A와 함께 즉시 비승할 기회를 얻음
→ 원래 조직 은의 때문에 거절
→ 조직 지도자가 충성을 존중한다는 언어 사용
→ 실제로는 기억을 강제로 읽음
→ 관계 비밀이 외부 조직에 노출될 위험 발생.

주인공 A는 별도 승급 과정에서 주변 충격 범위를 계산하지 못하는 명확한 실행 오차도 경험한다.

상태 변화: 새 협력 관계가 과거 의무를 자동 삭제하지 않으며, 정보·신체 권리 침해가 실제 비용이 된다.

## 사건군 D · 적 포획 장치를 성장 인프라로 역사용

적이 시간 가속 내부 공간에 주인공 A를 강제로 수용하려 함
→ 주인공 A가 이를 예상하고 의도적으로 진입
→ 내부 시간·자원으로 승급
→ 이미 날아오는 복수 공격을 시간 해상도로 분해
→ 맞춤 대응 즉석 합성.

상태 변화: 제약 장치가 성장 인프라로 바뀌고 TEC-07이 실시간 설계로 확장된다.

## 사건군 E · 기능 한정 최고 직위와 조직 내전

자기 이익을 숨기지 않는 주인공 A가 오히려 동기 예측 가능성을 인정받음
→ 임시 최고 전투 직위 수용
→ 운영권·영구 소속은 받지 않음
→ 다른 조직에서는 옛 명령을 현재 사람의 자유보다 우선하는 제도 폭력이 드러남.

상태 변화: 내부 직위도 포괄 종속과 분리된다.

## 사건군 F · 무코어 분산 적과 시간 벌기

강한 동료가 본체/코어를 장시간 탐색
→ 실패
→ 법역 전체에 존재가 분산돼 있음을 재판정
→ 비상 능력 재사용까지 24시간 생존 목표로 전환
→ 전체 존재를 실제 대상으로 지정해 종결
→ 공간 균열·기존 도구 파손·의식 상실 비용
→ 상위 후계자 A가 승리 잔여 힘 때문에 강제 상층 이동.

상태 변화: TEC-05/08의 기존 공식을 수정하고 관계 상대가 주인공 통제 밖의 층위로 이동한다.

## 사건군 G · 상층 우발 세계와 감정 수련

예정 항로 이탈
→ 우발 세계 착륙
→ 수리 장기화
→ 위험 지역을 다음 성장 자원 경로로 전환
→ 높은 법역과 낮은 일반 술식 사이 격차 확인
→ 외로움·관계 한계를 인정
→ 개념 술식으로 번역.

상태 변화: 기술 학습 입력이 외부 구조에서 자기 정서 경험까지 확장된다.

## 사건군 H · 독립 잠입 오분류와 조직 해체

서로 접선하지 않은 두 침투 팀이 유사한 표면 흔적 생성
→ 적 조직이 하나의 적으로 오분류
→ 병력/방어 자원 오배치
→ 내부 권력 찬탈 때문에 지도자 이동
→ 주인공 A가 고립 조건 이용
→ 억압 조직 해체
→ 사후 사회 통치권은 인수하지 않음
→ 강제 조종 옛 관계자는 제거 대신 지배 연결 차단.

상태 변화: 문제 해결 책임과 사후 통치 책임이 분리되고, 강제 상태/자발 적대 구분이 반복된다.

## 사건군 I · 상위 힘 모사의 원본 채무

직접 이기기 어려운 추적자를 더 큰 경계 밖 힘으로 유인
→ 제3자 감시 세력 개입으로 추격 해소.

그 과정에서 반복 모사해 온 다른 초월 존재의 힘을 크게 사용
→ 실제 원본이 감지
→ 과거 접촉과 힘 사용을 약속/채무로 재분류
→ 주인공 행동권 봉쇄
→ 강제 소환·승급·임무.

상태 변화: 기술 모사가 사회/형이상학적 관계 비용으로 회수된다.

## whole-work 인과 판정

이 구간의 세계 위기·조직 비승 계획은 주인공 A의 성장 때문에 발생한 것으로 확인되지 않는다. 장기 조직 계획과 멸망 정보는 독립 시계를 가진다.

주인공 성장의 기능은 **위기를 발생시키는 것보다 이미 진행 중인 위기에 개입할 수 있는 수단과 시점을 바꾸는 것**이다.
