# 181~240화 사건 인과 · 상층 규칙의 비용화와 초월 채무의 회수

## 전체 인과

상위 동맹 A와 미래 연구 의무 계약
→ 적 현혹으로 동맹의 판단 기준 붕괴
→ 자기 수련 기반 소모로 복귀·약속 이행
→ 유산 자원 인계
→ 파편 기반 상위 심상 방어 재구성
→ 관계 기반 없는 적 구원 설득 실패
→ 장기 동업자 A의 기존 조직 의무와 기억 강제 추출
→ 적 포획 도구 의도적 이용·시간 가속 수련
→ 승급·실시간 대응 술식 합성
→ 기능 한정 최고 무력 직위와 조직 내부 갈등
→ 강림형 법역의 반동
→ 법역 전체에 분산된 적과 24시간 지연전
→ 분산 전체 대상 제거·공간 파열·도구 파손
→ 옛 관계 정산·다음 경지 진입
→ 도주 계획 실패·우발 세계 착륙
→ 차기 경지 자원 표적화·현지 제한 계약
→ 감정 수용 기반 새 개념 술식
→ 독립 잠입팀 흔적 압축·적 방어 오배치
→ 억압 조직 해체·강제 조종 관계자 구출
→ 상위 추적자 발생
→ 부분 현현을 경계 밖으로 끌어 제3자 감시 세력 작동
→ 추격 해소
→ 반복 모사한 다른 상위 존재가 실제 감지
→ 과거 재회 말·힘 사용을 채무로 재분류
→ 강제 소환·행동 봉쇄·강제 승급
→ 다음 상위 임무 진입.

# 사건 단위

## EVT-7A · 유산 계약과 신념 붕괴

### 발생 조건

- 상위 동맹 A가 독점 기술과 제한된 수명을 보유.
- 자기 계통의 본능 문제를 해결할 방법을 찾지 못함.
- 주인공 A는 향후 더 높은 경지·지식을 얻을 가능성이 큼.

### 촉발 선택

현재 기술 제공 대가를 현재 복종이 아니라 미래 후대 연구 의무로 설정.

### 충돌

적의 현혹이 상위 동맹 A의 자기보존·소유 욕망을 증폭해 약속 기준을 실제로 무너뜨림.

### 결과·비용

- 상위 동맹 A가 자기 수련 기반을 태워 판단 복귀.
- 약속 이행과 적 제거.
- 개인 미래·인격 안정성 손실.
- 자원·의무를 주인공 A에게 인계.

### 새 선택지

주인공 A는 상위 자원뿐 아니라 미래 세대에 대한 의무를 보유.

## EVT-7B · 관계 기반 없는 구원 실패

과거 지식상 다른 미래가 가능한 적에게 현재 다른 선택을 제시하지만, 관계·신뢰 축적이 없어 거절됨.

결과:

- `가능 미래 정보`가 현재 선택을 강제하지 못함.
- 관계 투자 없이 한 번의 정확한 말로 사람을 바꾸는 공식이 실패.

## EVT-7C · 기존 조직 의무와 정보권 침해

장기 동업자 A는 주인공 A와의 상계 공동 목표에도 원래 조직 의무를 이유로 즉시 이탈하지 않음.

원래 조직 지도자는 verbal betrayal을 요구하지 않는 대신 기억을 강제 추출함.

결과:

- 새 관계와 오래된 의무가 경쟁 기준으로 병존.
- `말을 요구하지 않음 = 정보권 존중`은 무너짐.
- 주인공 A는 사적 정보와 제3자 관계 신뢰를 협상 담보로 사용해 임시 충돌을 닫음.

## EVT-7D · 포획 자원의 역사용과 실시간 설계

적 포획 수단 접근
→ 주인공 A가 위험을 예상하고 의도적으로 진입
→ 내부 시간 가속·자원 이용
→ 승급
→ 포획자 제거
→ 이미 발사된 복수 공격을 높은 시간 해상도로 관찰
→ 각각의 구조에 맞춘 대응을 즉석 합성.

상태 변화:

- 제약 장치 → 성장 인프라
- TEC-07 사전 연구 → 실시간 적응 설계.

## EVT-7E · 기능 직위와 법역 반동

주인공 A가 자기 이익을 숨기지 않자 오히려 동기가 예측 가능하다고 평가됨.

조직은:

- 공식 종문 소속 없이
- 운영권 없이
- 최고급 전투 역할만

주는 기능 한정 직위를 제안/부여.

동시에 강림형 법역은 큰 성능 뒤 의식 상실급 반동을 일으킴.

성과가 곧 지속 운용 가능성을 뜻하지 않음.

## EVT-7F · 무코어 분산 적과 24시간 지연전

적이 법역 전체의 미세 단위로 분산되어 단일 핵심이 없음.

코어 탐색 장시간 실패
→ 무코어 판정
→ 비상 능력 재사용까지 동료가 시간 구매
→ 주인공 A가 분산 전체를 하나의 실제 대상으로 지정
→ 전체 소멸.

비용:

- 법역 붕괴 폭발
- 주인공 의식 상실
- 상위 공간 균열
- 기존 공간 절단 도구 파손
- 관계 인프라에 의한 구조 필요.

## EVT-7G · 경지 구조 변화와 옛 관계 정산

분산 적 붕괴 자원을 흡수한 관계 상대는 외부 상위 체계에 의해 강제 승급/이동함.

주인공 A는 이를 통제할 수 없음.

그 뒤 하층부를 왕복하며:

- 옛 관계에 감사·자원 정산
- 현재 가치가 낮아진 자원의 재배치
- 후배/거점에 정보·자원 전달

을 수행하고 다음 경지로 진입.

새 경지에서는 육신/영혼 구조가 변해 TEC-08의 전제 자체가 좁아짐.

## EVT-7H · 도주 실패를 다음 자원 경로로

상층 도주 중 예상 밖 세계에 착륙하고 이동 수단 수리가 장기화됨.

주인공 A는 그 세계를:

- 단순 피난처가 아니라
- 미래 외부 세력 진출점
- 다음 경지에 필요한 희귀 자원 위치

로 재분류.

현지 피해 집단과 일회성 계약을 맺고 조직 해체와 자원 획득을 연결함.

## EVT-7I · 독립 잠입의 비의도 협업

주인공 측과 별도 잠입팀이 접선하지 않음.

그러나 적은 비슷한 외형/행동 흔적을 하나의 적으로 압축해 오판.

오판
→ 방어 자원 분산
→ 내부 지도자의 권력 찬탈 이동
→ 핵심 지도자 고립
→ 주인공 측 법역 전투 승리.

주인공은 독립팀을 직접 지휘하지 않고 혼란의 결과만 이용한다.

## EVT-7J · 강제 상태 구출과 조직 해체

적 상위 존재의 혈계/지배로 옛 관계자가 강제 적대 행동을 보임.

주인공 A는 이를 자발적 적대로 분류하지 않고, 별도 신뢰 관계의 격리 수단으로 지배 연결을 끊어 구출.

조직 붕괴 후:

- 피해 집단의 현재 해방은 지원
- 사후 사회 통치권은 맡지 않음.

## EVT-7K · 추격 역이용과 초월 채무

상위 추적자의 부분 현현이 이동 수단을 따라잡음.

직접 제거가 어려움
→ 주인공 A가 추적자를 자극해 더 큰 힘을 원래 경계 밖에 노출시킴
→ 그 힘을 감시하던 제3자 상위 세력이 공격
→ 추격 종료.

그러나 주인공 A가 다른 상위 존재의 형상/힘을 반복 모사한 행위가 실제 원본에게 감지됨.

감지
→ 강제 소환
→ 과거 재회 말과 힘 사용을 약속/채무로 재분류
→ 주인공 행동 봉쇄
→ 비상 능력 사용 불가
→ 자격 부족을 이유로 강제 승급
→ 새 임무.

# 권리·정보·자원 변화

## 권리

- 주인공 A: 미래 후대 연구 의무 추가.
- 장기 동업자 A: 기존 조직에 대한 잔여 의무가 살아 있음.
- 기능 조직: 주인공에게 전투 직위는 주지만 운영권/영구 소속권은 없음.
- 현지 피해 집단: 조직 해체 도움을 받지만 이후 주인공의 통치 대상이 되지 않음.
- 상위 존재 A: 객관적 정당성은 별개지만 과거 말/힘 사용을 근거로 주인공에게 임무·채무 권리를 주장하고 실제 강제력 행사.

## 정보

- 관계 기반 없는 정확한 미래 지식은 설득력이 부족할 수 있음.
- 기억 강제 추출은 verbal secrecy와 다른 정보권 침해.
- 두 잠입팀의 비슷한 흔적이 적의 단일 적 가설을 만들 수 있음.
- 초월 힘의 모사는 적에게 거짓 표면을 주는 동시에 원본에게 추적 신호가 될 수 있음.

## 자원

- 동맹의 유산 → 법역 방어 입력.
- 포획 도구 → 시간 가속 수련실.
- 붕괴 적 법역 → 관계 상대 강제 승급 자원.
- 우발 세계 → 다음 경지 자원 경로.
- 상위 힘 모사 → 전투 자산이자 채무/추적 비용.
