# 원영경식 상위 전투에서 육신 제압과 도주 영혼 종결을 분리한다

## 해결하는 문제

원영경 전후의 적을 육체적으로 쓰러뜨린 순간 전투가 끝난다고 처리하면 영혼·원영 도주·자폭·정보 유출 위험이 사라진다.

150~180화에서는 이 문제를 `육신 전투`와 `도주 영혼 종결`로 분업하는 방식이 반복됐다.

181~240화에는 중요한 적용 경계가 추가된다.

> 이 문법은 모든 상위 경지에 보편적인 것이 아니라 **육신과 도주 가능한 영혼/원영이 비교적 분리된 구조에서 강하게 성립**한다.

## 기본 작동 사슬

상위 적의 육신/법역/주 전투 수단 분석
→ 육신 제압 역할과 영혼 종결 역할 분리
→ 패배 뒤 이탈 형태·방향·속도 예상
→ 퇴로에 동료·광역 수단·비상 능력 사전 배치
→ 육신 제압
→ 영혼/원영 이탈 확인
→ 종결 역할 발동
→ 영혼 소멸 확인
→ 전리품·정보·관계 정산.

# 반복·변형 · 150~180화

## 150~156화 · 한 사람이 육신과 영혼 단계를 연속 처리

일반 수단으로 육신/전함 전투를 이긴 뒤 상대 영혼이 여러 갈래로 분열해 도주한다.

비상 능력은 육신을 이기는 필살기가 아니라 **이미 패한 적의 비가역 탈출을 닫는 종결 수단**으로 사용된다.

## 165~169화 · 육신 담당과 영혼 담당 분리

상위 동행자 A가 육신을 제압하고 다른 상위 동료를 퇴로에 미리 배치한다.

육신 패배
→ 원영 이탈
→ 대기 종결자 공격
→ 완전 제거.

## 170~177화 · 법역 학습과 종결 역할 분리

주인공 A는 새 법역을 직접 연습하기 위해 즉시 비상 능력을 쓰지 않는다.

법역/육신 전투
→ 상대 패배
→ 영혼 도주
→ 비상 능력 종결.

## 180화 · 넓고 빠른 영혼 공격을 다른 동료가 담당

육신을 잃은 적의 영혼을 광역·고속 공격을 가진 동료가 닫는다. 주인공 A는 이 기능을 별도 학습 후보로 분류한다.

# 181~240화의 반례·범위 수정

## 213~220화 · 법역 전체에 분산된 존재

적 A는 단일 육신과 별도 원영이 아니라 법역 전체의 수많은 단위에 자기 존재를 분산한다.

기존 단계:

육신 찾기
→ 육신 제압
→ 영혼 종결

이 성립하지 않는다.

동료의 코어 탐색도 실패한다.

주인공 A는 24시간 재사용이 돌아올 때까지 시간을 벌고 **분산된 전체 존재를 하나의 실제 대상으로 직접 종결**한다.

이는 TEC-08의 반례다.

> 대상 구조가 분산되어 `육신 단계`와 `영혼 단계`를 분리할 수 없으면 이 2단 문법을 적용하지 않는다.

## 221~224화 · 더 높은 경지에서 육신/영혼 구조 자체가 변한다

주인공 A가 다음 경지에 올라 관찰하는 전투 구조에서는 영적 신체와 정신/영혼의 관계가 원영경과 다르게 조직된다.

영적 신체는 에너지가 남으면 재생되고, 육신 파괴 뒤 별도 원영 하나가 도망가는 방식이 기본 종료 조건이 아니다.

따라서:

`육신 격파 → 원영 이탈 → 별도 종결`

을 모든 상위 경지에 일반화하는 해석은 `CONTRADICTED`다.

TH 자체는 폐기하지 않는다. 150~180화의 원영경식 이원 구조에서는 여러 독립 전투에서 실제로 반복됐기 때문이다.

# 수정된 적용 조건

TEC-08을 쓰기 전에 다음을 확인한다.

1. 상대에게 물리/영적 육신과 별도 도주 영혼·원영 단계가 실제로 있는가.
2. 육신을 잃어도 독립 의식·정보를 가진 영혼이 탈출 가능한가.
3. 그 영혼의 퇴로·속도를 감지할 수 있는가.
4. 종결자를 육신 전투에서 보존할 수 있는가.
5. 상대가 법역 전체·분산 개체·재생 신체처럼 단계 구분을 무효화하지 않는가.

조건 1~2가 성립하지 않으면 다른 종료 문법을 찾아야 한다.

# 왜 한 사람에게 전부 맡기지 않는가

원영경식 전투에서는 기능이 다르다.

- 육신 제압: 화력·법역·구조 파훼.
- 영혼 감지: 이탈 순간·방향 포착.
- 영혼 종결: 빠른 확정 수단 또는 넓고 빠른 봉쇄.

따라서 같은 구조가 성립할 때는 단계별 실패 조건을 다른 수단이 덮는 편이 안정적이다.

# CHARACTER·RELATIONSHIP 연결

주인공 A는 자신이 최종 공격자가 되어야 한다는 공로 욕망보다 **현재 대상의 실제 종료 조건**을 우선한다.

- 비상 능력을 영혼 단계에 남김.
- 다른 상위 동료를 퇴로에 배치.
- 더 적합한 광역 영혼 수단을 관찰·채택.
- 반대로 구조가 달라지면 익숙한 분업을 버림.

검증 관계를 실패 조건에 맞게 쓰는 기존 관계 판단과 연결된다.

# STORY·PROSE 연결

150~180화에는 육신 붕괴 뒤 짧은 추가 턴을 두어 독자의 승리 판정을 늦춘다.

육신 붕괴
→ 아직 끝 아님
→ 영혼 도주
→ 종결자
→ 완전 소멸.

213~224화에는 바로 이 익숙한 독자 기대를 깨며:

- 코어가 없음
- 별도 육신/영혼 단계가 없음
- 더 높은 경지의 신체 구조가 다름

을 보여 준다.

작품이 스스로 만든 전투 문법을 이후 경지의 반례로 수정한다.

# 비용과 실패 조건

- 도주 방향 오판 시 사전 배치 무효.
- 영혼 분열 시 단일 공격 부족 가능.
- 종결자를 빼 두면 육신 전투 화력 감소.
- 영혼이 미끼/분신이면 잘못된 대상 위험.
- 법역 전체 분산 구조에서는 육신 단계 자체가 없음.
- 더 높은 경지에서는 영적 신체/정신 구조가 원영경과 달라질 수 있음.

# 반례와 경계

- 낮은 경지에 항상 필요하지 않음.
- 영혼 도주 수단 없는 상대에는 과잉 배치.
- 213~220화: 분산 존재 때문에 단계 구분 실패.
- 221~224화: 경지 상승으로 이원적 몸/원영 기본 구조가 바뀜.
- 더 높은 상계/법칙 존재의 실제 종료 조건은 아직 `HOLD`.

# 상태 판정

150~180화의 여러 독립 전투에서 자기 종결·동료 사전 배치·법역 학습 뒤 종결·광역 종결이라는 변형이 충분히 반복되어 `VERIFIED_THREAD`는 유지한다.

다만 181~224화의 명확한 반례 때문에 적용 범위를 **원영경식 육신/도주 영혼 이원 구조 중심**으로 좁힌다.

`모든 상위 경지에 적용되는 보편 전투 공식`은 `CONTRADICTED`.
