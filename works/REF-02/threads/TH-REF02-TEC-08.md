# 표면 전투 형상을 죽음과 동일시하지 않고 현재 경지·종족의 실제 실존 앵커를 찾아 종결한다

## whole-work 재구성

이 TH는 처음에는 원영경 전투의:

`육신 제압 → 도주 원영/영혼 종결`

패턴으로 생성됐다.

181~284화의 반례를 왕복하면 육신/영혼이라는 구체 형식은 상위 경지에서 계속 깨진다.

그러나 더 높은 공통 메커니즘은 유지된다.

> **지금 눈앞에서 싸우는 형상이 실제 존재의 마지막 앵커인지 확인하고, 표면 승리와 비가역 종료를 분리한다.**

따라서 TH를 특정 경지의 `2단 전투`에서 **경지별 실존 앵커 판정**으로 상향 재구성한다.

## 상위 작동 사슬

현재 적의 표면 전투 형상 확인
→ 그 형상이 파괴되면 의식·정보·재생 가능성이 어디에 남는지 탐색
→ 경지/종족/법역에 따라 실제 실존 앵커 정의
→ 표면 전투를 앵커 노출·약화 단계와 분리
→ 필요하면 동료·비상 능력·내부 침투·광역 종결을 앵커에 배치
→ 앵커 제거/소멸을 확인한 뒤에만 완전 종료로 판정.

## 변형 1 · 원영경식 육신/도주 영혼 — DIRECT

150~180화 여러 독립 전투.

육신을 쓰러뜨려도:

- 원영이 이탈하거나
- 영혼이 여러 갈래로 분열하거나
- 다른 방향으로 도주

할 수 있다.

그래서:

육신 제압
→ 도주 영혼/원영 감지
→ 비상 능력 또는 사전 배치 동료가 종결

로 역할을 나눈다.

이 구간에서 `육신/영혼 2단`은 강하게 반복되므로 하위 패턴 자체도 유효하다.

## 변형 2 · 분산 법역 존재 — DIRECT / COUNTEREXAMPLE

213~220화.

적은 별도 육신·코어 하나에 존재하지 않고 법역 전체의 미세 단위에 자신을 분산한다.

기존:

육신 찾기
→ 코어 찾기
→ 영혼 퇴로 대기

가 장시간 실패한다.

새 판정:

> 법역 전체가 곧 현재 실제 대상.

주인공 A는 재사용 시간이 돌아올 때까지 동료와 함께 시간을 버틴 뒤 **분산 전체를 하나의 실제 존재로 지정해 종결**한다.

`모든 상위 적은 육신/영혼 두 단계다`는 하위 공식이 무너진다.

## 변형 3 · 더 높은 영적 신체 — DIRECT

221~224화.

경지가 올라가면 영적 신체·정신 구조가 달라져 에너지가 남는 한 신체가 재생될 수 있다.

원영경식:

`몸 파괴 → 원영 탈출`

이 기본 죽음 문법이 아니다.

이 장면은 TH 폐기 근거가 아니라 **앵커 판정 층을 한 단계 더 높여야 하는 근거**가 된다.

## 변형 4 · 외부 활동체와 내부 진체 — DIRECT

261~266화.

대승급 존재는 외부에서 활동하는 거대한 형상과 내부의 `진정한 본체/진체`를 분리할 수 있다.

주인공 A는 외부 거체를 공격해 죽음으로 착각하지 않는다.

일부러 내부로 들어감
→ 실제 진체 탐색
→ 진체와 직접 마주침
→ 목격 조건 차단
→ 비상 능력으로 진체 종결.

원문도 이 경지에서 비상 능력을 쓰려면 실제 진체와 마주해야 한다는 조건을 명시한다.

## 변형 5 · 인간형과 뿌리/세계 구조 — DIRECT

279~284화.

최종 적 A의 인간형 육체가 소멸해도 사건은 끝나지 않는다.

인간형 격파
→ 공간/대지의 뿌리 구조 잔존
→ 실제 존재가 살아 있음을 재판정
→ 다른 상위자 흡수
→ 세계수/파괴수 형태로 변형.

따라서 최종부의 앵커는 인간형 몸이 아니라 **뿌리·세계 구조 전체**로 이동한다.

주인공 A는 최종 형상과 과거 정체성을 연결할 행동 조건을 다시 만들어 비상 능력을 사용한다.

source boundary는 그 사용 순간에 끝나므로 실제 완전 제거 결과는 `HOLD`다.

# 관계·캐릭터와의 연결

## 공로보다 종료 조건

주인공 A는 자기가 모든 단계를 직접 처리해야 한다는 공로 욕망보다 실제 죽음 조건을 우선한다.

- 육신과 영혼을 다른 동료에게 분업.
- 광역 영혼 공격이 더 적합하면 동료에게 종결 맡김.
- 법역 전체가 대상이면 기존 분업 버림.
- 진체가 내부에 있으면 내부 침투.

## 관계 욕망도 앵커 접속 수단이 될 수 있음

최종 세계 파괴수는 인간형을 잃었어도 오래된 독점 정보 욕망에 반응한다.

주인공 A는 그 욕망을 이용해 시선·대상 정체성 연결을 만든다.

`MAC-REF02-0008`은 관계 정보가 최종 앵커 접속 조건이 되는 변형을 보존한다.

# STORY·PROSE 효과

이 TH는 독자의 `이겼다` 판정을 계속 늦춘다.

원영경:
육신 붕괴
→ 아직 끝 아님
→ 영혼 도주.

분산 존재:
코어를 못 찾음
→ 코어가 없었음.

대승경:
거대한 외부 몸
→ 실제 진체는 내부.

최종부:
인간형 소멸
→ 뿌리/세계 구조가 살아 있음.

작품은 같은 반전을 반복하는 대신 **경지가 올라갈수록 존재의 정의 자체를 바꿔 승리 조건을 재학습시킨다.**

# 성공 조건

- 현재 경지/종족의 존재 구조를 관찰할 수 있음.
- 표면 패배 뒤 정보·재생·도주가 어디로 이동하는지 확인.
- 앵커에 접근할 감지·침투·광역·비상 수단.
- 앵커를 종결하기 전 전리품 정산/방심을 미룸.
- 동료 역할을 경지별 실패 조건에 맞게 재배치.

# 실패·비용

- 이전 경지의 죽음 문법을 그대로 적용하면 잘못된 승리 판정 가능.
- 코어가 있다고 가정하면 무코어 존재에 시간을 낭비.
- 영혼 종결자를 미리 빼 두면 현재 전투 화력이 줄어듦.
- 내부 진체 접근은 적 몸 안으로 들어가야 해 위험.
- 앵커가 세계 구조 전체라면 국소 공격이 무의미할 수 있음.
- target/gaze 조건을 만들기 위해 상대 욕망을 건드리면 관계적 위험 증가.

# 하위 공식의 상태

- `원영경식 육신 → 영혼 종결`: `VERIFIED_SUBPATTERN`.
- `모든 상위 경지 = 육신/영혼 2단`: `CONTRADICTED`.
- `표면 전투 형상 격파 = 비가역 죽음`: 반복 반례로 `CONTRADICTED`.
- `경지별 실제 실존 앵커를 확인해야 한다`: 초·중·후반 분리 사례로 `SUPPORTED / VERIFIED_THREAD`.
