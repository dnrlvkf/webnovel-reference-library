# 상위 적 전투를 육신 제압과 도주 영혼 종결의 두 단계로 분리한다

## 해결하는 문제

상위 경지 적을 육체적으로 쓰러뜨린 순간 전투가 끝난다고 처리하면, 영혼·원영 도주·자폭·부활·정보 유출 같은 후속 위험이 사라진다.

또 모든 단계를 한 사람이 완벽히 처리해야 한다면 동료 배치와 전투 전 퇴로 설계의 의미가 약해진다.

## 작동 사슬

상위 적의 육신/법역/주 전투 수단 분석
→ 육신 제압 역할과 영혼 종결 역할을 분리
→ 상대가 패배 뒤 어떤 형태·방향·속도로 도주할지 예상
→ 필요하면 퇴로에 다른 동료·광역 수단·비상 능력을 사전 배치
→ 육신 제압
→ 영혼/원영 이탈 확인
→ 종결 역할 즉시 발동
→ 영혼 소멸 확인
→ 그 뒤 전리품·정보·관계 정산

## 반복·변형

### 150~156화 · 주인공 A가 두 단계를 연속 담당

상위 복수 대상 A의 전함·육신 전투를 일반 수단으로 이긴다. 상대 영혼은 하나로 머물지 않고 여러 갈래로 분열해 도주한다.

주인공 A는 이때 비상 능력을 사용한다.

기능은 `육신 전투를 이기는 필살기`가 아니라 **이미 패한 적이 영혼으로 빠져나가는 것을 비가역적으로 닫는 종결 수단**이다.

### 165~169화 · 육신 담당과 영혼 담당을 다른 동료로 분리

상위 동행자 A가 적 상위자의 육신을 제압할 수 있지만, 주인공 A는 그 승리만으로 끝내지 않는다.

사전에 다른 상위 동료를 도주 가능 경로에 배치한다.

육신 패배
→ 원영 이탈
→ 대기 중인 종결자 공격
→ 완전 제거

로 역할을 분업한다.

### 170~177화 · 법역 연습 뒤 비상 능력을 영혼 단계에만 사용

주인공 A는 원영경에 진입한 뒤 새 법역을 실제 상위 적에게 시험하고 싶어 한다.

즉시 비상 능력을 쓰지 않음
→ 법역·육신 전투를 직접 수행
→ 상대가 패배하고 영혼으로 도주
→ 그때 비상 능력으로 종결

학습 가치와 비가역 종결을 분리한다.

같은 구간의 후속 상위 포식자 전투에서는 숨은 동행자가 퇴로와 영혼 단계 일부를 맡는다.

### 180화 · 넓고 빠른 영혼 공격을 별도 동료가 담당

상층부 첫 포식자는 주인공 A의 새 방어·전투 체계에 육신을 잃는다. 영혼이 이탈하자 다른 상위 동료가 넓고 빠른 공격으로 도주를 닫는다.

주인공 A는 이런 유형의 광역·고속 공격이 영혼 도주 대응에 유리하다고 새 연구 과제로 분류한다.

## 왜 한 사람에게 전부 맡기지 않는가

상위 전투는 단계마다 필요한 기능이 다르다.

- 육신 제압: 화력·법역·구조 파훼
- 영혼 감지: 이탈 순간·방향 포착
- 영혼 종결: 매우 빠른 단일 확정 수단 또는 넓고 빠른 봉쇄 공격

따라서 `가장 강한 한 명`보다 **단계별 실패 조건을 다른 수단이 덮는 편**이 안정적일 수 있다.

## CHARACTER 연결

주인공 A는 자신이 최종 공격자가 되어야 한다는 공로 욕망보다 전투 종료 조건을 우선한다.

- 자기 비상 능력을 종결 단계에 남김
- 다른 상위 동료를 퇴로에 미리 배치
- 동료의 광역 영혼 공격을 관찰해 후속 학습 후보로 저장

검증 관계를 실제 실패 조건에 맞춰 쓰는 `RELATIONSHIP` 판단과 연결된다.

## STORY 연결

이 스레드는 독자의 승리 판정 시점을 늦춘다.

육신 붕괴
→ 아직 끝 아님
→ 영혼 도주
→ 종결자 등장
→ 완전 소멸

반복되면서 상위 적 전투는 육신 승리 뒤에도 긴장이 한 턴 더 남는다.

## PROSE 연결

전투 지문은 육신 파괴 직후 전리품 정산으로 넘어가지 않는다.

- 영혼이 빠져나오는 방향
- 분열 수
- 속도
- 누가 먼저 감지했는지
- 종결 수단의 범위·속도

를 짧은 추가 턴으로 붙인다.

상위 경지의 `죽음`이 한 사건이 아니라 단계적 상태 변화로 표현된다.

## 성공 조건

- 적이 영혼/원영으로 이탈할 수 있다는 사전 지식 또는 현장 감지
- 이탈 순간을 놓치지 않는 감각
- 퇴로를 예측하거나 넓게 덮는 수단
- 종결자가 육신 전투에 소모되지 않고 대기할 수 있음
- 동료 간 역할 신뢰

## 비용과 실패 조건

- 도주 방향이 예상과 다르면 사전 배치가 무효화될 수 있음.
- 적 법역·공간 이동이 영혼 퇴로를 바꾸면 종결자가 닿지 못할 수 있음.
- 종결자를 따로 빼 두면 육신 전투 화력이 줄어듦.
- 영혼이 여러 갈래로 분열하면 단일 공격만으로 부족할 수 있음.
- 영혼 자체가 미끼·분신일 경우 잘못된 대상을 종결할 위험.
- 상계급 존재가 영혼 형태 자체를 다르게 사용하면 현재 분업 구조가 실패할 수 있음.

## 반례와 경계

- 낮은 경지 적에게까지 항상 두 단계 분업이 필요한 것은 아님.
- 영혼 도주 수단이 없는 상대에게는 과잉 배치가 됨.
- 150~180화의 반복은 모두 상위 경지 전투에 집중되어 있음. 더 높은 상계 전투에서 같은 구조가 유지되는지 미확인.
- 아직 도주 영혼을 놓쳐 적이 실제 복귀한 실패 사례는 없음.

## `TH-REF02-CHR-02`와 차이

`TH-REF02-CHR-02`는 비상 단일 능력을 **언제 어떤 표적에 배분하는가**가 핵심이다.

이 스레드는 비상 능력 유무와 별개로 **상위 전투의 종료 조건을 육신/영혼 두 단계로 나누고 각 단계에 다른 역할을 배치하는가**가 핵심이다.

비상 능력이 종결자 중 하나로 들어갈 수 있지만 동일 메커니즘은 아니다.

## 승격 이유

150~156, 165~169, 170~177, 180화의 서로 다른 적·장소·동료 조합에서 반복된다.

- 자기 직접 종결
- 사전 배치 동료 종결
- 법역 학습 뒤 비상 능력 종결
- 광역 고속 동료 종결

이라는 변형이 있으며, 퇴로 오판·분열 영혼·화력 분산이라는 실패 조건도 분명해 `VERIFIED_THREAD`로 판정한다.
