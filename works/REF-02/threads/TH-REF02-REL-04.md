# 소속·보호·직위를 권리 묶음으로 해체해 필요한 기능만 수용하며, 협상 불가능한 강제는 별도 층으로 구분한다

## 기본 사슬

소속·보호·동행·의뢰·직위 제안
→ 명예 언어와 실제 권리·의무 분리
→ 거절권·비밀권·이동권·정보 제출·자원권·지휘권을 따로 계산
→ 비가역 종속은 거부
→ 범위가 한정된 거래/역할은 수용 가능
→ 성과로 접근권·보호·자원·직위 확대
→ 확대된 기능 권한이 전체 삶 소유권으로 번지지 않게 다시 제한
→ 목적 달성 뒤 역할·신원·의무 정산.

## 반복

- 초기 조직 입문: 특혜 뒤의 자원 상납·절대복종·영적 처벌을 확인하고 거부.
- 임대·중개: 안전·정보·일을 비용과 교환하지만 방법·과거 공개권은 주지 않음.
- 임시 집단전: 현장 역할은 수행하지만 사적 복종·영구 지휘권은 거부.
- 가입 없는 비경/신물 접근: 문제 해결 대가로 핵심 자원을 빌리되 조직 전체 소속은 거부.
- 상위 조직 내부 임무: 급여·임무·시설·일시 감시는 수용하지만 실제 신원·탐지법·모든 적 정보는 넘기지 않음.
- 기능 최고 직위: 전투 역할만 받고 운영권·영구 소속은 받지 않음.

## 핵심 판정

> **무엇을 받았는가보다 그 대가로 상대가 어떤 권리를 얻는가를 따로 본다.**

따라서:

조직 자원 사용
≠ 조직 가입
≠ 정보 전부 공개
≠ 영구 복종
≠ 운영권 위임.

## whole-work 경계 · 협상 가능한 권리와 강제의 분리

최종부에는 이 TH의 외부 경계가 명확해진다.

상위 존재 A는 계약을 제안하지 않고 주인공 A의 행동권 자체를 봉쇄한 뒤 승급·임무를 강제한다.

이 상황에서는:

- 거절권 협상 불가.
- 정보 공개 범위 협상 불가.
- 이동권 협상 불가.

주인공 A는 임무가 자기 기존 목표와 겹치는 부분을 이용할 수 있을 뿐, 상대가 강제로 가진 권리를 계약적으로 줄이지 못한다.

따라서 `모든 관계를 권리 분해 협상으로 통제할 수 있다`는 해석은 `CONTRADICTED`.

이 TH가 작동하려면 최소한 **상대가 조건을 선택·거절·교환할 행동 공간을 남겨야 한다.**

## 역방향 반례 · 주인공 A도 타인 권리를 직접 박탈한다

포획 강적 A에게는 이동·정보·행동권을 강제로 빼앗고 자기 승급을 돕게 한다.

최종 실존 위기에는 가까운 동료도 기습 봉인해 전장에서 제외한다.

즉 주인공 A가 자기 권리를 세밀하게 방어한다고 해서 타인에게 항상 같은 계약적 대칭을 적용하지 않는다.

이 문제는 `TH-REF02-CHR-06`에서 자율성 배분 기준으로 별도 추적한다.

## 비용

- 관계마다 권리를 다시 계산해야 해 협상 비용 큼.
- 비밀권을 남기면 상대 위험을 늦게 알 수 있음.
- 내부 역할을 수행하면 행적·정치 관계·공개 프로필이 누적됨.
- 거짓 데이터가 독립 검증과 충돌하면 배신 비용 확대.
- 상대가 압도적 강제력을 행사하면 권리 분해 자체가 불가능할 수 있음.

## whole-work 상태

거래·조직·보호·내부 직위·신체 승급 위임까지 충분한 반복과 변형이 있고, 마지막에는 `협상 가능한 권리`의 외부 경계까지 확인됐다.
