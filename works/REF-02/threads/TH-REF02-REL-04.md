# 종속 제안을 권리·의무로 해체하고 제한된 거래·보호·접근·내부 역할만 수용한다

## 해결하는 문제

강한 조직·고위 인물·실력 있는 동료가 주는 보호와 성장 기회를 거부하면서도 주인공 A가 무조건 고립된 개인으로 남지 않게 하는 문제.

후반에는 문제가 더 복잡해진다.

> 조직 바깥에 있어야만 독립적인가?
> 조직의 내부 임무·급여·안전 공간을 실제로 받으면서도 정보권·이탈권·비밀권을 자기 손에 남길 수 있는가?

121~180화는 이 경계를 직접 시험한다.

## 작동 사슬

소속·보호·동행·의뢰·영입·내부 역할 제안
→ 명예 표현과 실제 권리·의무 분리
→ 거절권·자원권·비밀권·이동권·정보 제출 범위 계산
→ 비가역 종속은 거부
→ 비용·완료 조건·통제 범위가 한정된 거래/내부 역할은 수용 가능
→ 수행 결과로 정보·시설·비경·신물·승급 접근권 확대
→ 업무상 협업·현장 역할·일시 감시 조건은 필요에 따라 수용 또는 역이용
→ 관계 전체를 포괄하는 상하권·정보 전부 공개권은 다시 거부
→ 계약 종료/목적 달성 뒤 역할·신원·의무 정산

## 초기 반복

### 조직 입문

입문 특혜가 자원 상납·절대복종·영적 처벌까지 포함하자 거부한다.

### 임대·중개 거래

안전 공간·정보·일거리·추천을 비용과 결과로 교환하되 방법·과거 공개 의무는 수용하지 않는다.

### 임시 동료와 보호 계약

작전 역할과 제한된 현장 통제는 받아들이지만 사적 복종이나 관계 전체 상하권은 거절한다.

## 61~120화의 확장

### 정보 제공과 사적 배경 공개 분리

필요한 위치·위험 정보는 거래하지만 정보 제공자가 허락하지 않은 사적 배경을 제3자에게 넘기지 않는다.

`정보를 샀다 = 그 사람의 모든 비밀을 소유한다`가 아니다.

### 가입 없이 핵심 비경·신물 접근권 획득

우호 조직의 해결하기 어려운 문제를 처리하고 조직 전체를 자기 전쟁에 끌어들이지 않는 대가로:

- 개인 비밀 수련공간 자유 접근
- 향후 신물 사용권
- 비밀 유지와 은인 분류

를 얻는다.

`조직 가입 거부 = 조직 자원 거부`는 `CONTRADICTED`.

### 상대의 `전쟁하지 말라`는 의사도 관계 권리

관계 상대는 자기 보호 욕망보다 주인공 A가 원하지 않는 대규모 전쟁을 일으키지 않는 선택을 한다.

관계 권리가 `나를 도와 달라`뿐 아니라 **내가 원하지 않는 비용을 대신 만들지 말라**까지 확장된다.

### 장거리 협업과 이동 자유 병존

동업자 A와 주인공 A는 같은 목적지에 남지 않아도 미래 협업을 약속하고 각자 이동한다. 장기 관계가 상시 동행·감시·보고 의무가 아님을 확인한다.

## 121~149화 · 조직 내부 역할을 실제로 수용한다

가짜 신분 B는 상위 조직 A의:

- 내부 시험
- 임무
- 보수
- 안전 공간
- 상위 후계자 A와의 팀 편성

을 실제로 받아들인다.

그러나 조직이 얻는 권리는 제한된다.

### 조직이 얻는 권리

- 임무 목표 제시
- 결과·증거 확인
- 조직 시설 내 일정한 질서·감시
- 보수와 후속 의뢰 제공

### 조직이 얻지 못하는 권리

- 실제 신원 전체
- 실제 탐지법의 원리
- 모든 적 정보의 자동 제출
- 숨은 법기·대표 전투 수단의 전체 공개
- 영구 소속
- 가짜 신분 B의 사적 관계·장기 목표 통제

주인공 A는 적 잠입자를 찾아도 탐지법을 제출하지 않고, 현장 정보를 일부 소각해 상위 조직 A가 더 넓은 적 계획을 즉시 알지 못하게 한다.

**내부 임무 수용과 정보 충성은 분리된다.**

## 내부 감시를 `권리 승인`이 아니라 `통제 가능한 조건`으로 처리

상위 조직 A가 보호 공간에 감시 수단을 붙였다고 해서 주인공 A가 이를 관계 전체의 정당한 감시권으로 인정한 것은 아니다.

주인공 A는:

감시 존재 예상
→ 직접 충돌하지 않음
→ 감시자가 볼 수련 데이터를 설계
→ 실제 핵심 수련은 다른 공간에서 수행
→ 조직은 자기 검증이 성공했다고 판단

으로 대응한다.

즉 `감시를 당했다 = 감시권을 인정했다`가 아니다.

일시 감시 조건을 **역이용 가능한 거래 비용**으로 취급한다.

## 공개 프로필과 조직 역할

가짜 신분 B는 조직 내부에서 화염 수사라는 일관된 역할을 유지한다. 이 역할은 보수·신뢰·임무 접근을 주지만 실제 능력 전체를 조직에 소유시키지 않는다.

역할 수행
→ 접근권 상승
→ 공개 프로필이 조직/적 모두에게 축적
→ 맞춤 카운터·추적 비용 상승
→ 목적 달성 뒤 신분 폐기

로 이어진다.

내부 역할도 수명이 있는 계약 자원이다.

## 150~180화 · 강한 개인에게도 같은 권리 원리 적용

### 상위 동행자 A

주인공 A보다 훨씬 강하지만 복수 목적이 안정적일 때:

- 제한 동행
- 공동 공격
- 전리품/보상 분배

를 수용한다.

상위자가 강하다는 이유로 지휘·신원 공개·영구 동행권을 주지 않는다.

### 장기 동업자 A

상위 승급에서 더 큰 권한을 맡긴다.

- 신체 조정
- 수련법 제공
- 자원 투입 판단
- 승급 보조

그러나 이 권한 확대도 비밀 전부 공개권으로 자동 전환되지 않는다.

승급 뒤 주인공 A가 상대 비밀을 더 볼 수 있게 돼도 즉시 질문하지 않고, 자기 비밀에도 같은 권리를 요구한다.

**권한 확대와 정보 소유권 확대는 별개다.**

## 상태 변화

주인공 A의 독립성은:

`조직 도움 거부`
→ `제한 거래`
→ `가입 없는 조직 핵심 자원 접근`
→ `가짜 신분으로 조직 내부 역할 수행`
→ `내부 감시·검증 데이터까지 자기 공개 범위 안에서 관리`
→ `개인 관계에서는 신체·승급 책임을 크게 위임하되 비밀권 유지`

로 확장된다.

현재 가장 정확한 문장은:

> 어떤 자원·역할·도움을 받는가보다, **그 대가로 상대가 자기 삶·정보·신체·미래에 어떤 권리를 얻는지 따로 설계한다.**

## 비용

- 조직 정식 구성원의 자동 보호·승급 자원은 없음.
- 관계마다 접근권·비밀권을 다시 협상해야 함.
- 비밀을 존중하면 상대 위험을 늦게 알 수 있음.
- 조직 핵심 자원을 빌리면 향후 호의·문제 해결 기대가 커질 수 있음.
- 내부 역할은 공개 프로필·행적·정치 관계를 누적함.
- 거짓 텔레메트리나 선택적 정보 제출이 다른 검증과 충돌하면 배신 비용이 커질 수 있음.
- 상위 승급에서 상대에게 신체 권한을 주면 상대 오판이 생명 비용으로 직결될 수 있음.
- 장거리 독립 이동은 관계 유지와 즉시 지원을 어렵게 함.

## 반례와 경계

- `조직 가입 거부 = 조직 자원 거부`: `CONTRADICTED`.
- `조직 내부 역할 수용 = 정보 충성·영구 종속`: 121~149화로 `CONTRADICTED` 해석.
- `감시를 받음 = 상대의 무제한 감시권 인정`: 거짓 텔레메트리 대응으로 `CONTRADICTED` 해석.
- 접근권이 깊어졌다고 조직 지휘권이 주인공 A에게 생기는 것은 아님.
- 은인·동업자 분류가 영구적 무상 지원을 뜻하지 않음.
- 신체 승급 권한을 맡겼다고 비밀 전부 공개권이 생기는 것은 아님.

## 현재 상태 유지 이유

조직 입문, 임대·중개, 임시 집단전, 보호 계약, 개인 비경 접근, 장거리 동업, 상위 조직 내부 역할, 강한 개인과의 동행 계약, 신체 승급 권한 위임까지 서로 다른 관계 유형에서 같은 `권리 범위 분해` 원리가 반복된다.

후반으로 갈수록 접근권과 맡기는 책임은 더 커지지만 포괄적 상하권·정보 소유권은 별도로 남는다.

`VERIFIED_THREAD` 유지.
