# 소속·보호·내부 직위를 권리 묶음으로 해체하고 필요한 기능만 수용한다

## 해결하는 문제

강한 조직·고위 인물이 주는 보호·자원·직위가 곧 삶 전체의 종속으로 이어지지 않으면서도 주인공 A가 무조건 고립되지 않게 하는 문제.

1~240화에서 독립성은:

> 조직 밖에 있는 상태

이 아니라

> **받는 자원·직위·보호마다 상대에게 넘기는 권리를 따로 정하는 능력**

으로 변한다.

## 기본 작동 사슬

소속·보호·동행·의뢰·직위 제안
→ 명예 표현과 실제 권리/의무 분리
→ 거절권·이동권·비밀권·정보 제출·신체권·지휘권 계산
→ 비가역 포괄 종속 거부
→ 비용·기간·역할·감시 범위가 한정된 거래/직위는 수용 가능
→ 결과로 정보·시설·비경·신물·승급 자원 접근 확대
→ 맡긴 권한이 다른 권리까지 자동 확장되는지 재점검
→ 목적 종료 뒤 신분·역할·의무 정산.

# 1. 초기 반복

## 조직 입문

특혜가 자원 상납·절대복종·영적 처벌을 요구하자 거부.

## 임대·중개

안전 공간·정보·일거리를 비용과 결과로 교환하되 방법·과거 공개는 별도 권리로 남김.

## 임시 동료·보호 계약

작전 역할과 제한 현장 통제는 수용하지만 사적 복종·관계 전체 상하권은 거부.

# 2. 61~120화 · 소속 없는 깊은 접근권

우호 조직의 내부 문제를 해결하고 조직 전체를 자기 전쟁에 끌어들이지 않는 대가로:

- 비밀 수련공간
- 신물 사용권
- 비밀 유지

를 얻는다.

`조직 가입 거부 = 조직 자원 거부`는 `CONTRADICTED`.

장기 관계에서도 이동 자유와 미래 협업이 함께 유지된다.

# 3. 121~149화 · 내부 역할과 정보 충성 분리

가짜 신분 B는 상위 조직의:

- 내부 시험
- 임무
- 보수
- 안전 공간
- 팀 편성

을 실제로 수용한다.

그러나 조직이 얻는 권리는 제한된다.

### 조직이 얻는 권리

- 임무 목표 제시.
- 결과/증거 확인.
- 시설 내 일정 질서와 관찰.
- 보수·후속 의뢰 제공.

### 조직이 얻지 못하는 권리

- 실제 신원 전체.
- 실제 탐지법 원리.
- 모든 적 정보 자동 제출.
- 숨은 전투 수단 전체 공개.
- 영구 소속.
- 사적 관계·장기 목표 통제.

**내부 역할 수행 ≠ 정보 충성 ≠ 삶 전체 종속.**

## 감시는 권리 승인과 다르다

조직이 보호 공간에 감시 수단을 두어도 주인공 A는 이를 무제한 정당한 감시권으로 인정하지 않는다.

감시 존재 예상
→ 감시자가 볼 데이터를 설계
→ 핵심 수련은 다른 공간
→ 검증자는 일관된 가짜 데이터만 확인.

`감시를 받음 = 감시권을 인정함`도 `CONTRADICTED` 하위 해석.

# 4. 150~180화 · 강한 개인과 신체 승급 권한

위험한 상위 동행자는 복수라는 안정 동기와 제한 계약이 맞으면 동행·공격·전리품 분배 관계로 수용한다. 강하다는 이유로 지휘·신원 공개·영구 동행권을 주지 않는다.

반대로 장기 동업자 A에게는 상위 승급 때:

- 신체 조정
- 수련법 제공
- 자원 투입 판단

같은 큰 권한을 맡긴다.

그러나 신체 성장 권한이 비밀 전부 공개권으로 전환되지는 않는다.

`권한 확대 = 다른 모든 권리 확대`는 아니다.

# 5. 207~212화 · 최고 무력 직위도 기능만 떼어 받을 수 있다

상층 조직 A는 주인공 A가 자기 이익을 숨기지 않는 점을 오히려 예측 가능한 동기로 평가한다.

그 결과 매우 높은 전투 직위를 제안/부여하지만 권리는 기능적으로 잘린다.

주인공 A가 받는 것:

- 동급 최고 전투자 수준의 전투 지위.
- 조직 자원 지원.
- 외부 위협 대응에서의 높은 전투 자율성.

주인공 A가 받지 않는 것:

- 조직 운영권.
- 행정 지휘권.
- 종문 전체의 일상 통제권.
- 영구 소속/혈연 의무.

조직이 주인공 A에게 얻지 못하는 것:

- 모든 개인 목적의 통제.
- 실제 비밀 전부.
- 조직 목적과 자기 생존 목표가 갈릴 때 자동 충성.

이 사례는 `높은 직위 = 높은 종속`이라는 단순 위계 공식을 반박한다.

직위는 **전투 기능과 책임만 크게 올리고 행정·생활 권한은 의도적으로 비워 둔 계약**이 될 수 있다.

# 6. 조직 규칙의 반대 사례

같은 구간의 다른 조직은 창시자의 오래된 명령을 현재 목적을 위한 수단이 아니라 절대법으로 취급한다.

그 결과 현재 지도자의:

- 이탈권
- 자기 판단권
- 정신 자율성

까지 침해하려 한다.

두 조직을 나란히 두면 차이가 선명하다.

### 제한 직위 조직

현재 목적
→ 역할 분리
→ 전투 기능만 위임
→ 운영/삶 전체 권리 남김.

### 절대 명령 조직

과거 명령
→ 목적보다 명령 형식 우선
→ 현재 지도자의 선택권까지 덮음.

`조직`이라는 명칭보다 **어떤 권리가 실제로 이전되는가**가 핵심이다.

# 7. 수정된 독립성 정의

초기:

강한 조직에 들어가지 않음.

후반:

- 가입 없이 핵심 자원 사용.
- 가짜 신분으로 내부 임무 수행.
- 감시 데이터를 자기 공개 범위 안에서 관리.
- 강한 개인과 제한 계약.
- 신체 승급 권한은 신뢰 관계에 크게 위임.
- 최고 전투 직위도 운영권 없이 기능적으로 수용.

따라서 현재 정의:

> 독립성은 도움·직위·조직을 거부하는 것이 아니라 **누가 자기 삶·정보·신체·이동·지휘에 어떤 권리를 얻는지 기능별로 분해해 설계하는 능력**이다.

# 비용과 실패 조건

- 정식 구성원의 자동 보호는 없음.
- 관계마다 권리를 다시 협상해야 함.
- 비밀권 때문에 위기 정보를 늦게 알 수 있음.
- 내부 역할은 공개 프로필·정치 관계를 누적함.
- 선택적 정보 제출이 들키면 배신 비용 확대.
- 신체 권한 위임은 상대 오판을 생명 비용으로 연결.
- 최고 전투 직위는 조직 위기 책임을 크게 늘릴 수 있음.
- 기능상 제한 직위도 주변 인물이 포괄 충성으로 오해할 수 있음.

# 반례와 경계

- `가입 거부 = 조직 자원 거부` — `CONTRADICTED`.
- `내부 역할 = 정보 충성/영구 종속` — `CONTRADICTED`.
- `감시 받음 = 무제한 감시권 승인` — `CONTRADICTED`.
- `높은 조직 직위 = 운영권·삶 전체 종속` — 207~212화로 `CONTRADICTED` 하위 해석.
- 신체 승급 권한을 맡김 = 비밀 전부 공개권 — `CONTRADICTED`.
- 제한된 권리 구조가 모든 조직에서 협상 가능한 것은 아님. 절대 명령 조직은 반대 사례.
