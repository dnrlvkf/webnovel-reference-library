# 전체 술식을 이해하지 않고 힘의 결합부·공급 발원점만 손상시킨다

## 해결하는 문제

주인공이 정식 교육을 받지 않은 진법·법역을 만났을 때, 갑자기 전체 이론을 이해하거나 단순 화력으로 완전히 파괴해야만 하는 문제.

## 작동 사슬

전체 이론을 모른다는 사실 인정
→ 현재 목적을 `해제·소유`가 아니라 `통과·지원 차단`으로 축소
→ 영력 감각망으로 힘의 밀집부와 흐름 탐색
→ 구조 전체보다 민감한 결합부 또는 공급 발원점 선택
→ 대상 규모가 버틸 수 있는 수단인지 판정
→ 물리적 법기 또는 응축 술식으로 국소 손상
→ 전체 시스템의 기능 정지 또는 약화
→ 완전 파괴가 아니라 다음 행동의 시간창 확보

## 반복·변형

### 38화 금쇄진

정식 교육을 받은 내문제자들은 진법 구조를 분석하고 해제 열쇠를 만들려 한다. 주인공 A는 영기가 밀집된 틈에 결단경 재료의 자율 법기를 끼워 넣고 결합부를 파괴한다. 목적은 진법 습득이 아니라 흑유곡 진입이다.

### 40화 법역

법역은 결단경보다 높은 힘이 작용해 자율 법기로 파괴할 수 없다. 주인공 A는 지도자에게 흘러가는 영기 방향을 역추적해 발원점을 찾고, 소멸 이치를 응축한 새 술식으로 정교한 구조에 흠집을 낸다. 목적은 법역 소유가 아니라 지도자 지원 차단이다.

## 표현 사슬

### 진법

자물쇠 전체를 이해하지 못함
→ 이음매에 송곳을 끼움
→ 결합부 파괴
→ 문 통과

### 법역

지하 수맥 전체를 이해하지 못함
→ 영기 흐름을 상류로 추적
→ 발원점 발견
→ 톱니바퀴 하나를 손상
→ 지도자 공급 중단

같은 해결 원리를 비유만 확대해 독자가 규모 변형을 추적하게 한다.

## 작동 결과

- 정식 교육 부족이 즉석 만능 이해로 지워지지 않음.
- 주인공 A의 감지·목적 축소·재료 판단이 해결의 핵심이 됨.
- 낮은 규모 장면이 상위 법역 파훼의 사전 규칙 설명이 됨.
- 법역 손상은 자동 복구 전의 시간창만 만들기 때문에 상위 위험이 보존됨.
- 정종 지도자 A와 주인공 A가 각자 전투·구조 파괴 역할을 맡아 협력함.

## 비용과 실패 조건

- 결합부 위치를 감지하지 못하면 사용할 수 없음.
- 대상 규모에 맞지 않는 법기를 밀어 넣으면 법기가 파괴됨.
- 국소 손상은 자동 복구될 수 있음.
- 술식 소유권이나 전체 제어권은 얻지 못함.
- 시간창 안에 후속 공격이 성공하지 않으면 원상 복귀함.

## 반례와 경계

- 두 장면은 같은 토벌 아크의 예고와 회수이므로 작품 전체 반복으로 확정하지 않음.
- 모든 진법·법역에 물리적 결합부나 단일 발원점이 존재하는지 미확인.
- 적이 결합부를 미끼로 만들거나 감각망을 속이는 반례 미확인.
- 국소 손상 때문에 더 위험한 폭주가 발생하는 사례 미확인.

## 상태 판정

38화와 40화에서 원리가 반복·변형됐고 결과도 직접 확인됐으나, 한 연속 아크의 사전 설명과 회수 관계다. 후속 독립 사건의 반복·실패를 확인하기 전까지 `VERIFIED_SCENE`으로 둔다.

## 다음 질문

다른 진법·봉인·법역에서도 목적을 축소하고 결합부만 손상시키는가. 완전 이론을 알아야 하거나 국소 파괴가 역효과를 내는 반례가 등장하는가.
