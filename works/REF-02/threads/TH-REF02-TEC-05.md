# 전체 시스템을 소유·해제하지 않고 결합부·공급·입력 가정·경계만 건드려 현재 목적을 연다

## 해결하는 문제

주인공이 정식 교육을 받지 않은 진법·법역·광역 술식 시스템을 만났을 때, 갑자기 전체 이론을 이해하거나 모든 구성 요소를 하나씩 파괴해야만 하는 문제.

121~180화에는 `항상 숨은 핵심을 찾아 파괴한다`는 공식 자체도 좁혀진다.

현재 목적에 더 싼 우회 수단이 있거나, 시스템이 기대하는 **입력 규칙을 깨는 편이 빠르면** 중추 탐색을 고집하지 않는다.

## 작동 사슬 · 확장형

전체 이론을 모른다는 사실 인정
→ 현재 목적을 `완전 해제·소유·전멸`이 아니라 `통과·지원 차단·기능 약화·재난 방향 변경·경계 진입`으로 축소
→ 현재 가진 정보로 시스템의 취약 구조 판정
→ 다음 중 가장 싼 방식을 선택

- 결합부 손상
- 공급 발원점 손상
- 네트워크 중추 파괴
- 상위 수단으로 직접 우회
- 시스템이 예상하지 못한 동종/이종 입력 주입
- 경계에 통로만 생성

→ 후속 이동·공격·아군 공세의 시간창 확보

핵심은 `코어 파괴`가 아니라 **전체를 해결하지 않고 현재 목적만 만족시키는 최소 구조 개입**이다.

## 반복·변형

### 38화 · 진법 결합부

정식 교육을 받은 내문제자들은 진법 구조를 분석하고 해제 열쇠를 만들려 한다. 주인공 A는 영기가 밀집된 틈에 자율 법기를 끼워 넣고 결합부를 파괴한다.

목적은 진법 습득이 아니라 통과다.

### 40화 · 법역 공급 발원점

법역 전체를 파괴할 수 없으므로 지도자에게 흘러가는 영기 방향을 역추적해 발원점을 손상한다.

목적은 법역 소유가 아니라 적 지도자 지원 차단이다.

### 58~59화 · 광역 독진 중추

수많은 항아리를 하나씩 제거하지 않고 독기 농도·영맥 연결을 따라 위장 중추를 찾아 파괴한다.

하나의 중추가 여러 구성 요소를 동시에 약화시켜 아군 공세 창을 만든다.

### 126화 · 중추 분석을 포기하는 경계

적은 가짜 신분 B의 공개 전력을 분석해 격리 진법을 만든다.

주인공 A는 진법 구조를 다시 분석해 중추를 찾을 수도 있지만, 이미 더 높은 급의 공간 우회 수단을 가지고 있다.

따라서:

`전체 분석을 해낼 수 있는가`
보다
`지금 목적에 가장 싼 방법이 무엇인가`

를 우선해 직접 이탈한다.

이 장면은 `중추를 찾을 수 있으면 반드시 찾아야 한다`는 하위 공식을 반박한다.

### 165~169화 · 대형 풍계 시스템의 입력 가정을 깨뜨린다

지역 전체 풍계 진법이 재난 수준으로 폭주한다.

주인공 A는 핵심을 찾는 데 시간을 쓰지 않고 더 높은 급의 별도 풍계 힘을 시스템 안에 주입한다.

기존 시스템은:

- 자기 내부에서 생긴 풍계 변화만 처리할 것을 전제로 함
- 외부 고급 풍계 신호를 별도 원천으로 안정적으로 분리하지 못함

외부 입력
→ 기존 입력과 교차 반응
→ 제어 판단 혼란
→ 폭주 방향/기능 변경

이 발생한다.

이번 변형은 `부품 파괴`가 아니라 **제어 시스템의 가정 파괴**다.

### 170~177화 · 법역 전체 파괴보다 경계 균열

상위 법역에 외부에서 개입해야 할 때 주인공 A와 동료들은 법역 전체를 소유·해제하려 하지 않는다.

공간 경계를 손상시킬 수 있는 수단
→ 법역 경계에 짧은 균열
→ 외부 인물 진입/이탈

로 목적을 축소한다.

## 표현 사슬

### 초기

전체 자물쇠 해석 불가
→ 이음매 선택
→ 손상
→ 통과

### 공급망

전체 영역 제어 불가
→ 영기 흐름 역추적
→ 발원점 손상
→ 지원 차단

### 네트워크

개별 구성 요소 너무 많음
→ 연결 분포 관찰
→ 중추 파괴
→ 다수 동시 약화

### 입력 시스템

중추 탐색 시간 부족
→ 시스템이 전제한 입력 규칙 추론
→ 예상하지 못한 외부 입력 주입
→ 제어 반응 충돌
→ 재난 방향 변경

### 법역 경계

전체 세계 해제 불필요
→ 경계 일부만 손상
→ 통로 확보

## 캐릭터 판단

주인공 A는 자기 기법을 증명하기 위해 가장 복잡한 해결법을 고르지 않는다.

- 통과만 하면 됨
- 적 지원만 끊으면 됨
- 여러 장치를 약화하기만 하면 됨
- 상위 우회 수단이 있으면 씀
- 제어 입력만 꼬이게 하면 됨
- 법역 안으로 들어가기만 하면 됨

문제 해결의 기준은 `얼마나 완전히 이해했는가`보다 **현재 상태를 다음 선택 가능한 상태로 바꾸는 최소 개입**이다.

## 관계·조직 연결

58화에는 동맹 상위자가 주인공 A에게 `급소를 스스로 판단해 찌를 권한`을 준다.

165~177화에는 주인공 A 혼자 시스템 전체를 책임지지 않고:

- 동료가 육신 전투
- 다른 동료가 영혼 퇴로
- 주인공 A가 진법 입력/법역 경계

처럼 시스템·전투 문제를 역할 분할한다.

## 작동 결과

- 정식 교육 부족이 사라지지 않음.
- 모든 구성 요소를 제거하는 반복 전투를 피함.
- 감지·목적 축소·입력 가정 판단이 핵심이 됨.
- 국소 개입이 다수 아군의 전투 조건을 동시에 개선함.
- `중추 파괴` 자체도 절대 공식이 아니라 비용 대비 선택지로 제한됨.

## 비용과 실패 조건

- 연결 구조·입력 가정을 잘못 읽으면 역효과 가능.
- 거짓 중추·다중 중추가 있으면 오판 가능.
- 외부 입력이 너무 강하면 아군까지 폭주에 휘말릴 수 있음.
- 시스템이 외부 입력을 독립적으로 분리·격리하면 교차 반응이 생기지 않을 수 있음.
- 국소 손상은 자동 복구될 수 있음.
- 법역 균열은 짧은 시간만 유지될 수 있음.
- 구조 개입이 전체 승리를 보장하지 않음.

## 반례와 경계

- 모든 시스템에 단일 중추가 존재한다고 일반화하지 않는다.
- 126화는 중추 분석보다 우회가 싸면 바로 포기한다.
- 165~169화는 코어 없이도 입력 가정을 깨는 방식으로 해결한다.
- 구조적 급소를 찾아도 상위 지휘관 개인 전력 문제는 별개다.
- 입력 교란 때문에 실제 대형 아군 피해가 발생하는 실패는 아직 미확인.

## 상태 판정

38화 진법, 40화 법역, 58~59화 독진에서 독립 반복되어 이미 `VERIFIED_THREAD`로 승격했다.

121~177화에는:

- 구조 분석 자체를 포기하는 비용 경계
- 제어 입력 가정 파괴
- 법역 경계 통로 생성

이 추가돼 스레드가 `코어 찾기 기법`이 아니라 **목적 축소형 시스템 개입 판단**으로 넓어졌다.

`VERIFIED_THREAD` 유지.
