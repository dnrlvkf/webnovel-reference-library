# 전체 시스템을 소유·해제하지 않고 현재 목적에 필요한 최소 구조만 건드리되, 구조가 없거나 도구 해상도가 부족하면 즉시 버린다

## 해결하는 문제

정식 교육을 받지 않은 진법·법역·광역 시스템을 만났을 때 전체 이론을 갑자기 이해하거나 모든 구성 요소를 하나씩 파괴해야만 하는 문제.

기존 스레드는 `중추 파괴`에서 출발했지만 121~240화 반례를 통해 더 정확한 상위 원리는 다음으로 수정됐다.

> **현재 상태를 다음 선택 가능한 상태로 바꾸는 최소 개입을 찾는다. 단, 그 구조가 실제로 존재하지 않거나 자기 감지/도구가 닿지 않으면 익숙한 해법을 고집하지 않는다.**

## 확장형 작동 사슬

전체 이론 부족 인정
→ 현재 목적을 통과·지원 차단·기능 약화·재난 방향 변경·경계 진입 등으로 축소
→ 현재 해상도로 취약 구조가 실제 보이는지 확인
→ 가장 싼 방식 선택:

- 결합부 손상
- 공급 발원점 손상
- 네트워크 중추 파괴
- 상위 수단으로 우회
- 시스템 예상 밖 입력 주입
- 경계에 통로만 생성

→ **단일 중추/경계가 없거나 자기 도구가 구조 층을 감당하지 못하면 해당 전략 폐기**
→ 다른 목적 달성 경로로 전환.

# 반복·변형

## 38화 · 결합부

전체 진법 해석 대신 영기 밀집 틈의 결합부를 손상해 통과.

## 40화 · 공급 발원점

법역 전체 파괴 대신 적 지도자에게 흘러가는 공급을 역추적해 일시 차단.

## 58~59화 · 네트워크 중추

수많은 독 장치를 개별 제거하지 않고 연결 분포를 읽어 위장 중추를 파괴, 여러 구역을 동시에 약화.

## 126화 · 구조 분석보다 우회가 싸면 포기

격리 진법을 분석할 수도 있지만 더 높은 공간 우회 수단이 있어 중추 탐색 자체를 하지 않음.

`찾을 수 있으면 반드시 중추를 찾아야 한다`는 하위 공식 `CONTRADICTED`.

## 165~169화 · 입력 가정 교란

대형 풍계 시스템의 핵심을 찾기보다 더 높은 별도 풍계 입력을 넣어 기존 제어 신호와 충돌시킴.

부품 파괴가 아니라 **시스템이 예상한 입력 규칙을 깨는 방식**.

## 170~177화 · 경계만 손상

법역 전체 소유/해제 대신 공간 경계에 짧은 통로만 만들어 진입·이탈 목적을 달성.

# 213~220화의 강한 반례

## 단일 핵심이 애초에 없다

상위 적 A는 자기 존재를 법역 전체의 미세 단위에 분산한다.

동료가 장시간 코어/본체를 찾지만 실패한다.

이 실패는 감지 부족이 아니라 **단일 코어라는 전제 자체가 틀렸기 때문**이다.

따라서:

`복잡한 시스템에는 결국 결정적 코어가 있다`

는 해석은 `CONTRADICTED`.

주인공 A는 코어 탐색을 포기하고 비상 능력의 재사용 시간을 버틴 뒤 분산 전체 존재를 직접 대상으로 삼는다.

## 더 높은 공간 구조에서 기존 도구가 파손

분산 적 제거 뒤 발생한 상위 공간 균열에 기존 공간 절단 수단을 적용하지만 도구가 부러진다.

이번 실패는:

- 목적 축소를 잘못해서가 아님
- 구조를 전혀 못 봐서만도 아님
- **실행 도구의 층위/내구가 대상 구조에 부족**해서 발생.

즉 최소 구조 개입도 `현재 도구가 실제로 그 구조에 작용 가능한가`를 별도 판정해야 한다.

실패 직후 새 구조 파훼를 즉석 완성하지 않고 관계망의 이동 수단으로 구조되는 점도 중요하다.

# 수정된 판단 기준

1. 현재 목적은 무엇인가.
2. 전체 시스템 이해가 정말 필요한가.
3. 결합부·공급·중추·입력 가정·경계 중 현재 목적에 유효한 구조가 실제 존재하는가.
4. 단일 핵심이 있다는 전제가 근거 있는가.
5. 더 싼 우회가 있는가.
6. 자기 감지 해상도가 구조를 볼 수 있는가.
7. 자기 법기/술식/동료가 그 층위에 실제로 작용 가능한가.
8. 실패했을 때 역폭주·도구 파손·아군 피해가 무엇인가.
9. 국소 개입 뒤 후속 행동을 수행할 시간·동료가 있는가.

# CHARACTER 연결

주인공 A의 장점은 `항상 약점을 찾아낸다`가 아니다.

- 약점이 있으면 최소 개입을 찾고,
- 약점 전제가 틀리면 버리며,
- 자기 도구가 안 먹히면 실패를 인정하고 다른 관계/수단으로 전환한다.

213~220화는 이 스레드를 만능 구조 해석 능력으로 만드는 것을 막는 핵심 반례다.

# 관계·조직 연결

구조 개입은 개인 천재성으로만 해결되지 않는다.

- 58화: 조직이 급소 판단 권한을 위임.
- 165~177화: 육신 전투·영혼 퇴로·진법 입력·법역 경계를 여러 동료가 역할 분할.
- 213~220화: 코어 탐색 실패 뒤 동료들이 24시간을 버는 동안 주인공 A가 다른 종료법을 준비.
- 공간 도구 파손 뒤 관계 인프라가 실제 탈출을 완성.

# 비용과 실패 조건

- 거짓 중추·다중 중추·무코어 구조.
- 입력 가정을 잘못 읽으면 역효과.
- 외부 입력이 아군까지 위험하게 만들 수 있음.
- 시스템이 외부 입력을 분리하면 교란 실패.
- 국소 손상 자동 복구.
- 법역 균열의 짧은 유지 시간.
- 대상 구조가 자기 감지 해상도보다 높으면 구조 자체를 못 읽음.
- 대상 구조를 읽어도 실행 도구가 약하면 도구가 파손됨.
- 최소 개입이 전체 승리를 보장하지 않음.

# 반례와 경계

- 모든 시스템에 단일 중추가 있다는 일반화 금지.
- 126화: 중추 분석보다 우회가 싸면 분석 포기.
- 165~169화: 코어 파괴 없이 입력 가정 교란.
- 213~220화: 단일 코어가 실제로 없음.
- 213~220화: 기존 공간 도구가 상위 균열에서 파손.
- `최소 개입이면 항상 성공한다` 역시 성립하지 않음.

# 상태 판정

38~59화의 독립 반복으로 `VERIFIED_THREAD`가 되었고, 121~240화에는 우회·입력 교란·경계 균열·무코어·도구 파손까지 성공과 실패가 모두 추가됐다.

상위 메커니즘은 유지하되 `중추 찾기`라는 좁은 공식은 명시적으로 폐기한다.

`VERIFIED_THREAD` 유지.
