# 전체 술식을 이해하지 않고 힘의 결합부·공급 발원점·중추만 손상시킨다

## 해결하는 문제

주인공이 정식 교육을 받지 않은 진법·법역·광역 술식 시스템을 만났을 때, 갑자기 전체 이론을 이해하거나 모든 구성 요소를 하나씩 파괴해야만 하는 문제.

## 작동 사슬

전체 이론을 모른다는 사실 인정
→ 현재 목적을 `완전 해제·소유·전멸`이 아니라 `통과·지원 차단·기능 약화`로 축소
→ 영력 감각망으로 힘의 밀집부·연결·공급 흐름 탐색
→ 구조 전체보다 민감한 결합부·발원점·중추 선택
→ 대상 규모에 맞는 수단 선택
→ 국소 손상
→ 여러 구성 요소의 기능이 동시에 약화
→ 후속 이동·공격·아군 공세의 시간창 확보

## 반복·변형

### 38화 · 진법 결합부

정식 교육을 받은 내문제자들은 진법 구조를 분석하고 해제 열쇠를 만들려 한다. 주인공 A는 영기가 밀집된 틈에 결단경 재료의 자율 법기를 끼워 넣고 결합부를 파괴한다.

목적은 진법 습득이 아니라 통과다.

### 40화 · 법역 공급 발원점

법역은 결단경보다 높은 힘이 작용해 자율 법기로 파괴할 수 없다. 주인공 A는 지도자에게 흘러가는 영기 방향을 역추적해 발원점을 찾고, 응축한 술식으로 정교한 구조에 흠집을 낸다.

목적은 법역 소유가 아니라 지도자에게 들어가는 지원을 잠시 끊는 것이다.

### 58~59화 · 광역 독진 중추

작량산에는 수많은 독 항아리가 흩어져 있고 각 항아리 주변에 적 수사가 배치되어 있다. 항아리를 하나씩 부수면 독기와 수비대 때문에 손실이 커진다.

주인공 A는 독기 농도의 차이와 항아리 사이 영맥을 탐색한다. 연결을 따라가 평범한 바위로 위장된 중추를 찾은 뒤 뇌술로 파괴한다.

중추 하나가 파괴되자 연결된 여러 항아리의 독기 방출이 동시에 약해진다. 다른 구역에서도 같은 방식으로 중추를 찾아 파괴해 동맹 전체의 공세 창을 만든다.

이번 사례는 38~40화와 다른 조직·다른 전장·다른 시스템에서 발생했다.

## 표현 사슬

### 진법

전체 자물쇠 해석 불가
→ 이음매 선택
→ 물리적 결합부 손상
→ 통과

### 법역

전체 영역 제어 불가
→ 영기 흐름을 상류로 추적
→ 공급 발원점 손상
→ 상위 적 지원 차단

### 독진

수많은 항아리 개별 파괴 비효율
→ 독기 분포와 연결 영맥 관찰
→ 위장 중추 발견
→ 중추 파괴
→ 여러 항아리 동시 약화
→ 아군 공세 확대

같은 원리를 `문`, `공급망`, `전장 네트워크`로 규모와 표면만 바꿔 반복한다.

## 캐릭터 판단

주인공 A는 `모르는 것을 전부 이해해야 한다`고 생각하지 않는다.

먼저 현재 목표를 축소한 뒤 그 목표에 필요한 최소 구조만 찾는다.

- 통과만 하면 됨
- 적 지원만 끊으면 됨
- 독진 전체를 소유할 필요 없이 기능만 약화하면 됨

정식 지식 부족을 만능 즉석 이해로 지우지 않고, 목적 제한과 감지 능력으로 보완한다.

## 관계·조직 연결

58화 동맹 상위자 A는 주인공 A에게 구체적인 공격 위치를 지시하지 않고 `급소를 스스로 판단해 찌를 권한`을 준다.

주인공 A의 구조 파괴 능력이 개인 기법에서 조직 내 역할로 번역된 사례다.

중추 파괴 뒤 동맹 수사들이 즉시 공세를 확대하므로 결과는 개인 승리가 아니라 집단 전장의 권한·위험 분포 변화로 이어진다.

## 작동 결과

- 정식 교육 부족이 사라지지 않음.
- 모든 구성 요소를 제거하는 반복 전투를 피함.
- 주인공 A의 감지·목적 축소·국소 화력 판단이 핵심이 됨.
- 국소 공격이 다수 아군의 전투 조건을 동시에 개선함.
- 이전 아크의 해결법이 다른 규모·조직전에서 재사용되어 장기 판단 기준으로 확인됨.

## 비용과 실패 조건

- 연결 구조를 감지하지 못하면 사용할 수 없음.
- 거짓 중추·다중 중추가 있으면 오판 가능.
- 대상 규모에 맞지 않는 수단이면 공격 도구가 파괴되거나 술식이 무효화될 수 있음.
- 국소 손상은 자동 복구될 수 있음.
- 중추 파괴가 전체 승리를 보장하지 않음. 59화 지상전이 우세해져도 60화 수장전 패배로 전쟁 전체 우위는 뒤집힘.
- 시간창 안에 후속 행동이 성공하지 않으면 효과가 제한됨.

## 반례와 경계

- 모든 진법·법역·전장 술식에 단일 중추가 존재한다고 일반화하지 않는다.
- 58~59화 독진은 중추가 여러 구역으로 나뉘어 있어 한 번의 파괴로 전체 전장이 끝나지 않는다.
- 구조적 급소를 찾아도 상위 지휘관 개인 전력 문제는 별개다.
- 국소 파괴가 폭주나 역류를 만드는 실패 사례는 아직 미확인.

## 상태 판정

38화 진법, 40화 법역은 같은 아크의 예고·회수였기 때문에 `VERIFIED_SCENE`에 머물렀다.

58~59화에는 다른 전쟁·다른 조직·다른 광역 시스템에서 같은 판단 사슬이 독립 반복된다. 또한 중추 파괴가 전체 승리를 보장하지 않는 비용도 60화에서 확인된다.

따라서 `VERIFIED_THREAD`로 승격한다.

## 다음 질문

후속 구간에서 구조적 중추가 둘 이상이거나 미끼일 때 어떻게 판정하는가. 중추 파괴가 역폭주·아군 피해를 만드는 반례가 나타나는가. 주인공 A가 감지하지 못하는 시스템에서는 이 방식을 포기할 수 있는가.
