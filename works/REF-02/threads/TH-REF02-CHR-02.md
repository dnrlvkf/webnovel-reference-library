# 압도적 단일 능력을 비상 자원으로 제한하고 일반 대응 체계를 구축한다

## 해결하는 문제

주인공이 초반부터 확정적이고 압도적인 능력을 가졌을 때 모든 갈등이 같은 버튼으로 끝나며 수련·협업·전술의 필요가 사라지는 문제.

## 작동 사슬

압도 능력 획득
→ 대기 시간·단일 대상·정면 시선·발동 전 행동 공백·노출 한계 확인
→ 상대의 욕망과 위치를 이용해 고립 조건 조립
→ 대체 수단이 없거나 미확인 수단의 위험이 큰 대상에게만 사용
→ 결과를 수련 자질·자원으로 전환
→ 다수전·접근전·공개 전투용 일반 기술 구축
→ 목격자·후속 위협·대체 수단이 있을 때 사용 보류
→ 일반 기술·방어 장비·단약·협업·기만으로 승리 조건 조립
→ 비상 능력은 다음 고립 상황까지 보존

## 반복·변형

- 초기 초월 위협: 대체 수단이 없고 고립된 상황에서 사용
- 초기 포식 관계 종료: 상대의 살해 의도와 고립 조건이 확정된 뒤 사용
- 다수전과 일반 무인전: 법술·거리 조절을 시험하며 사용 보류
- 도시 추살과 반복 임무: 새 공법과 기존 법술로 해결해 공개 임무 수행 가능성을 확보
- 집단 습격: 목격자와 미확인 위험이 있어 상위 적에게도 사용하지 않고 협업·기만·무기 탈취를 선택
- 21화 상위 적: 특수 자질을 의도적으로 노출해 생포 욕망을 강화하고, 공격 중단·근접·정면 시선을 만든 뒤 사용
- 22화 비경 요괴: 새 공격 기술과 방어 장비로 해결해 일반 대응 체계를 확장
- 25화 변화 경비자: 본질 경지는 파악했지만 미확인 특기가 남아 있어 정보 공개 전에 사용
- 30화 마도 하위 수사: 단약·검술·방어 장비·새 뇌법으로 제거하며 사용 보류

## 사용 판정 기준

비상 능력 사용은 상대 경지가 높다는 이유만으로 결정되지 않는다.

1. 즉시 치명성
2. 대체 수단의 존재
3. 상대 미확인 수단의 위험
4. 외부 목격과 추적 가능성
5. 정면 시선과 발동 공백 확보
6. 사용 뒤 더 큰 위협의 존재

21화는 1·2·5가 강하고 외부 노출을 통제했다. 25화는 미확인 수단의 위험이 커 신속 제거를 택했다. 22·30화는 일반 대응 수단이 충분해 보류했다.

## 상태 변화

비상 능력은 ‘주인공이 항상 이기는 이유’가 아니라 **일반 성장·관계·전술을 실험할 시간을 보장하는 최후 안전망**으로 재분류된다. 일반 기술이 성장할수록 사용 빈도는 줄지만, 고위험 선택을 가능하게 하는 심리적·전략적 기반은 커진다.

21화는 이 능력이 무조건 선행하는 힘이 아니라는 점을 확인한다. 상대가 위험 직감 직후 즉시 공격했다면 주인공 A가 먼저 죽었을 가능성이 높다. 성공은 능력 자체보다 상대의 생포 욕망과 주인공 A의 위치 설계에 의존했다.

## 비용

- 일반 기술 구축에 수련 시간과 자본이 필요함
- 공개 전투에서 부상과 실패 가능성을 감수함
- 능력을 숨기는 동안 상대에게 정보 우위를 일부 허용함
- 발동 전 행동 공백에서 선공당할 수 있음
- 비상 능력이 있다는 확신이 위험 허용치를 과도하게 높일 가능성
- 사용 뒤 공백·횟수·상위 감지 여부가 아직 확인되지 않음

## 반례와 경계

- 발동 직전 실제 선공을 받아 실패한 반례는 아직 없음
- 능력 보류가 실제 패배나 동료 사망을 초래한 반례는 아직 없음
- 다수 동료 중 한 명만 살릴 수 있는 상황의 대상 우선순위 미확인
- 사용 뒤 공백 동안 더 큰 위협이 이어지는 장기 비용 미확인
- 비상 능력 사용 자체가 상위 존재에게 감지되는지 미확인
- 변신 경비자에게 사용한 판정이 과잉 대응이었는지 비교 사례 부족

## 현재 상태 유지 이유

초기 생존·관계 종료·다수전·도시 임무·집단전·21화 상위 적·25화 변화 경비자라는 떨어진 구간에서 반복과 변형이 확인되었다. 성공 조건과 실패 가능성, 일반 기술 구축 비용도 확인되어 `VERIFIED_THREAD`를 유지한다.

## 다음 질문

31~40화의 상위 마도 적 결전에서 비상 능력이 필요한가. 사용한다면 발동 조건·사용 뒤 공백·후속 추적이 어떻게 나타나는가.
