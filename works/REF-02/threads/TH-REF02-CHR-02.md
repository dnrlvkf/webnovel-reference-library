# 압도적 단일 능력을 제한 자원으로 배분하고 대상 정체성·자기/상대 행동시간·사용자 행동권까지 계산한다

## 해결하는 문제

초반부터 확정적인 단일 능력이 모든 갈등의 만능 버튼이 되어 수련·전술·장비·관계·위협 순서·경지별 행동시간·대상 구조를 지워 버리는 문제.

1~240화에서 이 능력은 강적 제거 버튼이 아니라 **제약과 목적을 계속 재판정하는 제한 자원**으로 운용된다.

## 기본 작동 사슬

능력 획득
→ 단일 대상·정면 시선·발동 공백·재사용 시간·노출 한계 확인
→ 일반 기술·장비·단약·협업 체계 병렬 구축
→ 현재 적과 후속 위협·회수 자원·목격자를 함께 계산
→ 대체 수단·학습 가치가 충분하면 사용 보류
→ 상대가 발동 공백 안에 개입 가능한지 판정
→ 주인공 A 자신이 그 시간층을 인지·따라갈 수 있는지 판정
→ 대상의 실제 정체성이 단일 신체에 고정되는지 확인
→ 필요하면 욕망·상태 변화·목격자 부재·시간 벌기로 유효 조건 조립
→ 사용자에게 행동권이 실제로 남아 있는지 확인
→ 사용
→ 생존·자원 보존·영혼 종결·시간 확보로 결과 전환.

# 반복·변형

## 초기~60화

- 초기 초월 위협: 대체 수단이 없어 고립 상황에서 사용.
- 초기 포식 관계: 상대 살해 의도와 고립을 확인한 뒤 사용.
- 도시 임무/다수전: 일반 기술·협업을 시험하기 위해 보류.
- 21화 상위 적: 생포 욕망을 이용해 공격 중단·정면 조건을 만든 뒤 사용.
- 31~33화: 24시간 재사용 주기를 비경 폐쇄 시간과 수확 일정에 결합.
- 41~42화: 현재 강적이 아니라 그 뒤의 포식자에게 남겨 둠.

## 61~120화 · 경지명이 아니라 행동시간

- 상위 중기 대상 제거 성공.
- 상위 후기 대상은 평상시 행동시간 우위 때문에 저경지 시점 직접 지정 위험.
- 같은 후기 대상이 스스로 행동 층위를 낮춘 순간 제거 성공.
- 높은 경지라도 공격 동작이 단순·예측 가능하면 사용 가능.
- 상대 자폭 전 자원을 온전히 남기기 위해 사용.

따라서 `상위 후기 이상이면 안 통한다`는 고정 경지 상한은 `CONTRADICTED`.

## 121~180화 · 자기 시간층·영혼 종결

- 목격자 없는 고립 조건에서 상위 적과 영혼까지 제거.
- 육신 전투는 일반 수단으로 이긴 뒤 분열 영혼 도주 단계에만 사용.
- 주인공 A가 원영경에 올라 미세 행동시간을 인지하면서 과거 상대적 시간차 일부가 사라짐.
- 새 법역을 직접 시험할 학습 가치 때문에 즉시 사용하지 않고 최종 영혼 단계에 남겨 둠.

## 213~220화 · 단일 몸이 없어도 실제 대상 전체를 지정

상위 적 A는 몸/법역을 수많은 단위로 분산해 단일 코어가 없다.

동료가 코어를 찾는 전략은 장시간 실패한다.

주인공 A는 재사용 24시간이 돌아올 때까지 시간을 벌고, **분산된 전체 존재가 동일한 실제 대상임을 인식한 상태에서 법역 전체를 하나의 대상으로 지정**한다.

결과적으로 모든 분산 단위가 동시에 소멸한다.

새 경계:

> 대상 지정은 반드시 한 개의 고정된 육체 위치를 요구하는 것이 아니라, 실제 대상 정체성을 올바르게 묶어 인식할 수 있는가와 관련된다.

이는 분신·가짜 본체를 잘못 지정하는 실패와는 다르다. 그 실패는 아직 `HOLD`다.

## 238~240화 · 부분 현현과 사용자 행동권

상위 추적자의 일부 힘/현현은 본체 그 자체가 아니다. 주인공 A는 이를 일반적인 단일 생명 대상처럼 즉시 처리하지 못하고, 더 큰 힘을 경계 밖에 노출시켜 제3자 감시 세력을 작동시키는 다른 해법을 택한다.

그 뒤 다른 상위 존재 A에게 강제 소환된다.

주인공 A는 비상 능력 사용 가능성을 계산하지만, 상대가 **주인공 A의 행동 자체를 완전히 봉쇄**한다.

이때는 대상이 아무리 명확해도 능력을 발동하지 못한다.

새 하드 경계:

> 능력의 위력과 별개로 사용자가 시선·판단·발동 행동을 수행할 최소 행동권을 잃으면 능력은 실전 선택지가 아니다.

# 사용 판정 기준 · 1~240화

1. 즉시 치명성.
2. 일반 기술·도주·협업의 대체 가능성.
3. 상대 미확인 수단.
4. 외부 목격·후속 추적.
5. 정면 시선·대상 지정 조건.
6. 재사용 시간과 사건 제한 시간.
7. 후속 더 큰 위협.
8. 일반 대응 체계를 시험·학습할 가치.
9. 상대가 발동 공백보다 빠르게 행동·인지할 수 있는가.
10. 주인공 A가 그 행동시간을 인지·따라갈 수 있는가.
11. 사용 뒤 온전히 보존해야 할 자원이 있는가.
12. 육신 승리 뒤 영혼/원영의 비가역 종결이 필요한가.
13. 현재 전투를 새 경지·법역의 연습장으로 쓸 가치가 있는가.
14. 대상이 한 신체에 고정되어 있는가, 분산돼 있어도 실제 정체성을 하나로 묶어 지정 가능한가.
15. 대상이 본체인지 부분 현현·대리 힘인지.
16. **사용자에게 최소 시선·판단·발동 행동권이 남아 있는가.**

# 상태 변화

비상 능력의 기능은:

강적 제거
→ 일반 성장 실험의 안전망
→ 연속 위협 사이 제한 자원
→ 자원 상태 보존 수단
→ 육신 승리 뒤 영혼 종결 수단
→ 새 경지 실전 연습 뒤 마지막 실패를 닫는 안전장치
→ 분산된 실제 존재 전체의 종결 수단

으로 확장됐다.

반대로 238~240화에는 능력이 강해도 **사용자 행동권을 잃으면 무력화**된다는 상위 경계가 생긴다.

# 비용과 실패 조건

- 일반 기술·연체·법기·관계망 구축에 대량 자원 필요.
- 사용을 미루는 동안 상대의 추가 행동·제3자 피해를 감수.
- 24시간 재사용이 표적 우선순위와 장기 지연전을 강제.
- 학습/자원 보존 때문에 사용을 늦추다 손실이 생길 유인.
- 분산 대상을 실제 하나로 잘못 묶으면 오판 가능성.
- 부분 현현·대리체가 본체와 어떻게 연결되는지 모르면 대상 판정 자체가 불명확.
- 상위 존재가 사용자 행동을 봉쇄하면 발동 불가.

# 반례와 경계

- `특정 경지 이상에는 절대 안 통한다` — `CONTRADICTED`.
- `단일 고정 육신이 있어야 한다` — 213~220화로 강한 하위 해석 수정.
- `대상이 명확하면 언제나 사용할 수 있다` — 238~240화의 행동 봉쇄로 `CONTRADICTED`.
- 본체 아닌 부분 현현을 제거하면 원본도 제거되는지는 미확인.
- 분신·가짜 본체에 잘못 지정하는 실제 실패는 아직 없음.
- 다수 대상 중 한 명만 살릴 수 있는 우선순위 실패도 미확인.

# 현재 상태 유지 이유

초기 생존·포식 관계·도시 임무·비경 수확·연속 위협·상위 중/후기·자폭 자원 보존·목격자 없는 제거·영혼 종결·원영경 시간층·학습 목적·무코어 분산 존재·상위 행동 봉쇄까지 반복·변형·비용·반례가 누적됐다.
