# 압도적 비상 능력을 만능 버튼이 아니라 대상·행동권·노출·후속 위협을 계산하는 제한 종결 자원으로 배분한다

## whole-work 핵심

비상 능력은 초반부터 매우 강하지만 작품은 그 강함을 전투 전체의 대체재로 쓰지 않는다.

주인공 A는 일반 수련·장비·협업·기술 학습을 계속 구축하고, 비상 능력은 **지금 가장 비가역적으로 닫아야 하는 실패 조건**에 배분한다.

## 사용 판정 사슬

현재 위협 확인
→ 일반 기술·도주·협업으로 해결 가능한지 확인
→ 상대의 미확인 수단과 후속 더 큰 위협 확인
→ 재사용 시간과 사건 제한 시간 계산
→ 실제 대상을 지정할 수 있는지 확인
→ 상대와 자기의 행동시간 비교
→ 목격/추적 비용 확인
→ 온전히 보존해야 할 자원 또는 학습 기회 확인
→ 표면 승리 뒤 실제 실존 앵커 종결이 필요한지 확인
→ 사용자가 능력을 발동할 최소 행동권을 가지고 있는지 확인
→ 조건을 만족하면 사용.

## 반복·변형

### 초기 생존과 포식 관계 종료

대체 수단이 없거나 상대의 살해 의도와 고립 조건이 충분히 확정된 순간 사용한다.

### 일반 전투 체계 구축을 위해 보류

도시 임무·다수전에서는 일반 기술과 협업을 시험한다. 강적이라도 지금 배울 가치와 안전망이 충분하면 즉시 사용하지 않는다.

### 재사용 시간과 사건 시계 결합

비경·분산 적 전투에서는 24시간 재사용 주기를 폐쇄 시각·수확 일정·시간 벌기 전략과 결합한다.

### 자원 보존

상대가 자폭해 성장 자원을 파괴하기 전에 사용하거나, 핵심 법보를 꺼낼 때까지 승리 시점을 늦춘 뒤 사용한다.

### 육신 승리 뒤 실존 앵커 종결

원영경에서는 육신 승리 뒤 도주 영혼/원영을 종결하는 용도로 사용한다.

분산 법역에서는 법역 전체를 실제 대상으로 지정한다.

대승급 존재에게는 외부 거체가 아니라 내부 진체와 직접 마주친 뒤 사용한다.

최종 세계 파괴수에게는 인간형이 없는 상태에서도 오래된 관계 욕망을 이용해 실제 대상·시선 조건을 조립한 뒤 사용한다.

`TH-REF02-TEC-08`과 연결된다.

## 행동시간 상한의 변화

초기에는 상위 적이 대상 지정 공백보다 빠르게 움직일 수 있어 위험하다.

주인공 A의 경지가 오르면서 자기 시간 인지·행동층도 올라가 기존 상한 일부가 사라진다.

따라서 상한은 경지 이름이 아니라:

> 상대가 지정 전에 개입할 수 있는가
> + 주인공 A가 그 개입 시간층을 인지·대응할 수 있는가

의 상대차다.

## whole-work 최종 경계 · 행동권 자체가 없으면 사용 불가 — DIRECT

238~240화의 초월 존재는 주인공 A의 행동권을 직접 봉쇄한다.

주인공 A는 비상 능력을 생각하지만 발동할 수 없다.

즉:

`능력을 보유함`
≠
`대상이 있음`
≠
`사용할 행동권이 있음`.

압도 능력의 가장 강한 외부 경계다.

## 대상 정체성

whole-work에서 대상 지정은 단순 외형 좌표보다 깊어진다.

- 육신/영혼이 분리된 적: 실제 영혼/원영.
- 법역 전체 분산 존재: 분산된 전체 동일 존재.
- 대승급 외부체: 내부 진체.
- 세계 구조와 합쳐진 적: 과거 정체성 잔여와 현재 전체 존재를 연결해야 함.

비상 능력이 강할수록 `무엇을 진짜 대상으로 볼 것인가`가 더 중요해진다.

## 비용

- 발동 전 행동 공백.
- 재사용 시간 때문에 표적 우선순위 강제.
- 사용을 미루는 동안 피해 가능.
- 학습·자원 보존 욕심 때문에 위험을 더 받을 유인.
- 목격자에게 실제 수단 노출 가능.
- 상대가 사용자 행동권을 직접 봉쇄하면 사용 불가.
- 잘못된 본체/분신을 실제로 오지정하는 실패는 source boundary 내 직접 확인되지 않음.

## HOLD / NOT OBSERVED

- `분신/가짜 본체를 잘못 실제 대상으로 지정해 능력을 낭비하는 실패`: `NOT_OBSERVED_WITHIN_SOURCE_BOUNDARY`.
- 284화 사용 뒤 실제 최종 세계 상태: source boundary 밖 `HOLD`.
