# 압도적 단일 능력을 제한 자원으로 배분하고 일반 대응 체계를 구축한다

## 해결하는 문제

초반부터 확정적이고 압도적인 단일 능력이 모든 갈등의 만능 버튼이 되어 수련·전술·장비·관계·위협 순서의 의미를 지우는 문제.

## 작동 사슬

압도 능력 획득
→ 단일 대상·정면 시선·발동 전 공백·재사용 시간·노출 한계 확인
→ 일반 기술·장비·단약·협업 체계 병렬 구축
→ 현재 적뿐 아니라 후속 위협 순서까지 계산
→ 대체 수단이 충분하면 사용 보류
→ 즉시 치명성·미확인 수단·고립 조건이 겹치면 사용
→ 결과를 성장·자원·시간으로 전환
→ 경지 상승 뒤 기존 발동 한계 자체를 다시 재평가

## 반복·변형

- 초기 초월 위협: 대체 수단이 없고 고립된 상황에서 사용.
- 초기 포식 관계 종료: 상대의 살해 의도와 고립 조건이 확정된 뒤 사용.
- 다수전·도시 임무: 일반 기술과 협업을 시험하며 보류.
- 21화 상위 적: 생포 욕망을 이용해 공격 중단·근접·정면 시선을 만든 뒤 사용.
- 25화 변화 경비자: 본질 경지는 알지만 미확인 특기가 남아 신속 제거.
- 30화 하위 적 다수: 단약·검술·방어 장비·뇌법으로 해결하며 보류.
- 31~33화: 24시간 재사용 주기를 비경 폐쇄 시각과 맞춰 보스 수확 일정으로 사용.
- 41화 상위 적 A: 새 술식과 외부 기운으로 제거하고 비상 능력 보류.
- 42화 상위 협력자 A: 41화에서 남겨 둔 비상 능력으로 영력 고갈 뒤의 다음 포식자를 제거.

## 사용 판정 기준

1. 즉시 치명성
2. 대체 수단의 존재
3. 상대 미확인 수단의 위험
4. 외부 목격·추적 가능성
5. 정면 시선과 발동 공백 확보
6. 재사용 시간과 사건 제한 시간
7. **사용 뒤 이어질 더 큰 위협의 존재**
8. 일반 대응 체계를 시험할 가치

41~42화는 7번을 직접 검증한다. 현재의 강적에게 쓰면 이길 수 있어도 다음 포식자 앞에서 영력 고갈 상태가 될 것을 예상해 남겨 둔다.

## 경지 상승 뒤 재판정 — HYPOTHESIS

49화 축기 후 주인공 A는 정신 활동 속도가 빨라진 경험을 근거로, 더 높은 경지 존재에게는 자신이 대상을 지정하는 짧은 순간도 충분한 대응 시간이 될 수 있다고 추론한다.

- 현재 확인: 축기경에서 체감·판단 속도가 달라짐 — `DIRECT`
- 상위 존재에게 비상 능력 발동 전 대응 시간이 생김 — `HYPOTHESIS`
- 실제 실패 사례 — 미확인

기존 능력이 경지 상승과 함께 무조건 강해지는 것이 아니라, 오히려 상위 전투에서 작동 한계를 새로 보게 만드는 정보 효과다.

## 상태 변화

비상 능력은 `주인공이 항상 이기는 이유`가 아니라 **일반 성장·전술을 실험할 시간을 보장하고 연속 위협 사이에 배분하는 최후 안전망**으로 재분류된다.

일반 대응 수단이 늘수록 사용 빈도는 줄고, 사용 시점의 선택 중요도는 커진다.

## 비용

- 일반 기술 구축에 시간·자본 필요
- 공개 전투에서 부상·영력 고갈 위험 감수
- 숨기는 동안 상대에게 정보 우위 일부 허용
- 발동 전 행동 공백에서 선공당할 수 있음
- 재사용 시간 때문에 표적 우선순위를 강제당함
- 최후 수단이 있다는 확신이 과도한 위험 수용을 부를 가능성

## 반례와 경계

- 발동 직전 실제 선공으로 실패한 반례 없음.
- 능력 보류 때문에 실제 동료 사망·패배가 발생한 반례 없음.
- 다수 대상 중 누구를 살릴지 선택해야 하는 상황 미확인.
- 원영경 후기 이상에게 실제로 통하지 않는지 미확인.
- 사용 자체가 상위 존재에게 감지되는지 미확인.

## 현재 상태 유지 이유

초기 생존, 관계 종료, 다수전, 도시 임무, 비경 수확, 41~42화의 연속 위협까지 떨어진 구간에서 반복·변형과 비용이 확인되었다. `VERIFIED_THREAD`를 유지한다.

## 다음 질문

51~60화에서 새 경지의 일반 수단이 비상 능력의 사용 빈도를 더 낮추는가. 더 높은 경지 상대가 발동 공백을 실제로 이용하는 반례가 나타나는가.
