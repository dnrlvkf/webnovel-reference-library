# 검증된 동료를 직접 선택하고 서로의 실패 조건을 역할·자원으로 보완한다

## 해결하는 문제

주인공 A의 독립성이 `누구와도 깊게 협업하지 않고 모든 전투를 혼자 해결한다`는 고정 공식으로 변하는 문제.

## 작동 사슬

우연한 공동 임무
→ 서로 다른 역할과 성향 실전 검증
→ 계약 종료 뒤 관계 유지 가능성 보존
→ 후속 위험에서 불특정 인원과의 강제 협업 거부
→ 검증된 동료를 직접 선택
→ 각자 다른 실패 조건을 맡는 역할 분담
→ 실제 전투에서 서로의 맹점 보완
→ 보복·후속 위험에서 구조 행동
→ 후속 재회에서 다시 직접 선택
→ 임무 보수 외 장비·비급·이동 인프라 투자
→ 관계를 다음 전투의 준비된 자산으로 유지

## 18~19화 · 첫 실전 검증

임시 동료들의 구속·화력과 주인공 A의 기만·무기 탈취·즉석 기술 해석이 결합돼 상위 적을 상대한다. 초기 위계가 결과 뒤 동등한 동료 호칭으로 바뀐다.

## 55~57화 · 직접 선택과 실제 맹점 보완

주인공 A는 불특정 산수 집단과 함께 움직이는 것을 거부하지만 혼자 싸우겠다고 하지 않는다. 과거 실전에서 검증한 동료 A·B를 직접 부른다.

56화에는 주인공 A가 핵심 적을 압도한 뒤에도 최후 독포자 확산에 즉시 대응하기 어렵고, 동료 B의 광역 화력이 그 실패 조건을 제거한다.

57화에는 적 보복으로 동료 A·B가 죽음 직전까지 가고 주인공 A가 실제 구조 행동을 수행한다. 동료들은 주인공 A가 없는 자리에서 더 깊은 관계를 원한다고 말하지만 그 욕망은 아직 당사자에게 전달되지 않는다.

## 101~104화 · 관계를 다시 선택하고 계약 외 투자를 한다

시간이 지나 동료 A·B는 독립적으로 제작·수련 기반을 키웠다. 주인공 A는 다음 고위험 작전에서 다시 두 사람을 직접 고른다.

이번 변형에서는 단순 역할 분담을 넘어:

- 이동·거점 접근 경로를 연결함
- 위험한 역할의 명시 보수를 지급함
- 임무 보수와 별도로 비급·법기를 추가 제공함
- 추가 제공이 두 사람의 장기 성장과 향후 협력 능력을 높인다는 전략적 이유도 인정함

즉 관계 자원이 `전투 때 도움을 받는다`에서 **상대의 미래 역량에 미리 투자한다**로 확장된다.

## 생명 단위 도움 의향의 경계

101~104화에서 동료 A·B는 주인공 A의 일이라면 목숨을 걸 수 있다는 취지의 의향을 직접 말한다.

현재 판정:

- 동료 A·B의 발언/의향: `DIRECT`
- 주인공 A가 동일한 무제한 의무를 약속함: 미확인
- 상호 생명 단위 보호 계약 성립: `HOLD`

주인공 A는 추가 자원과 위험 보상을 제공하지만, 자기 핵심 생존 자원을 포기하겠다고 약속하지 않는다.

## 관계 권리 변화

### 초기

- 함께 싸울 권리: 우연한 계약 배치
- 정보 공개: 최소
- 지시권: 임무 구조에 따라 제한
- 보호 기대: 계약 범위

### 55~60화

- 주인공 A가 직접 동료 선택
- 역할 합의와 반복 작전
- 성장 비밀을 강제로 캐묻지 않을 권리
- 서로의 즉시 위험을 제거하는 보호 행동

### 101~110화

- 장기 공백 뒤에도 직접 재선택 가능
- 이동/거점 네트워크 연결
- 고위험 역할의 추가 보상 요구·지급권
- 임무 밖 성장 자원 투자
- 동료가 독립 사업·기술 소유권을 유지함
- 주인공 A가 원하지 않는 전쟁 비용을 관계 상대가 존중하는 외부 사례와 병렬됨

## 캐릭터 판단 연결

주인공 A가 선호하는 동료는 단순히 친한 사람이 아니다.

- 자기와 다른 기술 축
- 비밀을 강제로 캐묻지 않음
- 역할을 실제로 수행함
- 위험 순간 행동으로 보완함
- 장기 공백 뒤에도 자기 성장 기반을 유지함

따라서 관계 선택 기준은 `친밀감`보다 **실전 역할 + 정보 경계 + 자율성 + 반복 신뢰**다.

## 표현 구현

57화는 주인공 부재 POV로 동료들의 더 깊은 관계 욕망을 독자에게만 공개한다.

101~104화에는 감정 확인 대화보다:

재회
→ 위험 임무 제안
→ 역할 배분
→ 추가 보상
→ 장비·비급 제공
→ 실제 합동전

으로 관계가 유지됐음을 증명한다.

작가는 `오랜 친구`라고 요약하지 않고 **다시 자원을 걸고 같이 움직이는 행동**으로 관계를 갱신한다.

## 비용과 실패 조건

- 팀 활동 때문에 동료가 주인공 A의 적에게 보복 표적이 될 수 있음.
- 동료에게 고급 자원을 투자하면 주인공 A의 현재 자원량이 줄어듦.
- 동료의 목숨 단위 의향이 실제로 실행되면 주인공 A가 원하지 않는 희생이 발생할 수 있음.
- 장거리 이동·상위 조직 침투로 물리적 거리가 늘어나 관계 유지 비용이 커짐.
- 역할이 겹치거나 더 깊은 비밀 공유가 필요한 경우 현재 경계가 바뀔 수 있음.

## 반례와 적용 한계

- 불특정 산수 집단과의 협업 거부가 모든 집단전 거부는 아님.
- 구조 한 번으로 친구·의형제 관계가 자동 성립하지 않음.
- 동료 A·B의 강한 의향이 상호 맹세를 뜻하지 않음.
- 주인공 A가 두 사람을 위해 비상 능력·결단 자원 같은 핵심 생존 자원을 실제 포기한 사례는 아직 없음.

## 상태 판정

18~19화, 55~57화, 101~104화라는 떨어진 시기에서 `검증 → 직접 선택 → 역할 보완 → 구조 → 재선택 → 장기 투자`가 반복·확장된다. 실제 맹점 보완과 보복 비용도 확인되어 `VERIFIED_THREAD`를 유지한다.

## 다음 질문
