# 검증된 동료를 직접 선택하고 서로의 실패 조건을 역할로 보완한다

## 해결하는 문제

주인공 A의 독립성이 `누구와도 깊게 협업하지 않고 모든 전투를 혼자 해결한다`는 고정 공식으로 변하는 문제.

## 작동 사슬

우연한 공동 임무
→ 서로 다른 역할과 성향 실전 검증
→ 계약 종료 뒤 관계 유지 가능성 보존
→ 후속 위험에서 불특정 인원과의 강제 협업 거부
→ 검증된 동료를 직접 선택
→ 각자 다른 실패 조건을 맡는 역할 분담
→ 주인공 A의 해결 불가능 지점을 동료가 실제로 보완
→ 적의 보복으로 동료가 위기에 빠짐
→ 주인공 A가 실제 구조 행동 수행
→ 동료 측에 더 깊은 관계 욕망 발생
→ 관계 권리는 아직 후속 검증 대기

## 반복·변형

### 18~19화 · 첫 실전 검증

주인공 A는 임시 동료들과 집단전에 들어간다. 동료의 구속·화력과 주인공 A의 기만·무기 탈취·즉석 기술 해석이 결합돼 상위 적을 상대한다.

초기에는 위계와 신참 취급이 있었지만 결과 뒤 동등한 동료 호칭으로 재분류된다.

### 55화 · 동료를 직접 고른다

동맹 조직 A가 제공하는 산수들과 함께 움직이는 것을 거부한다. 그러나 혼자 싸우겠다고 하지 않는다.

과거 실전에서 능력과 성향을 확인한 동료 A·B를 직접 부른다.

독립성의 기준이 `단독`이 아니라 **관계를 선택할 권리**라는 점이 드러난다.

### 56화 · 동료가 실제 실패 조건을 제거한다

주인공 A는 결단경 책임자를 압도하지만, 거의 죽은 적이 독성 포자를 광역 확산시키는 최후 수단을 쓴다.

미세 포자가 지하 공간 전체에 퍼지면 주인공 A도 즉시 대처하기 어렵다. 동료 B의 광역 화염이 포자를 태워 위험을 제거한다.

주인공 A도 혼자였다면 위험했음을 인정한다.

이 장면은 동료가 단순 화력 보조가 아니라 **주인공의 실제 맹점을 막는 기능**을 가졌음을 직접 증명한다.

### 57화 · 동료 측 관계 욕망과 주인공의 구조

동료 A·B는 주인공 A가 없는 자리에서 현재 관계가 아직 서로 복수할 정도로 깊지 않다고 인정한다. 동시에 앞으로는 그런 사이가 되고 싶었다고 말한다.

적의 보복 습격으로 두 사람이 죽음 직전까지 갔을 때, 주인공 A가 약속 장소의 소란을 확인하고 빠른 경로로 접근해 두 사람을 구조한다.

관계의 감정 설명과 실제 보호 행동이 같은 회차에서 서로 검증된다.

## 관계 권리 변화

### 초기

- 함께 싸울 권리: 우연한 계약 배치에 의존
- 정보 공개: 최소
- 지시권: 임무 구조에 따라 제한
- 보호 기대: 계약 범위

### 55~60화

- 주인공 A가 직접 동료를 선택함
- 세 사람이 역할을 합의해 반복 작전을 수행함
- 성장 비밀을 캐묻지 않을 권리/침묵권을 존중함
- 서로의 즉시 위험을 제거하는 보호 행동이 발생함
- 동료 A·B는 더 깊은 관계를 원하지만 상호 복수 의무는 아직 미성립

## 캐릭터 판단 연결

주인공 A는 사람 수가 많다고 안전하다고 보지 않는다. 검증되지 않은 용병은 지휘 충돌·허세·정보 노출 때문에 위험할 수 있다.

반대로 검증된 동료는:

- 자기와 다른 기술 축을 가짐
- 자신의 비밀을 강제로 캐묻지 않음
- 약속한 역할을 수행함
- 위험 순간 실제 행동으로 보완함

따라서 관계 선택 기준은 친밀감 하나가 아니라 `실전 역할 + 정보 경계 + 계약 신뢰`다.

## 표현 구현

57화는 관계의 깊이를 주인공 A의 내면 독백으로 선언하지 않는다.

주인공 부재의 동료 POV
→ 현재 거리를 인정
→ 더 가까워지고 싶은 욕망
→ 실제 죽음 위기
→ 주인공의 실용적 구조 지시
→ 구조 성공

으로 배치한다.

독자는 동료들의 욕망을 알지만 주인공 A는 모른다. 관계 상태를 즉시 확정하지 않고 후속 전달·행동을 기다리게 한다.

## 비용과 실패 조건

- 팀으로 활동하면 동료가 주인공 A 때문에 보복 표적이 될 수 있음.
- 주인공 A의 높은 생존 평판이 동료들에게 과도한 안전감을 줄 수 있음.
- 역할이 겹치거나 정보 공개가 더 필요해질 경우 현재 협업 경계가 무너질 수 있음.
- 주인공 A가 동료를 살리기 위해 더 큰 개인 비용을 감수하는 사례는 아직 없음.

## 반례와 적용 한계

- 불특정 산수 집단과의 협업 거부가 `모든 집단전 거부`는 아님.
- 한 번 구조했다고 친구·의형제 관계가 자동 성립하는 것은 아님.
- 동료 A·B의 복수 의향은 현재 욕망이지 공식 약속이 아님.
- 주인공 A가 관계 욕망을 알게 된 뒤 부담을 느끼거나 거리를 두는 반례 가능성 미확인.

## 상태 판정

18~19화 첫 협업과 55~57화의 직접 선택·상호 보완·상호 구조가 떨어진 구간에서 반복·변형된다. 동료가 주인공 A의 실제 실패 조건을 제거하는 성공과, 팀 활동 때문에 보복 표적이 되는 비용도 확인된다.

따라서 `VERIFIED_THREAD`로 판정한다.

## 다음 질문

61~70화에서 동료 A·B가 주인공 A의 더 높은 위험 선택을 제지하거나 보완하는가. 주인공 A가 두 사람을 위해 자기 생존·성장 자원을 실제로 포기하는가. 57화 관계 욕망이 당사자 간 언어·권리로 전환되는가.
