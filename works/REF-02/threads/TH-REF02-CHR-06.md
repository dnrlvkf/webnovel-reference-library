# 상대의 현재 선택·이력·강제성·관계 기반을 구분하고 제거·계약·구출의 허용 범위를 구성한다

## 해결하는 문제

주인공 A의 적 처리 기준을 `항상 상대 선공을 기다린다`, `탐욕스러우면 죽인다`, `적 조직에 있으면 적이다` 같은 하나의 도덕 공식으로 평탄화하면 실제 판단 변형이 사라진다.

1~240화의 상위 원리는:

> 상대가 무엇을 **스스로 선택했는지**, 무엇을 **강제로 당하고 있는지**, 과거 이력과 현재 행동이 어떻게 연결되는지, 관계/신뢰 기반이 실제로 있는지를 확인하고 제거·계약·구출 중 어떤 행동이 허용되는지 스스로 구성한다.

이다.

# 1. 초기 기본 사슬 · 12~60화

상대 탐욕·생포·살해 욕망 감지
→ 즉시 치명적 선공하지 않음
→ 상대가 자기 욕망을 행동으로 확정할 조건 유지/강화
→ 상대가 포식·살해 선택
→ 준비된 반격
→ 위협 제거·자원 회수
→ 주인공 A가 결과 원인을 상대 선택에 연결.

54~55화에는 모욕/언어 갈등과 실제 살해 시도를 분리해 체면 갈등만으로 제거하지 않는 경계가 생긴다.

# 2. 61~120화 · 현재 선공·과거 이력·갈등 조립

## 현재 선공 없이 제거

반복 포식 이력·조직 역할·주변 피해가 충분한 약탈자는 현재 장면에서 먼저 치명 공격을 완성하지 않아도 제거한다.

`현재 선공 필수`는 `CONTRADICTED`.

## 성장 자원 때문에 갈등 경로를 선택

주인공 A는 필요한 성장 자원을 가진 적 조직이 직접 움직이게 만들기 위해 분쟁 확대 경로를 의도적으로 선택한다.

상대 욕망은 방어 대상이 아니라 사건 조건이 되기도 한다.

## 과거 적대자도 현재 선택 재확인

과거 지식상 다른 관계 가능성이 있는 적에게 현재 선택을 한 번 더 제시한다. 상대가 현재 충성을 스스로 고르자 그 선택을 우선해 적으로 재분류한다.

`과거 적대 이력 = 즉시 제거`도 `CONTRADICTED`.

# 3. 121~180화 · 강제 상태와 관계 이용 비용

## 적 조직 내부 강제 상태 분리

적 거점에 있어도 조종/강제 복종 가능성이 높은 일반인과 실제 적대 술자를 구분한다.

판정 요소:

- 현재 행동이 자발적인가.
- 강제 술식/위계 때문에 움직이는가.
- 적대 결정을 내릴 정보·선택권이 있었는가.

`적 조직 공간에 있음 = 제거 대상`은 `CONTRADICTED`.

## 비공개 정보로 공개 적대 증거 만들기

잠입자를 이미 알아도 실제 탐지법은 공개하지 않는다. 공개 규칙을 던져 상대가 회피·도주하게 하고, 그 행동을 제3자가 볼 수 있는 적대 증거로 전환한다.

## 관계 상대 이용 비용

상위 후계자 A의 추적 욕망을 자기 이탈의 주의 분산으로 사용한다. 상대에게 추적·정치 위험이 남으므로 `타인 비용을 줄인다`와 `타인을 전략 자원으로 쓰지 않는다`는 별개다.

## 위험한 강자와 제한 계약

복수라는 안정된 동기가 있고 현재 목표·보상 범위가 맞으면 자기보다 훨씬 강한 상대도 제거/도주 대신 제한 계약한다.

# 4. 189~194화 · 정확한 미래 지식도 관계 기반 없이는 사람을 바꾸지 못한다

과거 지식상 다른 선택이 가능한 적에게 주인공 A가 다른 미래를 제시한다.

그러나 현재에는:

- 공동 경험 부족
- 신뢰 축적 부족
- 관계 권리 부족

이 있어 설득이 실패한다.

새 경계:

> 상대에게 다른 선택 가능성을 **안다**는 것과, 상대가 그 말을 신뢰할 관계 기반을 **가진다**는 것은 다르다.

이 사례는 105~107화의 `현재 선택 재확인`과 반대 조건을 보여 준다. 한쪽은 현재 선택 확인이 의미 있었지만, 이번에는 관계 기반이 없어 말이 선택을 바꾸지 못한다.

# 5. 231~237화 · 강제 적대 관계자를 제거하지 않고 지배 연결을 끊는다

상위 존재의 지배로 옛 관계자 A가 적대 행동을 한다.

주인공 A는 행동 표면만 보고 적으로 확정하지 않는다.

강제 지배 확인
→ 직접 살해 보류
→ 신뢰할 수 있는 별도 동료의 격리 공간 사용
→ 외부 지배 연결 차단
→ 관계자 생존.

121~126화의 `강제 상태 일반인 분리`가 **자기 관계망의 강한 적대 행동**에서도 반복된다.

따라서:

> 강제된 행동이 치명적이어도 자발 적대와 동일 책임을 자동 부여하지 않는다.

가 `SUPPORTED`로 올라간다.

# 6. 수정된 작동 사슬 · 1~240화

상대 현재 행동·과거 이력·조직 역할·욕망 확인
→ 행동의 자발성/강제성 판정
→ 현재 선택을 바꿀 여지가 있고 관계 기반이 충분한지 확인
→ 관계 기반이 없으면 설득 효과를 과대평가하지 않음
→ 반복 포식 구조가 충분하면 현재 선공만 기다리지 않을 수 있음
→ 성장/생존 목적상 필요하면 상대 성향이 작동할 조건을 능동 조립할 수 있음
→ 비공개 정보는 상대 반응으로 공개 증거화할 수 있음
→ 안정 동기와 제한 권리가 있으면 위험한 상대와 계약 가능
→ 강제 상태면 제거보다 지배 연결 차단/구출 가능성 검토
→ 자발 적대 범위가 충분히 확인되면 제거/반격
→ 자원·정보·안전 회수
→ 사후 책임과 제3자·관계 비용을 분리 추적.

# 7. 사실 판정과 자기합리화

- 실제 선공·포식 행동: 장면별 `DIRECT`.
- 반복 포식 이력·조직 역할: `DIRECT`/`SUPPORTED`.
- 강제 상태/자발 적대 분리 행동: `DIRECT`.
- 갈등 조건 의도적 조립: `DIRECT`.
- 관계 상대 욕망을 주의 분산에 이용: `DIRECT`.
- 관계 기반 없는 설득 실패: `DIRECT`.
- 강제된 옛 관계자를 살해하지 않고 연결을 끊음: `DIRECT`.
- `상대가 먼저 현재 장면에서 공격해야만 제거`: `CONTRADICTED`.
- `적 조직 구성원은 모두 제거 대상`: `CONTRADICTED`.
- `강제로 공격하면 자발 적대와 같은 책임`: `CONTRADICTED` 하위 해석.
- `다른 미래를 알면 정확한 한마디로 상대를 바꿀 수 있음`: `CONTRADICTED`.
- 이후 모든 제거가 객관적으로 도덕 정당하다는 해석: 여전히 `HYPOTHESIS`.

# 8. 비용과 실패 조건

- 상대 성향을 잘못 읽으면 불필요한 적 생성.
- 갈등을 키우면 제3자·우호 조직에 보복 비용.
- 관계 상대를 이용하면 추적·정치 비용이 상대에게 남음.
- 과거 이력만으로 현재 변화 가능성을 닫으면 오판.
- 강제 상태를 자발 적대로 오독하면 무고한 피해.
- 반대로 강제 상태라고 잘못 판단하면 실제 적을 놓칠 수 있음.
- 현재 선택을 확인하는 동안 상대가 먼저 행동할 수 있음.
- 관계 기반 없는 설득에 시간을 쓰면 전투 위험 증가.
- 안정 동기로 본 계약 상대가 다른 목표를 숨기면 보증 비용 확대.

# 9. 반례와 적용 한계

- 54~55화: 모욕만으로 제거하지 않음.
- 66~72화: 현재 선공 없어도 포식 이력으로 제거.
- 105~107화: 적대 소속이어도 현재 선택 재확인.
- 121~126화: 적 거점의 강제 상태 일반인 분리.
- 150~156화: 위험 강자와 안정 동기 계약.
- 189~194화: 관계 기반 없는 미래 설득 실패.
- 231~237화: 치명적 강제 행동을 하는 옛 관계자를 제거하지 않고 지배 연결 차단.

# 10. 상태 판정

12~240화의 여러 적대 유형에서 `적대 근거·강제성·관계 기반 확인 → 허용 범위 설정 → 제거/계약/구출`이 반복되고, 초기 하위 공식들이 후속 반례로 계속 좁혀졌다.

상위 판단 사슬은 오히려 더 선명해졌으므로 `VERIFIED_THREAD` 유지.
