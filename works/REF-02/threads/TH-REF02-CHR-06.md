# 상대의 적대 선택·이력을 확인하고 필요하면 그 조건을 조립해 제거 범위를 정한다

## 해결하는 문제

주인공 A의 반복 제거 행동을 `항상 상대가 먼저 때린 뒤 정당방위한다` 또는 `탐욕스러운 자는 곧바로 죽인다`라는 한 문장으로 평탄화하면, 실제로는 무엇을 적대 근거로 인정하고 언제까지 현재 선택을 확인하며 언제 갈등 조건을 능동적으로 조립하는지가 사라진다.

## 1~60화에서 확인된 기본 사슬

상대의 탐욕·독점·생포·살해 욕망 감지
→ 즉시 치명적 선공으로 넘어가지 않음
→ 상대가 자기 욕망에 따라 행동할 조건을 유지하거나 강화
→ 상대가 포식·살해 선택을 행동으로 확정
→ 준비된 반격
→ 위협 제거와 필요 자원 회수
→ 주인공 A가 결과 원인을 상대 선택에 귀속

12화, 20~21화, 42화, 50화에서 이 사슬이 반복되었다.

54~55화에는 `언어적 도발/모욕`과 `실제 살해 시도`를 분리해, 기분 나쁨이나 돈·체면 분쟁만으로 치명적 제거하지 않는 경계가 추가되었다.

## 61~120화에서의 수정

### 66~72화 · 현재 선공이 없는 적도 제거할 수 있다

상층부 이동 중 만난 일부 약탈 집단은 현재 장면에서 주인공 A에게 먼저 치명적 공격을 완성하기 전에 제거된다. 판단 근거는 단일 표정이나 기분이 아니라 반복 포식 이력·현재 역할·주변 피해와 같은 누적 정보다.

이 사례는 `현재 장면에서 반드시 상대가 먼저 치명적 공격해야 한다`는 강한 하위 명제를 무너뜨린다.

### 90~94화 · 갈등 자체를 성장 자원 경로로 선택한다

주인공 A는 다음 결단 자원을 가진 상위 적대 조직 A가 직접 움직이게 만들기 위해 분쟁을 회피하지 않는다. 상대의 성향과 조직 반응을 알고 **갈등이 커질 경로를 의도적으로 선택**한다.

이제 상대 욕망은 단순 방어 대상이 아니라 미래 자원 획득 조건을 조립하는 재료가 된다.

### 105~107화 · 과거 이력보다 현재 선택을 다시 확인하는 변형

상위 관찰자 B는 적 조직 소속이고 실제로 주인공 A를 추적하지만, 주인공 A는 과거 지식 때문에 한 번 다른 선택 가능성을 제시한다.

상대가 현재 관계와 충성을 스스로 다시 선택
→ 적대 행동으로 그 선택을 확정
→ 주인공 A가 과거 기억의 기대를 버리고 현재 적으로 재분류
→ 제거

이 장면은 `과거 적대 이력이 있으면 항상 즉시 제거`도 아님을 보여 준다.

## 수정된 작동 사슬

상대의 현재 행동·과거 이력·조직 역할·욕망을 확인
→ 치명적 적대가 아직 불명확하면 현재 선택을 더 관찰하거나 질문
→ 이미 반복 포식 구조가 충분히 확인됐으면 현재 선공만을 기다리지 않을 수 있음
→ 필요한 성장·생존 목표가 있으면 상대 성향이 작동할 조건을 능동적으로 조립할 수 있음
→ 적대 범위가 충분히 확인되면 제거/반격
→ 자원·정보·안전을 회수
→ 사후 책임을 상대의 선택/이력과 연결해 해석

## 자기합리화와 사실 판정

현재 구분은 다음과 같다.

- 상대의 실제 선공·포식 행동: `DIRECT`
- 상대의 반복 포식 이력·조직 역할: 장면별 `DIRECT` 또는 `SUPPORTED`
- 주인공 A가 갈등 조건을 의도적으로 조립한 사실: `DIRECT`
- `상대가 먼저 현재 장면에서 공격해야만 제거한다`: `CONTRADICTED`
- `과거 이력만 있으면 누구든 즉시 제거한다`: `CONTRADICTED`
- `그러므로 이후 모든 죽음과 자원 회수 책임은 상대에게 있다`: 주인공 A의 자기설명은 `DIRECT`, 객관적 도덕 정당성은 `HYPOTHESIS`

## 캐릭터 판단

핵심은 정당방위 형식을 기계적으로 지키는 것이 아니다.

주인공 A는:

1. 누가 실제 포식자/적대자인지 근거를 모으고,
2. 현재 선택이 달라질 여지가 있으면 확인하며,
3. 위험과 성장 가치가 충분하면 상대 성향이 드러날 조건을 먼저 만들고,
4. 자기 기준상 제거 가능한 범위가 성립했다고 판단할 때 행동한다.

따라서 `선공하지 않는 선인`도 `이득이면 아무나 죽이는 약탈자`도 아닌 **허용 범위를 스스로 구성하는 인물**로 보는 편이 정확하다.

## 표현 구현

- 상대 욕망을 상대 POV·행동·과거 기록 중 하나로 먼저 충분히 보여 준다.
- 주인공 A가 조건을 능동적으로 만들었을 때는 그 계획을 일부 늦게 공개해 피해자/유인자 경계를 남긴다.
- 105~107화에는 상대 내면을 먼저 열어 현재 충성 선택을 독자에게도 증명한 뒤 주인공 A의 과거 기억과 충돌시킨다.
- 사후 자기평가는 짧게 끝내고 객관적 도덕 해설을 별도로 붙이지 않는다.

## 비용과 실패 조건

- 상대 성향을 잘못 읽으면 불필요한 적을 만들 수 있음.
- 의도적으로 갈등을 키우면 제3자와 우호 조직이 보복 비용을 받을 수 있음.
- 과거 포식 이력만으로 현재 변화 가능성을 닫으면 오판할 위험이 있음.
- 현재 선택을 더 확인하다가 상대가 먼저 행동하면 즉시 위험해질 수 있음.
- 성장 자원 때문에 갈등을 조립하는 행위가 누적되면 자기 정당화와 선제 약탈의 경계가 흐려질 수 있음.

## 반례와 적용 한계

- 54~55화: 모욕/언어 갈등만으로 제거하지 않음.
- 66~72화: 현재 선공이 없어도 충분한 포식 이력으로 제거 가능.
- 105~107화: 적대 소속이어도 과거 정보 때문에 현재 선택을 한 번 확인함.

이 세 변형 때문에 스레드를 `현재 선공 대기` 하나로 설명할 수 없다.

## 상태 판정

초기부터 107화까지 서로 다른 적대 유형에서 `적대 근거 확인 → 허용 범위 설정 → 필요하면 조건 조립 → 제거/회수`가 반복된다. 동시에 `현재 선공 필수` 하위 명제가 후속 반례로 무너져 스레드 자체는 유지하되 적용 범위를 좁혔다.
