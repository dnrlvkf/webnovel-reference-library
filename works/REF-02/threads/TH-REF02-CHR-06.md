# 상대의 적대 선택·이력·강제 상태를 구분하고 필요하면 조건을 조립해 제거 범위를 정한다

## 해결하는 문제

주인공 A의 반복 제거 행동을 `항상 상대가 먼저 때린 뒤 정당방위한다` 또는 `탐욕스러운 자는 곧바로 죽인다`라는 한 문장으로 평탄화하면, 실제로는 무엇을 적대 근거로 인정하고 언제까지 현재 선택을 확인하며 언제 갈등 조건을 능동적으로 조립하는지가 사라진다.

121~180화에는 `적대 조직 안에 있다`와 `자발적으로 적대 행위를 선택했다`를 분리하는 기준이 추가된다.

## 1~60화에서 확인된 기본 사슬

상대의 탐욕·독점·생포·살해 욕망 감지
→ 즉시 치명적 선공으로 넘어가지 않음
→ 상대가 자기 욕망에 따라 행동할 조건 유지/강화
→ 상대가 포식·살해 선택을 행동으로 확정
→ 준비된 반격
→ 위협 제거와 필요 자원 회수
→ 주인공 A가 결과 원인을 상대 선택에 귀속

12화, 20~21화, 42화, 50화에서 반복된다.

54~55화에는 `언어적 도발/모욕`과 `실제 살해 시도`를 분리해, 기분 나쁨이나 돈·체면 분쟁만으로 치명적 제거하지 않는 경계가 추가된다.

## 61~120화에서의 수정

### 66~72화 · 현재 선공이 없는 적도 제거할 수 있다

일부 약탈 집단은 현재 장면에서 먼저 치명적 공격을 완성하기 전에 제거된다. 근거는 단일 표정이나 기분이 아니라 반복 포식 이력·현재 역할·주변 피해 같은 누적 정보다.

`현재 장면에서 반드시 상대가 먼저 치명적 공격해야 한다`는 강한 하위 명제가 무너진다.

### 90~94화 · 갈등 자체를 성장 자원 경로로 선택한다

주인공 A는 다음 성장 자원을 가진 상위 적대 조직이 직접 움직이게 만들기 위해 분쟁을 회피하지 않는다.

상대의 성향과 조직 반응을 알고 **갈등이 커질 경로를 의도적으로 선택**한다.

상대 욕망은 단순 방어 대상이 아니라 미래 자원 획득 조건을 조립하는 재료가 된다.

### 105~107화 · 과거 이력보다 현재 선택을 다시 확인

상위 관찰자 B는 적 조직 소속이고 실제로 주인공 A를 추적하지만, 주인공 A는 과거 지식 때문에 한 번 다른 선택 가능성을 제시한다.

상대가 현재 관계와 충성을 스스로 다시 선택
→ 적대 행동으로 확정
→ 주인공 A가 과거 기억의 기대를 버리고 현재 적으로 재분류
→ 제거

`과거 적대 이력이 있으면 항상 즉시 제거`도 아님을 보여 준다.

## 121~180화의 확장

### 121~126화 · 적대 조직 내부의 강제 상태를 분리한다

잠입 조직의 거점에는 실제 적대 술자뿐 아니라 조종·강제 복종을 당했을 가능성이 높은 일반인이 함께 있다.

주인공 A는 중심 적대자를 제거한 뒤 주변의 강제 상태 인물까지 동일하게 죽이지 않는다.

판정 요소가 추가된다.

- 현재 행동이 자발적인가
- 강제 술식/위계 때문에 움직이는가
- 실제 적대 결정을 내릴 정보·선택권이 있었는가

따라서 `적 조직 공간에 있음 = 제거 대상`은 `CONTRADICTED` 해석이다.

### 121~126화 · 비공개 정보로 상대가 스스로 적대 증거를 만들게 한다

주인공 A는 잠입자를 이미 알고 있어도 실제 탐지법을 공개하지 않는다. 공개 규칙을 만들어 상대가 회피·도주하게 하고 그 행동을 제3자가 확인하게 한다.

`상대의 선택을 확인한다`는 기존 기준이 **정보전의 공개 증거 생산**으로 변형된다.

### 133~149화 · 관계 상대 이용의 실제 비용

상위 후계자 A의 애착·추적 욕망을 주인공 A는 자기 이탈에 도움이 되는 주의 분산으로 계산한다.

후계자 A가 계속 추적하면 상위 조직 A의 관심도 그 방향에 묶인다.

이는 `타인 비용을 제한하려 한다`와 동시에:

- 관계 상대가 추가 추적 위험을 짐
- 이용 사실을 상대가 나중에 알게 됨
- 상대가 자기 조직의 희생 대상이 된 상황과 겹침

이라는 실제 비용을 남긴다.

기존 `갈등을 키우면 제3자·우호 조직이 보복 비용을 받을 수 있음`이 **관계 상대 수준에서 현실화**된다.

### 150~156화 · 위험한 상위자도 안정 동기면 계약 가능

상위 동행자 A는 주인공 A보다 훨씬 강하고 고가 이동 자원에도 관심이 있다. 그러나 복수라는 장기 동기가 비교적 안정적이고 현재 목표가 겹친다.

주인공 A는 `강함 + 탐욕 가능성`만으로 적으로 확정하지 않는다.

- 동기 지속성
- 보상 구조
- 현재 공격 선택
- 계약 범위

을 보고 제한 동행을 수용한다.

따라서 `위험한 강자 = 제거/도주`도 고정 공식이 아니다.

## 수정된 작동 사슬 · 1~180화

상대의 현재 행동·과거 이력·조직 역할·욕망·강제 상태를 확인
→ 현재 행동이 자발적 적대인지 분리
→ 치명적 적대가 불명확하면 현재 선택을 더 관찰하거나 질문
→ 이미 반복 포식 구조가 충분히 확인됐으면 현재 선공만을 기다리지 않을 수 있음
→ 필요한 성장·생존 목표가 있으면 상대 성향이 작동할 조건을 능동적으로 조립할 수 있음
→ 비공개 우위 정보가 있으면 상대 반응을 통해 공개 가능한 적대 증거를 만들 수 있음
→ 안정된 동기가 있고 권리 범위를 제한할 수 있으면 위험한 상대와도 계약 가능
→ 적대 범위가 충분히 확인되면 제거/반격
→ 자원·정보·안전 회수
→ 사후 책임을 상대 선택/이력과 연결해 해석하되 제3자·관계 비용은 별도로 추적

## 자기합리화와 사실 판정

- 상대의 실제 선공·포식 행동: 장면별 `DIRECT`
- 반복 포식 이력·조직 역할: `DIRECT` 또는 `SUPPORTED`
- 강제 상태 인물과 자발적 술자를 분리한 행동: `DIRECT`
- 주인공 A가 갈등 조건을 의도적으로 조립한 사실: `DIRECT`
- 관계 상대의 추적 욕망을 주의 분산으로 이용한 사실: `DIRECT`
- `상대가 먼저 현재 장면에서 공격해야만 제거한다`: `CONTRADICTED`
- `적 조직 구성원은 모두 동일 제거 대상이다`: `CONTRADICTED`
- `과거 이력만 있으면 누구든 즉시 제거한다`: `CONTRADICTED`
- `그러므로 이후 모든 죽음과 자원 회수 책임은 상대에게 있다`: 주인공 A의 자기설명은 `DIRECT`, 객관적 도덕 정당성은 `HYPOTHESIS`

## 캐릭터 판단

핵심은 정당방위 형식을 기계적으로 지키는 것이 아니다.

주인공 A는:

1. 누가 실제 포식자/적대자인지 근거를 모으고,
2. 그 행동이 자발적인지 강제된 것인지 구분하고,
3. 현재 선택이 달라질 여지가 있으면 확인하며,
4. 위험과 성장 가치가 충분하면 상대 성향이 드러날 조건을 먼저 만들고,
5. 위험한 상대라도 동기가 안정되면 제한 계약 가능성을 열고,
6. 자기 기준상 제거 가능한 범위가 성립했다고 판단할 때 행동한다.

따라서 `선공하지 않는 선인`도 `이득이면 아무나 죽이는 약탈자`도 아닌 **허용 범위를 스스로 구성하고 비용을 분리 추적하는 인물**로 보는 편이 정확하다.

## 표현 구현

- 상대 욕망을 POV·행동·과거 기록 중 하나로 먼저 충분히 보여 줌.
- 강제 상태가 의심되면 주변 인물의 행동 자유도를 따로 보여 줌.
- 주인공 A가 조건을 능동적으로 만들었을 때는 계획 일부를 늦게 공개해 피해자/유인자 경계를 남김.
- 비공개 탐지에서는 실제 규칙을 말하지 않고 상대 반응이 증거가 되게 함.
- 위험한 상위 동행자 A와는 감정 평가보다 보상·복수 목적의 안정성을 대사와 행동으로 검증.
- 사후 자기평가는 짧게 끝내고 객관적 도덕 해설은 별도로 붙이지 않음.

## 비용과 실패 조건

- 상대 성향을 잘못 읽으면 불필요한 적 생성.
- 의도적으로 갈등을 키우면 제3자와 우호 조직이 보복 비용 부담.
- 관계 상대의 욕망을 이용하면 그 상대에게 추적·정치 비용이 남을 수 있음.
- 과거 포식 이력만으로 현재 변화 가능성을 닫으면 오판 위험.
- 강제 상태를 자발적 적대로 잘못 읽으면 무고한 피해 가능.
- 현재 선택을 더 확인하다가 상대가 먼저 행동하면 즉시 위험.
- 안정 동기로 본 계약 상대가 실제로는 다른 목표를 숨기면 보증·동행 비용 확대.
- 성장 자원 때문에 갈등을 조립하는 행위가 누적되면 자기 정당화와 선제 약탈 경계가 흐려질 수 있음.

## 반례와 적용 한계

- 54~55화: 모욕/언어 갈등만으로 제거하지 않음.
- 66~72화: 현재 선공 없어도 충분한 포식 이력으로 제거 가능.
- 105~107화: 적대 소속이어도 현재 선택 한 번 확인.
- 121~126화: 적대 조직 공간에서도 강제 상태 인물은 중심 적대자와 분리.
- 150~156화: 위험한 상위자라도 복수 동기가 안정되면 계약·동행 가능.

이 변형들 때문에 스레드를 `현재 선공 대기` 하나로 설명할 수 없다.

## 상태 판정

초기부터 180화까지 서로 다른 적대 유형에서 `적대 근거·강제 상태 확인 → 허용 범위 설정 → 필요하면 조건 조립 → 제거/계약/회수`가 반복된다.

하위 공식은 계속 무너지지만 상위 판단 사슬은 더 정교해졌다.

`VERIFIED_THREAD` 유지.
