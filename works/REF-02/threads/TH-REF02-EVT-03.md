# 사건 보상을 다음 결핍을 해결하는 복수 기능 인프라로 재배치한다

## 해결하는 문제

보상 장면이 숫자와 장비를 누적하는 데 그치고 다음 사건의 선택 구조를 바꾸지 못하는 문제.

## 작동 사슬

현재 결핍 확인
→ 위험한 사건 수락 또는 강적 제거
→ 보상·전리품·관계 권리 획득
→ 원래 명칭과 용도에서 분리해 기능 분석
→ 성장·방어·은폐·탐색·제작·정보 중 둘 이상에 재배치
→ 새 선택지 개방
→ 보유 사실·출처·관계 의무 때문에 다음 위험 발생

## 반복·변형

### 초기 초월 위협

승리 결과를 후천 수련 자질로 바꿔 일반 성장 체계에 진입한다. 비상 능력 자체가 성장 체계를 대체하지 않는다.

### 초기 포식 관계 종료

공법·단약·은신처 통제권을 회수해 독립 성장 기반으로 전환한다.

### 21화 상위 적 제거

- 핵심 영기 → 다음 경지 도전 영력
- 방어 장비 → 공개 전투·탈출
- 고급 저장 도구 → 상위 보물 은폐
- 단약·자본 → 회복과 대기 시간 단축

### 22화 비경 공략

새 탐색법과 일반 공격 기술을 이용해 금 속성 축기 자원과 판매 가능한 영초를 확보한다. 전투 성장이 자원 탐색 능력으로 확장된다.

### 25~26화 보물 탈취

공식 목표는 거래 무산이지만, 획득한 상위 보물은 광역 비상 공격·약점 속성 보완·연단용 진화로 재분류된다. 의뢰자에게 소진된 것처럼 보여 소유권 분쟁과 탈취 위험을 줄인다.

### 26~27화 관계 보상

작은 상호 교환과 거주 위기 해결이 거주권·연단 시설·공간 확장·기술 교육으로 돌아온다. 물건이 아니라 관계 권리가 생산 인프라가 된다.

## 상태 변화

주인공 A의 성장은 전리품 수량보다 `선택 가능한 해결 방식의 종류`가 늘어나는 것으로 제시된다.

- 비상 단일 제거
- 일반 공격·방어
- 광역 공격
- 기파 은폐
- 약초 탐색
- 단약 생산
- 정보·의뢰 접근
- 안전 공간

하나의 자원을 복수 문제에 연결하기 때문에 다음 아크가 이전 보상에서 자연스럽게 발생한다.

## 비용

- 보유 사실과 출처를 숨겨야 함
- 강한 장비·보물 사용은 영력과 탈출 비용이 큼
- 관계 인프라는 상대의 가족·사업·정보 이해관계와 연결됨
- 전리품 의존이 강해질수록 원 소유 조직의 추적 위험이 커짐

## 반례와 경계

- 현재 결핍과 맞지 않아 장기간 보관만 하는 보상 미확인
- 잘못된 기능 재분류로 자원을 손상시키는 실패 미확인
- 관계 보상이 배신·과도한 대가 요구로 뒤집히는 사례 미확인
- 획득 자원이 너무 강해 기존 일반 기술을 폐기하게 되는지 미확인

## 승격 이유

초기 능력·공법 회수, 21화 상위 적 전리품, 25~26화 상위 보물, 26~27화 관계 시설이라는 떨어진 사건에서 반복과 변형이 확인되었다. 보유 사실 은폐·사용 비용·관계 의무라는 비용도 함께 확인되어 `VERIFIED_THREAD`로 판정한다.
