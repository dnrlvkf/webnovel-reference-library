# 진영 명분보다 실제 지출·요구 권리·위험 전가를 보고 협력 상대를 고른다

## 해결하는 문제

주인공이 정종·마도·흑문 같은 표면 진영만으로 선악과 신뢰를 판단하면, 작품이 이미 보여 준 조직 내부의 포식·감시·소모 구조가 사라지는 문제.

## 작동 사슬

조직의 보호·입문·영입 제안
→ 명분과 실제 제공 자원 분리
→ 상대가 되돌릴 수 없이 지출하는 비용 확인
→ 계약 뒤 요구할 복종·정보·이동·전리품 권리 계산
→ 위험 비용을 누가 부담하는지 확인
→ 가장 제한된 범위의 협력 선택
→ 성과와 포로·정보를 제공
→ 감시·위계·포식 징후가 나타나면 장기 신뢰로 올리지 않음
→ 공동 목표가 끝난 뒤 재정산 준비

## 반복·변형

### 초기 조직 입문 제안

강한 정파 조직의 입문 문서는 보호와 성장 기회를 말하지만 실제로는 자원 상납·절대복종·영적 처벌을 포함한다. 주인공 A는 명분보다 잃는 권리를 보고 거부한다.

### 중개 관계

중개자 A와는 출신·수법을 전부 공개하지 않고 결과와 보수만 교환한다. 반복 실적이 정보·추천 접근권으로 확대된다.

### 경쟁 영입

마도 조직 A의 희귀 공법은 기존 사본이라 실제 지출이 작다. 정종 조직 A의 운영석과 영석은 되돌릴 수 없는 비용이다. 주인공 A는 선금을 낸 정종 측과 토벌 계약을 맺는다.

### 안전과 감시

정종 분당은 외부 습격을 막지만 내부 관찰을 동반한다. 주인공 A는 보호를 신뢰 증거가 아니라 감시 가능한 접근권으로 함께 기록한다.

### 위계와 하위 인원 소모

정종 내문제자 A는 소속과 경지를 근거로 사적 명령권을 요구한다. 지도자 A는 내문제자를 미끼로 사용한다. 마도 지도자 A도 쓸모가 끝난 동맹과 자기 수하를 소모한다. 양쪽 명분은 달라도 위험 비용 전가 구조가 반복된다.

### 법역 위기

정종 지도자 A는 절체절명 상황에서 주인공 A의 지시를 따르고 시간을 벌어 준다. 평시 경지 위계보다 사건 해결 정보가 임시 권한을 만든다.

## 상태 변화

주인공 A는 조직에 가입하지 않으면서도 조직 자원을 사용할 수 있다.

- 중개 가격 경쟁
- 안전 공간
- 포로 심문과 작전 정보
- 대규모 전장 접근
- 결단경 지도자의 시간 확보

대신 감시·과대 기대·위계 충돌·공로 정산 위험이 누적된다. 독립은 관계 부재가 아니라 관계별 권리를 잘게 나누는 방식으로 유지된다.

## 비용

- 조직 보호를 장기 신뢰로 바꾸지 못해 매번 계약 범위를 재검토함
- 유용한 외부 인재로 평가될수록 더 위험한 임무와 감시를 받음
- 선금을 받았기 때문에 토벌전 지원 의무가 생김
- 지도자의 탐욕이 성과·전리품 소유권 분쟁으로 전환될 가능성
- 양쪽 조직과 동시에 적대하거나 추적당할 위험

## 반례와 경계

- 실제 비용을 지불한 조직도 사후에 과도한 권리를 요구할 수 있음. 아직 결전 후 정산 미확인.
- 하위 인원 소모가 없는 평등한 조직 관계 미확인.
- 명분과 실제 행동이 일치하는 조직 지도자 반례 미확인.
- 주인공 A가 장기 조직 보호 없이는 해결할 수 없는 사건에서 어느 권리를 양보하는지 미확인.

## 승격 이유

초기 입문 계약, 중개 거래, 경쟁 영입, 정종 분당 감시, 내문 위계, 양 조직의 하위 인원 소모라는 떨어진 관계·조직 장면에서 같은 판정 기준이 반복·변형됐다. 실제 선금과 보호라는 보상뿐 아니라 감시·의무·소모 위험도 확인되어 `VERIFIED_THREAD`로 판정한다.
