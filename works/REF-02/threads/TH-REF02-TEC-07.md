# 적·자기 기술을 구조로 읽어 파훼·재현·개량하고, 결국 새 기술을 담는 실행 플랫폼까지 합성한다

## 해결하는 문제

주인공 A가 새 법술을 필요할 때마다 갑자기 떠올리거나 단순히 더 강한 화력으로 해결하면, 전투 경험이 장기 학습 체계로 축적되는 과정이 사라진다.

121~180화에는 학습 결과가 개별 술식에 머물지 않고 **여러 관찰 결과를 담는 법역/실행 환경**으로 올라가는 변형이 추가된다.

## 작동 사슬

적 기술 또는 미지 구조에 노출
→ 영기 흐름·결합·선행 변화·작동 조건 관찰
→ 힘의 총량보다 구조적 약점/규칙 파악
→ 파훼
→ 동일 원리를 자기 자원으로 재현
→ 현재 목적에 맞게 형태·집중도·전달 방식 개량
→ 필요하면 연체·오행·저주·감지·법역 등 다른 분야 원리까지 합성
→ **여러 기술을 다시 담아 쓸 수 있는 상위 구조/플랫폼으로 통합할 수 있음**
→ 다음 전투의 일반 수단으로 편입

## 61~120화 반복·변형

### 71~74화 · 저주 구조

상대 저주가 연결되는 영적 구조를 읽어 끊는다. 이후 약한 연결부를 그대로 복제하지 않고 더 안정적인 구조로 재구성해 직접 전달형 술식으로 바꾼다.

`파훼 → 재현 → 개량`의 언어가 처음 명확해진다.

### 80~81화 · 빙 계열 술식

오행 이치와 영기 구조를 함께 읽어 상대의 빙결 방식을 파훼한다. 흩뿌리는 공격을 더 얇고 집중된 한 줄기로 바꿔 관통 효율을 높인다.

### 91~93화 · 이동술

상대가 이동하기 직전 에너지가 한쪽으로 기우는 선행 변화를 감지한다.

예측
→ 저주로 순간 정지
→ 상대 이동 구조 관찰
→ 같은 전투에서 자기 이동술 재현

재현에는 성공하지만 육체가 속도를 버티지 못해 심한 부상을 입는다. **기술 이해와 신체 적응은 별도 문제**다.

### 101~104화 · 자동 방어

여러 속성 공격이 방어막에 막힌다. 공격은 단순 실패가 아니라 순환 구조를 읽기 위한 진단이다.

오행별 반응 관찰
→ 방어가 `두께`가 아니라 표면 순환으로 유지된다고 판정
→ 빙결 압축 경험 + 연체공법의 힘 압축 원리 합성
→ 흐름 자체를 절단하는 새 술식 생성

서로 다른 연구 축의 원리를 합성하는 단계까지 발전한다.

### 107화 · 순양 화염

상위 관찰자 B의 화염이 오행 화기보다 더 근본적인 순양 범주라는 점을 실전에서 이해한다. 기존 극양 자원과 음양 이해를 결합해 자기 고유 화염을 만든다.

### 119화 · 자기 술식 재설계

이미 사용하던 광역 진화를 다시 분석한다. 넓게 퍼지는 성질에 직진·관통 이치를 부여해 단일 대상용으로 바꾼다.

학습 대상이 적 기술에 한정되지 않고 **자기 기술도 현재 문제에 맞게 다시 구조화**된다.

## 121~180화의 확장

### 127~132화 · 혈계 기술을 기존 연구 체계에 편입

적 상위자의 혈계 제어 수단을 단순 전리품으로 저장하지 않는다.

기존 독·혈 연구 경험
+ 새 혈계 연결 구조
+ 자기 법기 전달 방식
→ 새로운 제어·공격 운용

으로 합성한다.

새 지식은 이전 스레드와 단절된 `한 번의 새 기술`이 아니라 기존 자료망에 편입된다.

### 157~164화 · 일회성 보호 원리를 상시 방어 후보로 재구성

이전에 사용·관찰한 일회성 자동 방어 수단의 반응 원리를 다시 꺼낸다.

사용 경험
→ 어떤 방향에서 들어와도 자동 반응하는 조건 분해
→ 자기 영력/법기 체계로 상시 운용 가능한 형태 탐색
→ 후속 제작 방어체계에 반영

`소모품 사용 → 끝`이 아니라 소비한 도구도 구조 학습 재료가 된다.

### 170~177화 · 개별 기술 합성에서 법역 플랫폼으로

원영경 승급 때 주인공 A는 하나의 기존 법역을 그대로 복제하지 않는다.

입력 자료:

- 자기 고유의 빈 내적 공간
- 여러 적에게서 관찰한 법역
- 장기 동업자 A가 전달한 상위 수련법
- 직접 경험한 상계 심상
- 기존 오행·음양·압축·공간 경험

이것을 하나의 고정 심상으로 압축하지 않고 **비어 있는 법역 플랫폼**으로 조직한다.

공백
→ 필요한 세계/심상을 올릴 수 있는 실행 환경
→ 상대의 법역을 현재 문제에 맞는 심상으로 대응

학습 결과가 `새 필살기`에서 **새 기술을 담는 시스템**으로 한 단계 올라간다.

### 관찰 해상도가 모방 품질을 결정한다

상대 상위 적 A도 상계 존재의 심상을 법역에 구현한다. 그러나 상대는 간접·열화된 관찰에 가깝다.

주인공 A는 더 직접적인 기억·접촉 경험을 가지고 있다.

같은 범주의 심상을 구현해도:

- 원천을 얼마나 직접 봤는가
- 세부 구조를 얼마나 기억하는가
- 자기 법역이 그 정보를 얼마나 유연하게 담는가

에 따라 결과가 달라진다.

`기술명을 알고 있다 = 같은 품질로 재현할 수 있다`가 아니다.

## 성공 조건

- 영기/구조를 관찰할 감각이 있음
- 상대 기술을 일정 시간 버틸 생존 수단이 있음
- 구조 변화와 결과를 비교할 여러 시험이 가능함
- 이미 알고 있는 다른 분야 원리를 호출할 수 있음
- 재현한 힘을 몸이나 법기가 감당할 수 있음
- 상위 법역 단계에서는 관찰 자료를 담을 **자기 고유 구조**가 필요함

## 비용과 실패

- 구조를 읽기 전 시험 공격·피격 비용 발생
- 재현 직후 육체가 망가질 수 있음
- 상계 힘처럼 현재 이해 범위를 넘는 힘은 즉시 재현하지 못하고 별도 저장만 가능
- 상대가 정보를 주기 전에 즉시 제거되면 학습 기회가 사라짐
- 모든 적 기술을 배우는 것이 목표가 아니라 현재 성장/전투 체계와 연결 가능한 것만 편입함
- 법역 플랫폼이 여러 심상을 담을 수 있어도 **심상끼리 충돌하지 않는다는 보장은 없음**
- 직접 경험이 부족한 심상은 열화 모방에 머물 가능성

## `TH-REF02-TEC-05`와 차이

`TH-REF02-TEC-05`는 정식 이론을 몰라도 전체 시스템을 소유하지 않고 현재 목적에 필요한 최소 구조를 건드리는 문제 해결법이다.

이 스레드는 거기서 더 나아가:

- 원리를 이해하고
- 자기 수단으로 재현하며
- 다른 원리와 결합하고
- 장기적으로 자기 실행 체계에 편입하는

**학습·창안 메커니즘**이다.

126화처럼 상위 우회 수단으로 진법을 그냥 빠져나가고 배우지 않는 장면은 TEC-05의 비용 경계이지 TEC-07의 학습 사례가 아니다.

## CHARACTER 연결

주인공 A는 `강한 기술을 많이 모으는 사람`보다 **패배·피격·막힌 공격·소모품 사용을 관찰 자료로 바꾸는 사람**으로 그려진다.

그래서 강한 적과 직접 싸울 학습 가치가 충분하면 더 안전한 대리 전투나 비상 능력 즉시 사용을 거절할 수 있다.

170~177화가 대표적이다.

## STORY·PROSE 연결

- 먼저 실패/피격/오해를 장면화함.
- 지문은 위력보다 흐름·방향·압축·연결·법역 규칙을 관찰함.
- 원리를 알아낸 직후 결과를 붙여 추론을 검증함.
- 후속 장면에서 같은 기술을 다시 써 체계 편입을 증명함.
- 빈 법역은 상대에게 결핍으로 오해된 뒤 실제 심상 구현으로 재분류됨.
- `MAC-REF02-0004`가 이 상위 단계의 표현 구조를 보존함.

## 반례와 미확인

- 잘못 읽은 구조 때문에 오판하는 본격 실패 사례는 **121~180화에서도 아직 부족함**.
- 상대가 일부러 거짓 구조를 노출하는 반례 미확인.
- 관찰은 가능하지만 자기 법역/몸에서 재현할 수 없는 상계 법칙의 경계 추가 확인 필요.
- 여러 심상을 한 플랫폼에 담을 때 상호 충돌·정체성 혼란이 비용이 되는지 미확인.
- 배운 기술이 너무 많아 운용 복잡성이 비용이 되는지 미확인.

## 승격·유지 이유

71~119화의 저주·빙결·이동·방어·순양 화염·자기 화염 재설계에 더해 121~177화에는 혈계 합성·소모품 방어 원리 재구성·법역 플랫폼 통합이 추가된다.

개별 술식 수준을 넘어 `관찰 경험을 자기 실행 환경으로 누적한다`는 상위 변형까지 확인되어 `VERIFIED_THREAD`를 유지한다.
