# 경험을 구조로 읽어 파훼·재현·개량·합성하지만 실패는 주로 구현 용량과 정보 해상도에서 발생한다

## whole-work 질문

`파훼 → 재현 → 개량`이 작품 전체에서 실제로 어떻게 실패하는가.

특히 주인공 A가 **구조 자체를 잘못 읽어 틀린 이론을 확신하는 실패**가 있는지 초·중·후반을 왕복했다.

## 핵심 작동 사슬

새 힘·기술·현상·내적 경험에 노출
→ 작동 전후의 흐름·시간·연결·법칙을 관찰
→ 현재 목적에 필요한 구조를 분리
→ 파훼 또는 재현 가능성 판단
→ 자기 몸·법기·법역·인지가 그 구조를 감당하는지 확인
→ 재현·개량·다른 원리와 합성
→ 실전 검증
→ 실패가 생기면 `이해 / 구현 / 운용 / 관측 / 원본 관계` 중 어느 층이 문제인지 다시 분리
→ 일반 체계에 편입하거나 봉인.

## 반복·변형

### 구조 이해 → 재현 → 개량

71~119화의 저주·빙결·이동·방어·상위 화염·자기 기술 재설계에서 반복된다.

상대 기술명을 그대로 복사하지 않고 연결 방식·흐름·선행 변화를 읽은 뒤 자기 자원에 맞는 형태로 재구성한다.

### 여러 분야 합성 → 실행 플랫폼

121~177화에는 혈계·독 연구·소모품 방어·법역 경험·내적 공간·상위 심상을 한 체계에 묶는다.

결과는 개별 필살기보다 여러 심상을 담는 `빈 법역 플랫폼`으로 올라간다.

### 파편 정보와 추론

189~194화에는 직접 경험 없는 상위 심상을 남겨진 파편 정보로 재구성한다.

재현 자체는 가능하지만 완전한 관찰과 달리 빈 부분을 추론으로 채워야 해 정신 비용과 품질 경계가 커진다.

### 실시간 적응 설계

201~206화에는 이미 날아오는 복수 공격을 높은 시간 해상도로 분해하고 각 공격에 맞는 대응을 도착 전에 즉석 합성한다.

학습 사슬이 `전투 뒤 연구`에서 `전투 중 설계`까지 확장된다.

### 외부 기술이 아닌 자기 감정도 입력

225~230화에는 외로움·관계 한계를 배제하지 않고 이해한 뒤 그 경험을 새 개념 술식으로 번역한다.

학습 입력은 적 기술에 한정되지 않는다.

### 6계위 · 상위 법칙 직접 접속

267~284화에는 하위 법칙의 응용이 아니라 세계를 규정하는 더 높은 법칙층에 직접 접속한다.

주인공 A는 기존 흡수·재구성 원리와 상위 법칙을 결합해 상대의 상위 공격까지 흡수·재구축해 되돌린다.

다른 강자도 같은 가르침을 자기 무공 체계와 결합해 별도 변형을 만든다.

`같은 지식 → 같은 기술`이 아니라 **기존 체계에 따라 출력이 달라지는 학습**이다.

# whole-work 실패 분포

## 1. 구조 이해 성공 / 육체 구현 실패 — DIRECT

90~94화 이동술.

상대의 이동 전 선행 변화를 읽고 같은 전투에서 재현해 승리한다.

그러나 반복 급회전 속도를 몸이 견디지 못한다.

결론:

`이해 성공 + 재현 성공 ≠ 지속 운용 가능`.

기술을 봉인하고 별도 신체 수련이 필요해진다.

## 2. 정보 해상도 부족 / 인지 비용 — DIRECT

189~194화 파편 재구성.

직접 본 원천보다 불완전한 파편을 추론으로 채울 수는 있지만 정신 부담이 커진다.

실패는 구조가 완전히 틀린 것이 아니라 **원천 해상도가 낮아 비용과 확실성이 악화**되는 형태다.

## 3. 강림 성공 / 해제 후 연속 행동 실패 — DIRECT

207~212화.

상위 심상 법역은 실전에서 강하게 작동하지만 해제 뒤 손 떨림·정신 붕괴·약물 회복이 필요하다.

`발동 성공 = 전투 후에도 계속 행동 가능`이 아니다.

## 4. 이해가 있어도 도구가 층위를 못 버팀 — DIRECT

213~220화.

기존 공간 문제를 해결해 온 도구가 더 높은 공간 구조에서 실제로 파손된다.

주인공의 구조 이해가 충분해도 실행 매체의 층위가 낮으면 실패한다.

## 5. 상위 플랫폼 ≠ 일반 기술 자동 고도화 — DIRECT

225~230화.

높은 개념 법역을 쓸 수 있어도 평상 술식 전체가 같은 법칙층으로 자동 상승하지 않는다.

별도 훈련과 번역이 필요하다.

## 6. 기술 자체는 맞지만 운용 가정이 전투 기만에 깨짐 — DIRECT

248~260화.

새 흡수/반전 기술로 강적을 받아내려 하지만 상대가 마지막 순간 공격 각도를 바꾼다.

고집중 기술은 복합 페이크에 취약했고, 주인공 A는 자기가 상대 전투 감각을 얕봤다고 인정한다.

즉시 해당 기술을 고집하지 않고 고속 이동·광역 통제로 복귀한다.

이 실패는 `구조 이론 오독`보다 **집중/운용 조건과 상대 판단을 잘못 계산한 실패**다.

## 7. 6계위 · 지속·영혼·관측 한계 — DIRECT

상위 법칙에 직접 접속해도:

- 유지 시간이 짧고
- 영혼 부담이 크며
- 공격 가능 거리가 관측 가능 거리보다 길어 결과 확인이 안 될 수 있다.

더 높은 법칙 이해가 정보 피드백 문제를 없애지 않는다.

## 8. 모사 원본이 실제 관계 비용을 청구 — DIRECT

238~240화.

상위 존재의 힘·심상을 반복 모사한 행위가 실제 원본에게 감지되어 강제 소환·승급·임무로 돌아온다.

학습·모사는 기술적으로 성공했지만 **원본과 독립된 무료 정보 자산이 아니었다.**

# 순수 구조 오판 질문

1~284화 whole-work 왕복에서 다음은 확인했다.

- 잘못된 `단일 코어가 있을 것`이라는 가정이 장시간 실패하는 사례는 있음. 그러나 이것은 `TH-REF02-TEC-05`의 시스템 진단 문제이며, TEC-07에서 잘못 읽은 구조를 재현해 틀린 기술을 만든 사례는 아님.
- 상위 기술을 재현한 뒤 실패한 사례는 대부분 몸·도구·인지·반동·집중·피드백·원본 관계 층에 있음.

따라서:

> `TEC-07의 순수 잘못된 구조 판독 실패`

은 **`NOT_OBSERVED_WITHIN_SOURCE_BOUNDARY`**.

`그런 실패가 불가능하다`고 판정하지 않는다. 단지 1~284화 원문에서 직접 확인되지 않았다.

# 왜 이 실패 분포를 기록하는가

이 작품의 학습형 주인공을 `한 번 보면 뭐든 완벽히 카피한다`고 요약하면 잘못이다.

작가는 이해력을 매우 높게 주되 실패를 다른 층에 배치한다.

> **원리를 알아도 몸이 못 따라갈 수 있고, 도구가 부러질 수 있고, 집중이 깨질 수 있고, 관측이 닿지 않을 수 있고, 원본이 권리를 주장할 수 있다.**

그래서 학습 능력이 강해질수록 새 실패 조건도 상위 층으로 이동한다.
