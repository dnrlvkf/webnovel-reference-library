# 표면 정보와 본질 정보층을 분리해 위장·노출·추적을 교차시킨다

## 해결하는 문제

변신·경지 은폐·도난 기술·거짓 신분이 단순한 반전 장치로 끝나지 않고, 누가 어떤 정보층에 접근하느냐에 따라 합리적 오판·추적·보호·포식 행동이 달라지게 하는 문제.

## 작동 사슬

행위자가 표면 형상·기술·영력·신분을 제시
→ 관찰자는 자기 도구와 사전 정보로 분류
→ 접근 가능한 정보층에 맞는 오판 또는 정확한 판정
→ 더 깊은 정보층이 불일치를 발견
→ 실제 자질·경지·소속 또는 별도 신원으로 재분류
→ 기습·포식·은폐·보호·추적 행동 변화
→ 결과가 어느 정보층이 유효했는지 증명

## 반복·변형

### 20화 · 기술 표면과 영기 근원

하위 적은 표면 공법으로 소속을 오분류하고, 상위 관찰자는 영기 근원을 읽어 특수 자질과 과거 사건을 연결한다.

### 25화 · 무생물 변신

변화 경비자는 일반 감각을 속이지만 상태 정보에는 본질이 남아 기습 전에 제거된다.

### 26화 · 상위 보물 은폐

의뢰자는 하위 경지 사용자가 상위 보물 기파를 감출 수 없다고 합리적으로 판단한다. 고급 저장 도구라는 비공개 조건 때문에 이 판정이 틀어진다.

### 28~29화 · 경지 축소와 거짓 신분

영력 탐색과 비경 금제는 위장 경지를 읽지만 상태 정보는 실제 경지와 소속을 드러낸다.

### 34~40화 · 유용한 오해

제작자와 조직 인물들은 주인공 A의 숨은 배후·경지·법기 의존도를 서로 다르게 추론한다. 주인공 A는 자신에게 유리한 오해를 굳이 정정하지 않는다.

### 44~46화 · 별도 활동 신원

표면 은폐가 적극적인 **추적 신원 분리**로 확장된다.

- 얼굴 변경
- 체형 변경
- 복장 색 변경
- 기존 주력 법기 미사용
- 대표 법술 미사용
- 다른 출처의 제한 부보 사용
- 즉석 가명 사용

원영경 상위자 A는 이 묶음을 하나의 인물상으로 기억하고 공개 추적한다. 실제 주인공 A는 그 추적이 정종 고경지 화염 사용자 쪽으로 빗나갈 것으로 계산한다.

### 49화 · 계층 편견을 통과권으로 전환

문지기 A는 주인공 A의 표면 경지와 출신을 낮게 분류해 선공한다. 짧은 제압 뒤 오히려 숨은 고경지 인물로 오분류하며, 주인공 A는 이를 정정하지 않고 중층부 접근에 사용한다.

## 상태 변화

위장은 절대 성공/실패가 아니라 **정보층별로 다른 사회적 흔적**을 만든다.

- 하위 관찰자: 기술·복장·경지 표면으로 소속과 강함 추론
- 상위 영기 관찰자: 영기 근원에서 표면 오분류 교정
- 상태 정보 관찰자: 변신·경지 축소·거짓 이름 관통
- 활동 신원 설계: 관찰자가 틀린 인물을 실제 추적하게 만듦

41~50화의 핵심 변화는 `나를 못 알아보게 한다`에서 `다른 사람을 알아봤다고 믿게 한다`로 목표가 확대된 점이다.

## 표현 구현

- 먼저 오판하는 인물의 관찰 근거를 보여 줘 멍청한 착각으로 처리하지 않음.
- 본질 정보는 표면과 대조해 독자가 불일치를 확인하게 함.
- 46화 공개 추적 선언 뒤 곧바로 주인공 A의 실제 추적 방향 계산을 붙여 위협을 삭제하지 않고 방향을 분리함.
- 49화에는 상대의 잘못된 상위 경지 판정을 주인공 A가 말로 정정하지 않고 행동 결과로 통과권에 사용함.

## 비용과 실패 조건

- 특수 자질·영기 흔적은 상위 관찰자에게 노출 가능.
- 활동 신원 A에 상위 적대와 범죄 흔적이 누적됨.
- 실제 신원과 활동 신원을 연결하는 관찰자가 나오면 분산했던 위험이 합쳐질 수 있음.
- 본질 정보가 있어도 상대 기술·욕망·후속 조직 대응까지 자동으로 알 수 없음.
- 위장 때문에 기존 강한 법기·대표 술식을 사용할 수 없어 전투 수단이 제한됨.

## 반례와 경계

- 상태 정보 자체가 차단·오염·위조되는 사례 미확인.
- 활동 신원 A와 실제 신원이 재연결되는 실패 미확인.
- 모든 오판은 정보층 차이로 설명되지 않으며 감정·탐욕·시간 압박이 별도 원인일 수 있음.
- 주인공 A가 본질 정보를 보고도 잘못 행동하는 반례 미확인.

## 현재 상태 유지 이유

20·25·26·28~29·44~46·49화의 떨어진 사건에서 정보층의 반복·변형·비용이 확인되었다. 특히 44~46화는 수동 은폐에서 능동적 추적 신원 설계로 경계를 넓혔다. `VERIFIED_THREAD`를 유지한다.

## 다음 질문

51~60화에서 활동 신원 A의 공개 흔적이 실제 신원과 연결되는가. 상태 정보가 불완전하거나 차단되는 상대가 나타나는가.
