# 표면 정보와 본질 정보층을 분리해 위장·노출·오판을 교차시킨다

## 해결하는 문제

변신·도난 기술·경지 은폐·거짓 신분이 단순한 반전 장치로만 쓰이고, 누가 어떤 정보층을 볼 수 있는지에 따른 판단 차이가 사라지는 문제.

## 작동 사슬

행위자가 표면 형상·기술·영력·신분을 제시
→ 일반 관찰자는 표면 정보로 소속·경지·위험을 분류
→ 관찰 수준에 맞는 합리적 오판 발생
→ 더 깊은 구조 또는 별도 정보층을 보는 관찰자가 불일치를 발견
→ 실제 자질·이름·경지·소속 재분류
→ 기습·포식·고문·포섭·은폐 중 새 행동 발생
→ 결과가 어느 정보층이 우세했는지 증명

## 반복·변형

### 20화 · 표면 기술과 깊은 영기 구조

하위 적은 외부 조직의 기술을 보고 주인공 A를 그 조직 소속으로 오분류한다. 상위 관찰자는 영기의 근원을 읽어 표면 소속을 교정하고 특수 자질과 과거 사건을 연결한다.

### 21화 · 의도적 자질 노출과 숨은 비상 능력

상위 적은 특수 자질의 가치를 정확히 읽지만 비상 능력은 모른다. 부분적으로 더 깊은 정보를 본 것이 오히려 생포 욕망과 방심을 강화한다.

### 25화 · 무생물 변신 경비자

변화 경비자는 무생물로 완벽히 변신해 일반 감각과 은신 탐지를 회피한다. 주인공 A의 상태 정보에는 실제 종족·경지·소속이 남아 있어 기습 전에 제거된다.

### 26화 · 상위 보물 은폐

의뢰자 A는 연기경 수사가 상위 보물의 기파를 숨길 수 없다고 합리적으로 판단한다. 주인공 A가 상위 적에게서 회수한 고급 저장 도구라는 비공개 조건 때문에 이 판정이 틀어진다.

### 28~29화 · 경지 축소와 거짓 신분

영력 탐색과 비경 금제는 잠입자를 연기경으로 읽는다. 상태 정보는 축기경 대원·거짓 이름·실제 소속을 드러낸다. 일반 경쟁 집단은 금제와 감각을 신뢰해 전멸하고, 주인공 A는 보호 대상을 격리한다.

## 상태 변화

위장은 절대적 성공이나 실패가 아니다. 관찰자의 도구와 사전 정보에 따라 같은 표면이 다른 결과를 낳는다.

- 하위 관찰자에게는 위장 성공
- 상위 영기 관찰자에게는 신원 노출
- 상태 정보 관찰자에게는 변신·경지 축소 실패
- 상위 저장 도구의 존재를 모르는 의뢰자에게는 보물 은폐 성공

정보 우위는 인물의 지능보다 `접근 가능한 정보층`에 의해 제한된다.

## 표현 구현

- 먼저 오판하는 인물의 내면과 근거를 충분히 제시함
- 단순히 멍청해서 속았다고 처리하지 않음
- 본질 정보는 표면과 나란히 제시해 불일치를 독자가 확인하게 함
- 정보층 차이가 공격 중단·생포·기습·보호 격리·거짓 정산이라는 후속 행동을 바꿈
- 결과 장면에서 어느 판정이 유효했는지 확정함

## 비용과 실패 조건

- 주인공 A의 특수 자질은 상위 관찰자에게 노출될 수 있음
- 상태 정보가 없는 동료와 보호 대상은 주인공 A의 경고를 믿지 않음
- 표면 오분류에 기대면 더 깊은 관찰자가 나타날 때 역추적 위험이 커짐
- 고급 은폐 도구의 출처를 숨겨야 함
- 본질 정보가 있어도 상대의 모든 기술·욕망·후속 조직 대응을 알 수 있는 것은 아님

## 반례와 경계

- 상태 정보 자체가 오염·차단·위조되는 사례 미확인
- 표면과 본질이 일치해 추가 해석이 필요 없는 장면도 존재함
- 모든 오판을 정보층 차이로 설명하지 않음. 감정·욕망·시간 압박이 별도 원인일 수 있음
- 주인공 A가 본질 정보를 보고도 잘못된 행동을 선택하는 반례 미확인

## 승격 이유

20화의 기술/영기 구조, 25화의 무생물 변신, 26화의 보물 기파 은폐, 28~29화의 경지 축소와 거짓 신분이라는 떨어진 구간에서 반복과 변형이 확인되었다. 일반 감지·상위 영기 판독·상태 정보·저장 도구라는 서로 다른 관찰 수단과 실패 비용도 확인되어 `VERIFIED_THREAD`로 승격한다.

## 다음 질문

후속 구간에서 상태 정보가 차단되거나 불완전한 대상이 나타나는가. 마도 조직이 주인공 A의 표면 기술·자질·보물 흔적 중 어느 정보층을 이용해 추적하는가.
