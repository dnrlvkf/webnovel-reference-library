# 표면 정보·검증 데이터·행동 흔적·본질 정보·원본 귀속을 분리해 오판과 재연결을 만든다

## 해결하는 문제

변신·경지 은폐·가짜 신분·기술 모사가 단순 성공/실패 트릭으로 끝나지 않고, 관찰자가 접근한 **정보층과 입력 데이터**에 따라 서로 다른 합리적 판정을 만들고 그 판정이 추적·보호·공격·채무 행동으로 이어지게 하는 문제.

## 기본 작동 사슬

행위자가 외형·기술·영력·문서·행동·감시 데이터를 제시
→ 관찰자는 자기 도구/사전 정보로 분류
→ 접근한 정보층에 맞는 오판 또는 정확한 판정
→ 주인공 A가 일부 층을 의도적으로 선택·가공할 수 있음
→ 다른 관찰자/깊은 정보/오래된 행동 흔적이 불일치를 발견
→ 실제 신원·별도 신원·원본 귀속으로 재분류
→ 공격·포섭·추적·검증·채무 행동 변화
→ 필요하면 가짜 신원/표면 전략 폐기.

# 1. 18~49화 · 표면 기술과 깊은 정보층

- 하위 적은 표면 공법으로 소속을 오분류하고 상위 관찰자는 영기 근원으로 교정.
- 변신은 일반 감각을 속이지만 상태 정보에는 본질이 남음.
- 경지 축소·거짓 이름도 더 깊은 정보에는 통하지 않음.
- 숨은 배후·법기 의존이라는 유용한 오해를 정정하지 않음.
- 얼굴·체형·복장·법기·법술·기술 출처를 묶어 별도 활동 신원을 만들고 추적을 분산.

# 2. 61~120화 · 깊은 재연결과 제도권 신분

## 깊은 체질 흔적

상위 관찰자가 현재 외형보다 깊은 체질/영적 흔적을 과거 사건과 연결해 실제 신원 가설을 만든다.

`가짜 신원 = 영구 분리`는 `CONTRADICTED`.

## 보여 줄 전력 표본 선택

공개 전투에서 전체 전력 중 일부만 보여 주고 목격자가 그 표본을 전체 전력으로 오판하게 둔다.

은폐가 `안 보여 줌`에서 **무엇을 배우게 할지 선택**으로 확장된다.

## 제도권 가짜 신분

외모뿐 아니라 문서·신분패·법기 외형·대표 술식 억제·사회적 이동 경로를 일관된 인물상으로 묶는다.

적대 조직은 오히려 이 가짜 신분을 실제 주인공 A를 추적할 외부 인재로 오분류한다.

# 3. 121~180화 · 검증은 진실보다 입력 일관성을 확인할 수 있다

## 비공개 탐지 결과의 공개 증거화

실제 탐지법을 숨긴 채 공개 가능한 거짓 규칙을 던지고, 잠입자가 회피/도주하게 해 제3자가 볼 수 있는 적대 증거를 만든다.

결과는 맞아도 정보 원천은 계속 숨는다.

## 공개 프로필이 맞춤 카운터를 유도

적은 가짜 신분의 반복 화염 표본을 학습해 맞춤 봉쇄를 준비한다. 주인공 A는 그 확신을 유지시켜 외부 목격자가 없는 폐쇄 공간을 만들게 하고 숨은 다른 수단을 사용한다.

## 거짓 텔레메트리

조직 감시를 제거하지 않고 감시자가 기대할 수련 데이터 자체를 설계한다.

감시
→ 일관된 가짜 수련 장면
→ 핵심 수련은 다른 공간
→ 조직 검증 성공.

따라서 `검증 통과 = 실제 능력/신원의 진실 검증`은 `CONTRADICTED`.

검증자는 **접근 가능한 입력 데이터의 일관성**을 확인했다.

## 행동 흔적 재연결과 신원 폐기

오래된 적은 얼굴·법술보다 시선·행동 습관·반응 방식의 지속성을 단서로 가짜 신원을 다시 의심한다.

신원 은폐는 무기한 유지가 아니라 수명과 누적 비용이 있는 도구가 된다.

# 4. 231~237화 · 두 독립 팀이 하나의 적으로 압축된다

주인공 측 잠입팀과 별도 잠입팀은 실제로 협의/접선하지 않는다.

그러나:

- 둘 다 신분/외형을 훔쳐 사용
- 비슷한 시기에 내부 혼란 발생
- 적 조직은 외부 관찰로 두 팀을 구분할 충분한 정보가 없음

때문에 **두 독립 행위자를 하나의 적 집단으로 압축**한다.

적의 단일 가설
→ 방어 인력과 지도자의 대응이 잘못된 하나의 위협 모델에 맞춰 이동
→ 두 팀이 실제 협력하지 않아도 서로의 혼란이 상대 팀의 침투 조건을 개선.

중요한 점:

> 정보 은폐는 나를 다른 사람으로 보이게 하는 것뿐 아니라, **서로 다른 사람들을 같은 원인으로 묶게 만드는 것**도 가능하다.

적의 오판은 무지 때문이 아니라 표면 입력의 유사성과 정보 부족에서 나온다.

# 5. 238~240화 · 모사 표면이 실제 원본에게 귀속된다

주인공 A는 상위 존재 A의 형상/힘을 다른 상위 추적자를 자극하는 위장으로 사용한다.

상대 추적자에게는:

`주인공 A가 상위 존재 A의 힘을 대표/모사하는 것처럼 보임`

이라는 표면 정보다.

그러나 실제 상위 존재 A는 그 모사를 **자기 힘 사용의 흔적**으로 감지한다.

즉 하나의 표현이:

- 적에게는 오인 유도용 표면 정보
- 실제 원본에게는 자기 계통/힘 사용을 가리키는 귀속 신호

로 동시에 작동한다.

원본 감지
→ 과거 접촉과 현재 모사를 연결
→ 힘 사용을 채무로 재분류
→ 강제 소환.

`PAY-REF02-0004`로 장기 회수한다.

# 정보층 모델 · 1~240화

1. 표면 감각: 외형·복장·대표 술식.
2. 영기/공법 감각: 기술 출처·영기 근원.
3. 상태/본질 정보: 변신·경지 축소를 관통.
4. 깊은 체질 정보: 오래된 사건과 현재 신원 재연결.
5. 제도권 검증: 문서·신분패·행적·제시된 텔레메트리의 일관성.
6. 행동 흔적: 시선·판단 습관·반응 방식.
7. **집단 원인 모델**: 서로 다른 행위자의 유사 흔적을 하나의 적/사건으로 압축.
8. **원본 귀속층**: 모사한 힘/형상이 실제 원본과 연결될 때 원본이 자기 흔적으로 판정.

어떤 층도 항상 절대적이지 않다.

# 표현 구현

- 오판자의 관찰 근거를 먼저 보여 줘 멍청한 착각으로 만들지 않음.
- 깊은 관찰자 POV를 열어 왜 과거 사건까지 연결하는지 설명.
- 같은 가짜 신분을 후계자·조직·주인공 계획이 서로 다르게 분류하게 함.
- 탐지 원리는 말하지 않고 상대 반응이 공개 증거가 되게 함.
- 조직이 스스로 `검증 성공`이라고 믿게 하되 독자는 거짓 입력을 알고 있음.
- 두 잠입팀에서는 독자가 실제 두 팀을 알고 적만 하나라고 믿어 병력 이동 인과를 이해함.
- 상위 모사에서는 적의 오인 성공 직후 실제 원본의 감지를 붙여 동일 표현의 정보층을 뒤집음.

# 비용과 실패 조건

- 깊은 체질·행동 흔적은 가짜 신원 뒤에도 장기 부채.
- 공개 프로필은 적 맞춤 카운터의 입력.
- 거짓 텔레메트리가 독립 검증과 충돌하면 신원 붕괴 가능.
- 행동 습관은 장기 위장에서 바꾸기 어려움.
- 독립 행위자들을 하나로 묶은 오판은 유리할 수도 있지만, 반대로 자기 행동이 타인의 행위와 묶여 더 큰 적대 책임을 뒤집어쓸 수도 있음.
- 상위 힘 모사는 실제 원본의 추적 좌표·채무 기록이 될 수 있음.

# 반례와 경계

- `활동 신원 = 실제 신원과 영구 분리` — `CONTRADICTED`.
- `제도권 검증 통과 = 핵심 정보 진실 검증` — `CONTRADICTED`.
- 모든 행동 흔적이 신원 재연결로 이어지는 것은 아님.
- 두 잠입팀 오인처럼 **다른 실체를 하나로 합치는 오판**도 존재.
- 모든 초월 힘 모사가 원본에게 감지되는 법칙은 `HOLD`.
- 원본 귀속 감지는 기존 접촉·반복 모사·대규모 공개 사용이 결합된 결과일 수 있음.
