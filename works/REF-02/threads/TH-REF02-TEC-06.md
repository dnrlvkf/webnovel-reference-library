# 적 기술에 당한 경험을 원리·재료 연구로 바꿔 다음 변형의 대응책을 선행 준비한다

## 해결하는 문제

적의 특수 독술·상태 이상이 매번 처음 보는 기믹처럼 등장해 주인공 A가 즉석 기지로만 빠져나가거나, 반대로 한 번 배운 해독법이 모든 독에 통하는 만능 규칙이 되는 문제.

## 작동 사슬

적 기술에 실제로 노출됨
→ 증상·발생 원리·기존 해독 실패 이유 확인
→ 현장에서 최소 해법으로 생존
→ 전투 뒤 적 자료·재료 수집
→ 이론 대조와 직접 실험
→ 변형별 대응 후보 준비
→ 후속 전투에서 다른 계통 기술에 노출
→ 상황에 맞는 특정 대응 수단 선택
→ 효과와 자체 비용 확인
→ 아직 검증 안 된 변형은 미확인으로 유지

## 52화 · 즉석 원리 파훼

결단경 적 A가 영력으로 만들어 낸 조사 계열 독술로 광범위하게 진액을 소실시킨다.

주인공 A는 일반 해독제가 아니라 술식의 이치 자체를 본다.

양명·조의 이치
→ 반대편 태음·습 이치 선택
→ 분산 법기 A에 영력을 실어 광역 술식 안으로 주입
→ 상쇄
→ 충돌 에너지를 뇌기로 재활용

이 단계는 `특정 독을 먹고 해독`이 아니라 적 술식의 원리 파훼다.

## 56화 · 자료와 재료를 챙긴다

적 생산 거점을 파괴하면서 주인공 A는 불태우기 전에 독물 재배 서책과 관심 있는 재료를 챙긴다.

당장 전투에 필요한 전리품보다 **다음 독술 변형을 연구할 자료**를 보존한다.

동료는 이를 공부 열심으로 해석하지만, 실제 기능은 59화에 확인된다.

## 59화 · 다른 육사독의 선행 대응

결단경 중기 적 A가 풍사 계열 독술을 사용한다.

이 독은 52화 조사독과 증상·계통이 다르다. 주인공 A는 특정 독버섯 재료를 즉시 복용하고 영력으로 그 성질을 운용한다.

이후 설명을 통해 52화 이후:

- 육사독 이론 정리
- 재배장 서책 수집
- 독물 재료 수집
- 직접 복용·효과 확인
- 여섯 계통별 대응 후보 준비

를 진행해 왔음이 공개된다.

풍사 대응은 실제 증상 완화로 검증된다.

## 캐릭터 판단

주인공 A는 `한 번 이겼으니 다음에도 즉석으로 풀 수 있다`고 가정하지 않는다.

첫 피격의 비용을 후속 준비 질문으로 바꾼다.

- 같은 조직은 다른 육사독을 쓸 수 있음
- 일반 해독제는 영력으로 만든 독에 부족함
- 현장에서 이론을 새로 세울 시간이 없을 수 있음
- 적의 생산 재료가 독이면서 동시에 대응 약재가 될 수 있음

따라서 승리 뒤 적의 자원과 지식을 다시 연구 대상으로 분해한다.

## 표현·스토리 구현

59화는 연구 과정을 미리 장황하게 보여 주지 않는다.

풍사독 피격
→ 특정 재료 즉시 복용
→ 독자가 `왜 독성 재료를 먹나` 질문
→ 약리 기능 설명
→ 52화 이후의 연구·자기 실험 압축 공개
→ 실제 증상 완화

으로 결과를 먼저 제시한다.

준비의 존재는 후속 사건에서 증명되고, 반복 실험 자체는 압축된다.

## 비용

- 52화 조사독 파훼 전에는 실제 진액 소실을 겪음.
- 연구 재료를 직접 시험하는 과정 자체가 위험함.
- 59화 대응 재료도 정상 정기를 손상시킬 수 있어 영력 운용이 필요함.
- 독 계통별 특효약이 다르므로 한 가지 재료로 모든 육사독을 해결할 수 없음.

## 반례와 적용 한계

- 59화에서 실제 검증된 것은 풍사 대응 하나뿐이다.
- 나머지 육사독 대응 후보가 실제로 모두 통한다는 것은 `HYPOTHESIS`.
- 독이 아닌 저주·신식 공격·혼합 독술에도 같은 연구 방식이 통하는지 미확인.
- 적이 기존 이론과 다른 변종을 사용하면 준비한 대응이 실패할 수 있음.
- 대응 재료의 부작용이 장기 비용으로 나타나는지 미확인.

## 상태 판정

52화에는 첫 육사독을 이치로 직접 파훼하고, 이후 별도 생산 거점에서 자료·재료를 수집한다. 59화에는 다른 육사독에 대해 선행 준비한 특정 대응 재료를 실제로 사용해 증상을 완화한다.

`첫 노출의 비용 → 후속 연구 → 다른 변형에서 준비 효과 검증`이라는 떨어진 작동 사슬이 확인되므로 `VERIFIED_THREAD`로 판정한다. 단, 여섯 계통 전체에 대한 만능 대응으로 넓히지 않는다.

## 다음 질문

61~70화 이후 다른 육사독이 등장할 때 준비한 후보가 실제로 통하는가. 이론과 다른 변종 때문에 실패하는가. 직접 자기 실험의 부작용이나 잘못된 약재 판정 비용이 나타나는가.
