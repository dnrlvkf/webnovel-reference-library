# 241~284화 문체·서술 프로필

## 시점과 서술 초점

기본은 주인공 A에 가까운 3인칭을 유지하지만, 최종부에서는 상대의 오판과 욕망을 보여 줄 필요가 있을 때 짧게 초점을 옮긴다.

핵심은 전지적 설명으로 모든 계획을 미리 밝히지 않는 것이다.

- 주인공의 숨은 전력은 상대가 카운터를 완성한 뒤 공개.
- 숨겨 둔 동료의 성장은 2대1 열세가 제시된 뒤 공개.
- 최종 적의 뿌리 잔존은 인간형 승리 뒤 공개.
- 마지막 비상 능력 조건은 상대의 오래된 독점 욕망이 반응할 때 완성.

정보 공개가 `설명 → 실행`보다 **오판/불리한 판정 → 숨은 조건 공개 → 즉시 결과** 순서로 배치되는 비율이 높다.

## 강제 상황의 감정 제시

상위 존재 A에게 행동권이 봉쇄되는 장면에서 주인공의 감정을 길게 분노로 풀지 않는다.

행동 불가 확인
→ 상대가 부과하는 임무 확인
→ 자기 기존 목표와 겹치는지 계산
→ 활용 가능한 부분을 추림.

감정은 권리·실행 가능성 계산으로 빠르게 변환된다.

이는 `강제 = 곧 충성`이라는 독자 오해를 막는다.

## 대승경 심마 · 감정과 설정을 한 장면에서 묶는다

심마는 추상 독백으로 시작하지 않는다.

평온했던 과거 생활 재현
→ 반복되는 편안함
→ 실제 과거 인물과 맞지 않는 태도 발견
→ 허상 판정
→ `살아간다`의 의미를 자기 존재 방식으로 재정의
→ 승급 구조 설명.

행동·기억 검증이 먼저 오고 철학적 문장이 뒤에 온다.

따라서 장기 캐릭터 기준 갱신이 설교보다 **거짓 장면 판별의 결과**로 나온다.

## 6계위 설명의 위치

새 경지를 숫자 상승으로만 설명하지 않는다.

전투 직전/직후에 다음을 분산해 보여 준다.

- 상위 법칙과 하위 법칙의 관계.
- 접속 유지 시간.
- 영혼 부담.
- 초장거리 작동 범위.
- 결과 관측 해상도.
- 적도 같은 법칙에 개입할 수 있음.

설정은 실제 선택 제약과 함께 배치된다.

`이 힘은 강하다`
보다
`이 힘은 짧고 비싸며, 누구에게 써야 하는가`
를 먼저 체감하게 한다.

## 전투 문장 리듬

최종부 전투는 모든 공격을 길게 묘사하지 않는다.

일반 교환:

감지
→ 짧은 판단
→ 기술
→ 상대 재판정.

6계위 교환:

법칙 선택
→ 유지 가능 시간/자원 계산
→ 발동
→ 상대의 법칙 개입
→ 결과 또는 정보 공백.

특히 초장거리 공격은 결과를 바로 보여 주지 않아 `공격 가능 범위 > 관측 가능 범위`라는 새 전투 감각을 문체로 만든다.

## 강한 힘과 전투 경험 분리

최종 상위자 A는 압도적 힘을 갖지만 실제 근접 생사전 경험은 적다.

포획 강적 A와 주인공 A는:

- 공격 각도 기만
- 희소 자원 소모 유도
- 페이크와 진입 거리
- 몸이 먼저 반응하는 전투 습관

으로 그 격차를 드러낸다.

서술은 `경지가 높으니 모든 판단도 빠르다`로 처리하지 않고, **힘의 격과 전투 의사결정의 숙련을 별도 축으로 묘사**한다.

## 관계 대사의 기능

### 동료

감정 이름보다 역할 약속이 먼저 나온다.

- 성공 확률이 낮아도 같이 갈지.
- 무엇을 맡길지.
- 누가 최종 상대를 맡을지.
- 어떤 힘을 아껴야 할지.

동료 관계는 고백보다 전투 배치와 자원 보존 요구로 증명된다.

### 최종 적

대사는 책임 귀속 경쟁으로 작동한다.

상대: 지금의 나는 네 영향 때문이다.

주인공 A: 내 개입이 네 자유를 좁힌 부분은 인정할 수 있지만, 현재 네 선택까지 내가 한 것은 아니다.

감정 대화가 곧 캐릭터의 책임 기준 검증이 된다.

## 마지막 조건 조립의 문체

세계 파괴수는 일반적인 설득이 통하는 인간형 상태가 아니다.

주인공 A는 장황한 감정 호소 대신 상대에게 오래 남은 한 욕망을 찌른다.

- 독점적 정보.
- 다른 관계자보다 먼저 아는 우선권.

짧은 제안
→ 상대 시선 이동
→ 정체성 접속 확인
→ 비상 능력 발동.

지문은 상대가 왜 그 말에 반응하는지 장황하게 재설명하지 않는다. 이전 관계 축적을 독자가 기억하도록 요구한다.

## 장면 종료

최종 source boundary는 결과 정산이 아니다.

상대의 욕망을 움직여 발동 조건을 만들고 비상 능력을 사용하는 순간에 닫힌다.

그래서 문장 기능은 `모든 문제가 해결됨`이 아니라 **지금까지 가장 오래 숨긴 수단과 관계 약점이 같은 순간 접속됨**을 보여 주는 데 있다.

후속 결과는 원문 경계 밖이므로 연구에서 보충하지 않는다.

## 조건부 변주 정리

- 강제 상황: 감정 → 권리/목표 계산으로 빠르게 전환.
- 심마/내면: 과거 장면 → 불일치 발견 → 직접 기준 언어화.
- 상위 법칙 전투: 위력보다 법칙층·지속·관측·개입을 묘사.
- 조직전: 개인 공격보다 역할·보존 자원·전선 배치 강조.
- 관계 대화: 감정 명칭보다 선택권·책임·역할 협상.
- 최종 조건 조립: 설명보다 오래된 욕망을 짧게 호출하고 행동 결과를 붙임.

## 독자 판단 효과

문체는 최종부에서도 주인공의 강함을 단순 과시하기보다 계속 한계를 만든다.

- 강제당할 수 있음.
- 새 기술도 전투 감각에 막힘.
- 6계위도 시간과 영혼 비용이 있음.
- 초장거리 공격 결과를 모를 수 있음.
- 최종 적을 한 번 쓰러뜨려도 존재가 남을 수 있음.

따라서 상승한 힘과 함께 **새로운 정보·권리·존재론적 불확실성**도 같은 비율로 커진다.
