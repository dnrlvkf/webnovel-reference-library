# 181~240화 문체 · 실패·권리 침해·시간 해상도·감정 수련을 먼저 체감시키고 설명은 뒤에 둔다

## whole-work correction

195~200화의 기존 조직 의무와 기억 강제 추출 당사자는 장기 동업자 A가 아니라 **상위 동행자 A (`REL-REF02-0006`)**다. 해당 장면의 문체 기능은 유지하되 역할 귀속을 교정한다.

## 신념 붕괴

상위 동맹 A의 좋은 의도를 해설로 보호하지 않는다.

장기 기준 설명
→ 현혹이 경쟁 욕망을 키움
→ 실제 배신 욕망과 행동 가능성
→ 자기 붕괴 인식
→ 비가역 자기 비용
→ 약속 복귀.

신뢰는 설명보다 `무너진 뒤 어떤 비용으로 돌아오는가`로 표현된다.

## 관계 의무와 권리 침해

상위 동행자 A는 새 협력 관계가 있어도 원래 조직 은의를 말로 직접 선언한다.

조직 지도자는 `친구를 자기 입으로 배신시키지 않겠다`는 식으로 충성을 존중하는 언어를 쓴 뒤 실제 기억에는 강제로 접근한다.

존중 대사
→ 신체/정보 침해 행동

을 붙여 **말의 도덕성과 실제 권리 행사를 분리**한다.

## 높은 시간 해상도 전투

승급 뒤 이미 날아온 공격은 단순 슬로모션이 아니다.

공격의 구조·방향·속성 분해
→ 각 공격에 필요한 대응을 별도 조립
→ 도착 전 실행.

경지 상승을 숫자보다 `전에는 한 덩어리였던 시간을 더 작은 판단 단위로 읽는다`는 서술 변화로 체감시킨다.

## 법역·강림 반동

강한 상위 심상을 쓴 뒤:

- 손 떨림
- 정신 붕괴 위험
- 약물 회복

을 곧바로 붙인다.

강한 기술의 장관보다 **사용 뒤 연속 행동이 가능한가**를 비용으로 제시한다.

## 무코어 적

본체/코어 탐색을 짧게 실패시키지 않고 장시간 반복한다.

탐색 지속
→ 실패 누적
→ `애초에 코어 없음` 재판정.

설명을 먼저 주지 않아 독자도 기존 공식을 같이 포기하게 만든다.

## 외로움 수련

관계가 깊어져도 모든 것을 공유하거나 영원히 함께 있지 않는다는 사실
→ 비밀·이동권의 한계
→ 외로움 인정
→ 자기 존재의 일부로 수용
→ 새 개념 술식
→ 사용 뒤 피로.

감정을 장식이 아니라 기술 입력으로 쓰되 즉시 무한 보상으로 만들지 않는다.

## 독립 잠입 정보차

주인공 팀, 다른 침투 팀, 적 조직이 서로 다른 정보만 가진 상태를 유지한다.

적은 두 팀을 하나로 오분류하고 주인공은 그 오판만 이용한다.

독자에게 모든 계획을 한 시점에서 설명하지 않고 **각 행위자의 정보 접근권 자체를 장면 구조로 사용**한다.

## 초월 존재와 강제 승급

상대가 너무 커 전체를 한 번에 인식하지 못함
→ 부분 관찰을 조합
→ 행동권 봉쇄
→ 자기 소멸처럼 느끼는 감각
→ 실제 승급 과정으로 재판정
→ 새 법칙을 즉시 시험.

`강하다`는 설명보다 관찰·행동 자체가 실패하는 방식으로 격차를 표현한다.

## whole-work 연결

이 구간의 문체는 반복적으로:

오판/실패/권리 침해를 먼저 체감
→ 주인공/독자의 기존 분류가 흔들림
→ 구조 설명
→ 즉시 다음 행동으로 새 판정 검증

의 순서를 사용한다.

후반 경지가 높아져도 설명이 먼저 정답을 주는 비율보다 **실패를 통해 규칙을 다시 배우게 하는 비율**이 높다.
