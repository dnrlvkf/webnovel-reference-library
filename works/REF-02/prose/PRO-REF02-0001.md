# 설명을 선택·시험·재분류로 닫는 서술 운용

## 적용 조건

새 제도·도시·공법·속성·조직 정보를 독자에게 전달하면서 현재 선택과 긴장을 유지해야 할 때.

## 현재 판정

1~30화의 기본 구조는 `규칙 설명 → 현재 선택 → 즉시 시험 또는 거래 → 상대 재분류 → 새 한계·다음 문제`다. 21~30화에서는 이 구조가 비상 능력의 발동 조건, 전리품 기능 분해, 연단 실습, 비경 금제의 실패, 관계 권리의 확대에 적용된다.

## 시점과 서술 초점

- 기본은 주인공 A의 계산에 밀착한 3인칭이다.
- 조직 추천자, 현장 책임자, 상위 관찰자, 변화 경비자, 마도 잠입자의 내면으로 이동한다.
- 상대 시점은 위협을 과장하기 위한 장식이 아니라 `왜 합리적으로 방심했는가`, `어떤 정보층을 보지 못했는가`, `무슨 욕망 때문에 행동을 늦췄는가`를 제공한다.
- 배신이나 잠입 자체를 오래 감추지 않는다. 긴장은 위치·타이밍·회복률·관찰 수준의 경쟁에서 생긴다.

## 서술 거리와 감정 제시

감정은 짧게 제시된 뒤 권리·자원·위험 계산으로 전환된다. 다만 다음 장면에서는 서술 거리가 잠시 가까워진다.

- 상위 적 제거 뒤 영혼의 피로와 수면 필요
- 비좁은 방에서 느끼는 안전감
- 어린 가족 구성원과 먹거리를 주고받는 생활 감각
- 임대인 A가 인간 희생 연단을 회상하는 장면

이 감정 체류는 독립 감상으로 끝나지 않는다. 휴식 시간, 거주권, 임무 동기, 시설 사용권, 도덕적 경계라는 후속 상태를 만든다.

## 정보 설명 위치

- 비상 능력 제약 설명 뒤 발동 직전 실패 가능성 복기
- 속성 이론 뒤 새 공격 기술과 약초 탐색
- 계약 제도 뒤 보수 정산과 관계 호칭 변화
- 도시 재개발 설명 뒤 보물 탈취 임무의 사적 동기
- 상위 보물 원리 뒤 광역 공격·은폐·연단 화력
- 팔괘 이론 뒤 실제 시연과 단약 제작
- 비경 금제 설명 뒤 경지 축소 술법이라는 실패 사례
- 안전지대 설명 뒤 보호 대상 격리와 봉인

설명은 현재 선택을 바꿀 때 길어지고, 같은 기능을 반복하는 수련·매각·이동은 압축된다.

## 상대 시점의 긴장 설계

### 21화 상위 적

상대는 주인공 A가 마지막 발악을 할 수 있다고 생각해 관찰한다. 위험 직감을 느끼고 영력을 끌어올리지만, 정보를 더 얻고 생포하려는 욕망 때문에 공격으로 전환하지 않는다. 독자는 비상 능력의 존재를 알아도 발동 전 공백 때문에 긴장한다.

### 25화 변화 경비자

상대는 무생물로 변신해 완벽히 숨었다고 믿고, 고문까지 상상한다. 짧은 발동 뒤 탁자가 시체의 원래 모습으로 돌아오는 배열이 정보층 차이를 결과로 보여 준다.

### 29~30화 마도 잠입자

잠입자는 경지를 낮춘 술법이 금제를 속였다고 믿고 경쟁자들을 제거한다. 30화의 상위 적은 죽은 수하보다 주인공 A의 포섭 가치를 높게 평가하며 길게 제안한다. 주인공 A가 그 시간을 회복에 사용했다는 사실은 대화 끝에 공개된다.

## 대사·지문 배열

주인공 A의 짧은 대사는 표면상 공손하거나 건조하지만 실제 의미는 뒤 행동과 권리 변화에서 확정된다.

- 방법 공개 요구에는 비공개로 답함
- 축기 자원 요청은 중개 관계의 다음 권리를 시험함
- 보물 소진 설명은 공식 의뢰 완료와 실제 소유권을 분리함
- 보호 대상에게는 설명 뒤 실제 살해 능력과 봉인으로 통제권을 확정함
- 상위 적의 포섭 대사에는 즉시 반박하지 않고 회복 시간으로 활용함

## 문장·문단 리듬

- 복잡한 설명은 내부 질문과 짧은 판정 문단으로 잘게 나눈다.
- 전투 전에는 감지·욕망·회복률 계산을 확장한다.
- 기술 발동 순간에는 짧은 기술명·결과·상태 변화를 붙인다.
- 승리 뒤에는 전리품을 하나씩 기능별로 해체해 호흡을 다시 늘린다.
- 생활 장면에서는 먹거리·차·방의 크기 같은 감각을 짧게 반복해 관계 변화를 체감시킨다.
- 30화 화말은 상대 80%와 주인공 A 100%의 조건을 정리한 직후 선제 공격으로 닫힌다.

## 관찰자 수준에 따른 정보 기능

- 하위 적은 표면 공법으로 소속을 오분류한다.
- 상위 적은 영기의 근원과 특수 자질을 읽는다.
- 변화 경비자는 외형을 완벽히 바꾸지만 상태 정보에는 본질이 남는다.
- 경지 축소 술법은 영력 탐색과 비경 금제를 속이지만 상태 정보는 실제 경지를 표시한다.
- 의뢰자 A는 연기경이 상위 보물의 기파를 숨길 수 없다고 합리적으로 판단해 거짓 설명을 믿는다.

같은 표현이 누구의 관찰 능력을 통과하느냐에 따라 위장·폭로·오판·안전 판정으로 달라진다.

## 설명과 창안

새 기술은 지식을 떠올렸다는 선언으로 끝나지 않는다.

기존 속성 원리
→ 현재 장비와 체질에 적용
→ 첫 결과의 한계 확인
→ 응축·범위·방향 수정
→ 새 기술명과 실전 사용
→ 영력 소비·회복 비용 확인

연단도 게임의 자동 조작을 그대로 옮기지 않고 실제 시연·팔괘 조절·약재 투입·환기·제환 순서를 거친다.

## 화말 운용

화말은 다음 행동의 시험점을 남긴다. 보스 출현, 축기 자원 요청, 사적 동기가 결합된 임무 수락, 상위 보물 기파, 광역 발동, 마도 세력 추론, 위장 경지 폭로, 자유 전장 선언, 회복률 차이와 선제 공격처럼 현재 판정이 다음 화에서 검증될 위치에서 닫힌다.

## 작동 결과

- 설명이 백과사전이 아니라 선택의 근거가 된다.
- 상대 시점이 악역의 장식이 아니라 오판과 욕망의 인과를 제공한다.
- 생활 장면이 다음 전투의 동기·시설·교육을 만든다.
- 반복 임무를 압축해도 관계·접근권 변화는 선명하게 남는다.
- 주인공의 강함이 단일 능력보다 감지·준비·회복·장비·정보 통제의 결합으로 읽힌다.

## 반례와 미확인

- 정치·조직 설명이 더 커지는 후속 구간에서도 즉시 선택과 시험으로 닫히는지 확인 필요
- 상위 관찰자의 내면 설명이 길어져 긴장이 정지하는 사례 미확인
- 생활 장면이 사건 인프라로 연결되지 않는 순수 휴식 장면의 운용 미확인
- 새 기술 설명이 반복되어 전투 결과보다 공법 강의가 앞서는 실패 사례 미확인
- 30화 화말의 회복률 조건이 실제 승패를 얼마나 정확히 예고하는지 미확인
