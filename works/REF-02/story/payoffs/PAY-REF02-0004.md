# 초반 재회 예고와 힘의 차용이 후반의 실제 채무·강제 소환으로 회수된다

## 원문 재진입

- seed: `85화`의 상위 존재 A 최초 접촉
- reinforcement: `174~175화`의 상위 심상 반복 모사
- payoff: `SC-REF02-0081 / 238~240화`
- identity: sealed

## 초기 배치

주인공 A는 상위 존재 A와 첫 접촉 뒤 그 관계를 좋은 인연으로 보지 않는다. 상대는 이후 다시 만나게 될 방향의 말을 남기고, 주인공 A는 가능하면 그 관심에서 벗어나려 한다.

당시에는 그 말이 실제 구속력을 가진 약속인지, 단순 흥미인지, 위협적 예고인지 확정되지 않는다.

## 중간 누적

후속 성장 과정에서 주인공 A는 상위 존재 A의 힘·형상·심상을 자기 법역과 전술에 여러 번 모사한다.

당장은:

- 더 높은 구조를 재현하는 전투 자원
- 상대 법역을 압도하는 정보 우위
- 다른 초월 존재를 자극하는 위장 수단

으로 기능한다.

이 단계에서는 `모사 = 원본에게 실제로 보이는 신호`라고 확정하지 않는다.

## 회수 조건

238~240화 도주전에서 주인공 A는 더 강한 추적자를 끌어내기 위해 상위 존재 A의 형상·힘을 외부 우주에서 다시 크게 모사한다.

그 결과 실제 상위 존재 A가 이를 감지한다.

상대는 초기 접촉의 말과 이후 힘 사용을:

- 다시 만나기로 한 약속
- 자기 힘을 사용한 채무
- 자기 계통과 연결된 특이한 존재

로 재해석한다.

## 후속 사건

감지
→ 강제 소환
→ 주인공 A의 이탈권 상실
→ 비상 능력 사용 검토
→ 상위 존재가 행동 자체를 봉쇄해 발동 불가
→ 임무 수행 자격을 이유로 강제 승급
→ 새로운 세계 법칙·임무에 편입.

과거에 유용했던 힘의 모사가 **실제 사회적·형이상학적 채무와 권리 침해로 전환**된다.

## 작가의 핵심 선택

상위 힘 모사의 대가를 즉시 체력 소모나 저주로 붙이지 않는다.

초기 애매한 말
→ 수십 화의 유용한 차용
→ 독자가 성장 자산으로 익숙해짐
→ 더 큰 규모의 공개 모사
→ 원본 감지
→ 과거 말의 관계 의미 재해석
→ 강제 소환·승급·임무.

긴 지연 뒤 **기술 사용의 비용을 관계 권리 문제로 회수**한다.

## 독자 판정 변화

초기: 피해야 할 멀리 있는 상위 관심.

중간: 주인공 A가 독립적으로 이용하는 강력한 기술 자료.

회수 뒤: 과거 기술 자산이 사실 **추적 좌표·채무 기록·강제 관계의 씨앗**이기도 했음.

## 상태 변화

- 주인공 A: 상위 힘의 독립 모사자 → 원본이 실제 권리를 주장하는 채무/임무 대상.
- 상위 존재 A: 멀리 있는 위험 원천 → 직접 소환·승급·명령권을 행사하는 관계 행위자.
- 비상 능력: 최후 대응 후보 → 사용자의 행동 자체가 봉쇄되면 발동할 수 없는 경계 확인.
- 성장: 자율적 승급 계획 → 외부 상위자가 강제로 다음 경지에 밀어 넣는 사건.

## 비용과 경계

- 모든 기술 모사가 원본에게 감지된다는 법칙은 확정하지 않는다.
- 기존 접촉·반복 모사·공개 우주의 대규모 재현이 결합된 결과일 수 있다.
- 상위 존재 A가 주장하는 `약속`과 `채무`의 객관적 계약 정당성은 별개다.
- 강제 승급은 전력 상승이지만 선택권 침해와 새 임무 비용을 동시에 가진다.

## 원문을 다시 읽어야 하는 이유

85화만 보면 장기 회수인지 불명확하고, 238~240화만 보면 강제 소환이 갑작스러운 개입처럼 보인다.

세 구간을 왕복해야:

1. 주인공 A가 처음부터 그 인연을 꺼렸다는 점,
2. 그럼에도 힘 구조는 반복 이용했다는 점,
3. 모사의 규모·장소가 달라진 뒤 실제 원본이 반응했다는 점,
4. 초기의 애매한 재회 말이 상대 시점에서는 약속으로 재분류된다는 점

을 복원할 수 있다.

## 향후 검색할 집필 상황

- 강력한 외부 힘을 빌리거나 모사하는 성장에 장기 비용을 붙일 때
- 초반의 애매한 위협/약속을 수백 화 뒤 관계 권리로 회수할 때
- 기술 사용 대가를 자원 소모가 아니라 추적·채무·소속 문제로 바꿀 때
- 과거 보상이 훗날 더 큰 선택권 침해의 원인이 되게 할 때
