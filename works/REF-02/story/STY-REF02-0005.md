# 61~120화 · 보상 기능을 다음 아크의 결핍으로 재배치하고 상호 오해를 침투 경로로 만든다

## 현재 판정

61~120화는 전쟁 승리·상계 힘·결단이라는 대형 보상을 닫힌 성취로 처리하지 않는다. 각 보상은 곧바로 새로운 사용 조건과 결핍을 만든다.

- 전쟁 승리 → 상위 포식자와 원영경 단계의 위협
- 오행 법보 → 육체가 다속성 운용을 견디지 못하는 문제
- 상계 힘 → 몸에서 쓸 수 있는 수련법 부족
- 연체공법 → 결단 자원 확보를 위한 다음 적대 조직과의 충돌
- 결단 성공 → 개인 산수로 감당하기 어려운 자원 규모
- 가짜 신분 → 상위 조직 검증과 정체 노출 위험

## 목표 배열

전쟁 결산
→ 상위 포식자 제거
→ 오행/생산 기반 확장
→ 동업자 A 추적
→ 위험 상계 유물 분쟁
→ 원영경 후기 조건부 제거
→ 상계 힘 분리 저장
→ 연체공법 확보
→ 결단 자원 갈등 의도적 선택
→ 우호 조직의 비밀 부담 해결
→ 극음·극양 자원 확보
→ 결단
→ 적 수장 B 제거
→ 귀수성 이탈
→ 대륙 환란 정보 확인
→ 제도권 가짜 신분 B 구축
→ 상위 후계자 A 접근
→ 상위 조직 A의 고용/초빙 경로 유도

## 장면화와 압축

### 상세 장면화

- 61~65화: 전쟁 마무리와 상위 포식자 제거
- 73~83화: 위험 유물, 파훼→재현→개량, 원영 후기 시간층
- 84화: 상계 힘을 통합하지 못하고 별도 저장하는 선택
- 89화: 같은 위험 행동의 판단 근거를 두 인물로 대비
- 101~107화: 적 방어 진단·상위 관찰자 B의 선택·극양 자원 확보
- 108~112화: 결단 의식과 결단 직후 전투 시험
- 117~120화: 상위 후계자 A 접촉과 상호 역이용 계획

### 압축

- 생산 기반 정착과 반복 재배
- 수련 비급의 반복 연습
- 소규모 의뢰 누적
- 이동과 준비 기간
- 가짜 신분 준비의 행정 절차 중 기능 변화가 없는 부분

반복 훈련은 압축하고, **수련법이 실제로 이전 실패를 해결하는 첫 장면**을 다시 상세화한다.

## 실제 사건 순서와 제시 순서

### 61~65화 · 상위 포식자의 법보를 먼저 꺼내게 한다

실제 계획은 상위 포식자 A를 제거하는 것뿐 아니라 법보를 안전하게 회수하는 것까지 포함한다. 그러나 장면에서는 상대가 법보를 꺼낼 때까지 주인공 A가 제거 수단을 보류해 목적이 행동 순서로 드러난다.

결과적으로 독자는 `위협 제거`가 아니라 `위협 제거 + 자원 회수 조건 조립`이었다고 재판정한다.

### 82~83화 · 비상 능력의 실패를 먼저 믿게 한다

원영경 후기 상위자 A의 시간 우위를 충분히 보여 주어 기존 비상 능력이 사실상 막힌 것으로 보이게 한다. 이후 상대가 다른 목적 때문에 스스로 행동 층위를 낮추는 순간에만 제거가 가능해진다.

기존 가설 `높은 경지라서 안 됨`을 `현재 시간/행동 조건 때문에 안 됨`으로 재판정시킨다.

### 101~104화 · 실패 공격을 진단으로 재해석한다

자동 방어에 여러 공격이 막힌다. 상대는 주인공 A의 공격이 무효라고 판단하지만, 후속 장면에서 주인공 A는 속성별 반응과 흐름을 읽고 있었다는 사실이 드러난다.

실패처럼 보인 공격
→ 구조 정보 축적
→ 타 분야 압축 원리 합성
→ 방어 표면을 관통하지 않고 순환 자체 절단

으로 사건 의미가 바뀐다.

### 105~107화 · 적 조직 내부 판단 차이를 먼저 보여 준다

적 수장 A는 주인공 A를 자기 아래로 굴복시킬 수 있다고 믿는다. 상위 관찰자 B는 깊은 정보를 보고 오히려 위험하다고 판단한다.

독자는 두 판단을 모두 본 뒤 상위 관찰자 B가 명령을 어기고 먼저 움직이는 이유를 `배신`이 아니라 보호 의무로 이해한다.

### 117~120화 · 동일 접촉을 세 번 재판정한다

1. 주인공 A와 상위 후계자 A: 독립 고수와 상위자의 우연한 협업처럼 보임.
2. 상위 후계자 A와 조직: 후계자가 가짜 신분 B를 주인공 A 추적에 적합한 인재로 추천함.
3. 주인공 A의 내면: 바로 그 고용·초빙 경로를 이용하려고 처음부터 특정 이동편을 골랐음.

상호 오해가 사건의 실패가 아니라 **침투 인프라**가 된다.

## 독자와 인물의 정보 차이

- 동업자 A의 장기 목표: 주인공 A도 전부 알지 못함. 독자 역시 제한된 상태로 유지.
- 105~107화: 독자는 적 수장 A보다 상위 관찰자 B의 위험 판단을 더 먼저 알게 됨.
- 117~120화: 상위 후계자 A와 부친은 가짜 신분 B가 누구인지 모르고, 주인공 A는 두 사람의 성향과 미래 경로를 더 많이 앎.
- 120화 말: 상위 조직 간부는 자기가 상대를 읽는다고 생각하지만 감각 시도가 역으로 파괴됨.

## 장기 Payoff

### 생산망 유격전 → 61화 수장 약화

51~60화의 반복 생산 거점 파괴와 핵심 인력 제거가 61화 현재 수장 A의 장기전·전력 운용 부담으로 회수된다.

### 초기 깊은 체질 흔적 → 106화 재연결

오래된 사건의 깊은 정보는 여러 활동 신원과 외형 변경 뒤에도 남아 있다. 상위 관찰자 B가 이를 읽고 현재 주인공 A를 초기 사건과 연결한다.

### 몸 수련 → 고속 이동술 실전 운용

91~93화 새 이동술은 신체를 심하게 손상시킨다. 98화 이후 연체 수련이 실제로 진행되고, 101~104화에는 같은 계열 고속 움직임을 전투 자원으로 안정적으로 쓴다.

### 극음·극양 자원 → 태극 결단

95~107화에 별도 사건으로 획득한 두 극단 자원이 108~112화에서 음양 통합과 새로운 순음·순양 술식으로 회수된다.

## 보상 뒤의 다음 문제

- 상위 법보 → 다속성 가능 / 신체 적응 문제
- 상계 에너지 → 새로운 힘 / 상계 존재 관심과 사용법 부족
- 연체공법 → 몸 강화 / 수련 시간과 별도 역할 분담 필요
- 우호 조직 접근권 → 결단 자원 / 조직 비밀과 미래 관계 의무
- 결단 → 압도적 전력 / 더 비싼 성장 자원과 상위 조직 필요
- 가짜 신분 → 제도권 접근 / 깊은 감지·조직 검증 위험

## 화말 동력

적응형 대구간에서 화말은 같은 패턴으로만 반복되지 않는다.

- 새로운 상위 위협 등장
- 기존 능력의 상한 발견
- 위험한 힘의 사용법 질문
- 다음 성장 자원의 위치 확정
- 관계 상대의 비공개 목적
- 제도권 가짜 신분이 실제 검증을 받는 순간

120화는 가짜 신분 B의 감각 방어가 상위 조직 간부의 첫 검증을 역으로 파괴하는 순간에 닫혀 다음 배치의 `검증/초빙` 사건을 연다.

## 후속 재판정 후보

- 상위 후계자 A에게 심은 자유 욕망이 주인공 A에게 유리한지 역위험인지.
- 가짜 신분 B가 정식 조직 자원에 접근한 뒤 활동 신원 A와 동일한 장기 추적 부채를 만드는지.
- 결단경의 새 힘이 원영경 단계에서 다시 한계를 만나는 방식.
- 동업자·검증 동료와의 장거리 관계가 부재 중 어떤 행동을 낳는지.
