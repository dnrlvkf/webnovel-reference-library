# 내부 검증의 오해를 키워 침투하고, 관계 오독·승리 후 잔존 위협을 다음 사건으로 전환하는 121~180화 배열

## 현재 판정

121~180화는 `검증 통과 → 안전`, `강적 격파 → 전투 종료`, `관계 심화 → 진실 공개` 같은 닫힌 보상을 반복해서 열어 버린다.

검증 성공은 더 깊은 오해와 접근권을 만들고, 육신 승리는 영혼 도주 문제를 열며, 관계 심화는 비밀을 없애는 대신 **더 큰 책임을 맡겨도 비밀권이 유지되는가**를 시험한다.

# 1. 121~126화 · 비공개 사실을 공개 증거로 바꾸되 정보 출처는 남기지 않는다

실제 사건 순서:

주인공 A가 깊은 탐지로 잠입자를 이미 식별
→ 조직과 주변인은 그 탐지법을 모름
→ 주인공 A가 거짓 공개 검증 규칙을 제시
→ 실제 잠입자가 회피·도주
→ 주변인이 적대성을 직접 확인
→ 주인공 A는 실제 탐지법을 공개하지 않은 채 제거

제시 방식은 `주인공이 정답을 말한다`보다 **상대의 반응을 다음 정보 공개 단계로 사용**한다.

독자와 제3자는 최종 적대 사실을 공유하지만, 그 사실을 처음 알아낸 원천은 계속 비대칭으로 남는다.

# 2. 127~132화 · 감사와 안전을 분리하고 감시 성공 자체를 거짓으로 만든다

상위 적 제거 뒤 조직 A의 감사·보상은 실제다. 그러나 곧 감시 가능한 안전 공간이 붙는다.

작가는 감사를 곧바로 배신으로 부정하지 않는다.

현재 감사
→ 보호 자원
→ 감시 장치
→ 주인공 A가 감시를 예상
→ 거짓 수련 텔레메트리
→ 조직 내부 검증 성공

으로 배열한다.

따라서 독자는 `감사가 가짜였다`가 아니라 **진심과 권리 구조는 별개**라는 쪽으로 재판정한다.

# 3. 133~149화 · 잘못된 관계 해석을 실제 상태 변화에 사용한다

상위 후계자 A는 주인공 A의 전술적 행동을 자기희생으로 해석한다. 이 해석은 실제 의도와 다르다.

그러나 작가는 바로 정정하지 않는다.

전술 행동
→ 후계자 A의 자기희생 오독
→ 분노·보호 우선순위 상승
→ 비밀을 알고 싶은 욕망
→ 실제로는 거리를 두어 수련 비밀권 존중
→ 후속 정치 사건에서 더 큰 관계 선택

잘못된 해석이 **사실을 바꾸지는 않지만 관계 상태를 바꿀 수 있다**는 점이 핵심이다.

# 4. 영향은 명령이 아니라 독립 선택으로 회수한다

주인공 A는 정치 후보 A에게 자기 이익과 자기 삶을 기준으로 조직을 판단하라는 짧은 질문을 남긴다.

후속에서:

주인공 A 부재
→ 조직이 정치 후보 A에게 꼭두각시가 되는 선택 요구
→ 정치 후보 A가 스스로 통제 수단 거부
→ 기존 지배자를 죽이는 명령도 거절
→ 그 뒤에야 주인공 A가 도착해 결과를 보호

이다.

주인공 A가 옆에서 명령을 반복하지 않은 채 선택이 발생해 `말 → 복종`이 아니라 `질문 → 자기 판단`임을 보존한다.

`PAY-REF02-0003`으로 연결한다.

# 5. 가짜 신분 아크는 성공이 아니라 폐기 가능성까지 포함한다

가짜 신분 B는 조직 내부 접근·보상·정보를 얻는 데 성공한다.

그러나 오래된 적은 얼굴이 아니라 시선·행동 흔적을 통해 다시 인물을 연결한다. 관계·정치 비용도 누적된다.

따라서 스토리는 가짜 신분을 영구 해결책으로 고정하지 않는다.

침투 성공
→ 공개 프로필이 적에게 학습됨
→ 관계·정치적 흔적 누적
→ 행동 특징으로 재연결 가능성
→ 목적 달성 뒤 신분 폐기

위협은 지우는 것이 아니라 **층을 분산하고 수명이 다하면 버리는 자원**으로 제시된다.

# 6. 150~156화 · 복수의 전투 보상보다 숨은 자원의 노출 시점을 먼저 설계한다

위험한 상위 동행자 A의 복수 대상은 고급 자원과 특수 전함을 가진다.

주인공 A는 승리 가능성이 생겼다고 바로 전투를 끝내지 않는다.

상대가 숨은 핵심 자원을 꺼냄
→ 그 자원이 접근 가능한 상태가 됨
→ 육신 승리
→ 영혼 분열 도주
→ 비상 능력으로 비가역 종결
→ 유해·보상 정산

`언제 이길 수 있는가`보다 **언제 이겨야 원하는 상태가 남는가**가 사건 배열을 결정한다.

# 7. 157~169화 · 개인 관계망을 연합 인프라로 확대하되 동기를 통일하지 않는다

옛 거점 피해 뒤 여러 세력이 모인다. 작가는 모두에게 같은 정의·우정을 부여하지 않는다.

각 세력의 동기를 따로 보여 준 채:

- 보증
- 정보
- 보수
- 연구 자원
- 정치 이익
- 개인 복수

가 같은 전투 목표 위에 잠시 겹친다.

이 때문에 연합은 감정적 단일체가 아니라 **권리·이익의 교집합**으로 읽힌다.

# 8. 승리의 완료 지점을 `육신 → 영혼`으로 뒤로 민다

후반 상위 전투에서 같은 리듬이 반복된다.

육신 제압
→ 영혼/원영 도주
→ 퇴로에 대기한 종결 수단
→ 영혼 제거

150~156, 165~169, 170~177, 180화에서 다른 조합으로 반복된다.

독자는 육신이 무너진 순간에도 전투 종료를 확신할 수 없게 된다.

이는 `TH-REF02-TEC-08`과 연결된다.

# 9. 165~169화 · 공평한 보상을 `누가 덜 받는가`가 아니라 전체 관계 비용으로 재배열

전리품 정산에서 한 세력이 명분상 받지 않으려 한다.

그 선택을 그대로 미덕으로 닫지 않고:

한 세력의 무보수
→ 다른 세력만 가져감
→ 다른 세력이 탐욕스럽게 보이는 평판 비용
→ 보상 형식 재협상

으로 확장한다.

공평성은 개인 도덕의 크기가 아니라 **함께 싸운 사람들의 해석 권리**까지 포함한다.

# 10. 170~177화 · `빈 법역`을 세 단계로 재분류한다

독자 초기 정보:

- 주인공 A의 법역은 비어 있음

상대 판정:

- 미완성
- 상상력 부족

주인공 A의 재정의:

- 아직 하나의 세계에 할당되지 않은 플랫폼

즉시 검증:

- 직접 기억한 상계 심상 투사
- 상대의 열화 모방 심상 압도

`약해 보임 → 말로 반박 → 승리`가 아니라 **상대 분류 → 구조 정의 → 상태 변화로 증명**한다.

`MAC-REF02-0004`로 재독한다.

# 11. 관계 미스터리는 주인공의 정보 능력이 높아진 뒤에만 일부 해제한다

장기 동업자 A는 초반부터 비밀이 많았다. 178화 전후에야 과거 상태와 장기 목표 일부가 직접 공개된다.

그 전제는:

- 주인공 A가 원영경에 올라 더 깊게 감지할 수 있게 됨
- 상대에게 실제 상위 승급 책임을 맡겼음
- 둘의 다음 공동 목표가 상계로 확대됨

이다.

즉 정보 공개량은 단순 친밀도보다 **현재 공동 위험과 판단 필요성**에 맞춰 늦춰진다.

그리고 공개 뒤에도 모든 이유를 설명하지 않는다.

# 12. 화말과 다음 동력

- 내부 임무 성공 → 더 큰 정치 사건
- 정치 균열 → 상위 후계자 A의 자율성·추적
- 가짜 신분 폐기 → 실제 신원 이동
- 복수 성공 → 상위 동행자 A의 원조
- 옛 거점 귀환 → 상위 세력 신체 강탈 전쟁
- 기지 승리 → 원영경 승급
- 원영경 승리 → 숨어 있던 상위 포식자
- 관계 비밀 일부 공개 → 상계 공동 목표
- 180화 상층부 진입 → 새 층의 포식 규칙

보상은 다음 층의 조건을 여는 방식으로 종료된다.

# 후반 재판정 후보

- 상위 후계자 A의 자율성 선택이 다시 주인공 A와 교차하면 133~149화 관계 오독의 장기 의미가 바뀔 수 있음.
- 정치 후보 A의 독립 선택이 국가 운영 실패/성공으로 이어지면 `PAY-REF02-0003`의 효과 재판정 필요.
- 빈 법역 플랫폼이 서로 충돌하는 심상 때문에 실패하면 `MAC-REF02-0004`와 `TEC-07`의 확장성 비용이 생김.
- 장기 동업자 A의 상계 목적이 주인공 A의 생존 목표와 충돌하면 178화 비밀권 합의가 비용으로 돌아올 수 있음.

# 다음 질문

181~240화에서 새 상층부가 어떤 정보·법칙·관계 비용을 요구하며, 121~180화에서 얻은 원영경·법역·연합 관계가 반복 성공이 아니라 실패·반례를 얻는가.
