# 승리·은폐·성장 보상을 즉시 다음 비용으로 뒤집는 41~50화 배열

## 현재 판정

41~50화는 장기 보상을 닫힌 보상으로 두지 않는다. 외부 적 승리 뒤 내부 포식, 공로 은폐 뒤 소문, 희귀 영물 획득 뒤 가명 추적, 축기 성공 뒤 기존 성장법 가치 하락, 제도권 접근 뒤 약탈을 연속 배치한다.

## 실제 사건 순서와 제시 순서

### 41~42화 · 승리 뒤 내부 포식

실제 사건은 상위 적 A 제거 → 영력 고갈 → 상위 협력자 A의 포식 선택 → 비상 능력 반격 → 사망 원인 위장이다.

제시 순서는 상위 적의 마지막 술식과 새 뇌법 창안 → 영력 고갈 → 상위 협력자의 내면 욕망 공개 → 주인공 A의 일상적 보수 질문 → 공격 → 비상 능력 → 주인공 A가 이미 의도를 예상했다는 사후 설명이다.

독자 정보가 `배신을 먼저 안다 → 주인공은 모를 수 있다고 본다 → 주인공도 알고 있었다`로 두 번 재판정된다.

### 43화 · 은폐 뒤 소문

사망 원인을 조작했지만 생존자와 소문은 주인공 A가 실제 승리자일 수 있다는 가설을 만든다. 정보 은폐의 성공과 사회적 추론의 실패를 바로 붙여 주거·얼굴 노출을 다음 문제로 만든다.

### 44~46화 · 공식 실패를 잠입 인프라로 전환

공식 탈환대의 출발과 고전을 먼저 장면화한다. 주인공 A는 참가자가 아니라 관찰자로 남아 방어 장치·적 시선·소모 상태를 얻은 뒤 별도 신원으로 개입한다.

원영경 상위자 A의 공개 저주를 먼저 크게 제시하고, 다음에 주인공 A가 그 추적이 활동 신원 A를 향하도록 설계했다는 계산을 붙인다. 위협은 사라지지 않고 방향만 바뀐다.

### 46~48화 · 장기 성장 보상과 새 결핍

축기단 제작과 축기 의식은 이전 수십 화의 자원 수집을 긴 장면으로 회수한다. 48화 첫 실전은 새 경지의 성능을 검증하지만, 바로 저순도 영기 흡수의 효율 저하를 보여 준다.

`축기 성공 → 이전 성장법 가치 하락 → 고순도 단약 필요 → 중층부 접근`으로 목표가 이동한다.

### 48~50화 · 신뢰 경로와 약탈 경로의 중첩

중개자 A의 소개 → 행동대장 A의 인정 → 임시 출입패 → 경매라는 제도적 신뢰 경로가 열린다. 같은 공간에서 계층 편견·낙찰자 암살·추적 약탈이 발생한다.

중층부는 더 안전한 문명권이 아니라 **절차적 보호와 사적 약탈이 동시에 존재하는 층**으로 제시된다.

## 장면화·압축·생략

- 상위 적의 마지막 술식·새 뇌법 창안·축기 의식·첫 중층부 경매는 상세 장면화
- 한 달간의 연단 시간과 반복 수련은 압축
- 공식 탈환대의 전투는 주인공 A에게 필요한 방어 구조가 드러나는 부분만 선택적으로 보여 줌
- 관계 감정은 설명보다 대사 교환과 작별 행동을 장면화
- 50화의 선행 함정 계획은 공격 뒤까지 생략했다가 공개

## 목표 전환

법역 생환
→ 내부 포식에서 살아남기
→ 공로·거처 노출 관리
→ 마지막 축기 기반 영물 확보
→ 활동 신원 분리
→ 축기단 제작과 축기
→ 고순도 성장 자원 확보
→ 중층부 경매 접근
→ 숨은 법기 확보
→ 추가 약탈자 대응

## 독자와 인물의 정보 차이

- 42화: 독자는 상위 협력자의 포식 욕망을 주인공 A의 대응 전 먼저 앎.
- 48화: 중개자 A의 내면은 독자에게도 차단되어 걱정의 성격을 확정할 수 없음.
- 50화: 주인공 A의 독 대비·고립 유인 계획은 독자에게도 공격 뒤 늦게 공개됨.

같은 구간 안에서 POV 전환, 비전환, 주인공 정보 지연을 각각 다른 기능으로 사용한다.

## 보상 뒤의 다음 문제

- 상위 적 승리 → 영력 고갈 / 내부 포식
- 내부 포식 제거 → 비밀 공간 / 공로 소문
- 비밀 공간 → 안전 / 기존 관계 종료
- 희귀 영물 획득 → 축기 가능 / 가명 추적
- 축기 → 전투력 상승 / 저순도 성장법 가치 하락
- 중층부 접근 → 고급 자원 / 계층 편견·약탈
- 숨은 법기 낙찰 → 새 전력 / 추가 추적자 발생

## 화말 연결

화말은 승리 자체보다 다음 시험 조건에 붙는다. 영력 고갈 뒤 접근하는 협력자, 공개 추적 선언, 축기 돌입, 고순도 자원 필요, 숨은 법기 낙찰 경쟁, 추가 약탈자의 추적이 다음 회차 동력이다.

## 후반 재판정 후보

- 활동 신원 A가 실제 신원과 연결되면 44~46화의 은폐 성공이 장기 비용으로 재판정될 수 있음.
- 중개자 A의 비공식 의무가 실제 위험 부담으로 이어지면 48~49화 관계 장면의 의미가 확대될 수 있음.
- `상대가 먼저 공격하도록 기다린다`는 전략이 실패하거나 도덕적 비용을 만들면 50화의 정당방위 배열이 재판정될 수 있음.

## 다음 질문

51~60화에서 숨은 법기의 첫 성능을 어떤 순서로 공개하며, 중층부 약탈·제도적 판정·가명 추적 중 어느 문제가 다음 장기 아크의 중심으로 이동하는가.
