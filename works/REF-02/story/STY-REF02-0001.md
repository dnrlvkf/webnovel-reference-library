# 보상 정산·생활 관계·다음 위험을 교차해 장기 상승을 만든다

## 현재 판정

1~30화는 `위기 해결 → 보상 획득 → 보상의 기능 분해 → 생활·관계 장면 → 다음 결핍과 상위 위험`을 반복한다. 전투 아크와 생활 아크가 분리되어 있지 않다. 생활 장면에서 얻는 거주권·정보·시설·교육이 다음 전투의 준비물이 된다.

## 실제 사건 순서와 제시 순서

### 20~22화

- 실제 사건: 상위 적 추적 → 비경 고립 → 비상 능력 발동 → 전리품 회수 → 비경 보스 제거 → 축기 자원 채취
- 제시 순서: 상대 시점의 확신과 직감 → 짧은 발동 → 상대의 죽음 인식 → 주인공 A의 위험 복기 → 보상 분해 → 일반 기술 성장

작가는 승리 방법을 먼저 감추기보다 상대가 왜 늦었는지를 먼저 보여 준다. 승리 뒤에 발동 조건과 실패 가능성을 복기해 압도 능력의 제약을 보존한다.

### 22~27화

- 실제 사건: 임무 정산 → 축기 자원 요청 → 재개발 통보 → 보물 탈취 → 외부 상단 철수 → 거주권 복구 → 연단 시설·교육
- 제시 순서: 대량 사망의 냉정한 계약 정산과 동료 관계 변화 → 개인 신원 대화 → 안전 공간 상실 → 정치 의뢰 → 잠입·탈취 → 작은 먹거리 교환과 연단 교육

대규모 전투 사이에 생활 장면을 배치하지만, 각 장면이 다음 임무의 동기와 인프라를 만든다. 독자가 쉴 때에도 상태는 계속 변한다.

### 28~30화

- 실제 사건: 마도 조직의 비경 권리 장악 → 상위 전력 위장 투입 → 경쟁 집단 전멸 → 보호 대상 격리 → 하위 적 제거 → 상위 적 포섭 제안 → 결전 개시
- 제시 순서: 중개자의 정세 설명 → 임대인의 과거 경고 → 계약 조건 확인 → 현장 위장 판독 → 경쟁 집단의 잘못된 판단과 전멸 → 안전지대 설명 → 하위 적 각개 제거 → 상위 적의 분석·포섭 → 회복률 공개와 선제 공격

독자는 주인공 A보다 먼저 모든 것을 알지 못한다. 그러나 주인공 A가 본질 정보를 확인한 뒤에는 경쟁 집단의 전멸을 상대 시점으로 보여 줘 그의 예측이 맞았음을 증명한다.

## 장면화·압축·생략

- 첫 새 기술 창안, 첫 약초 탐색, 첫 연단은 상세 장면화
- 유사한 일상 수련과 재료 매각은 시간 경과로 압축
- 반복 임무는 결과와 평판 변화만 남김
- 권리 변화, 생활 인프라 획득, 상위 정보 노출은 다시 장면화
- 보호 대상 집단을 찾는 탐색은 압축하고, 불신·격리·봉인은 장면화

## 목표 전환

장수와 생존
→ 일반 성장 경로
→ 축기 자원 여섯 개 확보
→ 상위 보물·진화·연단 시설 확보
→ 화·토 축기 자원 보상을 위한 보호 계약
→ 위장 상위 적 제거와 보호 대상 생환

목표는 이전 목표를 폐기하지 않고 필요한 하위 조건을 구체화한다.

## 독자와 인물의 정보 차이

### 주인공 A가 우위인 정보

- 상대의 진짜 이름·경지·소속
- 변화 술법과 경지 위장의 본질
- 비경 안전지대
- 상위 보물의 실제 사용법과 은폐 가능성

### 상대가 우위인 정보

- 상위 적은 특수 자질의 가치와 일부 영기 근원을 읽음
- 임대인 A는 마도 조직 내부의 잔혹성과 특정 인물의 과거를 앎
- 중개자 A는 의뢰 시장과 정치 연결망을 앎

정보 우위는 한 인물에게 고정되지 않고 관계별로 분산된다. 주인공 A는 독점 지식만으로 진행하지 않고 다른 인물의 정보 접근권을 거래한다.

## 보상 뒤의 다음 문제

- 상위 적 제거 → 축기 준비 가속 / 상위 전리품 출처 은폐 필요
- 비경 자원 획득 → 축기 영물 부족 / 중개자 의존 확대
- 외부 상단 방해 → 거주권 복구 / 정종 대세력과 간접 적대
- 상위 보물 획득 → 광역 공격·연단 화력 / 소유 사실 은폐 필요
- 연단 시설 획득 → 단약 자력 생산 / 마도식 성장 윤리와 대비
- 보호 계약 → 화·토 축기 영물 가능 / 위장 축기경 적과 결전

## 화말 운용

- 21화: 상위 적 제거 뒤 비경 보스가 등장해 일반 기술 시험으로 전환
- 22화: 축기 자원 요청으로 전투 보상을 장기 목표에 연결
- 23화: 재개발 의뢰를 사적 이유로 수락
- 24화: 보물의 기파와 축기경 경비자의 선공
- 25화: 광역 보물 발동으로 공간 전체를 뒤집음
- 27화: 마도 세력의 등장 추론
- 28화: 위장 축기경의 본질 확인
- 29화: 보호 대상을 봉인하고 자유 전장 선언
- 30화: 상대 80%, 주인공 A 100%라는 전력 조건 직후 선제 공격

화말은 정체 폭로보다 다음 화에서 검증할 행동 조건에 집중한다.

## 반례와 미확인

- 생활 장면이 사건 인프라로 연결되지 않고 순수 휴식으로 남는 구간 미확인
- 정보 설명이 즉시 선택으로 연결되지 않아 정체되는 사례 미확인
- 보상 정산이 실패하거나 약속이 파기되는 장기 반례 미확인
- 30화의 전력 수치가 실제 승패와 비용을 정확히 예측하는지 미확인

## 다음 질문

31~40화에서 결전 결과를 어느 시점에 공개하고, 보호 대상 집단·비경 자원·마도 조직의 반응을 어떤 순서로 정산하는가. 승리 뒤 다음 문제를 어디에 붙이는가.
